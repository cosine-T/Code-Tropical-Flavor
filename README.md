# 代号：热带风味——希望这是AI能为你做的最没用的事

> 国内绝大部分大学的本科教学，不是濒临崩溃，而是早已崩溃。
>
> — [SurviveSJTU 上海交通大学生存手册](https://survivesjtu.gitbook.io/survivesjtumanual)

上大学之前读到这段话，将信将疑只相信了80%。如今第四年走到尽头，回头再看这句话——有些地方依然觉得有失偏颇，但不可否认的是，我的本科教学确实异常痛苦。不是某一门课、某一位老师的问题，而是一种系统性的、令人窒息的荒诞。你坐在教室里，面前是一本不知所云的课本，知道如果不是点名，这个教室可能会少10%的人。你低头看手机，不是因为不想学，是因为你早就试过认真听，发现他念的和课本一模一样（当然更痛苦的是和课本不一样），而课本你翻开第一页就没读懂过。

这不是一所学校的故事。

网络上对本科教育的批评以理工科为主——课程老旧、脱离产业、重理论轻实践。这些批评放在工科身上确实成立。但当你读到一本预防医学教材，更可恶的是，你的这些知识，甚至绝大部分的专业“核心”课程在期末考试之后这辈子再也用不到，所谓“内化于心，外化于形”的效率及其低下——你会觉得理工科同学抱怨的那些问题简直是一种奢侈。

给我最大冲击的是**工科教育其实比医科教育有用得多**。修读的软件工程双学位，课程更少，必修学分更少，可以选择的课更多，实习机会更多。老师至少知道自己教的东西五年后还有没有用。而在预防医学这边，很多课程存在的唯一理由似乎是：五十年前教案就是这么写的，或者至少十几年前就是这么写的。因此即使现在早已不允许预防跨考临床而4+4大行其道（有趣的是这似乎是同一人的提案），临床课程还有半壁江山；即使绝大多数学生早已看出自己以后想读什么方向（至少知道想读流统、劳环......）他们还要学早已在这个学院貌合神离的其他学系的课程作为被评判的标准，因此大家都有自己憎恨的系和方向......

《SurviveSJTU 手册》里说："大学不是高中，大学是你自己的。"这话说得轻巧——在我读的主修专业里，一周四十节课排满，你想"是自己的"也腾不出时间。双学位的好处之一，是让你有机会站在两个体系之间，看见彼此各自的荒诞。

## 大学生到底在困惑什么

不只是课本。是从来不听讲的课程，是五花八门参差不齐的老师 PPT（有的用宋体白底黑字写了二十年），是往届学长学姐流传下来的各种资料，可能跟今年的大纲风马牛不相及。复习的时候，你面前摆着课本、大纲、PPT、往届题、网盘里一百个 G 的资料——每一样都号称重要，每一样都没人帮你理清楚它们之间是什么关系。

这就是这个仓库要做的事。

## 这个仓库是什么

**代号：热带风味** 是一套用 LaTeX 生成的学复习笔记，配合 Claude Code 的 Skill 系统，实现了从多源资料（教学大纲、授课 PPT、往届笔记 PDF）到结构化、可编译、可条件渲染的复习笔记的半自动化工作流。

### 仓库结构

```
HXnote/
├── note/
│   ├── hxnotebook.sty              # 统一样式包（彩色文本框、封面、条件渲染开关）
│   └── grade4/
│       ├── 课程笔记.tex            # 笔记主文件
│       ├── */chapters/             # 各科目章节 tex 文件
│       └── */参考/                 # 参考资料（大纲 PPT 往届笔记）
├── skills/
│   ├── step1-multidocument2latexnote.md  # 从资料生成 LaTeX 笔记
│   └── step2-chapter-review.md           # 章节内容核查与修订
├── scripts/
│   └── build.py                    # 条件编译脚本
└── README.md
```

### 笔记效果

笔记采用统一的色彩体系——深红标识重点掌握、主题色标识概念释义、深绿提示要点、橙色标记考点。每章开头有导览框说明学习目标（掌握/熟悉/了解），章末附有选择题、名词解释、简答题及参考答案。所有内容严格对应教学大纲的双下划线（掌握）和单下划线（熟悉）标注，大纲中的教学难点在正文中特别标记。

### Skill 系统

本仓库定义了两个 Claude Code Skill，它们串联起从原始资料到终稿的完整工作流：

**Step1 — 多源资料生成 LaTeX 笔记（`step1-multidocument2latexnote`）**

从课程大纲（.doc）、授课 PPT（.pptx/.pdf）、往届笔记中提取结构化信息，按大纲框架生成主 .tex 文件和若干章节 .tex 文件。自动识别大纲中的重要程度标记（双下划线 → `\keybox`，单下划线 → `\imp{}`），使用统一的 `hxnotebook.sty` 样式包。Step1 的输出是一份可直接用 xelatex 编译的完整 LaTeX 工程。

**Step2 — 章节内容核查与修订（`step2-chapter-review`）**

对 Step1 生成的初稿进行逐章核查：比照大纲确认重点内容无遗漏、无冗余，检查难点标注是否到位，交叉核对教师 PPT 和往届笔记中的知识点细节。所有修改建议以列表形式呈现，由用户逐项确认后执行，确保人对内容的最终控制权。

**条件编译（`scripts/build.py`）**

支持通过命令行参数控制是否渲染章导览（`--no-intro`）和复习题（`--no-review`）。复习阶段可以根据需要灵活选择输出内容——系统背诵时保留全部，快速浏览时关闭导览和题目。

## 一种悲哀

说到底，这个仓库的本质是一种悲哀。不是因为它的技术不好——用 agent 整理出来的笔记确实很棒，整齐、醒目，比任何一个单人花上百个小时做出来的东西都要好。悲哀在于它竟然需要存在。

你被不想修读的课程折磨了整个学期——不是因为知识无用，而是因为教这些东西的人从未想过你为什么要学。然后绝大多数人又欺软怕硬，即使老师讲的很好，翘课的人依然很多；讲的很烂，人也很烂的老师往往却又极高的出勤率和前排就坐率——当然这只是因为他点名罢了。你没有像我一样，在不喜欢的课上直接走人——我理解，我也经常走不掉。

课本的作者、上课的老师、排课的人，从来不需要考虑学生的学习需求。他们不需要想学生想学什么，不想学什么，想看什么样的课件，拿到手的是什么样的笔记。他们的教学不需要被评价、被反馈、被优化。当然，现在的大学生也压抑羞涩，沉默和忍耐构成了这个系统最稳固的基石。

但我们还是要学。不管教得好不好，不管考得有没有道理，知识本身不会因为传递方式糟糕就失去价值。

**祝各位顺利。**
