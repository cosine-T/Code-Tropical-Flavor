% ----- 1.1 儿童少年的生存与发展 -----
\section{儿童少年的生存与发展}

\subsection{研究的目标人群与年龄分期}

\begin{defbox}
\textbf{研究的目标人群：}以中、小学学生为主，向前为学前儿童、婴幼儿，向后往大学生群体延伸，覆盖从出生婴儿到发育成熟的青年群体。
\end{defbox}

\begin{keybox}
\textbf{儿童少年年龄分期（WHO标准）：}

\textbf{分期} & \textbf{年龄范围} & \textbf{主要特点} \\

\end{keybox}

\subsection{生长发育与健康的生命连续体}

\begin{defbox}
\textbf{生命历程观：}生长发育是累积和连续的过程，个体从"胎儿—儿童—少年—青壮年—老年"构成完整的生命历程，每一个阶段健康既是前一阶段的延续，也是下一阶段的基础。

儿童少年发展潜力的发挥必须通过整个生命历程中的支持性环境来实现。"支持性环境"是能够激发儿童少年最佳发展潜力的系统、力量和因素，是由贯穿整个生命历程的卫生服务、政策、计划和社区共同参与。
\end{defbox}

% ----- 1.2 儿童少年生物和社会特征 -----
\section{儿童少年生物和社会特征}

\begin{keybox}
\textbf{（一）处于生长发育过程中}

生长发育是儿童少年的基本特征之一，也是社会发展的一面镜子。了解儿童少年生长发育规律，并深入研究其影响因素，是制定儿童少年保健工作的相应政策和行动纲领的重要前提。

\textbf{（二）接受学校教育的塑造}

接受教育是儿童少年的一个重要社会特征，学校集体生活构成其重要的生活内容。创造良好的学校物质环境和社会支持环境，建立健康促进学校，开展综合性学校卫生服务，是促进其身心健康和生长发育潜能的重要条件。

\textbf{（三）具有社会脆弱性与健康易损性}

在全人口中，儿童少年由于其身心以及各种能力发育的不完善，始终是一个弱势的群体。儿童神经系统发育不成熟，与成人相比，更容易受到有害生物和环境因素影响，从而造成发育和行为异常。

在不同的社会生态环境层面——个体、人际间、社区、结构和政策层面，以及在不同的发展阶段，儿童少年的心理健康受到多个动态因素的影响。
\end{keybox}

\subsection{儿童少年生存与发展权利}

\begin{defbox}
\textbf{（一）生存权：}每一个儿童都应该享有的对自己生命权以及维持基本健康生活需求的生活条件保障权。

\textbf{（二）发展权：}保障儿童成长过程中的各种需要得到满足，包括儿童有接受一切形式的教育（正规的和非正规的教育）的权利。能够给予儿童的身体、心理、精神、道德与社交发展的相应生活水平。
\end{defbox}

% ----- 1.3 儿童少年卫生学学科体系 -----
\section{儿童少年卫生学学科体系}

\subsection{研究内容}

\begin{keybox}
\textbf{儿童少年卫生学的四大研究内容：}

\begin{enumerate}[leftmargin=*, itemsep=3pt]
    \item \imp{儿童少年生长发育规律}——生长发育作为人类最为复杂的生物学现象，是本学科研究的永恒主题，也是学科首先要研究和认识的理论问题。包括身体发育和心理发育两个方面。

    \item \imp{儿童少年健康状况及其决定因素}——以保护、促进、增强儿童少年身心健康为宗旨，提出相应的卫生要求和适宜的卫生措施，维护儿童少年的健康，减少疾病，预防死亡，提高生存质量。

    \item \imp{儿童少年健康服务}——包括：生长发育和健康监测；健康教育和健康促进；常见病防治与健康管理；心理卫生服务；学校营养服务；校园安全管理与伤害及暴力预防；体育与体力活动促进。

    \item \imp{儿童少年卫生学的技术和方法}——人体测量、健康相关体能测试、行为评定等。
\end{enumerate}
\end{keybox}

\subsection{相关理论}

\begin{keybox}
\textbf{（一）三级预防理论}

三级预防理论是学科发展的重要理论构架。三级预防是儿童少年健康促进的首要和有效手段，是现代医学为人们提供的健康保障。

\begin{enumerate}[leftmargin=*]
    \item \imp{一级预防（病因预防）}：在疾病尚未发生时针对致病因素采取措施。\textbf{最积极、最有效的预防措施}。
    \item \imp{二级预防（"三早"预防）}：早发现、早诊断、早治疗，防止或减缓疾病发展。
    \item \imp{三级预防（临床预防）}：对症治疗和康复治疗措施。
\end{enumerate}

\textbf{（二）生物-心理-社会医学模式}

人类的健康与疾病取决于生物、心理和社会等各种因素，保护与促进人类健康，要从人们的生活环境、行为、精神和卫生服务等多方面努力。

\textbf{（三）生态健康观}

健康的决定因素包括生物学因素、行为生活方式和心理因素、卫生服务因素以及物质和社会环境因素，强调儿童少年健康是上述因素相互依赖和相互作用的结果，并在多个层面上交互作用来影响个体和群体的健康。

\textbf{（四）生命周期理论}

按照年代和时间顺序，将疾病相关的危险因素以及健康促进因素从孕前、孕期或围生期、童年早期、学龄期、青春期直至下一代的顺序列出图谱。
\end{keybox}

\subsection{应用体系}

\begin{defbox}
\textbf{（一）国际儿童少年健康服务：}儿童少年日常生活的大部分时间通常是在学校度过，因此，学校在为儿童少年长期提供密集且大规模的卫生保健服务方面具有不可替代的作用。

\textbf{（二）我国儿童少年健康服务：}
\begin{itemize}[leftmargin=*]
    \item 我国全链条的儿童少年健康服务："孕产妇健康管理—0$\sim$6岁儿童健康管理—学校卫生"全链条式服务，并完善儿童少年的医疗保障体系。
    \item 将儿童少年健康服务融入到所有的政策：加强教育、卫生、体育、环境、民政等各个部门协作，共同制定政策和实施行动。
\end{itemize}
\end{defbox}

% ----- 1.4 学科发展 -----
\section{儿童少年卫生学学科发展}

\subsection{学科建设和人才培养}

\begin{defbox}
\textbf{学科建设历程：}
\begin{itemize}[leftmargin=*]
    \item 1951年，中国5所院校的卫生系相继成立了学校卫生教研组
    \item 1952年后，全国各地陆续建立学校卫生科（组），由学校卫生医师开展工作
    \item 1955年，全国高等学校院系调整，只保留了6个卫生系
    \item 1978年后，各高校陆续成立儿童少年卫生教研室
    \item 1997年后，教育部将儿少卫生与妇幼保健学设为公共卫生与预防医学二级学科
\end{itemize}

\textbf{人才培养：}《儿童少年卫生学》作为预防医学、妇幼保健医学等本科专业学生的必修课程，也是儿少卫生与妇幼保健学硕士、博士研究生的必修课程，在公共卫生与预防医学专业人才培养方面发挥重要作用。
\end{defbox}

\subsection{法律法规建设和政策发展}

\begin{keybox}
\textbf{法律法规：}法律明确规定了家庭、学校、社会给予儿童少年受教育、受保护的义务和责任。《学校卫生工作条例》明确规定了学校卫生工作的任务、工作要求和管理分工等。

\textbf{党和国家政策发展：}
\begin{itemize}[leftmargin=*]
    \item 1951年：发布《关于改善各级学校学生健康状况的决定》
    \item 1991年：签署《儿童生存、保护和发展世界宣言》《九十年代行动计划》
    \item 1992年：颁布《九十年代中国儿童发展规划纲要》
    \item 2001年：颁布《中国儿童发展规划纲要（2001—2010）》
    \item 2011年：颁布《中国儿童发展规划纲要（2011—2020）》
    \item 2021年：颁布《中国儿童发展纲要（2021—2030年）》
\end{itemize}

构建了学校卫生工作的法规制度和政策框架；使学校卫生工作的开展做到了有章可循、有法可依；促进了学校卫生工作规范化。
\end{keybox}

\subsection{卫生标准体系建设}

\begin{defbox}
\textbf{学校卫生标准发展：}
\begin{itemize}[leftmargin=*]
    \item 1951年：中央人民政府政务院《关于改善各级学校学生健康状况的决定》
    \item 1964年：卫生部、教育部等下发的《中小学校保护学生视力暂行办法（草案）》
    \item 1985年：召开了"学校卫生标准研讨会"
    \item 1987年：颁布了《学校课桌椅卫生标准》《中小学校教室采光和照明卫生标准》
    \item 2005年：在卫生部组织开展《卫生标准体系建设》
    \item 目前平均每年制（修）订学校卫生标准（含卫生行业标准）3$\sim$5项
\end{itemize}
\end{defbox}

\subsection{健康中国建设与中小学健康促进行动}

\begin{defbox}
\textbf{《"健康中国2030"规划纲要》与健康中国战略：}加强健康教育与健康素养提升、增强体质与体育锻炼、改善营养状况、心理健康关注、重大疾病防控、视力保护、健康环境保障、贫困儿童的健康保障等。

\textbf{中小学健康促进行动：}加强中小学健康促进，增强儿童少年体质，是促进中小学生健康成长和全面发展的需要。
\end{defbox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{儿童少年卫生学}：研究维护和促进儿童少年健康的学科，研究对象为0$\sim$24岁儿童少年，重点为中小学生群体。\textbf{生命历程观}：生长发育是累积和连续的过程，个体从"胎儿—儿童—少年—青壮年—老年"构成完整的生命历程，每一阶段健康既是前一阶段的延续，也是下一阶段的基础。\textbf{支持性环境}：能够激发儿童少年最佳发展潜力的系统、力量和因素，由贯穿整个生命历程的卫生服务、政策、计划和社区共同参与。\textbf{三级预防}：一级（病因预防）、二级（"三早"预防）、三级（临床预防）的分级预防策略。

    \item 七个分期：婴儿期（生命的第1年）、幼儿期（第2$\sim$3年）、学龄前期（3$\sim$5岁）、儿童中期（5$\sim$9岁，约小学阶段）、青春期早期（10$\sim$14岁）、青春期晚期（15$\sim$19岁）、青少年或青年期（20$\sim$24岁）。

    \item (1)处于生长发育过程中——生长发育是儿童少年的基本特征之一，也是社会发展的一面镜子；(2)接受学校教育的塑造——学校集体生活构成其重要的生活内容；(3)具有社会脆弱性与健康易损性——身心及各种能力发育不完善，始终是弱势群体，更容易受到有害生物和环境因素影响。

    \item (1)儿童少年生长发育规律（学科永恒主题，包括身体发育和心理发育）；(2)儿童少年健康状况及其决定因素（以促进身心健康为宗旨，提出卫生要求和措施）；(3)儿童少年健康服务（生长发育监测、健康教育、常见病防治、心理卫生、营养、校园安全、体育促进等七大类）；(4)儿童少年卫生学的技术和方法（人体测量、体能测试、行为评定）。

    \item 一级预防（病因预防）：在疾病尚未发生时针对致病因素采取措施，最积极有效；二级预防（"三早"预防）：早发现、早诊断、早治疗，防止或减缓疾病发展；三级预防（临床预防）：对症治疗和康复治疗措施。三级预防是儿童少年健康促进的首要和有效手段。

    \item "孕产妇健康管理—0$\sim$6岁儿童健康管理—学校卫生"全链条式服务，完善儿童少年医疗保障体系；将儿童少年健康服务融入所有政策，加强教育、卫生、体育、环境、民政等部门协作。

    \item 1951年5所院校成立学校卫生教研组；1978年后各高校成立儿少卫生教研室；1997年设为公共卫生与预防医学二级学科；《儿童少年卫生学》为预防医学等本科专业必修课程。
\end{enumerate}
