% ----- 1.1 儿童少年卫生学概述 -----
\section{儿童少年卫生学概述}

\begin{defbox}
\textbf{儿童少年卫生学（Child and Adolescent Health）}是研究维护和促进儿童少年健康的一门学科。研究儿童少年的生长发育规律及其变化特点，分析影响因素（遗传和环境因素），阐明儿童少年机体与学习、生活环境之间的相互关系，制定相应的卫生要求和措施，预防疾病、增强体质、促进身心健康，为生命阶段健康奠定良好基础，从而达到终身健康的目的。
\end{defbox}

\subsection{研究对象}

儿童少年卫生学以\keyword{0--24岁儿童少年}为研究对象，\imp{重点人群为中小学生群体}。研究范围涵盖从出生到青年期的全生命周期，包括胎儿期、婴儿期、幼儿期、学龄前期、学龄期、青春期和青年期。

\subsection{研究内容}

\begin{tcolorbox}[colback=light, colframe=main, boxrule=0.5pt, arc=4pt, title=\textbf{儿童少年卫生学的四大研究内容}, breakable]
\begin{enumerate}[leftmargin=*, itemsep=3pt]
    \item \imp{儿童少年生长发育规律}——生长发育是儿童少年的基本特征之一，也是社会发展的一面镜子。了解生长发育规律是研究影响因素、制定保健措施的重要前提。包括体格发育和心智发育两个方面。
    \item \imp{儿童少年健康状况及影响因素}——以促进儿童身心健康为宗旨，分析影响因素（遗传和环境），提出相应卫生要求和措施。重点关注生长发育的群体差异和个体差异。
    \item \imp{儿童少年健康教育}——包括健康教育和健康问题，健康促进与健康教育，健康管理与健康服务。学校教育是儿童少年的一项重要经历，学校生活环境构成重要的教育内容。
    \item \imp{儿童少年卫生学的技术和方法}——包括体格测量、体能测试、心理行为测评等，是学科研究的基本工具。
\end{enumerate}
\end{tcolorbox}

\section{儿童少年年龄分期及各期特点}

\begin{keybox}
\textbf{儿童少年年龄分期（WHO标准）：}

\begin{tabularx}{\textwidth}{l>{\raggedright\arraybackslash}p{2.5cm}X}
\hline
\textbf{分期} & \textbf{年龄范围} & \textbf{主要特点} \\

\end{keybox}

\begin{tipbox}
\textbf{各阶段发展任务的核心理念：}每一发展阶段建立在前一阶段的基础上，也为下一阶段奠定基础。"生命历程"（life course）——从胚胎、儿童、少年至壮年、老年，是整个生命的过程，每一阶段的发展既承接前一阶段的成果，也为后一阶段的健康奠定基础。

儿童发展潜力的发挥必须通过贯穿生命过程中的支持性环境来实现。支持性环境包括能够优化儿童最佳发展潜力的系统性环境因素，如贯穿发育全程的营养、社会环境、政策和计划。
\end{tipbox}

% ----- 1.3 生命历程观 -----
\section{生长发育与健康发展的生命历程观}

\begin{defbox}
\textbf{生命历程理论（Life Course Theory）}：生长发育是积累和建构的过程，遵循"胚胎→儿童→少年→壮年→老年"的整个生命过程。每一阶段建立在前面阶段的基础上，也形成下一阶段的基础。儿童少年发展潜力的发挥必须通过贯穿生命过程中的支持性环境来实现。

\textbf{支持性环境}：能够优化儿童最佳发展潜力的系统性环境因素，包括贯穿发育全程的营养、社会环境、政策、计划等共同参与。
\end{defbox}

\subsection{儿童少年健康与发育权利}

\begin{keybox}
\textbf{儿童的四项基本权利（联合国《儿童权利公约》）：}
\begin{enumerate}[leftmargin=*]
    \item \imp{生存权}——每一儿童都应享有的固有生命权以及维持或改善基本生活水准的权利
    \item \imp{发展权}——保障儿童成长过程中的各种需要得到满足，包括儿童有权接受一切形式的教育（正规和非正规教育）
    \item \imp{受保护权}——保护儿童免受一切形式的歧视、虐待和忽视
    \item \imp{参与权}——儿童有权对影响其本人的一切事项发表意见
\end{enumerate}
\end{keybox}

% ----- 1.4 学科体系 -----
\section{儿童少年卫生学学科体系}

\subsection{三级预防策略}

\begin{keybox}
\textbf{三级预防——学科发展的重要理论功能：}

\begin{enumerate}[leftmargin=*]
    \item \imp{一级预防（Primary Prevention）/ 病因预防}：在疾病尚未发生时，针对致病因素或危险因素采取措施，是预防疾病和消灭疾病的根本措施。\textbf{最积极、最有效的预防措施}。如：计划免疫、健康教育、营养指导。
    \item \imp{二级预防（Secondary Prevention）/ 临床前期预防}：早期发现、早期诊断、早期治疗的"三早"预防，主要针对症状前阶段的疾病。如：生长发育监测、常见病筛查。
    \item \imp{三级预防（Tertiary Prevention）/ 临床预防}：针对已患病者，采取及时有效的治疗和康复措施，防止病情恶化、预防并发症和伤残、促进功能恢复。如：疾病治疗、康复训练。
\end{enumerate}
\end{keybox}

\subsection{生长发育概述}

\begin{defbox}
\textbf{生长（Growth）}：指细胞繁殖、增大和细胞间质增加，表现为组织、器官、身体各部和全身在大、小、长短和重量上的增加以及身体化学成分的变化，属\imp{形态和化学}范畴。

\textbf{发育（Development）}：指身体组织、器官和各系统在功能上的不断分化和完善过程，包括心理、行为和体能的成熟，属\imp{功能}范畴。也称之为"发展"或"心理发展"。生长和发育密不可分，生长是发育的前提，发育寓于生长之中。

\textbf{成熟（Maturity）}：指生长和发育达到一个比较完备的阶段，标志着个体在形态、生理功能、心理素质等方面都已达到成人水平，具备独立生活和生殖养育下一代的能力。
\end{defbox}

\begin{defbox}
\textbf{生长发育可塑性（Plasticity of Growth and Development）}：人的结构和功能为适应内外环境变化而经历的改变能力。生长发育是遗传和环境共同作用的结果，可塑性反映了机体对环境变化的适应能力，在儿童少年期尤为显著。

\textbf{生物学成熟度（Biological Maturity）}：专指某一特定生长发育指标当时达到的发育水平占成人水平的百分比。例如，新生儿脑重约350--400g，相当于成人脑重的25\%，6岁时脑重已达成人的90\%。

\textbf{发育终点}：达到成人水平即为发育终点。
\end{defbox}

\subsection{生长发育的5大模式}

\begin{keybox}
\textbf{儿童生长发育的5大模式（研究框架）：}
\begin{enumerate}[leftmargin=*]
    \item \imp{生长发育规律}——最基本的特征，是所有研究和应用的前提。了解规律→研究影响因素→制定保健措施。
    \item \imp{学校教育的促进}——学校教育是儿童的重要经历，学校生活环境构成重要的教育内容。建设良好的学校物质环境和人际支持环境，发展综合性学校卫生服务。
    \item \imp{生长发育的脆弱性与健康不平等}——儿童因系统发育不成熟、抵抗力弱，始终是一个脆弱的群体。在不同生态环境（个人、人际、社区、结构、政策层面）和不同发展阶段，儿童健康都会受到多重生态因素的影响。
    \item \imp{生命历程的多维影响}——生态系统的时空维度影响儿童发展。
    \item \imp{多学科交叉融合}——儿童少年卫生学与其他学科的交叉融合。
\end{enumerate}
\end{keybox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{儿童少年卫生学}：研究维护和促进儿童少年健康的一门学科，研究生长发育规律及其变化特点，分析影响因素，阐明机体与学习、生活环境的相互关系，制定卫生要求和措施。\textbf{生长}：细胞繁殖增大和间质增加，表现为形态和化学变化。\textbf{发育}：组织器官功能上的分化和完善，属功能范畴。\textbf{成熟}：生长发育达到完备阶段，形态、功能、素质均达成人水平。

    \item \textbf{生长发育可塑性}：人的结构和功能为适应内外环境变化而经历的改变能力，在儿童少年期尤为显著。\textbf{三级预防}：一级（病因预防）、二级（临床前期预防/三早）、三级（临床预防/治疗康复）的分级预防策略。

    \item \textbf{研究对象}：0--24岁儿童少年，重点人群为中小学生群体。\textbf{四大研究内容}：(1)生长发育规律；(2)健康状况及影响因素；(3)健康教育和服务；(4)技术和方法。

    \item 八个分期：胎儿期（受精至分娩）、新生儿期（0--28天）、婴儿期（第1年，第一生长突增）、幼儿期（2--3岁）、学龄前期（3--5/6岁）、学龄期（6--11/12岁）、青春期（10--19岁，第二生长突增）、青年期（15--24岁）。

    \item 一级预防（病因预防）最积极有效，如计划免疫、健康教育；二级预防为"三早"（早发现、早诊断、早治疗），如生长发育监测和常见病筛查；三级预防为治疗康复，防止病情恶化和并发症。

    \item 生长是形态和化学变化（量变），发育是功能分化和完善（质变）。生长是发育的前提，发育寓于生长之中，两者密不可分。

    \item 生命历程理论强调每一阶段建立在前一阶段基础上，也为后一阶段奠基。儿童期是健康发展的关键窗口期，早期不良暴露会产生长期健康效应。支持性环境（营养、社会、政策）贯穿全程对实现最佳发展潜力至关重要。
\end{enumerate}
