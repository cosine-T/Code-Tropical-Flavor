% ----- 2.1 生长发育指标体系 -----
\section{生长发育指标体系}

\subsection{体格发育指标}

\begin{defbox}
\textbf{体格发育（Physical Growth）}：指身体外部形态的发育，是身体发育的主要方面。包括长度指标、宽度指标、重量指标和综合评价指标。

\begin{enumerate}[leftmargin=*]
    \item \imp{长度指标}：3岁以前测卧长/身长，学龄期测身高、坐高、指距、上肢长、下肢长
    \item \imp{宽度指标}：围度和径距。围度包括头围、胸围、腰围、上臂围、大腿围、小腿围；径距包括肩宽、骨盆宽、胸前后径、头前后径、头左右径
    \item \imp{重量指标}：体重（目前学校卫生监测最常用指标）
    \item \imp{综合评价指标}：BMI（Quetelet指数）、身高比、腰臀比等
\end{enumerate}
\end{defbox}

\begin{tipbox}
\textbf{BMI（身体质量指数）}：BMI = 体重(kg) / 身高$^2$(m$^2$)，能较准确反映不同群体、个体胖瘦变化。青春期发育使体重快速增加，BMI高百分位数的变化趋势是制定肥胖防控策略和措施的重要依据。
\end{tipbox}

\subsection{体能发育指标}

\begin{defbox}
\textbf{体能（Physical Fitness）}：是健康素质的重要组成部分，应全面、准确测定个体的体能和健康状况。分为\imp{生理功能}和\imp{运动能力}。

\textbf{（一）生理功能指标：}
\begin{itemize}[leftmargin=*]
    \item \imp{心血管功能指标}：心率（随年龄增长而减慢）、血压（随年龄增长而升高）、动态血压
    \item \imp{肺功能指标}：呼吸频率、肺活量、最大通气量
    \item \imp{综合功能发育指标}：肺活量、血压、心率等
\end{itemize}

\textbf{（二）运动能力指标：}
\begin{itemize}[leftmargin=*]
    \item \imp{力量（Strength）}：俯卧撑、引体向上、握力、立定跳远、仰卧起坐、投掷等
    \item \imp{耐力（Endurance）}：20m折返跑、50m×8往返跑（小学）、1000m跑（中学男生）、800m跑（中学女生）、台阶运动试验；反映全身耐力的心肺功能——最大摄氧量（VO$_2$max）
    \item \imp{速度（Speed）}：短跑、游泳、滑雪等
    \item \imp{灵敏性（Agility）}：10m×4往返跑、跳绳、乒乓球、平衡木等
    \item \imp{柔韧性（Flexibility）}：坐位体前屈、立位体前屈
    \item \imp{平衡（Balance）}、\imp{协调性（Coordination）}、\imp{反应时（Reaction Time）}
\end{itemize}
\end{defbox}

\subsection{心理行为发育指标}

\begin{defbox}
\textbf{心理行为发育}分为认知能力、情绪情感和个性人格三个方面：
\begin{enumerate}[leftmargin=*]
    \item \imp{认知功能指标}：认知能力（空间知觉、时间知觉、速度知觉）、注意能力、记忆能力、思维能力、执行功能等
    \item \imp{情绪状态指标}：焦虑、抑郁、恐惧、偏执等
    \item \imp{个性/人格}：气质（心理活动的强度、速度、稳定性与指向性等行为表现）和性格。人格是个体在适应环境成长过程中，与遗传和环境的交互作用下形成的稳定而独特的心理特征总和，气质和性格是人格最重要的部分
\end{enumerate}
\end{defbox}

\subsection{体成分}

\begin{defbox}
\textbf{体成分（Body Composition）}：指人体总重量中，脂肪组织和非脂肪组织（去脂体重）所占的百分比。常用指标包括：
\begin{itemize}[leftmargin=*]
    \item \imp{皮褶厚度}（肱三头肌、肩胛下角等部位）
    \item \imp{生物电阻抗}（Bioelectrical Impedance Analysis, BIA）
\end{itemize}
\end{defbox}

% ----- 2.2 生长发育一般规律 -----
\section{生长发育的一般规律}

\subsection{生长发育的阶段性、连续性和不平衡性}

\begin{keybox}
\textbf{（一）生长发育的阶段性}

生长发育的不同表现在于关键期或敏感期。处于不同发展阶段，其发展受环境影响的程度不同。

\textbf{生长发育的关键期（Critical Period）}：某一特定时期，机体对环境因素的敏感性最高，适宜刺激可促进发育，不良刺激可造成不可逆损伤。

\textbf{生长发育里程碑（Developmental Milestone）}：由美国心理学家和儿科医生罗伯特·詹姆斯·哈维格斯于1972年提出。认为个体发展到一定阶段应能达到一定的水平，这些发展任务由特定领域的技能任务来定义，既是对教育的指导，也是判断发育水平的依据。

\textbf{（二）生长发育的连续性——生长轨迹与追赶性生长}

\begin{defbox}
\textbf{生长轨迹现象（Trajectory of Growth）/ 生长管道现象}：生长发育是一个动态积累过程，在遗传潜力范围内，当外界环境没有变化时，生长发育过程较为稳定，呈现出轨迹现象。即使群体中各个体的生长轨迹存在有限的正常变异，这种稳定性仍然存在。

\textbf{追赶性生长（Catch-up Growth）}：生长发育过程中的各种干扰因素（如营养不良、疾病应激等）使生长发育迟缓，一旦这些影响因素被克服，则表现为向原有生长轨迹的强烈回归。年龄越小越明显，生长加速、发育被阻碍的儿童会表现得更加突出，其身体会出现巨大的代偿性生长，逐渐回到原来的生长轨迹。这一现象即为追赶性生长。
\end{defbox}
\end{keybox}

\subsection{头尾发展律与近侧发展律}

\begin{keybox}
\textbf{（一）运动能力发育的程序性}

\begin{enumerate}[leftmargin=*]
    \item \imp{头尾发展律（Cephalocaudal Development）}：胎儿期和婴幼儿期的粗大动作发育遵循从头到尾发展的程序性。\\
    大运动发育顺序：抬头→翻身→坐→爬→站→走→跑→跳（从头部到下肢）

    \item \imp{近侧发展律（Proximodistal Development）}：从身体近端（躯干）向远端（四肢末梢）发展的程序性。\\
    表现为：由粗大动作到精细动作，循躯干→上肢近端→上肢远端→手指精细动作发展
\end{enumerate}

\textbf{（二）身体比例的变化}

青春期前，身体比例变化也遵循头尾发展律：
\begin{itemize}[leftmargin=*]
    \item 2个月胎儿头长/身长比例 $\approx$ 1:1
    \item 出生时 $\approx$ 1:4
    \item 成人 $\approx$ 1:8
\end{itemize}
\end{keybox}

\subsection{不同组织器官生长发育的不平衡性}

\begin{keybox}
\textbf{Scammon生长模式（Scammon's Growth Model）——四种生长模式：}

\begin{table}[H]
\centering
\caption{Scammon生长模式的四种类型}
\begin{tabularx}{\textwidth}{lX}
\hline
\textbf{类型} & \textbf{特点} \\
\hline
\imp{一般型（淋巴系统除外的器官）} & 婴幼儿期发育快；学龄前期和学龄期发育平缓；青春期再次加快；青春期后逐渐停止 \\
\imp{淋巴系统型} & 淋巴结、扁桃体、胸腺等淋巴器官——儿童期发育很快，青春期达高峰，此后逐渐衰退，成人时仅相当于高峰期的一半 \\
\imp{神经系统型} & 中枢神经系统、脊髓、眼球等——出生后有一个生长突增期，婴幼儿期和学龄前期发育迅速，6岁时脑重已达成人90\%左右 \\
\imp{生殖系统型} & 睾丸、卵巢、子宫等生殖器官——青春期前基本处于停滞状态，青春期开始迅速加快发育直至成熟 \\
\hline
\end{tabularx}
\end{table}

\textbf{子宫生长模式（附加模式）}：子宫等器官出生时较大，随后迅速缩小，青春期开始前恢复到出生时大小，随后迅速增大。
\end{keybox}

\subsection{生长发育的个体差异性}

\begin{defbox}
\textbf{生长发育的个体差异性}：生长发育过程中，个体间存在明显的差异，反映在生长发育速度、最终水平等方面。这些差异是遗传和环境共同作用的结果，是生长发育的普遍现象。

\textbf{影响个体差异的因素}：
\begin{itemize}[leftmargin=*]
    \item 遗传因素——决定生长发育潜力
    \item 环境因素——决定生长发育速度和最终程度
    \item 遗传与环境的交互作用
\end{itemize}
\end{defbox}

\subsection{生长发育的高度可塑性}

\begin{defbox}
\textbf{生长发育的可塑性}：生长发育过程受外部环境因素或内部生理变化影响，通过基因-环境交互作用而改变发育轨迹。可塑性表现为发育速度、最终水平或成熟时机的变化，为在不断变化的环境中提供生存和繁殖成功的最佳机会。儿童少年青春期学习历练是可塑性的典型表现。
\end{defbox}

% ----- 2.3 生长发育的生态学模型 -----
\section{生长发育的生态学模型}

\subsection{Bronfenbrenner生态系统理论}

\begin{keybox}
\textbf{Bronfenbrenner的生态系统理论（Ecological Systems Theory）：}

由美国发展心理学家Urie Bronfenbrenner（1917--2005）提出，认为个体的发展嵌套在相互影响的一系列环境系统中，系统之间存在相互作用关系，个体与环境交互作用并影响着个体的发展。

\textbf{（一）空间维度}
\begin{enumerate}[leftmargin=*]
    \item \imp{微系统（Microsystem）}：个体活动和人际交往的直接环境，处于不断变化和发展中。如家庭、学校、同伴群体、社区等
    \item \imp{中间系统（Mesosystem）}：各微系统之间的联系和相互关系。如家庭与学校之间的关系
    \item \imp{外系统（Exosystem）}：个体不直接参与但对其发展产生影响的环境。如父母工作环境、社区资源
    \item \imp{宏系统（Macrosystem）}：文化、亚文化和社会阶层背景，是最外层
\end{enumerate}

\textbf{（二）时间维度——时间系统（Chronosystem）}

强调儿童的发展是在一个时间与环境相互作用的动态过程中发生的。生态系统不是一种恒定不变的结构体系，而是始终处于动态变化中。
\end{keybox}

\subsection{进化发育理论}

\begin{defbox}
\textbf{进化发育人类学（Evolutionary Developmental Anthropology）：}

\begin{enumerate}[leftmargin=*]
    \item \imp{适应性形成机制}：强调机体对适应性形成机制的重要性，以及使这些机制得以激活、发展的环境因素的作用（如马斯洛、罗杰斯等学者）
    \item \imp{生活史理论（Life History Theory）}：研究个体在不同生命目标（生存、成长和繁殖）之间进行权衡并适应性地分配资源的过程。在资源有限的情况下，机体需要决定如何分配能量资源，通过内分泌调节影响资源在生存、生长和繁殖功能的分配
\end{enumerate}
\end{defbox}

% ----- 2.4 生长发育的长期变化 -----
\section{生长发育的长期变化}

\begin{defbox}
\textbf{生长发育的长期变化（Secular Trend of Growth）}：指在较长时期内（通常数十年或更长时间），人群在生长发育水平上出现的持续性、趋势性变化。主要表现为：
\begin{enumerate}[leftmargin=*]
    \item \imp{身高、体重的增长}——各年龄组儿童的平均身高和体重逐代增高
    \item \imp{青春期提前}——月经初潮年龄逐代提前
    \item \imp{成人身高的增加}——一代比一代更高
    \item \imp{身体比例的轻微改变}
\end{enumerate}

\textbf{变化原因：}社会经济条件改善、营养水平提高、疾病控制进步、医疗卫生服务改善等综合因素作用的结果。

\textbf{影响：}是人群健康水平提高的正面指标，但也带来一些新问题（如肥胖率上升等）。
\end{defbox}

% ----- 2.5 生长发育评价的基本方法 -----
\section{生长发育评价的基本方法}

\subsection{生长发育评价的目的和内容}

\begin{defbox}
\textbf{生长发育评价}是运用科学方法对个体或群体儿童少年的生长发育水平、速度、趋势及匀称度等进行综合判断。主要目的包括：
\begin{enumerate}[leftmargin=*]
    \item 了解个体或群体的生长发育水平和健康状况
    \item 筛查生长发育异常和营养不良/肥胖
    \item 评价干预措施的效果
    \item 为卫生政策和健康规划提供依据
\end{enumerate}

\textbf{评价内容：}发育水平、生长速度、发育匀称度、成熟度。
\end{defbox}

\subsection{常用评价方法}

\begin{keybox}
\textbf{（一）指数法}

利用人体各部分的比例关系，用数学公式将两项或多项指标结合起来综合评价身体发育的匀称度。

\begin{itemize}[leftmargin=*]
    \item \imp{BMI（体质指数）}：BMI = 体重(kg) / 身高$^2$(m$^2$)，国际通用指标
    \item \imp{身高别体重（Weight-for-Height）}：反映身体充实度和营养状况
    \item \imp{坐高/身高指数}：反映身体比例
    \item \imp{胸围指数}：胸围/身高 $\times$ 100\%
\end{itemize}

\textbf{（二）离差法（标准差法）}

以均数($\bar{X}$)和标准差(SD)为基准评价个体发育水平的方法。

\begin{itemize}[leftmargin=*]
    \item \imp{等级评价法}：将$\bar{X} \pm$ SD划分5个等级（上等、中上等、中等、中下等、下等）
    \item 上等：$> \bar{X} + 2$SD；中上等：$\bar{X} + 1$SD $\sim$ $\bar{X} + 2$SD；中等：$\bar{X} \pm$ 1SD；中下等：$\bar{X} - 2$SD $\sim$ $\bar{X} - 1$SD；下等：$< \bar{X} - 2$SD
    \item \imp{曲线图法}：将各年龄-性别组的均值和标准差绘制成曲线，直观追踪个体生长轨迹
\end{itemize}

\textbf{（三）百分位数法}

以第50百分位数(P50)为中位水平，用P3、P25、P75、P97等百分位划分等级。\textbf{更适用于偏态分布指标（如体重）}。

\textbf{BMI超重/肥胖筛查标准（中国学龄儿童，WS/T 586-2018）：}
\begin{itemize}[leftmargin=*]
    \item P85 $\sim$ P95：超重
    \item $\geq$ P95：肥胖
\end{itemize}

\textbf{WHO标准 vs 中国标准：}WHO生长标准（2006年发布，针对5岁以下）为描述性理想生长标准；中国标准为根据本国儿童体质特征建立的参照标准，更适用于我国人群评价。

\textbf{（四）Z评分法（标准差分法）}

Z = (个体测量值 $-$ 参考人群中位数) / 参考人群标准差

常用于国际比较和营养状况评价。WHO推荐用于评价儿童营养状况：
\begin{itemize}[leftmargin=*]
    \item 年龄别身高Z分(HAZ) $<$ $-2$：生长迟缓（Stunting）
    \item 年龄别体重Z分(WAZ) $<$ $-2$：低体重（Underweight）
    \item 身高别体重Z分(WHZ) $<$ $-2$：消瘦（Wasting）
    \item BMI Z分 $>$ $+2$：肥胖
\end{itemize}

\textbf{（五）生长速度评价}

评价一定时期内的生长量，反映动态变化。常用年增长值（cm/年）和年增长率(\%)。生长速度评价是\imp{最敏感的生长评价方法}，能早期发现生长异常。

\textbf{（六）发育年龄评价}

用身体某些形态、功能或第二性征指标的发育水平与"标准年龄"比较，判断个体的发育年龄。
\begin{itemize}[leftmargin=*]
    \item \imp{骨骼年龄（骨龄）}：最常用的发育年龄指标。通过手腕部X线片骨化中心出现和骨骺愈合情况判断，是评价儿童生长发育成熟度的\keyword{金标准}
    \item \imp{牙齿年龄（牙龄）}：通过牙齿萌出和钙化时间评价
    \item \imp{第二性征年龄}：通过Tanner分期评价青春期发育进程
\end{itemize}
\end{keybox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{体格发育}：身体外部形态的发育，包括长度、宽度、重量和综合评价指标。\textbf{体能}：健康素质的重要组成部分，分为生理功能和运动能力。\textbf{Scammon模式}：四种生长模式（一般型、淋巴型、神经型、生殖型）。\textbf{追赶性生长}：抑制生长的因素去除后，机体向原有生长轨迹强烈回归的现象。

    \item \textbf{头尾发展律}：粗大运动从头到脚的发育顺序（抬头→坐→站→走）。\textbf{近侧发展律}：从躯干近端向四肢远端发展的程序性。

    \item \textbf{生长轨迹现象}：在稳定环境下，个体生长发育保持稳定趋势的现象。\textbf{长期变化}：数十年间人群生长发育水平的持续性趋势变化。

    \item （见正文定义）

    \item 三大类：(1)体格发育指标（长度、宽度、重量、综合评价）；(2)体能发育指标（生理功能：心率、血压、肺活量；运动能力：力量、耐力、速度、灵敏、柔韧）；(3)心理行为发育指标（认知、情绪、人格）。

    \item 头尾发展律：大运动→抬头→翻身→坐→爬→站→走→跑→跳。近侧发展律：粗大动作→精细动作，由躯干近端向远端发展。

    \item (1)一般型：婴儿期快→学龄期平缓→青春期加速；(2)淋巴型：儿童期快→青春期高峰→成人期衰退；(3)神经型：婴幼儿期迅速→6岁接近成人；(4)生殖型：青春期前停滞→青春期迅速。

    \item 追赶性生长是去除抑制因素后向原有轨迹回归的现象。年龄越小越明显，说明生长发育有强大的自我调节能力，早期干预对恢复生长发育至关重要。

    \item 四个层次：微系统（家庭、学校）→中间系统（微系统间的联系）→外系统（间接影响的环境）→宏系统（文化、社会阶层）。由内向外依次嵌套。

    \item 主要表现：身高体重逐代增高、青春期提前、成人身高增加。原因：社会经济改善、营养水平提高、疾病控制进步、医疗卫生改善。

    \item 主要方法：(1)指数法（BMI、身高别体重等）——简便快速筛查；(2)离差法（等级评价、曲线图）——以均数$\pm$标准差为基准；(3)百分位数法——适用于偏态分布，如P85-P95为超重、P95以上为肥胖；(4)Z评分法——用于国际比较和营养评价；(5)生长速度评价——最敏感的动态评价；(6)发育年龄评价——骨龄是金标准。
\end{enumerate}
