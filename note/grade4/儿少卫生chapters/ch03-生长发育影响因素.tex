掌握遗传因素对生长发育的影响（遗传度、双生子研究、GWAS）；掌握环境因素对生长发育的影响（自然环境、社会环境、家庭因素）；掌握基因-环境交互作用；熟悉表观遗传学机制；熟悉生长发育长期变化；理解促进生长发育的综合措施。本章"环境因素"为教学难点（*）。

% ----- 3.1 遗传因素 -----
\section{遗传因素}

\begin{defbox}
\textbf{遗传（Heredity）}：指形态结构、生理功能及疾病等的发育性状通过遗传物质从亲代向子代之间的传递。父母双方基因的不同组合通过受精卵传递给个体，通过基因控制蛋白质表达决定子代的遗传性状（如外貌、身高、性格、智力等）。每个儿童的基因决定了其生长发育的潜力（潜能），但这些潜能的发挥受环境因素制约，同时也受基因-环境交互作用影响。

\textbf{遗传度（Heritability）}：又称遗传力，用于衡量群体中某一性状的表型变异在多大程度上由遗传因素决定。遗传度 = 遗传方差 / 总表型方差。
\end{defbox}

\subsection{遗传度的研究方法}

\begin{keybox}
\textbf{（一）双生子研究法（Twin Study）}

比较同卵双生子（MZ，基因相同度100\%）和异卵双生子（DZ，基因相同度约50\%）在某一性状上的一致性差异，以估计遗传度。

\begin{itemize}[leftmargin=*]
    \item 若MZ的一致性明显高于DZ，说明该性状受遗传影响较大
    \item 遗传度（$h^2$）= 2 × ($R_{MZ}$ - $R_{DZ}$)（Holzinger公式简化）
\end{itemize}

\textbf{（二）全基因组关联研究（GWAS）}

在基因组范围内识别与表型性状相关的遗传变异（主要是SNP），并估计这些遗传变异所能解释的遗传度。\imp{GWAS估计的遗传度通常低于双生子研究估计的遗传度}，这种现象称为\keyword{遗传度缺失（Missing Heritability）}。如：身高GWAS遗传度约18.4\%。

\textbf{遗传度缺失的可能原因：}
\begin{enumerate}[leftmargin=*]
    \item 罕见变异未被GWAS检测到
    \item 基因-基因交互作用
    \item 基因-环境交互作用
    \item 表观遗传修饰
\end{enumerate}
\end{keybox}

\subsection{家族聚集性与种族差异}

\begin{defbox}
\textbf{家族聚集性（Familial Aggregation）}：某些性状或疾病在家族中出现的频率高于一般人群。亲子代之间是遗传最直接的表现。发育水平存在显著的家族聚集现象，反映了遗传因素在生长发育中的重要作用。

\textbf{生长发育的种族差异}：不同种族/民族群体的生长发育水平（如身高、体重、成熟时机等）存在差异，这种差异部分是遗传因素造成的，部分反映了社会经济文化环境的差异。
\end{defbox}

\subsection{遗传模式}

\begin{defbox}
\textbf{（一）单基因遗传（Single Gene Inheritance）}

由一对等位基因控制，通常遵循孟德尔遗传定律。一般表现为质量性状（有或无），群体中呈不连续分布。如\keyword{FGFR3基因突变}导致软骨发育不全，患者平均身高仅约130cm（侏儒症）。

\textbf{（二）多基因遗传（Polygenic Inheritance）}

大多数生长发育性状由多个基因共同控制，每个基因效应微小，在群体中呈正态分布（连续分布）。身高、体重等均属此类。
\end{defbox}

\subsection{表观遗传学}

\begin{keybox}
\textbf{表观遗传学（Epigenetics）}：研究在不改变DNA序列的情况下，基因表达发生可遗传变化的学科。主要机制包括：

\begin{enumerate}[leftmargin=*]
    \item \imp{DNA甲基化}——通常抑制基因表达
    \item \imp{组蛋白修饰}——改变染色质结构，影响基因可及性
    \item \imp{基因组印记（Genomic Imprinting）}——亲本来源特异性的基因表达
    \item \imp{非编码RNA调控}
\end{enumerate}

\textbf{经典实例：}孕期暴露己烯雌酚（DES）→子代HOXA10基因启动子异常甲基化→生殖道发育异常→增加子代生殖障碍和肿瘤风险。
\end{keybox}

% ----- 3.2 环境因素 -----
\section{环境因素（教学难点*）}

\begin{defbox}
\textbf{生长发育的影响因素框架：}
\begin{center}
遗传因素（生长发育潜力、发育可能达到的最高限度）\\
$\updownarrow$ 交互作用 \\
环境因素（影响生长发育速度和最终达到的程度）
\end{center}
\end{defbox}

\subsection{自然环境因素}

\begin{keybox}
\textbf{（一）地理气候因素}

地理气候因素对生长发育产生明显影响，主要通过以下指标反映：日照时间、年均气温、年均降水量、平均地表温度、年降水量、年平均湿度、海拔高度、大气压等。

\textbf{中国学生体质与健康调研的主要发现：}
\begin{itemize}[leftmargin=*]
    \item 生长发育存在\imp{南北差异}：北方儿童青少年的身高普遍高于南方
    \item 这种差异不完全是地理气候因素的作用，还与群体发展资源、生活方式、饮食习惯及社会经济状况密切相关
    \item 2019年全国学生体质与健康调研：以秦岭-淮河为界分15个北方群体和15个南方群体，北方儿童青少年群体身高显著高于南方
\end{itemize}

\textbf{（二）季节因素}

季节对生长发育有明显影响：
\begin{itemize}[leftmargin=*]
    \item \imp{春季（3--5月）}：身高增长最快，3--5月的生长量约为9--11月的2倍左右
    \item \imp{秋季（9--11月）}：体重增长最快，全年体重增长的2/3发生在9月--次年2月
    \item 夏季较热时部分儿童体重可能减少
    \item 月经初潮也受季节影响，中国女童初潮多发生在2--3月和7--8月
\end{itemize}
\end{keybox}

\begin{defbox}
\textbf{（三）化学性环境污染}

工业生产和人类活动使自然环境中的化学组成发生变化，增加有害化学物质成分，形成化学性环境污染（Environmental Chemical Pollution）。

主要类型及影响：

\textbf{1. 大气污染}
\begin{itemize}[leftmargin=*]
    \item 大气污染物（PM$_{2.5}$、SO$_2$、NOx等）→呼吸系统发育受损
    \item 长期暴露可影响儿童肺功能发育，增加呼吸系统疾病风险
\end{itemize}

\textbf{2. 铅（Lead）}

\imp{铅对儿童发育的影响无安全阈值}：
\begin{table}[H]
\centering
\caption{不同血铅水平对儿童发育的影响}
\begin{tabularx}{\textwidth}{lX}
\hline
\textbf{血铅水平（$\mu$g/dL）} & \textbf{对儿童的影响} \\
\hline
$<$5 & 神经系统功能下降、学业成绩下降、注意力不集中、行为问题、发育迟缓 \\
5--10 & 智商降低、听力损害、生长发育迟缓、维生素D代谢障碍 \\
$>$10 & 更严重的神经发育毒性、贫血等 \\
\hline
\end{tabularx}
\end{table}

\textbf{儿童铅敏感性高的原因：}户外活动多、摄入量大（手-口行为）、吸收率高、血脑屏障发育不完全。

\textbf{3. 环境内分泌干扰物（EEDs）}

\keyword{环境内分泌干扰物（Environmental Endocrine Disrupters, EEDs）}：对环境中天然激素的生成、释放、转运、代谢、结合和功能产生干扰作用，破坏机体内环境稳定状态，对个体功能和发育产生不良影响的外源性化学物质。
\begin{itemize}[leftmargin=*]
    \item 主要类别：双酚A（BPA）、邻苯二甲酸酯、二噁英、有机氯农药等
    \item 对儿童的影响：干扰生长发育、影响神经系统发育、导致性发育异常（性早熟或延迟）、增加肥胖风险
\end{itemize}
\end{defbox}

\begin{defbox}
\textbf{（四）物理性环境污染}

\begin{itemize}[leftmargin=*]
    \item \imp{噪声污染}：影响听觉系统发育、干扰学习注意力和睡眠质量
    \item \imp{电磁辐射污染}：持续暴露可能影响神经系统发育
    \item \imp{放射性污染}
\end{itemize}
\end{defbox}

\subsection{社会环境因素}

\begin{keybox}
\textbf{社会环境（Social Environment）}：指社会存在和发展所涉及的各类物质和精神条件的总和，包括社会经济文化体系、家庭因素及人际关系等。社会环境因素与自然生态环境因素交织，对儿童生长发育产生重要且长远的影响。

\textbf{（一）社会经济状况（Socioeconomic Status, SES）}

应用最广泛的综合概念，可从多方面影响儿童生长发育：
\begin{itemize}[leftmargin=*]
    \item 经济发展水平→生活水平和物资供应
    \item 食物可及性与丰富性
    \item 医疗卫生服务质量
    \item 父母的职业、受教育程度和家庭收入
\end{itemize}

随经济发展水平提高，儿童生长发育状况呈现持续改善趋势。但当经济发展到一定阶段后，其对生长发育的促进效应减弱，其他环境指标（如父母职业、受教育程度、家庭收入等）的重要性更加突出。

\textbf{（二）医疗卫生条件}

国家或地区的经济发展水平直接影响医疗卫生事业的投入程度。医疗资源配置、卫生服务可及性与公平性、疾病防治能力等，均与人群健康状况密切相关。\imp{儿童健康状况是衡量一个国家社会、经济、文化和医疗卫生发展水平的重要指标。}
\end{keybox}

\subsection{家庭因素}

\begin{defbox}
\textbf{家庭是儿童发展的最重要环境}，良好的家庭环境可促进儿童身心健康发展，不良家庭环境影响更为深远。

\textbf{（一）家庭经济状况}

直接影响儿童的居住条件、饮食营养水平、社交活动和教育资源投入等。

\textbf{（二）父母受教育程度}

父母受教育程度是家庭社会经济状况中的重要保护因素。受教育程度高的父母更可能：
\begin{itemize}[leftmargin=*]
    \item 关注儿童营养与健康
    \item 提供良好的学习环境
    \item 采取积极的教养方式
\end{itemize}

\textbf{（三）家庭结构与家庭氛围}

单亲家庭、隔代抚养、家庭冲突等可能对儿童心理健康产生不利影响。
\end{defbox}

% ----- 3.3 基因-环境交互作用 -----
\section{基因-环境交互作用}

\begin{keybox}
\textbf{（一）基因-环境相关性（Gene-Environment Correlation, rGE）}

指基因与环境共同作用和催化变化的过程，强调个体所处环境可能受其自身遗传特征的选择影响。即遗传影响个体对环境的主动选择和被动接受。

\begin{itemize}[leftmargin=*]
    \item \imp{被动型rGE}：父母既提供基因也提供环境（如高智商父母同时提供相关基因和丰富的家庭学习环境）
    \item \imp{唤起型rGE}：个体的遗传特征引发他人的特定反应
    \item \imp{主动型rGE}：个体主动选择与其遗传倾向相符的环境
\end{itemize}

\textbf{（二）基因-环境交互作用（Gene-Environment Interaction, G×E）}

指在不同遗传背景下，相似的环境对个体的影响效应不同；同时，在不同的环境条件下，遗传对个体的影响效应也不同。

\textbf{经典实例：}母乳喂养对不同FTO基因型儿童BMI变化轨迹和BMI峰值的影响效应存在显著差异。5个月以上的纯母乳喂养可显著降低FTO高风险基因型儿童的肥胖发生风险。\imp{母乳喂养有利于降低遗传因素对儿童超重/肥胖风险的影响。}
\end{keybox}

% ----- 3.4 促进措施 -----
\section{促进生长发育的措施}

\begin{enumerate}[leftmargin=*]
    \item \imp{改善营养}——保证充足、均衡的营养供给，特别是关键期的营养
    \item \imp{疾病防治}——加强计划免疫，预防和控制感染性疾病
    \item \imp{改善生活环境}——减少环境污染暴露，创造良好的学习和生活环境
    \item \imp{健康教育}——提高家长和儿童的健康素养
    \item \imp{定期生长发育监测}——早期发现发育偏移，及时干预
    \item \imp{社会政策支持}——制定有利于儿童健康发展的公共政策
    \item \imp{促进体育活动}——保证充足的户外活动和体育锻炼
    \item \imp{心理支持}——关注儿童心理健康，创造积极的家庭和学校氛围
\end{enumerate}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{遗传度}：衡量群体中某一性状表型变异由遗传因素决定程度的指标。主要研究方法：双生子研究法（比较MZ和DZ）、全基因组关联研究（GWAS）。\textbf{追赶性生长}：见第2章。\textbf{表观遗传学}：研究不改变DNA序列而基因表达发生可遗传变化的学科。

    \item \textbf{EEDs}：干扰内源性激素正常功能、破坏机体内环境稳态的外源性化学物质。\textbf{遗传度缺失}：GWAS估计的遗传度显著低于双生子研究估计值的现象。

    \item \textbf{G×E}：不同遗传背景下相同环境的效应不同，不同环境下相同遗传的效应也不同。\textbf{家族聚集性}：某些性状在家族中出现频率高于一般人群的现象。

    \item \textbf{长期变化}：见第2章。\textbf{SES}：衡量个体或家庭社会经济地位的综合指标，包括收入、职业、受教育程度等。

    \item 遗传度反映遗传因素在表型变异中的贡献比例。双生子研究比较MZ（100\%相同基因）和DZ（约50\%）的一致性差异；GWAS在全基因组范围识别相关遗传变异。GWAS估计值通常低于双生子估计值（遗传度缺失）。

    \item 自然环境：地理气候因素（南北差异、季节差异）、化学性污染（大气污染、铅、EEDs）、物理性污染。社会环境：社会经济状况、医疗卫生条件、家庭因素（经济、父母教育、家庭结构）。

    \item 影响：神经系统功能下降、智商降低、学业成绩下降、注意力不集中、生长发育迟缓、贫血等。儿童易感性原因：户外活动多、摄入量大（手-口行为）、吸收率高、血脑屏障发育不完全。

    \item 机制：DNA甲基化、组蛋白修饰、基因组印记、非编码RNA调控。实例：孕期暴露DES→子代HOXA10甲基化异常→生殖道发育异常。

    \item G×E概念：不同遗传背景下相同环境有不同效应，反之亦然。实例：纯母乳喂养（>5个月）可降低FTO高风险基因型儿童的肥胖风险。

    \item 改善营养、疾病防治、改善生活环境、健康教育、定期监测、社会政策支持、促进体育活动、心理支持，八个方面综合推进。
\end{enumerate}
