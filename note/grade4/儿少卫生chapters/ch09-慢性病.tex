\chapter{儿童少年慢性病}
\setcounter{chapter}{9}
\chapterintro{
掌握儿童少年常见慢性病的类型；掌握儿童哮喘的流行特点、病因（遗传与环境因素）及三级预防；掌握儿童糖尿病的类型和防治；掌握儿童高血压的定义、危险因素及预防；了解儿童恶性肿瘤的类型和特点；理解生命早期干预对成人慢性病预防的重要意义。
}

\begin{defbox}
\textbf{儿童少年慢性病：}在儿童少年期起病或具有早期危险因素的慢性非传染性疾病（NCDs）。随着疾病谱从传染病向慢性病转变，儿童慢性病已成为全球重要的公共卫生问题。常见类型包括哮喘、糖尿病、高血压和恶性肿瘤。
\end{defbox}

% ----- 9.1 哮喘 -----
\section{儿童少年哮喘}

\subsection{哮喘流行特点}

\begin{keybox}
\textbf{全球：}2019年儿童哮喘死亡人数、发病率和残疾调整寿命年率分别为1.29万人[95\%UI：1.06$\sim$1.57]、2200万人（95\%UI：1500$\sim$3100）和510万人（95\%UI：340$\sim$750），与1990年相比分别下降了65.1\%、5.3\%和30\%。

\textbf{中国：}中国儿童哮喘协作组分别在1990年、2000年及2010年，采用统一问卷对全国范围内27个城市0$\sim$14岁儿童进行了三次全国儿童哮喘调查，发现城市儿童哮喘总体患病率呈上升趋势，累计患病率自1990年的1.09\%上升至2000年的1.97\%，并于2010年进一步上升至3.02\%。
\end{keybox}

\subsection{哮喘病因与影响因素}

\begin{defbox}
\textbf{遗传因素：}哮喘是易感者的基因表达、个体免疫状态、精神状态、内分泌和健康状态协同作用。

\textbf{环境因素：}
\begin{enumerate}[leftmargin=*]
    \item \imp{变应原}：是哮喘发生、发展的关键因素。变应原主要分吸入性、食物性两大类。
    \item \imp{呼吸道病毒感染}：是引起哮喘患者气道高反应性的重要原因。
    \item \imp{气候变化}：气温、气湿、气压的变化等，对哮喘发作都有诱发作用。
    \item \imp{空气污染}：工业烟雾、光化学烟雾、臭氧、氧化氮、酸性烟雾和颗粒等。
    \item \imp{食物}：许多哮喘患儿对鱼虾、腰果等食物过敏。
    \item \imp{其他因素}：较常见的物质如金首饰、香水等。
\end{enumerate}
\end{defbox}

\subsection{哮喘预防控制}

\begin{keybox}
\textbf{哮喘三级预防：}
\begin{enumerate}[leftmargin=*]
    \item \imp{一级预防}：以早期预防为主，避免接触可致敏性物质，消除一切可导致哮喘发生、发展的高危致病因素。
    \item \imp{二级预防}：目标是对出现变应性疾病"初发"症状患儿加强预防，防止其再次发作。
    \item \imp{三级预防}：着重于防止症状呈不可逆性，避免出现后遗症。
\end{enumerate}

\textbf{避免接触变应原：}积极采取各种预防措施，避免与变应原接触是关键。

\textbf{普及哮喘防控知识，倡导适度锻炼：}哮喘防治知识的宣教不仅应针对儿童和家长，还应针对周围相关人群。
\end{keybox}

% ----- 9.2 糖尿病 -----
\section{儿童糖尿病}

\begin{defbox}
\textbf{儿童糖尿病的类型：}
\begin{enumerate}[leftmargin=*]
    \item \imp{1型糖尿病（T1DM）}——儿童期最常见的糖尿病类型（占90\%以上），为自身免疫性胰岛$\beta$细胞破坏导致胰岛素绝对缺乏。发病高峰为10$\sim$14岁（青春期）。临床特点：起病急，"三多一少"（多饮、多尿、多食、体重减少）症状典型；需要终身胰岛素治疗；糖尿病酮症酸中毒（DKA）是最常见的急性并发症；慢性并发症包括微血管病变（视网膜病变、肾病、神经病变）。
    \item \imp{2型糖尿病（T2DM）}——近年来随儿童肥胖率上升而增多，以胰岛素抵抗为特征。多见于肥胖、有家族史的青少年。
    \item \imp{特殊类型糖尿病}——如青少年发病的成人型糖尿病（MODY），由单基因突变引起。
\end{enumerate}

\textbf{防治策略：}早期识别与及时诊断（警惕"三多一少"）；规范胰岛素治疗（模拟生理胰岛素分泌模式）；血糖监测（自我血糖监测和HbA1c定期检测）；医学营养治疗（个体化饮食方案）；规律运动；心理社会支持；学校管理（提供支持性环境，协助血糖监测和胰岛素使用）。
\end{defbox}

% ----- 9.3 高血压 -----
\section{儿童高血压}

\begin{defbox}
\textbf{儿童高血压：}儿童血压超过同性别、年龄和身高别的第95百分位值。

\textbf{诊断标准（中国）：}
\begin{itemize}[leftmargin=*]
    \item 正常血压：收缩压和舒张压 $<$ P90
    \item 正常高值血压（高血压前期）：P90 $\leq$ 血压 $<$ P95（或$\geq$120/80mmHg）
    \item 高血压：血压 $\geq$ P95。分两期：1期高血压（P95 $\leq$ 血压 $<$ P99 + 5mmHg）；2期高血压（血压 $\geq$ P99 + 5mmHg）
\end{itemize}

\textbf{儿童期高血压以继发性为主}（肾脏疾病是最常见继发原因）；随肥胖率上升，原发性高血压比例逐渐增加。

\textbf{主要危险因素：}\imp{超重和肥胖是最重要的可改变危险因素}；家族史；膳食因素（高盐摄入、低钾低钙饮食）；体力活动不足；静态行为过多；低出生体重；睡眠问题。

\textbf{预防与控制：}定期血压监测（3岁以上儿童每年至少测量一次血压）；生活方式干预（一线治疗——控制体重为最重要措施、减少钠盐摄入、增加蔬菜水果、每天$\geq$60min中高强度运动、减少屏幕时间）；药物治疗（生活方式干预无效或2期高血压时考虑）。
\end{defbox}

% ----- 9.4 恶性肿瘤 -----
\section{儿童恶性肿瘤}

\begin{defbox}
\textbf{儿童恶性肿瘤的特点：}
\begin{enumerate}[leftmargin=*]
    \item 与成人恶性肿瘤不同，儿童恶性肿瘤以胚胎性肿瘤和造血系统恶性肿瘤为主
    \item \imp{常见类型}：白血病（最常见，约占儿童恶性肿瘤的30\%）、脑和中枢神经系统肿瘤、淋巴瘤、神经母细胞瘤、肾母细胞瘤（Wilms瘤）、骨肉瘤
    \item 儿童恶性肿瘤总体上对治疗的反应优于成人，治愈率较高
    \item \imp{危险因素}：遗传因素（如唐氏综合征与白血病）、电离辐射暴露、某些化学物质暴露、病毒感染（如EB病毒与淋巴瘤）、免疫缺陷
\end{enumerate}

\textbf{早期发现的重要性：}儿童恶性肿瘤的早期发现和规范治疗对预后至关重要。学校卫生工作者应关注儿童的异常体征（如不明原因发热、苍白、出血倾向、肿块、不明原因疼痛等），及时转诊。
\end{defbox}

% ----- 9.5 生命早期干预的意义 -----
\section{生命早期干预对慢性病预防的意义}

\begin{keybox}
\textbf{生命早期起源假说（Barker假说/DOAD假说）：}胎儿期和生命早期的营养不良及不良暴露，可通过"编程"机制增加成年期高血压、糖尿病、冠心病等慢性病的发生风险。

\textbf{核心观点：}
\begin{enumerate}[leftmargin=*]
    \item 动脉粥样硬化的早期病变（脂纹）可在儿童期甚至婴幼儿期出现，且病变程度与心血管危险因素水平密切相关
    \item 儿童期可改变的心血管危险因素包括：血脂异常、肥胖（特别是中心性肥胖）、高血压、吸烟和二手烟暴露、缺乏体力活动、不健康膳食
    \item \imp{生命早期干预是预防成人动脉粥样硬化性心血管疾病的最有效策略}
    \item 儿童期慢性病防控对终身健康具有重要意义
\end{enumerate}
\end{keybox}

% ----- 复习题 -----
\section{复习题}

\begin{enumerate}[leftmargin=*, itemsep=8pt]
    \item \textbf{【名词解释】}支气管哮喘；1型糖尿病；儿童高血压；Barker假说（生命早期起源假说）
    \item \textbf{【简答题】}简述儿童哮喘的流行趋势、病因与三级预防策略。
    \item \textbf{【简答题】}简述儿童1型糖尿病的临床特点和防治原则。
    \item \textbf{【简答题】}简述儿童高血压的诊断标准及主要危险因素。
    \item \textbf{【简答题】}简述儿童恶性肿瘤的特点和常见类型。
    \item \textbf{【简答题】}为什么慢性病的预防应从儿童期开始？试述生命早期干预的重要意义。
\end{enumerate}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{支气管哮喘}：以慢性气道炎症和气道高反应性为特征的异质性疾病，以反复发作的喘息、咳嗽、气促、胸闷为主要临床表现，常在夜间和/或凌晨发作或加剧。\textbf{1型糖尿病}：自身免疫性胰岛$\beta$细胞破坏导致胰岛素绝对缺乏，是儿童最常见糖尿病类型（90\%以上），发病高峰为10$\sim$14岁。\textbf{儿童高血压}：血压超过同性别、年龄和身高别的P95。\textbf{Barker假说}：胎儿期和生命早期不良暴露可通过"编程"机制增加成年期慢性病风险。

    \item 流行趋势：中国城市儿童哮喘累计患病率从1990年1.09\%→2000年1.97\%→2010年3.02\%，呈上升趋势。病因：遗传因素（基因表达+免疫状态+精神状态+内分泌+健康状态协同）；环境因素（变应原为关键因素、呼吸道病毒感染、气候变化、空气污染、食物、其他如金首饰香水）。三级预防：一级（避免接触致敏物质、消除高危致病因素）、二级（对"初发"症状患儿加强预防防止再次发作）、三级（防止症状不可逆、避免后遗症）。

    \item 临床特点：起病急、"三多一少"（多饮多尿多食体重减少）、需终身胰岛素治疗、DKA是最常见急性并发症、慢性微血管病变。防治原则：早期识别诊断、规范胰岛素治疗、血糖监测（自我监测+HbA1c）、医学营养治疗、规律运动、心理社会支持、学校管理。

    \item 诊断标准：正常血压$<$P90→正常高值P90$\sim$P95→高血压$\geq$P95（分1期和2期）。儿童以继发性高血压为主（肾脏疾病最常见）。危险因素：超重肥胖（最重要可改变因素）、家族史、高盐饮食、体力活动不足、静态行为多、低出生体重、睡眠问题。防治：定期血压监测（3岁以上每年至少一次）+生活方式干预（控制体重为最重要措施）+药物治疗（必要时）。

    \item 特点：以胚胎性肿瘤和造血系统恶性肿瘤为主，对治疗反应优于成人。常见类型：白血病（最常见，约占30\%）、脑和中枢神经系统肿瘤、淋巴瘤、神经母细胞瘤、肾母细胞瘤、骨肉瘤。危险因素：遗传因素、电离辐射、化学物质、病毒感染、免疫缺陷。

    \item 动脉粥样硬化早期病变（脂纹）可在儿童期甚至婴幼儿期出现；病变程度与心血管危险因素水平密切相关；儿童期危险因素可追踪至成人；生命早期干预比成人期干预更有效；儿童期是慢性病预防的最关键窗口期。
\end{enumerate}
