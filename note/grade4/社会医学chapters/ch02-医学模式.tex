\section{医学模式的概念}

\begin{defbox}
\textbf{模式（Model）：}指从事物中抽象出某些特征，构成关于某种事物的标准形式，对人们观察、思考和解决问题起着指导作用。即人们认识和解决问题的思想和行为方式。

\textbf{医学模式（Medical Model）：}人类在与疾病抗争和认识自身生命过程的实践中得出的对健康观和疾病观等重要医学观念的本质概括。包括：医学的总体结构特征；指导医学实践的基本观点；体现以医学为对象的自然观和方法论。
\end{defbox}

\section{医学模式的演变}

\begin{keybox}
\textbf{神灵主义医学模式} → \textbf{自然哲学医学模式}（经验医学时期） → \textbf{机械论医学模式}（近代医学时期） → \textbf{生物医学模式}（现代医学时期） → \textbf{生物-心理-社会医学模式}

\textbf{生物医学模式（约1800$\sim$1970年）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{背景}：社会生产力发展，科学技术水平提高；能量守恒和转化定律、细胞学说、生物进化论三大发现；疾病的细菌学病因理论
    \item \textbf{含义}：从生物学角度认识健康与疾病，反映病因、宿主和自然环境三者内在联系的医学观和方法论
    \item \textbf{基本观点}：模式建立在生物科学基础上；流行病学三角模式（生态学模式）——健康是宿主、环境和病因三者之间的平衡，疾病则是该平衡的破坏；机体组织结构的改变和生理生化功能的异常导致疾病发生；病因多系生物的、理化的，单因单果的疾病表现形式；没有病即是健康
    \item \textbf{意义}：诊断（细胞病理学）、治疗（疼痛、感染和失血）、预防（杀菌灭虫、预防接种、抗菌药物）
    \item \textbf{不足}：强调人的生物属性，没有认识到人的社会属性；重视机体生理活动，忽视心理活动
\end{itemize}
\end{keybox}

\section{生物-心理-社会医学模式与健康观}

\subsection{产生背景}

\begin{keybox}
\textbf{1. 疾病谱和死因谱的改变}——生物医学模式使传染病防治技术取得重大突破，全球疾病和死因结构发生了显著改变，影响人群健康的主要疾病已由传染病转变为慢性非传染性疾病。

\textbf{2. 健康需求的提高}——随着生产力发展和生活水平提高，人们的健康需求日益多样化，不再仅仅满足于疾病的防治，而是积极地提高健康生活的品质。这就要求医疗卫生工作必须应对多样化的健康需求，全面满足人们生理、心理和社会的健康需求。

\textbf{3. 医学社会化}——医学是社会性的事业，承担着社会保健职能。随着城市化发展，生产和生活消费行为进一步社会化，公共卫生和社会保健问题日益突出。许多健康问题无法依靠传统的医疗卫生技术予以解决，必须采取社会化的措施才能找到解决方案。整个社会系统都承担着保健职能。

\textbf{4. 医学学科的内部融合与外部交叉发展}——在对人的疾病、健康开展微观研究的同时，必须考虑人的完整性，考虑人具有的心理属性；人的社会性决定影响人群健康因素的多样性及社会性；医学的社会化导致解决健康问题需要全社会参与。
\end{keybox}

\subsection{生物-心理-社会医学模式的内涵（难点*）}

\begin{keybox}
\textbf{含义：}指从生物、心理、社会等方面来观察、分析、思考以及处理健康与疾病相关问题的医学观和方法论。

\textbf{几种生物-心理-社会医学模式：}
\begin{itemize}[leftmargin=*]
    \item \imp{恩格尔（Engel）的医学模式}：从Person→Family→Community→Society/Nation多层次系统理解健康
    \item \imp{布鲁姆（Blum）的环境健康医学模式}：Health受Physiology、Medical Service、Psychology、Society、Behavior factors综合影响
    \item \imp{综合健康医学模式（Lalonde-Dever模式）}：由拉隆达（Lalonde）和德威尔（Dever）在布鲁姆模式基础上提出，将影响人类健康及疾病的主要因素分为\keyword{环境因素、行为生活方式、生物遗传、卫生服务}四大类，每一大类又包括三小类。认为不同的疾病四大类影响因素作用不同。
\end{itemize}

\textbf{基本内涵：}
\begin{enumerate}[leftmargin=*]
    \item 强调了心理、社会因素在医学研究系统中应有的位置
    \item 更加准确肯定了生物因素的含义和生物医学的价值
    \item 全方位探求影响人类健康与疾病的因果关系——健康问题是医学问题也是社会问题
\end{enumerate}

\textbf{对医学实践的影响——"四个扩大"：}
\begin{enumerate}[leftmargin=*]
    \item 从治疗服务扩大到预防保健服务
    \item 从生理服务扩大到心理服务
    \item 从院内服务扩大到院外服务
    \item 从技术服务扩大到社会服务
\end{enumerate}
\end{keybox}

\subsection{健康观}

\begin{keybox}
\textbf{（一）消极健康观（传统健康观）}

"无病就是健康"是传统健康观的核心。特征：(1)单一性；(2)以二元形式来记录健康（疾病或死亡的有或无）；(3)健康与否由医生作出判断。

\textbf{（二）积极健康观（WHO整体健康观）}

WHO指出："健康而且是一种躯体上、心理上和社会适应方面的完好状态，不仅仅是没有疾病和虚弱现象。"（Health is a state of complete physical, mental and social wellbeing, and not merely the absence of disease or infirmity.）

\textbf{积极健康的内容：}
\begin{enumerate}[leftmargin=*]
    \item \imp{躯体健康}：躯体的结构完好和功能正常
    \item \imp{心理健康}：正确认识自我、正确认识环境、及时适应环境
    \item \imp{社会适应能力良好}：①每个人的能力应在社会系统内得到充分的发挥；②作为健康人应有效地扮演与其身份相适应的角色；③每个人的行为与社会规范相一致
\end{enumerate}

\textbf{积极健康观的特征：}
\begin{enumerate}[leftmargin=*]
    \item \imp{健康具有多维性}：包括身体健康、心理健康、社会健康、角色功能和健康感觉。疾病（disease，生物尺度）、病患（illness，感觉尺度）、患病（sickness，行动尺度）
    \item \imp{健康具有连续性}：健康谱——从完全健康到最差的健康状态或死亡是个连续变化的谱级。亚健康状态：虽无明显的疾病，但呈现活力降低、适应力不同程度减退的生理状态。亚临床状态：没有临床症状体征，但存在生理性代偿或病理性改变的临床检测证据
    \item \imp{健康描述的功能性}：着重于处于某种健康状态下的个人其行为能力如何，即用行为或功能术语表述健康
\end{enumerate}

\textbf{健康概念的扩展：}从个体健康扩大到群体健康，以及人类生存空间的完美。如健康社区、健康城市、健康国家（如健康中国2030）。树立"人人为健康，健康为人人"的正确概念，把健康问题看作是全社会、全民的事业。
\end{keybox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{医学模式}：人类在与疾病抗争和认识自身生命过程的实践中得出的对健康观和疾病观等重要医学观念的本质概括。\textbf{生物医学模式}：从生物学角度认识健康与疾病，反映病因、宿主和自然环境三者内在联系的医学观和方法论。\textbf{生物-心理-社会医学模式}：从生物、心理、社会等方面来观察分析和处理健康与疾病相关问题的医学观和方法论。\textbf{综合健康医学模式（Lalonde-Dever）}：将影响健康的因素分为环境因素、行为生活方式、生物遗传、卫生服务四大类。
    \item \textbf{消极健康观}："无病就是健康"，特征为单一性、二元形式、医生判断。\textbf{积极健康观}：WHO定义——躯体上、心理上和社会适应方面的完好状态，不仅仅是没有疾病和虚弱。\textbf{亚健康}：虽无明显疾病但活力降低、适应力减退的生理状态。\textbf{亚临床}：无临床症状体征但存在生理性代偿或病理性改变的检测证据。
    \item 神灵主义医学模式→自然哲学医学模式（经验医学）→机械论医学模式（近代医学）→生物医学模式（现代医学约1800-1970）→生物-心理-社会医学模式。
    \item 基本观点：建立在生物科学基础上；流行病学三角模式（健康是宿主-环境-病因平衡）；组织结构改变和生理生化异常导致疾病；病因多系生物理化单因单果；无病即健康。不足：强调生物属性忽视社会属性；重视生理活动忽视心理活动。
    \item (1)疾病谱和死因谱改变（传染病→慢性非传染病）；(2)健康需求提高（多样化、品质化）；(3)医学社会化（公共卫生问题突出、需社会化措施）；(4)医学学科内部融合与外部交叉发展（需考虑人的完整性和心理属性）。
    \item 基本内涵：(1)强调心理社会因素应有位置；(2)更准确肯定生物因素含义和生物医学价值；(3)全方位探求影响健康的因果关系。四个扩大：治疗→预防保健、生理→心理、院内→院外、技术→社会。
    \item 由Lalonde和Dever在Blum环境健康医学模式基础上提出，将影响健康的因素分为四大类：环境因素、行为生活方式、生物遗传、卫生服务，每大类又包括三小类。不同疾病四大类因素作用不同。
    \item 内容：躯体健康（结构完好功能正常）+心理健康（正确认识自我/环境/及时适应）+社会适应良好（能力发挥+角色扮演+行为规范一致）。特征：(1)多维性（身体健康+心理健康+社会健康+角色功能+健康感觉，disease/illness/sickness三维度）；(2)连续性（健康谱、亚健康和亚临床状态）；(3)功能性（用行为或功能术语表述健康）。
\end{enumerate}
