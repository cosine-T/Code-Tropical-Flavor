\chapter{社会经济因素与健康}
\setcounter{chapter}{4}
\chapterintro{
掌握经济发展水平与健康的双向作用（难点*）；熟悉经济发展的衡量指标（GDP/GNP/HDI等）和健康的衡量指标；熟悉健康投资的内涵；了解经济发展与卫生服务的关系。
}

\section{基本内涵及衡量指标}

\subsection{经济发展的衡量指标}

\begin{defbox}
\textbf{经济}是指一个国家国民经济的总称。\textbf{经济发展（Economic Development）}是人类不断改善生产生活质量、逐步摆脱贫困落后状态、持续提高社会经济福利的过程，其终极目标落脚于人们幸福生活的最终实现。

\textbf{传统指标：}GDP（国内生产总值）、GNP（国民生产总值）、人均GDP、人均GNP、卫生总费用（Total Health Expenditure, THE）、人均卫生总费用。

\textbf{新的衡量指标（关注可持续性发展）：}人类发展指数（HDI）、真实发展指标（GPI）、国民幸福指数（NHI）、全球幸福指数（GHI）、物质生活质量指数（PQLI）。
\end{defbox}

\subsection{健康的衡量指标}

\begin{defbox}
人群健康状况指标：期望寿命（Expectancy life）、婴儿死亡率（Infant mortality rate）、孕产妇死亡率（Maternal mortality rate）、发病率（incidence rate）、患病率（prevalence rate）、健康期望寿命（Healthy life expectancy）、伤残调整生命年（DALYs）。
\end{defbox}

\section{经济发展与健康}

\begin{keybox}
\textbf{经济发展与健康的双向性作用关系：}健康水平的提高 ↔ 经济发展 ↔ 带来健康新问题。

\textbf{一、经济发展对健康的促进作用及途径}
\begin{enumerate}[leftmargin=*]
    \item 经济发展提高了居民物质生活水平，提供了保障人群健康的生活条件
    \item 经济发展有利于增加健康投资
    \item 经济发展可通过影响其它途径（如教育）促进人群健康
\end{enumerate}

\textbf{二、经济发展对健康促进作用的有限性}

经济增长与健康水平之间并不存在必然联系。当经济发展到一定水平，影响健康的不再是经济的绝对水平，而是社会经济的公平性。Wilkinson指出：在发达国家，健康水平最高的不是那些最富有的国家，而是那些最具有社会公平性的国家。

\textbf{三、经济发展带来的新问题}
\begin{enumerate}[leftmargin=*]
    \item 环境的污染和生态破坏（公害病、已有疾病加重、常见病更为频发）
    \item 生活方式改变（营养、身体活动）
    \item \imp{现代社会病的产生}——随着现代科技高速发展，由新的生活方式所带来的一系列疾病和社会现象，如"富贵病"和"文明病"（肥胖、高血压、糖尿病、性病、车祸、吸毒、新的成瘾性疾病等）
    \item 心理健康问题的凸显——社会竞争加剧、生存压力加大、导致心身疾病、严重者可致精神病甚至自杀和报复性他杀
    \item 负性社会事件增多
    \item 社会人口特征剧烈变化（老龄化、社会流动人口增加→疾病传播+卫生服务提供）
\end{enumerate}

\textbf{四、健康对经济发展的作用}
\begin{enumerate}[leftmargin=*]
    \item 增加劳动力供给（平均寿命延长）
    \item 提高劳动生产率（劳动效率提高、伤病减少、出勤增加）
    \item 减少疾病损失，减少资源消耗
    \item 促进教育受益实现
    \item 促进自然资源利用
\end{enumerate}
\end{keybox}

\section{经济发展与健康投资}

\begin{defbox}
\textbf{健康投资（Health Investment）：}指人们为了获得良好的健康而消费的食品、闲暇时间和卫生服务的资源。WHO提出投资于健康的理念（宏观经济与卫生）。

\textbf{目的：}维持或提高现有健康存量（耐久资本）。健康存量增加：吸收营养、接受卫生服务、运动锻炼、教育等（健康投资）。健康存量减少：疾病、营养不良、衰老、劳损等（折旧）。

\textbf{意义：}减轻潜在疾病的经济负担；改善人群的健康水平；促进经济发展、社会进步和国家安全。

\textbf{投资主体：}私人健康人力资本投资（家庭营养保健支出、医疗私人支出、居住环境改善、休息等）+ 公共健康人力资本投资（医疗卫生设施建设、公共卫生环境建设、医疗工作者薪酬支付、居民医疗补贴等）。

\textbf{健康投资效益：}两个效益——经济效益和社会效益；两个层面——微观和宏观。经济效益：个体/家庭收入水平增加和宏观经济增长。社会效益：个体幸福感提高和社会和谐稳定。
\end{defbox}

\section{复习题}

\begin{enumerate}[leftmargin=*, itemsep=8pt]
    \item \textbf{【名词解释】}经济发展；GDP；卫生总费用；健康投资；HDI
    \item \textbf{【简答题】}试述经济发展与健康的双向性作用关系。
    \item \textbf{【简答题】}简述经济发展给健康带来的新问题。
    \item \textbf{【简答题】}简述健康对经济发展的促进作用。
    \item \textbf{【简答题】}简述健康投资的内涵和意义。
\end{enumerate}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{经济发展}：人类不断改善生产生活质量、逐步摆脱贫困落后状态、持续提高社会经济福利的过程。\textbf{GDP}：一个国家或地区范围内所有常住单位在一定时期内生产最终产品和提供劳务价值的总和。\textbf{卫生总费用}：在一定时期内为提供卫生服务所消耗的经济资源。\textbf{健康投资}：人们为了获得良好健康而消费的食品、闲暇时间和卫生服务的资源。\textbf{HDI}：人类发展指数，新型经济发展衡量指标。
    \item 双向作用：(1)经济发展对健康的促进作用（提高生活水平、增加健康投资、通过教育等途径促进健康）；(2)健康对经济的促进作用（增加劳动力供给、提高劳动生产率、减少疾病损失和资源消耗、促进教育受益和自然资源利用）。有限性：经济增长与健康水平不存在必然联系，影响健康的是社会经济公平性。
    \item (1)环境的污染和生态破坏；(2)生活方式改变；(3)现代社会病的产生——"富贵病""文明病"（肥胖、高血压、糖尿病等）；(4)心理健康问题凸显（竞争加剧、心身疾病）；(5)负性社会事件增多；(6)社会人口特征剧烈变化（老龄化、流动人口增加）。
    \item (1)增加劳动力供给（平均寿命延长）；(2)提高劳动生产率（效率提高+伤病减少+出勤增加）；(3)减少疾病损失，减少资源消耗；(4)促进教育受益实现；(5)促进自然资源利用。
    \item 内涵：为了获得良好健康而消费的食品、闲暇时间和卫生服务的资源，目的是维持或提高健康存量。意义：减轻潜在疾病经济负担、改善人群健康水平、促进经济发展/社会进步/国家安全。投资主体包括私人和公共健康人力资本投资。效益：经济效益（个体收入+宏观增长）+社会效益（幸福感+社会和谐）。
\end{enumerate}
