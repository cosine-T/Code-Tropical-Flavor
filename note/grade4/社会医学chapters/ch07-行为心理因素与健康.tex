\section{心理因素与健康}

\subsection{人格与健康}

\begin{defbox}
\textbf{人格（Personality）}：个体在遗传基础上，通过与后天环境的交互作用而形成的相对稳定、独特的心理行为模式的总和。
\end{defbox}

\end{keybox}

\subsection{认知与健康}

\begin{defbox}
\textbf{认知（Cognition）}是人们对客观事物进行信息加工的认识过程，包括感觉、知觉、记忆、思维、想象和语言等。认知方式影响人们对健康信息的获取、理解和运用，以及疾病应对策略的选择。
\end{defbox}

\subsection{心理压力与健康（教学难点*）}

\begin{keybox}
\imp{（教学难点*）}\textbf{心理压力（Psychological Stress）的基本理论：}

\textbf{1. Selye的应激理论（General Adaptation Syndrome, GAS）：}\\
加拿大生理学家Hans Selye提出，应激是机体对各种刺激的非特异性反应，分为三个阶段：
\begin{enumerate}[leftmargin=*]
    \item \imp{警觉反应阶段（Alarm Reaction）}：机体识别应激源，启动"战斗或逃跑"（Fight or Flight）反应，交感神经系统和下丘脑-垂体-肾上腺轴（HPA轴）激活
    \item \imp{抵抗阶段（Resistance）}：机体适应持续存在的应激源，维持较高的生理激活水平，若适应成功则恢复
    \item \imp{衰竭阶段（Exhaustion）}：如果应激持续存在且机体资源耗尽，适应能力下降，导致疾病或死亡
\end{enumerate}

\textbf{2. Lazarus的认知评价理论：}\\
压力不是客观刺激本身，而是个体对刺激的主观认知评价结果。三个阶段：
\begin{enumerate}[leftmargin=*]
    \item \imp{初级评价（Primary Appraisal）}：评价刺激是否构成威胁
    \item \imp{次级评价（Secondary Appraisal）}：评价自己的应对资源和能力
    \item \imp{重新评价（Reappraisal）}：根据新信息和新经验对刺激和应对能力重新评估
\end{enumerate}

\textbf{3. 持久过大压力的不良后果：}
\begin{enumerate}[leftmargin=*]
    \item 心理障碍——焦虑症、抑郁症、创伤后应激障碍（PTSD）、职业倦怠（Burnout）
    \item 心身疾病——冠心病、高血压、消化性溃疡、哮喘、免疫功能下降
    \item 行为问题——物质滥用（酒精、烟草、成瘾药物）、饮食紊乱、社交退缩
    \item 认知功能下降——注意力、记忆力、决策能力受损
\end{enumerate}
\end{keybox}

% ----- 7.2 健康相关行为 -----
\section{健康相关行为}

\subsection{行为与健康相关行为}

\begin{defbox}
\textbf{行为（Behavior）}：个体在内外环境刺激作用下产生的可观察的反应和活动。

\textbf{健康相关行为（Health-related Behavior）}：个体或群体与健康和疾病有关的行为。分为两类：
\begin{itemize}[leftmargin=*]
    \item \imp{促进健康行为（Health-promoted Behavior）}：有利于健康的行为，如合理饮食、定期锻炼、规律作息、遵医行为等
    \item \imp{危害健康行为（Health-risky Behavior）}：不利于健康或导致疾病的行为，如吸烟、酗酒、吸毒、不合理饮食、缺乏运动等
\end{itemize}
\end{defbox}

\subsection{健康相关行为的基本特征}

\begin{enumerate}[leftmargin=*]
    \item \imp{习得性}：健康行为大多是通过学习和经验积累获得的，非先天固有
    \item \imp{稳定性与可变性}：行为一旦形成具有一定稳定性，但可通过干预改变
    \item \imp{可干预性}：行为是可改变的，通过健康教育、政策引导等手段进行干预
    \item \imp{社会性}：行为受社会文化、经济、制度等社会因素影响
    \item \imp{累积性}：行为的健康效应是长期累积的结果
\end{enumerate}

\subsection{健康行为的观点与理论（教学难点*）}

\begin{keybox}
\imp{（教学难点*）}\textbf{健康行为改变的主要理论：}

\textbf{1. 知信行模式（Knowledge-Attitude-Behavior Model, KAB/KAP）：}
\begin{itemize}[leftmargin=*]
    \item 知识（Knowledge）→ 信念/态度（Attitude）→ 行为（Behavior）
    \item 认为健康知识是形成正确健康信念和态度的基础，健康信念和态度是行为改变的动力
    \item 局限性：知信行过程不是简单的线性关系，存在"知行不一"现象
\end{itemize}

\textbf{2. 健康信念模型（Health Belief Model, HBM）：}\\
由Rosenstock等提出，认为人们采取健康行为取决于以下五个因素：
\begin{enumerate}[leftmargin=*]
    \item \imp{感知到易感性（Perceived Susceptibility）}：认为自己可能患某种疾病
    \item \imp{感知到严重性（Perceived Severity）}：认为疾病会带来严重后果
    \item \imp{感知到益处（Perceived Benefits）}：认为采取健康行为有好处
    \item \imp{感知到障碍（Perceived Barriers）}：认识到采取健康行为的障碍和代价
    \item \imp{行动线索（Cues to Action）}：激发行为改变的内外提示
\end{enumerate}

\textbf{3. 阶段变化理论（Transtheoretical Model, TTM）：}\\
由Prochaska和DiClemente提出，行为改变经历五个阶段：
\begin{enumerate}[leftmargin=*]
    \item 无意图期（Precontemplation）——未考虑改变
    \item 意图期（Contemplation）——开始考虑改变
    \item 准备期（Preparation）——准备采取行动
    \item 行动期（Action）——已开始改变行为
    \item 维持期（Maintenance）——持续保持新行为
\end{enumerate}

\textbf{4. 计划行为理论（Theory of Planned Behavior, TPB）：}\\
行为意向受三个因素影响：①行为态度；②主观规范；③知觉行为控制。
\end{keybox}

% ----- 7.3 行为心理问题的干预 -----
\section{行为心理问题的干预}

\begin{enumerate}[leftmargin=*]
    \item \imp{健康教育与健康促进}：提高健康素养，传播健康知识，塑造积极态度和行为
    \item \imp{认知行为治疗（CBT）}：改变不良认知模式和行为习惯
    \item \imp{行为矫正（Behavior Modification）}：运用正负强化、替代学习等手段
    \item \imp{环境干预}：改变社会环境以支持健康行为（限烟区、健康食堂等）
    \item \imp{政策法规干预}：立法限制危害健康行为（公共场所禁烟、酒驾处罚等）
    \item \imp{社区干预}：以社区为基础的综合性行为干预项目
\end{enumerate}

% ----- 7.4 吸烟与控烟 -----
\section{吸烟与控烟}

\subsection{吸烟的健康危害}

\begin{keybox}
\textbf{吸烟是最重要的可预防性致死原因。}
\begin{itemize}[leftmargin=*]
    \item 吸烟与肺癌、COPD、冠心病、脑卒中等25种以上疾病密切相关
    \item 中国是全球最大的烟草消费国和生产国，吸烟人数约3.5亿
    \item \imp{二手烟（被动吸烟）}同样严重危害健康，无"安全"暴露水平
    \item \imp{三手烟（环境烟草烟雾残留）}也存在潜在健康危害
    \item 每年全球约800万人死于烟草相关疾病（其中约100万死于被动吸烟）
\end{itemize}
\end{keybox}

\subsection{控烟的政策措施}

\begin{enumerate}[leftmargin=*]
    \item \imp{WHO《烟草控制框架公约》（FCTC）}——首个国际公共卫生条约（2003年通过）
    \item \imp{MPOWER六大控烟策略}（WHO，2008年）：
    \begin{itemize}
        \item \textbf{M}onitor——监测烟草使用和预防政策
        \item \textbf{P}rotect——保护人们免受烟草烟雾危害（无烟环境立法）
        \item \textbf{O}ffer——提供戒烟帮助
        \item \textbf{W}arn——警示烟草危害（图形健康警示标签）
        \item \textbf{E}nforce——禁止烟草广告、促销和赞助
        \item \textbf{R}aise——提高烟草税和价格（最有效的单项措施）
    \end{itemize}
    \item \imp{中国控烟措施}：《烟草控制法》推进、公共场所禁烟令、烟草税上调、烟盒警示标签
\end{enumerate}

\subsection{控烟倡导运动}

\begin{defbox}
\textbf{倡导（Advocacy）}：为动员政治和社会力量，推动政策改变和资源分配而采取的有组织的社会行动。控烟倡导通过四个方面——收集证据、建立联盟、媒体宣传、政策对话——推动控烟立法和政策实施。
\end{defbox}

\subsubsection*{二、名词解释}
\begin{enumerate}[leftmargin=*]
    \item \textbf{健康相关行为}：个体或群体与健康和疾病有关的行为，分为促进健康行为和危害健康行为两类。
    \item \textbf{知信行模式}：健康行为改变的理论模式，认为知识是态度/信念的基础，态度/信念是行为改变的动力，路径为知识→信念→行为。
    \item \textbf{倡导}：为动员政治和社会力量推动政策改变和资源分配而采取的有组织社会行动。
    \item \textbf{GAS}：Selye提出的应激反应三阶段模型——警觉反应、抵抗和衰竭阶段。
\end{enumerate}

\subsubsection*{三、简答题}
\begin{enumerate}[leftmargin=*]
    \item 三阶段：①警觉反应——机体识别应激源，交感神经和HPA轴激活，"战斗或逃跑"；②抵抗——适应持续应激源，维持高生理激活水平；③衰竭——资源耗尽，适应能力下降，导致疾病或死亡。
    \item 五要素：感知到易感性、感知到严重性、感知到益处、感知到障碍、行动线索。人们采取健康行为的可能性取决于对疾病的威胁感知和改变行为的利弊权衡。
    \item 五大特征：习得性、稳定性与可变性、可干预性、社会性、累积性。
    \item Monitor（监测）、Protect（无烟环境保护）、Offer（提供戒烟帮助）、Warn（警示危害）、Enforce（禁止烟草广告促销赞助）、Raise（提高烟草税价）。烟草税是最有效的单项措施。
    \item 主要方法：健康教育与健康促进、认知行为治疗（CBT）、行为矫正（正负强化）、环境干预（限烟区、健康食堂）、政策法规干预（禁烟令等）、社区综合性干预。
\end{enumerate}
