\section{卫生服务研究概述}

\begin{defbox}
\textbf{卫生服务研究（Health Services Research）：}是探讨卫生服务的需要、需求、利用以及卫生资源的配置、卫生服务的质量等方面的问题，为卫生事业管理提供科学依据的研究领域。

\textbf{研究内容：}卫生服务需要/需求/利用、卫生资源配置、卫生服务质量、卫生服务评价等。

\textbf{研究方法：}描述性研究、分析性研究、实验性研究、评价性研究等。
\end{defbox}

\section{卫生服务需要、需求与利用（难点*）}

\begin{keybox}
\textbf{（一）基本概念}

\begin{itemize}[leftmargin=*]
    \item \imp{卫生服务需要（Health Services Need）}：依据人们的实际健康状况与"理想健康状态"之间存在差距而提出的对医疗、预防、保健、康复等服务的客观需要，包括个人觉察到的需要和由医疗卫生专业人员判定的需要。分为\imp{觉察到的需要（Perceived Need）}和\imp{潜在需要（Potential Need）}
    \item \imp{卫生服务需求（Health Services Demand）}：在一定时期内、一定价格水平上，人们愿意而且能够购买的卫生服务量
    \item \imp{卫生服务利用（Health Services Utilization）}：实际发生的卫生服务的消费量，即有效需求量
\end{itemize}

\textbf{（二）需要与需求的相互关系}

需要是需求的前提，但需要不一定转化为需求。需要>需求（有需要但无购买意愿或能力）；需要<需求（无实际需要但产生需求，如过度诊疗）。

\textbf{（三）影响卫生服务需要与利用的因素：}人口因素、经济因素、文化教育因素、卫生资源配置、医疗保障制度等。

\textbf{（四）卫生服务需要常用指标：}
\begin{itemize}[leftmargin=*]
    \item 疾病频率指标：两周患病率 = 两周内患病人数/调查人数 × 100\%
    \item 慢性病患病率 = 慢性病患病人数/调查人数 × 100\%
    \item 疾病严重程度指标：两周卧床率、两周休工/休学率、两周活动受限率
\end{itemize}

\textbf{（五）卫生服务利用常用指标：}
\begin{itemize}[leftmargin=*]
    \item 两周就诊率 = 两周内就诊人次数/调查人数 × 100\%
    \item 年住院率 = 年住院人次数/调查人数 × 100\%
    \item 未就诊率、未住院率
\end{itemize}
\end{keybox}

\section{卫生资源}

\begin{defbox}
\textbf{卫生资源（Health Resources）：}是指提供卫生服务所需的人力、经费、设施、装备、药品、信息和知识技术等资源的总称。

\textbf{卫生人力资源（Health Manpower）：}是卫生资源最重要的组成部分，研究内容包括卫生人员数量、结构（学历/职称/专业/年龄）、分布（地区/城乡/机构间）。

\textbf{卫生费用（Health Expenditure）：}研究内容包括卫生费用来源（政府/社会/个人）、卫生费用分类（经常性费用/投资性费用）、卫生费用评价指标（卫生总费用占GDP百分比、人均卫生费用、政府卫生支出占财政支出百分比等）。
\end{defbox}

\section{卫生服务综合评价（难点*）}

\begin{defbox}
卫生服务综合评价是通过对卫生服务需要、卫生服务利用和卫生服务资源三个方面的综合测量，评价卫生服务的效率、效益和效果。评价框架包括：高需要/低利用→资源不足；高需要/高利用→资源效率高；低需要/高利用→可能存在过度利用；低需要/低利用→资源闲置等。
\end{defbox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{卫生服务研究}：探讨卫生服务需要/需求/利用以及卫生资源配置、服务质量等问题的研究领域。\textbf{卫生服务需要}：依据实际健康状况与"理想健康状态"的差距而提出的对预防/医疗/保健/康复服务的客观需要，分觉察到的需要和潜在需要。\textbf{卫生服务需求}：在一定时期和价格水平上人们愿意且能够购买的卫生服务量。\textbf{卫生服务利用}：实际发生的卫生服务消费量，即有效需求量。
    \item \textbf{卫生资源}：提供卫生服务所需的人力/经费/设施/装备/药品/信息/知识技术等总称。\textbf{卫生人力资源}：卫生资源最重要的组成部分，研究内容包括数量/结构/分布。\textbf{卫生费用}：广义指一定时期内为提供卫生服务所消耗的经济资源。
    \item 需要是需求的前提，但需要不一定转化为需求。需要>需求（有需要但无购买意愿或能力）；需要<需求（无实际需要但产生需求如过度诊疗）。利用是实际发生的消费量=有效需求量。
    \item 人口因素、经济因素、文化教育因素、卫生资源配置、医疗保障制度等。
    \item 需要指标：两周患病率、慢性病患病率、两周卧床率/休工休学率/活动受限率。利用指标：两周就诊率、年住院率、未就诊率、未住院率。
\end{enumerate}
