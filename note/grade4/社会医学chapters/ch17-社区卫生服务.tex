\section{社区与社区卫生服务概述}

\subsection{社区}

\begin{defbox}
\textbf{社区（Community）：}
\begin{enumerate}[leftmargin=*]
    \item 以一定地理区域为基础的社会群体
    \item 由具有共同文化、共同利益和共同意识的人群组成的社会单位
    \item WHO定义：社区是指一固定的地理区域范围内的社会团体，其成员有着共同的兴趣，彼此认识且互相来往，行使社会功能，创造社会规范，形成特有的价值体系和社会福利事业
\end{enumerate}

\textbf{构成社区的要素：}(1)一定的人口（人的因素）；(2)一定的地域（空间因素）；(3)一定的生活服务设施；(4)特有的文化背景和生活方式；(5)一定的生活制度和管理机构。

\textbf{社区类型：}地域型社区（城市社区、农村社区）、功能型社区（企业/学校/军营等）。
\end{defbox}

\subsection{社区卫生服务}

\begin{keybox}
\textbf{社区卫生服务（Community Health Service, CHS）：}是社区建设的重要组成部分，是在政府领导、社区参与、上级卫生机构指导下，以基层卫生机构为主体，全科医师为骨干，合理使用社区资源和适宜技术，以人的健康为中心、家庭为单位、社区为范围、需求为导向，以妇女、儿童、老年人、慢性病人、残疾人、贫困居民等为重点，以解决社区主要卫生问题、满足基本卫生服务需求为目的，融预防、医疗、保健、康复、健康教育、计划生育技术服务功能等为一体的，有效、经济、方便、综合、连续的基层卫生服务。

\textbf{CHS的对象：}全体社区居民，包括健康人群、亚健康人群、高危人群、重点保健人群（妇女/儿童/老年人/慢性病人/残疾人/贫困居民）和病人。

\textbf{全科医学（General Practice）：}是整合临床医学、预防医学、康复医学以及人文社会学科相关内容为一体的综合性医学专业学科，是社区卫生服务的核心学科。

\textbf{CHS的特点（难点*）：}
\begin{enumerate}[leftmargin=*]
    \item \imp{以健康为中心}——非以疾病为中心
    \item \imp{以人群为对象}——非以个体为对象
    \item \imp{以家庭为单位}——考虑家庭背景进行综合服务
    \item \imp{以社区为范围}——主动服务于社区中全体居民
    \item \imp{提供综合服务}——融预防、医疗、保健、康复、健康教育、计划生育技术服务六位一体
    \item \imp{提供连续性服务}——从生到死的全程服务
    \item \imp{提供可及性服务}——地理上接近、技术上适宜、经济上可负担
    \item \imp{提供协调性服务}——协调利用各种资源
    \item \imp{提供个体化服务}——以人为本
    \item \imp{以需求为导向}——根据居民需求确定服务内容
\end{enumerate}

\textbf{CHS的服务方式：}门诊服务、出诊/家庭访视、家庭病床、社区急救、转诊服务、健康管理服务等。
\end{keybox}

\subsection{社区卫生服务的意义}

\begin{defbox}
\begin{enumerate}[leftmargin=*]
    \item 是提供基本卫生服务、满足人民群众日益增长的卫生服务需求的重要途径
    \item 是深化卫生改革、建立与社会主义市场经济体制相适应的城市卫生服务体系的重要基础
    \item 是建立城镇职工基本医疗保险制度的迫切要求
    \item 是加强社会主义精神文明建设、密切党群干群关系、维护社会稳定的重要途径
    \item 是逐步实现"人人享有卫生保健"目标的重要策略
\end{enumerate}
\end{defbox}

\section{社区卫生服务的管理（难点*）}

\begin{defbox}
\textbf{CHS管理的内容：}
\begin{enumerate}[leftmargin=*]
    \item \imp{组织管理}：建立健全社区卫生服务网络，明确各级各类机构的职责和任务
    \item \imp{人员管理}：全科医师、社区护士等社区卫生服务人员的培训、考核和管理
    \item \imp{质量管理}：建立服务质量标准和评价体系
    \item \imp{信息管理}：建立居民健康档案，实施信息化管理
    \item \imp{财务管理}：合理使用社区卫生服务经费
    \item \imp{绩效评价}：对社区卫生服务的效率、效益、效果进行综合评估
\end{enumerate}

\textbf{绩效评价维度：}可及性、有效性、效率、公平性、满意度等。
\end{defbox}

    \item \textbf{【名词解释】}社区；社区卫生服务（CHS）；全科医学
    \item \textbf{【简答题】}简述构成社区的五大要素。
    \item \textbf{【简答题】}简述社区卫生服务的特点（难点*）。
    \item \textbf{【简答题】}简述社区卫生服务的对象和意义。
    \item \textbf{【简答题】}简述社区卫生服务管理的主要内容。
\end{enumerate}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{社区}：一固定地理区域范围内的社会团体，成员有共同兴趣/彼此认识/互相来往/行使社会功能/创造社会规范/形成特有价值体系和社会福利事业。\textbf{CHS}：社区建设的重要组成部分，在政府领导/社区参与/上级指导下的基层卫生服务，六位一体。\textbf{全科医学}：整合临床/预防/康复医学及人文社会学科为一体的综合性医学专业学科，社区卫生服务的核心学科。
    \item 五大要素：(1)一定的人口；(2)一定的地域；(3)一定的生活服务设施；(4)特有的文化背景和生活方式；(5)一定的生活制度和管理机构。
    \item 十大特点：(1)以健康为中心；(2)以人群为对象；(3)以家庭为单位；(4)以社区为范围；(5)提供综合服务（六位一体：预防/医疗/保健/康复/健康教育/计划生育技术）；(6)连续性服务；(7)可及性服务；(8)协调性服务；(9)个体化服务；(10)以需求为导向。
    \item 对象：健康人群+亚健康人群+高危人群+重点保健人群（妇女/儿童/老年人/慢性病人/残疾人/贫困居民）+病人。意义：(1)满足基本卫生服务需求的重要途径；(2)深化卫生改革建立服务体系的重要基础；(3)建立医保制度的迫切要求；(4)加强精神文明建设维护社会稳定；(5)实现"人人享有卫生保健"目标的重要策略。
    \item 六大内容：组织管理、人员管理、质量管理、信息管理、财务管理、绩效评价（可及性/有效性/效率/公平性/满意度等维度）。
\end{enumerate}
