% ----- 第一节 营养学与食品卫生学的定义 -----
\section{营养学与食品卫生学的定义}

\begin{keybox}
\textbf{营养学与食品卫生学的定义：}

\textbf{营养与食品卫生学（nutrition and food hygiene）：}研究膳食与机体的相互作用及其对健康的影响、作用机制以及据此提出预防疾病、保护和促进健康的措施、政策、法规等。

\textbf{营养：}机体从外界摄取食物，经过体内消化、吸收和（或）代谢后，或参与构建组织器官，或满足生理功能和体力活动需要的必要生物学过程。

\textbf{营养学：}研究食物中对人体有益的成分及人体摄取和利用这些成分以维持、促进健康的规律和机制，在此基础上采取具体的、宏观的、社会性措施改善人类健康、提高生命质量。包括三大领域：食物营养（营养素、食物、烹调方式）、人群营养（生命早期、儿童青少年、老年）、公共营养（DRIs、膳食指南）。基础营养、食物营养、公共营养、特殊人群营养、临床营养。

\textbf{食品卫生学：}研究食物中可能存在的、危害人体健康的有害因素及其对机体的作用规律和机制，在此基础上提出具体、宏观的预防措施，以提高食品卫生质量，保护食用者安全。
\end{keybox}

% ----- 第二节 营养学与食品卫生学的联系与区别 -----
\section{营养学与食品卫生学的联系与区别}

\begin{keybox}
\textbf{营养学与食品卫生学的联系与区别：}

\imp{联系：}从广义上讲，两者有共同的研究对象：\keyword{食物（food）}和\keyword{人体}，即研究食物（饮食）与健康的关系。

\imp{区别：}从狭义上讲，两者在具体研究目标、研究目的、研究方法和理论体系等方面各不相同。\imp{营养学是研究食物中的有益成分与健康的关系}，\imp{食品卫生学则是研究食物中有害因素与健康的关系}。
\end{keybox}

% ----- 第三节 近代主要关注的问题 -----
\section{营养学发展的历史及展望（了解）}

\begin{tipbox}
\textbf{营养学发展的历史：}
\begin{itemize}[leftmargin=*]
    \item \textbf{古代：}经验性认识食物与健康关系。中国春秋战国时期《黄帝内经》已有``五谷为养，五果为助，五畜为益，五菜为充''的膳食论述
    \item \textbf{18-19世纪（现代营养学的萌芽）：}Lavoisier首次阐明能量代谢的氧化本质；Liebig提出蛋白质是机体最主要的功能物质
    \item \textbf{20世纪（营养学的蓬勃发展）：}发现必需氨基酸、必需脂肪酸、各种维生素，提出RDA和DRIs概念
    \item \textbf{21世纪（分子营养学时代）：}营养与基因关系研究（营养基因组学）、营养与慢性病预防、功能食品开发
\end{itemize}

\textbf{展望：}
\begin{itemize}[leftmargin=*]
    \item 精准营养：基于个体基因组成、代谢特征和肠道微生物组的个性化营养
    \item 营养与慢性病：从营养素预防慢性病的作用机制到膳食模式干预
    \item 可持续营养：关注食物系统与环境可持续性的关系
    \item 食物成分数据库与生物信息学的结合
\end{itemize}
（来源：0613营养笔记概述）
\end{tipbox}

\section{食品卫生学发展的历史与展望（了解）}

\begin{tipbox}
\textbf{食品卫生学发展的历史：}
\begin{itemize}[leftmargin=*]
    \item \textbf{古代：}《唐律疏议》已有关于不洁食物致病的记载和处罚规定
    \item \textbf{19世纪：}食品化学污染物和微生物污染的发现推动了食品卫生学发展
    \item \textbf{20世纪：}食品安全法规体系建立，FAO/WHO食品法典委员会（CAC）成立，农药残留、食品添加剂的安全评价体系逐步完善
    \item \textbf{21世纪：}食品安全风险分析框架（风险评估、风险管理、风险交流）成为国际共识
\end{itemize}

\textbf{展望：}
\begin{itemize}[leftmargin=*]
    \item 新型食品安全风险（纳米材料、新型食品接触材料等）的评估
    \item 食品安全快速检测技术的发展
    \item 食品安全追溯和预警体系的完善
    \item 全球气候变化对食品安全的影响
\end{itemize}
（来源：0613营养笔记概述）
\end{tipbox}

\section{营养与食品卫生学的研究内容与方法（了解）}

\begin{tipbox}
\textbf{研究内容：}
\begin{itemize}[leftmargin=*]
    \item \textbf{营养学方面：}营养素代谢与需要量、食物营养成分分析、各类食物的营养价值、特殊人群营养、公共营养（营养调查、DRIs、膳食指南）、临床营养、分子营养学
    \item \textbf{食品卫生学方面：}食品污染与预防（微生物污染、农药和兽药残留、有害金属、N-亚硝基化合物等）、食品添加剂管理、各类食品的卫生问题、食源性疾病及其预防、食品安全风险分析与监督管理
\end{itemize}

\textbf{主要研究方法：}
\begin{itemize}[leftmargin=*]
    \item 实验室研究（生化分析、细胞和动物实验、临床试验）
    \item 流行病学调查（横断面调查、队列研究、干预研究）
    \item 营养调查与监测（膳食调查、人体测量、生化检验、临床检查）
    \item 食品安全风险评估（危害识别、危害特征描述、暴露评估、风险特征描述）
    \item 食物成分分析方法（化学分析、仪器分析）
\end{itemize}
（来源：0613营养笔记概述）
\end{tipbox}

% ----- 第四节 相关概念 -----
\section{相关概念}

\subsection{食品安全（掌握）}

\begin{keybox}
\textbf{食品安全（food safety）：}
\begin{enumerate}[leftmargin=*]
    \item 对食品按其原定用途进行制作、食用时不会使消费者健康受到损害的一种担保（1996年世界卫生组织）
    \item 食物中有毒、有害物质对人体健康影响的公共卫生问题（WHO）
    \item 食品安全，指食品无毒、无害，符合应当有的营养要求，对人体健康不造成任何急性、亚急性或者慢性危害（《中华人民共和国食品安全法》）
\end{enumerate}
食品安全问题涉及两个关键词：一是有毒有害物质，一是对人体健康的不良影响。
\end{keybox}

\begin{tipbox}
\textbf{Food Security（食品安全或粮食安全）：}通常是指食品量的安全，即是否有能力得到或者提供足够的食物或者食品。
\end{tipbox}

\subsection{食品安全与食品卫生的关系（掌握）}

\begin{keybox}
\textbf{食品安全与食品卫生的关系：}

食品安全是属的概念，食品卫生是种的概念。

\textbf{共同点：}结果安全（无毒无害，符合应有的营养）、过程安全（保障结果安全的条件，环境等安全）。

\textbf{不同点：}范围不同（食品卫生不包含种植养殖）、侧重点不同（食品安全是结果安全+过程安全，食品卫生侧重过程安全）。
\end{keybox}

\subsection{食物、食品、食药物质、膳食}

\begin{defbox}
\textbf{食物、食品、食药物质、膳食的定义：}

\textbf{食物（food）：}供人类食用或饮用，含有营养素，不含有害物质，不是治疗用的药物。

\textbf{食品：}指各种供人食用或者饮用的成品和原料以及按照传统既是食品又是中药材的物品，但是不包括以治疗为目的的物品。

\textbf{食药物质（药食同源物质）：}传统作为食品，且列入《中华人民共和国药典》的物质。

\textbf{膳食（diet）：}人们日常食用的饮食，由多种食物组成。
\end{defbox}

% ----- 第五节 营养素 -----
\section{营养素}

\begin{keybox}
\textbf{营养素（六大类）：}蛋白质、脂类、碳水化合物、矿物质、维生素和水。
\end{keybox}

\begin{keybox}
\textbf{宏量营养素与微量营养素：}

\textbf{宏量营养素（macronutrients / calorigenic nutrients）：}人体需要量较多的营养素，包括蛋白质、脂类和碳水化合物，又称为\imp{产能营养素}。

\textbf{微量营养素（micronutrients）：}相对宏量营养素来说，人体需要量较少的营养素，包括矿物质和维生素。
\end{keybox}

% ----- 第六节 DRIs概览 -----
\section{膳食营养素参考摄入量（DRIs）}

\begin{keybox}
\textbf{中国居民膳食营养素参考摄入量（Dietary Reference Intakes, DRIs）：}

DRIs是一组每日平均膳食营养素摄入量的参考值。包括以下七项指标：

\begin{enumerate}[leftmargin=*]
    \item \textbf{平均需要量（Estimated Average Requirement, EAR）：}满足群体中50\%个体需要量的摄入水平，是制定RNI的基础。
    \item \textbf{推荐摄入量（Recommended Nutrient Intake, RNI）：}满足群体中97\%$\sim$98\%个体需要量的摄入水平，是个体每日摄入该营养素的目标值。
    \item \textbf{适宜摄入量（Adequate Intake, AI）：}当个体需要量资料不足、无法计算EAR时，通过观察或实验获得的健康人群某种营养素的摄入量。
    \item \textbf{可耐受最高摄入量（Tolerable Upper Intake Level, UL）：}平均每日可以摄入营养素的最高限量，对几乎所有个体不产生健康危害。
    \item \textbf{宏量营养素可接受范围（Acceptable Macronutrient Distribution Ranges, AMDR）：}蛋白质、脂肪和碳水化合物理想的摄入量范围（以占总能量\%表示）。
    \item \textbf{预防非传染性慢性病的建议摄入量（Proposed Intakes for Preventing Non-communicable Chronic Diseases, PI-NCD）：}以NCD一级预防为目标的必需营养素每日摄入量。
    \item \textbf{特定建议值（Specific Proposed Levels, SPL）：}以降低成年人膳食相关NCD风险为目标的其他膳食成分（如植物化学物）的每日摄入量。
\end{enumerate}
\end{keybox}
