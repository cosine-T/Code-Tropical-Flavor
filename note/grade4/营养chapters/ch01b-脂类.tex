\chapterintro{
掌握脂类的分类、脂肪酸的分类与命名、必需脂肪酸的概念及生理功能。熟悉食物脂类营养价值评价、磷脂和固醇类的功能。了解脂类的消化吸收及食物来源。

% ----- 第一节 脂类的分类 -----
\section{脂类的分类}

\begin{keybox}
\textbf{脂类（Lipids）分为两大类：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{脂肪（甘油三酯，Triglycerides）：}占体内脂类95\%。结构：一分子甘油+三分子脂肪酸。又称三酰甘油，主要储存于脂肪组织。
    \item \textbf{类脂：}占体内脂类5\%，包括磷脂（Phospholipids）和固醇类（Sterols）。
\end{enumerate}
\end{keybox}

% ----- 第二节 脂肪的生理功能 -----
\section{脂肪的生理功能}

\subsection{体内脂肪生理功能}
\begin{enumerate}[leftmargin=*]
    \item 贮存和提供能量：1g脂肪 = 9kcal（37.6kJ）
    \item 保温和润滑机体
    \item 节约蛋白质：充足脂肪减少蛋白质供能消耗
    \item 构成细胞膜等机体组织
    \item 内分泌作用：分泌瘦素、TNF-$\alpha$、IL-6、雌激素、IGF等
\end{enumerate}

\subsection{食物中脂肪的作用}
增强饱腹感、改善食物风味与感官性状、作为脂溶性维生素载体促进吸收。

% ----- 第三节 脂肪酸的分类及功能 -----
\section{脂肪酸的分类及功能}

\begin{keybox}
\textbf{脂肪酸分类：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{按碳链长度：}长链（$\geq$14碳，以18碳为主）、中链（8～12碳，水溶性好，直接吸收快速供能）、短链（$\leq$6碳，由膳食纤维在结肠发酵生成）
    \item \textbf{按饱和程度：}饱和脂肪酸（SFA）、单不饱和脂肪酸（MUFA，如油酸）、多不饱和脂肪酸（PUFA，如亚油酸、$\alpha$-亚麻酸）
    \item \textbf{按空间结构：}顺式脂肪酸（天然主流形式）、反式脂肪酸（人工氢化产生，升高CVD、2型糖尿病、肿瘤风险）
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{必需脂肪酸（Essential Fatty Acid, EFA，教学难点*）：}

定义：人体无法合成、必须由食物供给的脂肪酸。

两种必需脂肪酸：
\begin{enumerate}[leftmargin=*]
    \item 亚油酸（n-6系列）：C18:2
    \item $\alpha$-亚麻酸（n-3系列）：C18:3
\end{enumerate}

生理功能：
\begin{enumerate}[leftmargin=*]
    \item 构成磷脂和细胞膜
    \item 作为前列腺素等活性物质前体，调节血管、神经、免疫、血栓
    \item 参与胆固醇代谢，降低血脂
\end{enumerate}

缺乏表现：生长迟缓、皮炎、肝肾神经病变（多见于婴幼儿、肠病患者、长期肠外营养人群）。推荐每日EFA供能不少于总能量3\%。
\end{keybox}

\begin{tipbox}
\textbf{长链多不饱和脂肪酸（AA、EPA、DHA）：}
\begin{itemize}[leftmargin=*]
    \item n-6系列：亚油酸 $\rightarrow$ 花生四烯酸（AA），降血脂、维持组织膜
    \item n-3系列：$\alpha$-亚麻酸 $\rightarrow$ EPA $\rightarrow$ DHA
    \item DHA：促进脑/视网膜发育；EPA：抗炎、调节免疫、辅助抗肿瘤
\end{itemize}
\end{tipbox}

% ----- 第四节 类脂及其功能 -----
\section{类脂及其功能}

\subsection{磷脂}
兼具亲水性和亲脂性（乳化作用）。生理功能：构成细胞膜、乳化脂肪、保护血管、改善神经功能。缺乏可引发脂肪肝、动脉粥样硬化、皮肤病变。富含食物：鸡蛋、肝脏、大豆、麦胚、花生。

\subsection{固醇类（胆固醇）}
来源：动物性食品；人体肝、肠可内源性合成。生理功能：细胞膜组分，合成胆汁酸、性激素、肾上腺素、维生素D$_3$的原料。

% ----- 第五节 膳食脂肪的营养学评价与参考摄入量 -----
\section{膳食脂肪的营养学评价与参考摄入量}

\textbf{评价指标：}消化率（植物脂肪 > 动物脂肪）、必需脂肪酸含量、各类脂肪酸配比（SFA:MUFA:PUFA）、脂溶性维生素含量、EPA/DHA等特殊脂肪酸含量。

\begin{keybox}
\textbf{膳食推荐：}
\begin{enumerate}[leftmargin=*]
    \item 脂肪供能占总能量：20\%～30\%
    \item 必需脂肪酸供能：$\geq$3\%
    \item n-3:n-6比例：建议1:4～6
    \item 饱和脂肪酸：升高LDL；多不饱和脂肪酸：降胆固醇、易氧化；单不饱和脂肪酸（橄榄油为主）：降脂、抗氧化（地中海膳食模式）
\end{enumerate}
\end{keybox}

\textbf{食物分布：}动物脂肪/肉类以饱和和单不饱和脂肪酸为主，胆固醇高（海鱼除外）；植物油多不饱和脂肪酸丰富（椰子油、棕榈油除外）；磷脂以蛋黄、肝、大豆含量最高；胆固醇以动物内脏、蛋类含量最高。

    \item \textbf{【简答题】}简述脂类的膳食推荐摄入量。
    \item \textbf{【简答题】}简述反式脂肪酸的来源和健康危害。
\end{enumerate}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item 见本章概念定义。
    \item 亚油酸（n-6）和$\alpha$-亚麻酸（n-3）。功能：构成细胞膜、活性物质前体、参与胆固醇代谢。
    \item 脂肪供能20\%～30\%，EFA供能$\geq$3\%，n-3:n-6=1:4～6。
    \item 来源：植物油氢化（人造奶油、蛋糕、饼干、油炸食品）。危害：升高CVD、2型糖尿病、肿瘤风险，无必需脂肪酸活性。
\end{enumerate}
