\section{脂类的分类、代谢（了解）}

\begin{tipbox}
\textbf{脂类（Lipids）的概念与分类：}
脂类（lipids）、脂肪（fat）和类脂（lipoids）是一类化学结构相似或完全不同的有机化合物。
脂类 = 脂肪（Fat） + 类脂（Lipoids）。
\begin{itemize}[leftmargin=*]
    \item \imp{脂肪（fat）：}即甘油三酯（triglycerides），是体内最重要的储能和供能物质，占体内脂类总量的\imp{95\%}。
    \item \imp{类脂：}主要包括磷脂和固醇类，是细胞膜、组织器官，尤其是神经组织的重要组成。
\end{itemize}
适当摄入脂类对满足机体生理需要，促进VA、VE等脂溶性维生素的吸收和利用，维持人体健康有着重要作用。

\textbf{脂肪的消化、吸收与代谢：}

\textbf{1. 消化：}膳食脂肪（主要为甘油三酯）在小肠内被胆汁酸乳化成微团，在胰脂肪酶作用下水解为甘油一酯、甘油二酯和游离脂肪酸。

\textbf{2. 吸收：}甘油一酯和脂肪酸被肠黏膜细胞吸收后，在滑面内质网重新合成甘油三酯，与载脂蛋白、胆固醇、磷脂等结合形成乳糜微粒（CM），经淋巴系统进入血液循环。

\textbf{3. 代谢：}乳糜微粒中的甘油三酯在毛细血管壁上被脂蛋白脂酶水解为甘油和脂肪酸，脂肪酸进入组织细胞被利用。
\begin{itemize}[leftmargin=*]
    \item \textbf{脂肪的合成：}主要在肝脏、脂肪组织中，以乙酰CoA为原料合成脂肪酸，再与甘油酯化形成甘油三酯
    \item \textbf{脂肪酸的氧化：}通过$\beta$-氧化逐步降解为乙酰CoA，进入三羧酸循环彻底氧化供能
    \item \textbf{酮体的生成：}脂肪酸$\beta$-氧化产生的乙酰CoA在肝内可生成酮体（乙酰乙酸、$\beta$-羟丁酸、丙酮），供肝外组织利用
\end{itemize}

\textbf{4. 脂肪的储存与动员：}脂肪细胞可无限储存脂肪。禁食或饥饿时，脂肪动员增强，激素敏感性脂肪酶激活，甘油三酯水解为脂肪酸释放入血。

\textbf{5. 类脂代谢：}
\begin{itemize}[leftmargin=*]
    \item 磷脂：参与细胞膜结构和脂蛋白（VLDL、LDL、HDL）构成
    \item 胆固醇：可自身合成（主要在肝脏），也可从食物吸收；胆固醇在体内可转化为胆汁酸、类固醇激素、维生素D$_3$等
\end{itemize}

\textbf{体内脂肪分布：}
一般，男性以腹部和内脏脂肪较多，女性以臀部和大腿皮下脂肪较多。
体内脂肪主要分布于腹腔、皮下、肌肉纤维之间。
（来源：食品主要参考.txt）
\end{tipbox}

\section{脂类的生理功能}

\begin{tipbox}
\textbf{一、体内脂肪的生理功能：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{储存和提供能量：}1g脂肪 = \imp{9.46kcal}能量。脂肪细胞可无限地储存脂肪。脂肪不能给脑和神经细胞以及血细胞供能。
    \item \textbf{保温及润滑。}
    \item \textbf{节约蛋白质作用：}保护体内蛋白质不被用作能源物质，使蛋白质能被更有效地发挥其功能。
    \item \textbf{机体构成成分：}细胞膜。
    \item \textbf{脂肪组织内分泌功能：}可分泌雌激素等。
\end{enumerate}

\textbf{二、食物中脂肪的作用：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{增加饱腹感：}进入十二指肠，刺激产生肠抑胃素，使胃蠕动受到抑制。
    \item \textbf{改善食物感官性状。}
    \item \textbf{提供脂溶性维生素：}提供来源 + 促进吸收。
\end{enumerate}
（来源：食品主要参考.txt）
\end{tipbox}

\section{脂肪酸的分类}

\subsection{脂肪酸命名方法（了解）}

\begin{tipbox}
\textbf{脂肪酸表示方法：}表示为Cx:y，其中x为碳原子个数、y表示不饱和双键个数。如亚油酸C18:2，$\alpha$-亚麻酸C18:3。

\textbf{1. 简易命名（Cx:y）：}如上述表示方式。

\textbf{2. 系统命名：}按有机化学命名原则，以含羧基的碳链为母体，根据碳原子数和双键数命名。

\textbf{3. $\omega$/n 编号命名：}从甲基端（$\omega$端）开始计数，将第一个双键出现的位置标示为n-x或$\omega$-x。如亚油酸（n-6,18:2），$\alpha$-亚麻酸（n-3,18:3）。具有重要营养学意义的两类脂肪酸：
\begin{itemize}[leftmargin=*]
    \item \textbf{n-6系多不饱和脂肪酸：}亚油酸、花生四烯酸（AA）。降低胆固醇。AA是类二十烷酸的重要前体物质。促进生长发育及妊娠。
    \item \textbf{n-3系多不饱和脂肪酸：}$\alpha$-亚麻酸 $\rightarrow$（碳链延长）$\rightarrow$ EPA $\rightarrow$（碳链延长）$\rightarrow$ DHA。哺乳动物组织中，n-3脂肪酸的水平低于n-6脂肪酸。两种脂肪酸在体内代谢和组织分布不同。
\end{itemize}
注意事项：食物中主要以18碳脂肪酸为主。人体只能利用偶数个数碳原子的脂肪酸。
（来源：食品主要参考.txt）
\end{tipbox}

\subsection{脂肪酸分类（掌握）}

\begin{keybox}
\textbf{脂肪酸分类\difficulty：}
\textbf{1. 按碳链长度分类：}
\begin{itemize}[leftmargin=*]
    \item \imp{长链脂肪酸（long-chain fatty acid）：}含14$\sim$24碳
    \item \imp{中链脂肪酸（medium-chain fatty acid, MCFA）：}含8$\sim$12个碳
    \begin{itemize}
        \item 直接从门静脉吸收，不经淋巴
        \item 水溶性好，能直接被小肠吸收
        \item 无需形成乳糜颗粒，直接进入肝脏
        \item 细胞内可快速氧化供能，能很快被氧化生成酮体，但不能用于糖尿病、酮中毒及酸中毒、肝硬化者
    \end{itemize}
    \item \imp{短链脂肪酸（short-chain fatty acid, SCFA）：}含6碳以下（醋酸、丙酸、丁酸）
    \begin{itemize}
        \item 来源：膳食纤维、抗性淀粉、低聚糖、糖醇等，在结肠被肠道微生物发酵
        \item 功能：供能；促进细胞膜脂类物质合成；可能预防和治疗溃疡性结肠炎；可预防结肠肿瘤；对内源性胆固醇的合成有抑制作用
    \end{itemize}
\end{itemize}

\textbf{2. 按饱和程度分类：}
\begin{itemize}[leftmargin=*]
    \item \imp{饱和脂肪酸（saturated fatty acid, SFA）：}碳链中没有不饱和双键。棕榈油、椰子油、可可脂中含量高。HDL$\downarrow$，LDL$\uparrow$（HDL为血管保护因素，LDL为血管危险因素）
    \item \imp{不饱和脂肪酸（unsaturated fatty acid, USFA）：}碳链中含一个或多个不饱和双键
    \begin{itemize}
        \item \imp{单不饱和脂肪酸（MUFA）：}含一个不饱和双键，如油酸。HDL$\uparrow$、LDL$\downarrow$
        \item \imp{多不饱和脂肪酸（PUFA）：}含两个及以上不饱和双键，膳食中主要为亚油酸、$\alpha$-亚麻酸，存在于植物油中。HDL$\downarrow$、LDL$\downarrow\downarrow$
    \end{itemize}
\end{itemize}

\textbf{3. 按空间结构分类：}
\begin{itemize}[leftmargin=*]
    \item \imp{顺式脂肪酸：}大多不饱和脂肪酸为顺式
    \item \imp{反式脂肪酸：}天然的很少存在，主要存在于牛奶、人造奶油中
    \begin{itemize}
        \item HDL$\downarrow$、LDL$\uparrow$ $\rightarrow$ 增加心血管疾病的危险
        \item 可能诱发肿瘤、2型糖尿病
        \item 人造奶油、蛋糕、饼干、油炸食品、乳酪产品、花生酱等是反式脂肪酸的主要来源
    \end{itemize}
\end{itemize}

\textbf{4. 按双键位置分类（n系命名）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{n-6系多不饱和脂肪酸：}亚油酸 $\rightarrow$ 花生四烯酸（AA）
    \begin{itemize}
        \item 降低胆固醇
        \item 是一些磷脂的组成成分，维持组织膜流动性和神经细胞膜水平
        \item AA是类二十烷酸的重要前体物质
        \item 促进生长发育及妊娠
    \end{itemize}
    \item \textbf{n-3系多不饱和脂肪酸：}$\alpha$-亚麻酸 $\rightarrow$（碳链延长）$\rightarrow$ EPA $\rightarrow$（碳链延长）$\rightarrow$ DHA
\end{itemize}
（来源：食品主要参考.txt）
\end{keybox}

\section{必需脂肪酸}

\begin{keybox}
\textbf{必需脂肪酸（Essential Fatty Acid, EFA）：}人体不可缺少且自身不能合成，必须通过食物供给的脂肪酸，有\imp{亚油酸}（n-6系多不饱和）和\imp{$\alpha$-亚麻酸}（n-3系多不饱和）。

\textbf{EFA的功能：}
\begin{enumerate}[leftmargin=*]
    \item 构成磷脂的组成成分 $\rightarrow$ 构成细胞膜
    \item 前列腺素PG合成的前体 $\rightarrow$ 血管舒缩、神经传导等
    \item 参与胆固醇代谢
    \item 参与类二十烷酸合成（PG、TXA等），调节血压、血脂、血栓形成及免疫反应等
\end{enumerate}
（来源：食品主要参考.txt）
\end{keybox}

\begin{tipbox}
\textbf{EFA的缺乏与过量（了解）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{缺乏表现：}皮肤干燥、鳞屑样皮炎、生长迟缓、生殖障碍、脂肪肝、伤口愈合不良；婴幼儿可出现神经髓鞘和大脑发育受损、脂溶性维生素缺乏。脂肪摄入量过低可导致EFA缺乏。
    \item \textbf{过量风险：}过多摄入不饱和脂肪酸易发生脂质过氧化，增加氧化应激损伤；n-3和n-6脂肪酸比例失衡可能影响免疫功能。
\end{itemize}
（来源：食品主要参考.txt）
\end{tipbox}

\section{食物脂类营养价值评价（熟悉）}

\begin{tipbox}
\textbf{食物脂类营养价值评价四个方面：}
\begin{enumerate}[leftmargin=*]
    \item \imp{脂肪的消化率：}含不饱和脂肪酸、短链脂肪酸越多的脂肪 $\rightarrow$ 熔点越低 $\rightarrow$ 越容易消化。一般植物脂肪消化率 > 动物脂肪。

    \item \imp{必需脂肪酸（EFA）的含量：}一般，植物油中亚油酸和$\alpha$-亚麻酸的含量 > 动物脂肪（椰子油除外），因此植物油的营养价值更高。

    \item \imp{各种脂肪酸的比例：}一般推荐饱和脂肪酸:单不饱和脂肪酸:多不饱和脂肪酸 = \imp{1:1:1}。EFA摄入不少于总能量的\imp{3\%}，n-3系:n-6系 = \imp{1:4$\sim$6}。

    \item \imp{脂溶性维生素含量：}脂溶性维生素含量高的脂类，其营养价值越高。
    \begin{itemize}
        \item 植物油，特别是谷物种子的胚油，VE含量丰富
        \item 动物脂肪中器官脂肪（肝脏脂肪）富含VA、VD，海产鱼类肝脏脂肪中VA、VD更高
    \end{itemize}
\end{enumerate}

\textbf{参考摄入量：}成人脂肪摄入量应占总能量的\imp{20\%$\sim$30\%}。EFA摄入不少于总能量的3\%。
（来源：食品主要参考.txt）
\end{tipbox}

\section{脂类食物来源（熟悉）}

\begin{tipbox}
\textbf{脂类的食物来源：}
\begin{itemize}[leftmargin=*]
    \item \textbf{动物性来源：}动物脂肪组织（主要为甘油三酯，饱和脂肪酸含量较高）；器官脂肪（肝脏脂肪）含丰富VA、VD；海产鱼类肝脏脂肪中VA、VD更高；蛋黄、奶油等。
    \item \textbf{植物性来源：}植物油（如大豆油、花生油、菜籽油、橄榄油等），一般含不饱和脂肪酸较多，消化率高；植物油（特别是谷物种子的胚油）VE含量丰富；坚果类。
    \item \textbf{磷脂来源：}蛋黄（卵磷脂）、大豆（大豆磷脂）。
    \item \textbf{必需脂肪酸来源：}植物油中亚油酸和$\alpha$-亚麻酸的含量高于动物脂肪（椰子油除外），因此植物油是EFA的良好来源。亚麻籽油中$\alpha$-亚麻酸含量可达49\%。
\end{itemize}

一般，植物脂肪消化率 > 动物脂肪。

成人脂肪摄入量应占总能量的\imp{20\%$\sim$30\%}，EFA摄入不少于总能量的\imp{3\%}。
（来源：食品主要参考.txt）
\end{tipbox}

\begin{tipbox}
\textbf{【补充】脂肪酸的化学结构：}
脂肪酸由甲基端（-CH$_3$）和羧基端（-COOH）构成，碳原子首尾相连排成直线（偶数碳原子）。脂肪酸的通式：CH$_3$(CH$_2$)$_n$COOH。

\textbf{【补充】脂肪的构成：}
脂肪主要由甘油三酯组成，即3分子脂肪酸（FA）+ 1分子甘油。

\textbf{【补充】食物脂肪消化率与熔点的关系（详细）：}
\begin{itemize}[leftmargin=*]
    \item 熔点 < 体温：脂肪消化率约97$\sim$98\%
    \item 熔点 > 体温：脂肪消化率约90\%
    \item 熔点 > 50$^\circ$C：脂肪消化率更低
\end{itemize}
含不饱和脂肪酸和短链脂肪酸越多的脂肪，熔点越低，越容易消化。一般植物脂肪消化率 > 动物脂肪。

\textbf{【补充】EFA功能的另一表述（含保护皮肤）：}
\begin{enumerate}[leftmargin=*]
    \item 构成磷脂的组成成分
    \item 前列腺素合成的前体
    \item 参与胆固醇代谢
    \item 保护皮肤（防止皮肤干燥、鳞屑样皮炎等）
\end{enumerate}

\textbf{【补充】食物脂类营养价值评价的第五方面——稳定性：}
植物油中含有较多不饱和脂肪酸，在储存过程中容易氧化酸败，因此也应关注脂类的稳定性。含天然抗氧化剂（如VE）的油脂稳定性更好。
（来源：往届笔记手动.txt）
\end{tipbox}

\subsection*{参考答案要点}
\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{脂类（Lipids）：}脂类 = 脂肪（Fat）+ 类脂（Lipoids），是一类化学结构相似或完全不同的有机化合物。脂肪 = 甘油三酯（Triglycerides），占体内脂类总量的95\%，是体内重要的储能和供能物质，1g脂肪 = 9.46kcal能量。类脂主要包括磷脂和固醇类，是细胞膜、组织器官，尤其是神经组织的重要组成。\textbf{EFA}：人体不可缺少且自身不能合成，必须通过食物供给的脂肪酸，有亚油酸（n-6系）和$\alpha$-亚麻酸（n-3系）。\textbf{Cx:y}：x为碳原子个数，y表示不饱和双键个数。\textbf{n-3系}：$\alpha$-亚麻酸 $\rightarrow$ EPA $\rightarrow$ DHA。\textbf{n-6系}：亚油酸 $\rightarrow$ 花生四烯酸（AA）。

    \item \textbf{MCFA}：含8$\sim$12个碳，直接从门静脉吸收不经淋巴，水溶性好，能直接被小肠吸收，无需形成乳糜颗粒直接进入肝脏，细胞内快速氧化供能，能很快被氧化生成酮体，但不能用于糖尿病、酮中毒及酸中毒、肝硬化者。\textbf{SCFA}：含6碳以下（醋酸、丙酸、丁酸），来源于膳食纤维、抗性淀粉、低聚糖、糖醇等，在结肠被肠道微生物发酵，功能包括供能、促进细胞膜脂类物质合成、可能预防和治疗溃疡性结肠炎、可预防结肠肿瘤、对内源性胆固醇的合成有抑制作用。\textbf{反式脂肪酸}：天然很少存在，主要存在于牛奶、人造奶油中，HDL$\downarrow$/LDL$\uparrow$，增加心血管疾病的危险，可能诱发肿瘤、2型糖尿病。人造奶油、蛋糕、饼干、油炸食品、乳酪产品、花生酱等是主要来源。\textbf{类脂}：主要包括磷脂和固醇类，是细胞膜、组织器官（尤其神经组织）的重要组成。\textbf{乳糜微粒（CM）}：甘油三酯与载脂蛋白、胆固醇、磷脂等结合形成的脂蛋白颗粒，经淋巴系统进入血液循环。

    \item 消化：胆汁酸乳化 $\rightarrow$ 胰脂肪酶水解 $\rightarrow$ 甘油一酯和游离脂肪酸。吸收：肠黏膜细胞吸收后重新合成甘油三酯 $\rightarrow$ 与载脂蛋白、胆固醇、磷脂形成乳糜微粒 $\rightarrow$ 经淋巴入血。代谢：乳糜微粒中甘油三酯被脂蛋白脂酶水解 $\rightarrow$ 脂肪酸进入组织细胞，经$\beta$-氧化 $\rightarrow$ 乙酰CoA $\rightarrow$ 三羧酸循环彻底氧化供能。肝脏可将乙酰CoA生成酮体（乙酰乙酸、$\beta$-羟丁酸、丙酮）供肝外组织利用。类脂代谢：磷脂参与细胞膜和脂蛋白构成；胆固醇可自身合成也可从食物吸收，在体内转化为胆汁酸、类固醇激素、维生素D$_3$等。

    \item \textbf{分类：}脂类 = 脂肪（甘油三酯，占体内脂类总量的95\%）+ 类脂（磷脂和固醇类，细胞膜和神经组织的重要组成）。\textbf{生理功能：}体内脂肪功能5项--(1)储存和提供能量（1g脂肪=9.46kcal，脂肪细胞可无限储存，脂肪不能给脑/神经细胞/血细胞供能）；(2)保温及润滑；(3)节约蛋白质作用；(4)机体构成成分（细胞膜）；(5)脂肪组织内分泌功能（雌激素等）。食物中脂肪作用3项--(1)增加饱腹感（进入十二指肠刺激产生肠抑胃素）；(2)改善食物感官性状；(3)提供脂溶性维生素（来源+促进吸收）。

    \item \textbf{按碳链长度：}长链（14$\sim$24C）；中链MCFA（8$\sim$12C，水溶性好，直接吸收进入肝脏，快速氧化供能，但不能用于糖尿病/酮中毒/酸中毒/肝硬化者）；短链SCFA（$\leq$6C，醋酸/丙酸/丁酸，来自膳食纤维发酵，供能/预防结肠肿瘤/抑制内源性胆固醇合成）。\textbf{按饱和程度：}SFA（无双键，棕榈油/椰子油/可可脂中含量高，HDL$\downarrow$/LDL$\uparrow$）；MUFA（1个双键，如油酸，HDL$\uparrow$/LDL$\downarrow$）；PUFA（$\geq$2个双键，膳食中主要为亚油酸/$\alpha$-亚麻酸，存在于植物油，HDL$\downarrow$/LDL$\downarrow\downarrow$）。\textbf{按空间结构：}顺式脂肪酸（大多不饱和脂肪酸为顺式）；反式脂肪酸（天然很少存在，HDL$\downarrow$/LDL$\uparrow$，增加心血管疾病危险，可能诱发肿瘤/2型糖尿病）。\textbf{按双键位置：}n-6系（亚油酸 $\rightarrow$ AA，降低胆固醇，AA是类二十烷酸前体，促进生长发育及妊娠）；n-3系（$\alpha$-亚麻酸 $\rightarrow$ EPA $\rightarrow$ DHA）。食物中以18碳脂肪酸为主，人体只能利用偶数碳原子脂肪酸。

    \item EFA定义：人体不可缺少且自身不能合成，必须通过食物供给的脂肪酸。种类：亚油酸（n-6系多不饱和）和$\alpha$-亚麻酸（n-3系多不饱和）。功能：(1)构成磷脂的组成成分 $\rightarrow$ 构成细胞膜；(2)前列腺素PG合成的前体 $\rightarrow$ 血管舒缩、神经传导等；(3)参与胆固醇代谢；(4)参与类二十烷酸合成（PG、TXA等），调节血压、血脂、血栓形成及免疫反应等。缺乏：皮肤干燥、鳞屑样皮炎、生长迟缓、生殖障碍、脂肪肝、伤口愈合不良；婴幼儿神经发育受损、脂溶性维生素缺乏。过量：脂质过氧化增加氧化应激损伤；n-3/n-6比例失衡影响免疫功能。

    \item 四方面：(1)脂肪的消化率（含不饱和脂肪酸/短链脂肪酸越多 $\rightarrow$ 熔点越低 $\rightarrow$ 越易消化，一般植物脂肪消化率 > 动物脂肪）；(2)EFA含量（一般植物油 > 动物脂肪，椰子油除外）；(3)各种脂肪酸比例（SFA:MUFA:PUFA = 1:1:1，EFA不少于总能量3\%，n-3:n-6 = 1:4$\sim$6）；(4)脂溶性维生素含量（植物油胚油VE丰富，器官脂肪和海产鱼类肝脏脂肪含丰富VA/VD）。成人脂肪摄入量应占总能量的20\%$\sim$30\%，EFA摄入不少于总能量的3\%。

    \item 动物性：动物脂肪组织（饱和脂肪酸含量较高）、蛋黄、奶油、器官脂肪（VA/VD）、海产鱼肝。植物性：植物油（大豆油/花生油/菜籽油/橄榄油等，不饱和脂肪酸多，消化率高）、坚果。磷脂：蛋黄（卵磷脂）、大豆（大豆磷脂）。EFA来源：植物油中亚油酸和$\alpha$-亚麻酸含量 > 动物脂肪（椰子油除外），亚麻籽油中$\alpha$-亚麻酸含量可达49\%。成人脂肪摄入量应占总能量的20\%$\sim$30\%，EFA不少于总能量3\%。
\end{enumerate}
