% ----- 第一节 碳水化合物的分类 -----
\section{碳水化合物的分类}

\begin{defbox}
\textbf{碳水化合物（Carbohydrate）}由碳、氢、氧三种元素组成，氢氧比例恰为2:1。是人类膳食最主要的能量来源。
\end{defbox}

\begin{keybox}
\textbf{根据化学结构和生理作用分类（FAO/WHO 1998年）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{糖（1～2个单糖）：}单糖（葡萄糖、半乳糖）、双糖（蔗糖、乳糖、麦芽糖）、糖醇（山梨醇、甘露醇）
    \item \textbf{寡糖/低聚糖（3～9个单糖）：}异麦芽低聚寡糖、棉子糖、水苏糖、低聚果糖。功能性低聚糖多数无法被人体消化吸收，可在结肠被益生菌利用
    \item \textbf{多糖（$\geq$10个单糖）：}淀粉（人类主要能量物质，多见于谷类、根茎类）、非淀粉多糖（纤维素、半纤维素、果胶等）
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{食物血糖生成指数（Glycemic Index, GI，教学难点*）：}

定义：某食物食后2小时血糖曲线下面积 / 相等含量葡萄糖食后2小时血糖曲线下面积 $\times$ 100。

分类：
\begin{itemize}[leftmargin=*]
    \item 高GI（>70）：馒头88.1、面包87.9、大米83.2、面条81.6、西瓜72.0
    \item 中GI（56～70）：玉米粉68.0、荞麦54.0、香蕉52.0
    \item 低GI（<55）：牛奶27.6、绿豆27.2、大豆18.0、花生14.0、苹果36.0
\end{itemize}
\end{keybox}

% ----- 第二节 碳水化合物的消化和吸收 -----
\section{碳水化合物的消化和吸收}

消化过程：口腔唾液$\alpha$-淀粉酶初步消化 $\rightarrow$ 小肠（主要消化场所）双糖经蔗糖酶、乳糖酶等水解为单糖后吸收 $\rightarrow$ 结肠：小肠不可消化部分经细菌发酵产气及短链脂肪酸。

\begin{defbox}
\textbf{乳糖不耐受（Lactose Intolerance）：}肠道乳糖酶活性不足或缺乏，摄入乳制品后出现腹胀、腹泻、肠鸣等。原理：未被消化的乳糖进入结肠，被细菌发酵产气。
\end{defbox}

% ----- 第三节 碳水化合物的功能 -----
\section{碳水化合物的功能}

\begin{keybox}
\textbf{碳水化合物的主要功能：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{提供能量：}可消化碳水化合物16.7 kJ (4 kcal)/g；不可消化碳水化合物0～3 kcal/g
    \item \textbf{构成组织结构及生理活性物质：}如核酸中的核糖、糖蛋白、糖脂等
    \item \textbf{节约蛋白质作用（Protein-Sparing Action）：}虽然蛋白质可提供能量，但其主要功能是构成细胞和体内重要物质。当碳水化合物充足时，人体首先利用碳水化合物供给能量，从而减少了蛋白质单纯作为供能物质的分解代谢，有利于改善和提高蛋白质的利用，并增强体内氮的贮存量。
    \item \textbf{抗生酮作用（Anti-Ketogenic Effect）：}脂肪酸在体内分解代谢时产生的乙酰基需与碳水化合物代谢产生的草酰乙酸结合才能进入三羧酸循环而被彻底氧化。当碳水化合物不足时，因草酰乙酸不足使得脂肪酸不能被彻底氧化分解而产生过多酮体，可发生酮症酸中毒。反之，当碳水化合物充足时可防止酮症酸中毒的发生。\keyword{每日至少需130g碳水化合物以预防酮症。}
\end{enumerate}
\end{keybox}

\subsection{膳食纤维的功能}
维持肠道健康、促进排便；降低血胆固醇；延缓血糖升高；增加饱腹感，有助于体重控制；促进肠道有益菌群生长。

% ----- 第四节 参考摄入量及食物来源 -----
\section{参考摄入量及食物来源}

\begin{keybox}
\textbf{食物血糖负荷（Glycemic Load, GL，教学补充）：}

GL = GI $\times$ 摄入食物中可利用碳水化合物含量(g) / 100

\keyword{GL同时考虑了食物的升糖速度（GI）和实际摄入的可利用碳水化合物量}，能更准确反映一餐/一份食物对血糖的真实影响。低GI但摄入大量碳水化合物的食物，其GL仍可能很高。
\begin{itemize}[leftmargin=*]
    \item 高GL：GL $\geq$ 20；中GL：11～19；低GL：GL $\leq$ 10
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{中国居民膳食碳水化合物参考摄入量：}
\begin{itemize}[leftmargin=*]
    \item \textbf{成人：}EAR为120g/d，AMDR占总能量的50\%～65\%
    \item \textbf{孕妇：}孕早期 EAR额外+10g/d，孕中期+20g/d，孕晚期+15g/d；AMDR均为50\%～65\%
    \item \textbf{乳母：}EAR额外+30g/d，AMDR 50\%～65\%
    \item \textbf{添加糖限制：}建议添加糖摄入不超过50g/d，最好低于25g/d
    \item \textbf{酒精：}摄入量不超过15g/d，任何形式的酒精对人体健康都无益处
\end{itemize}
\end{keybox}

\textbf{食物来源：}高含量（>70g/100g）：白砂糖、藕粉、稻米、小米、小麦粉；中含量（10～70g/100g）：绿豆、黄豆、马铃薯、香蕉、苹果；低含量（<10g/100g）：牛乳、番茄、白菜。
