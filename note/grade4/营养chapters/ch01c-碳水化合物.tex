\chapter{碳水化合物}
\chapterintro{掌握碳水化合物的分类（单糖、双糖、寡糖、多糖）及抗性淀粉(RS)；掌握碳水化合物的五大功能，尤其是节约蛋白质作用和抗生酮作用；掌握血糖指数(GI)和血糖负荷(GL)的定义、公式及分级标准；熟悉膳食纤维及碳水化合物的食物来源与参考摄入量。}

\section{碳水化合物的分类}

\begin{keybox}
\textbf{碳水化合物的分类：}
\begin{itemize}[leftmargin=*]
    \item \imp{单糖：}不能被水解的最简单碳水化合物。葡萄糖、果糖、半乳糖、其他单糖（糖醇类）
    \item \imp{双糖：}蔗糖（最有商业意义，主要来源甘蔗、甜菜）、麦芽糖（两个分子葡萄糖组成）、乳糖（仅存在于奶制品的碳水化合物）、海藻糖
    \item \imp{寡糖：}低聚糖，3$\sim$10个单糖分子通过糖苷键聚合而成。功能性低聚糖：存在于水果、蔬菜。多数低聚糖不能或部分被消化吸收，在结肠被益生菌利用而产生短链脂肪酸。棉子糖、水苏糖
    \item \imp{多糖：}$>$10个糖单位的聚合物，一般不溶于水，无甜味，不形成结晶，无还原性。淀粉：人类的主要能源物质，存在于谷类、根茎类。膳食纤维：纤维素、木质素（非碳水化合物）、抗性低聚糖、果胶、抗性淀粉和其他不消化碳水化合物
\end{itemize}

\textbf{按人体可消化吸收：}
\begin{itemize}[leftmargin=*]
    \item \imp{可消化吸收：}淀粉、糊精、糖原
    \item \imp{不可消化吸收：}抗性淀粉、膳食纤维
\end{itemize}

\textbf{抗性淀粉(RS)：}不被健康人体小肠消化吸收的淀粉及其降解产物。
\end{keybox}

\section{碳水化合物的功能}

\begin{keybox}
\textbf{1. 提供能量：}可消化的碳水化合物1g=4kcal；不可消化的碳水化合物0$\sim$3kcal/g，平均2kcal/g。

\textbf{2. 构成组织结构及生理活性物质}

\textbf{3. 血糖调节作用}

\textbf{4. 节约蛋白质作用(sparing protein action)：}如果碳水化合物充足，人体首先利用碳水化合物供给能量，从而减少蛋白质单纯作为供给能量的分解代谢，有利于改善和提高蛋白质的利用，并增强人体内氮的贮存量，使蛋白质生理功能更有效地发挥。

\textbf{5. 抗生酮作用(antiketogenesis)：}脂肪酸在体内分解代谢时产生的乙酰基需与碳水化合物代谢产生的草酰乙酸结合，才能进入三羧酸循环进而最终被彻底氧化；当碳水化合物不足时，因草酰乙酸不足使脂肪酸不能彻底氧化分解而产生过多酮体，会发生酮症酸中毒；而当碳水化合物充足时可防止酮症酸中毒的发生。

\textbf{6. 膳食纤维促进肠道健康：}增加饱腹感、促进排便、降低血糖和血胆固醇、改变肠道菌群。
\end{keybox}

\section{血糖指数(GI)与血糖负荷(GL)}

\begin{keybox}
\textbf{血糖指数(GI)：}反映食物引起人体血糖升高程度的指标，是人体进食后机体血糖生成的应答状态。

\[\text{GI} = \frac{\text{试验食物餐后2h血糖曲线下面积}}{\text{标准食物餐后2h血糖曲线下面积}} \times 100\]

\begin{itemize}[leftmargin=*]
    \item \imp{低GI食物：GI $\leq$ 55}
    \item 中GI食物：55 $<$ GI $<$ 75
    \item \imp{高GI食物：GI $\geq$ 75}
\end{itemize}

\textbf{GI的影响因素：}食物淀粉性状、食物非淀粉多糖的种类和数量、食物蛋白质含量、烹调方法（煮熟的淀粉GI高）。越快被消化$\rightarrow$GI越高；脂肪和蛋白质延缓消化速度，因此脂肪和蛋白质含量高的食物GI低。

\textbf{血糖负荷(GL)：}评价某种食物摄入量对人体血糖影响的幅度。

\[\text{GL} = \text{食物GI} \times \frac{\text{摄入该食物的实际可利用CHO含量(g)}}{100}\]

\begin{itemize}[leftmargin=*]
    \item GL $<$ 10为低GL
    \item 10$\sim$20为中GL
    \item $>$ 20为高GL
\end{itemize}

GL越高，血糖总体水平越高（餐后）。GI相同的食物，其GL可能不同。
\end{keybox}

\section{碳水化合物的食物来源与参考摄入量}

\begin{defbox}
\textbf{碳水化合物的食物来源：}
\begin{itemize}[leftmargin=*]
    \item 主要：粮谷类及其制品
    \item 根茎块类蔬菜（土豆、红薯、芋头）
    \item 杂豆类及制品（红豆、绿豆、豌豆、蚕豆）
    \item 水果及制品
    \item 纯糖类及其制品（蜂蜜、糖果、白糖等）
\end{itemize}

\textbf{碳水化合物的参考摄入量：}我国建议2岁以上人群的碳水化合物供能比应为\imp{55\%$\sim$65\%}（蛋白质供能比10\%$\sim$15\%，脂肪20\%$\sim$30\%）。
\end{defbox}

\subsection*{参考答案要点}
\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{单糖：}不能被水解的最简单碳水化合物，包括葡萄糖、果糖、半乳糖、糖醇类。\textbf{寡糖：}低聚糖，3$\sim$10个单糖分子通过糖苷键聚合而成，如棉子糖、水苏糖。\textbf{抗性淀粉(RS)：}不被健康人体小肠消化吸收的淀粉及其降解产物。\textbf{GI：}GI=含50g碳水化合物试验食物餐后2h血糖应答曲线下面积/等量碳水化合物标准食物餐后2h血糖应答曲线下面积$\times$100\%。\textbf{GL：}GL=食物GI$\times$摄入该食物的实际可利用碳水化合物含量(g)/100。

    \item \textbf{节约蛋白质作用：}如果碳水化合物充足，人体首先利用碳水化合物供给能量，从而减少蛋白质单纯作为供给能量的分解代谢，有利于改善和提高蛋白质的利用，并增强人体内氮的贮存量，使蛋白质生理功能更有效地发挥。\textbf{抗生酮作用：}脂肪酸在体内分解代谢时产生的乙酰基需与碳水化合物代谢产生的草酰乙酸结合，才能进入三羧酸循环进而最终被彻底氧化；当碳水化合物不足时，因草酰乙酸不足使脂肪酸不能彻底氧化分解而产生过多酮体，会发生酮症酸中毒；而当碳水化合物充足时可防止酮症酸中毒的发生。

    \item 按分子结构分类：单糖（葡萄糖、果糖、半乳糖、糖醇类）；双糖（蔗糖、麦芽糖、乳糖、海藻糖）；寡糖（棉子糖、水苏糖，3$\sim$10个单糖）；多糖（淀粉、膳食纤维等，$>$10个糖单位）。按人体可消化吸收：可消化吸收（淀粉、糊精、糖原）；不可消化吸收（抗性淀粉、膳食纤维）。

    \item 节约蛋白质作用机制：碳水化合物充足$\rightarrow$人体首先利用碳水化合物供给能量$\rightarrow$减少蛋白质单纯作为供给能量的分解代谢$\rightarrow$改善和提高蛋白质的利用$\rightarrow$增强体内氮贮存量。抗生酮作用机制：脂肪酸分解$\rightarrow$产生乙酰基$\rightarrow$需与草酰乙酸（来自碳水化合物代谢）结合$\rightarrow$进入三羧酸循环彻底氧化；碳水化合物不足$\rightarrow$草酰乙酸不足$\rightarrow$脂肪酸不能彻底氧化$\rightarrow$酮体过多$\rightarrow$酮症酸中毒。

    \item GI定义：反映食物引起人体血糖升高程度的指标，GI=含50g碳水化合物试验食物餐后2h血糖应答曲线下面积/等量碳水化合物标准食物餐后2h血糖应答曲线下面积$\times$100\%。分级：低GI$\leq$55，中GI 55$\sim$75，高GI$\geq$75。影响因素：食物淀粉性状、非淀粉多糖的种类和数量、蛋白质含量、烹调方法（煮熟的淀粉GI高）；越快被消化$\rightarrow$GI越高，脂肪和蛋白质延缓消化速度。GL=食物GI$\times$摄入该食物的实际可利用碳水化合物含量(g)/100；GL$<$10低，10$\sim$20中，$>$20高；GL越高血糖总体水平越高，GI相同的食物GL可能不同。

    \item 主要食物来源：粮谷类及其制品；根茎块类蔬菜（土豆、红薯、芋头）；杂豆类及制品（红豆、绿豆、豌豆、蚕豆）；水果及制品；纯糖类及其制品（蜂蜜、糖果、白糖等）。参考摄入量：我国建议2岁以上人群碳水化合物供能比为55\%$\sim$65\%（蛋白质10\%$\sim$15\%，脂肪20\%$\sim$30\%）。
\end{enumerate}
