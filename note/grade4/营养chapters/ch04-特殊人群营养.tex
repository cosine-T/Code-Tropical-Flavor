% ----- 第一节 生命早期1000天 -----
\section{生命早期1000天与DOHaD理论}

\begin{keybox}
\textbf{生命早期1000天（The First 1000 Days of Life）：}
指从受精卵形成开始的孕期270天（约9个月）加上出生后至2周岁的730天（约2年），总计约1000天的生命早期窗口期。

\textbf{"机遇窗口期"的概念：}这一阶段是生长发育的关键期和敏感期，此时营养状态对个体终身的体格发育、认知潜能、免疫功能和慢性疾病风险产生深远和不可逆的影响。这是进行营养干预以获得最大健康收益的最佳时机。
\end{keybox}

\begin{keybox}
\textbf{DOHaD理论（发育源性健康和疾病，Developmental Origins of Health and Disease）：}
该理论的核心论点为：\textbf{生命早期的营养环境（宫内和出生后早期）可通过"发育程序化（Developmental Programming）"机制，对个体的远期疾病风险产生持久性影响。}

主要机制包括：
\begin{enumerate}[leftmargin=*]
    \item \textbf{表观遗传调控（Epigenetic Regulation）：}早期营养状态通过DNA甲基化、组蛋白修饰等表观遗传机制，改变基因的表达模式和组织分化方向，且这种变化可持续终生。
    \item \textbf{"节俭表型"假说（Thrifty Phenotype Hypothesis）：}宫内营养不良使胎儿产生"预测性适应"——调整代谢和内分泌系统以应对即将来临的"匮乏"环境。若出生后实际面临的是"营养过剩"环境（婴儿期过度喂养），则这种代谢-环境不匹配将大幅增加成年期代谢综合征风险。
    \item \textbf{远期疾病风险：}早期营养不良（宫内发育受限、低出生体重、婴儿期过快生长加速）显著升高成年期肥胖、2型糖尿病、心血管疾病（高血压、冠心病）、骨质疏松甚至某些癌症的发病风险。
\end{enumerate}
\end{keybox}

\begin{exambox}
\textbf{考点提示：} (1) 1000天的计算（270d+730d）；(2) DOHaD的核心逻辑——早期环境→发育程序化（表观遗传）→远期健康/疾病；(3)"不匹配"是DOHaD解释代谢综合征的核心机制——宫内"预测匮乏" + 出生后"实际营养过剩" → 代谢-环境失匹配 → 代谢综合征高风险。
\end{exambox}

\subsection{孕期生理特点}

\begin{keybox}
\textbf{孕期的主要生理变化：}

\textbf{1. 内分泌变化：}
\begin{itemize}[leftmargin=*]
    \item \textbf{人绒毛膜促性腺激素（HCG）：}妊娠后10天内可在血中检出，是早孕试验的基础。由胎盘合体滋养层细胞分泌，作用于黄体使月经黄体转变为妊娠黄体，维持妊娠早期所需的孕酮分泌。
    \item \textbf{人绒毛膜生长激素（HCS）：}由胎盘合体滋养层细胞分泌，具有促进乳腺发育和胎儿生长的作用，同时可降低母体胰岛素敏感性。
    \item \textbf{雌激素：}孕期显著升高，孕晚期可达非孕期的1000倍。主要由胎盘利用来自胎儿肾上腺的脱氢表雄酮（DHEA）合成雌三醇（E3）。作用：促进子宫和乳腺发育、增加子宫胎盘血流量。
    \item \textbf{孕激素（孕酮/Progesterone）：}主要由胎盘合体滋养层细胞分泌。维持子宫内膜蜕膜化、抑制子宫平滑肌收缩（安胎作用）、促进乳腺腺泡发育。
    \item \textbf{胰岛素敏感性下降（生理性胰岛素抵抗）：}由HCS、雌激素、孕激素及皮质醇等共同介导，是妊娠期糖尿病（GDM）的生理基础。
\end{itemize}

\textbf{2. 消化系统：}
\begin{itemize}[leftmargin=*]
    \item 贲门括约肌松弛→\keyword{早孕反应}（恶心、呕吐、胃灼热）。
    \item 胃肠道蠕动减慢→有利于营养素的吸收（尤其是钙、铁、叶酸），但易出现便秘。
\end{itemize}

\textbf{3. 循环系统：}血容量显著增加（孕中期起），血浆容量增加幅度大于红细胞增加幅度，出现\keyword{生理性贫血}。通常在孕20\~{}30周最明显。

\textbf{4. 体重增长：}正常体重女性（BMI 18.5\~{}23.9 kg/m$^{2}$）的孕期推荐体重增长范围为8\~{}14 kg，平均约12.5 kg。
\end{keybox}

\textbf{关键微量营养素需求：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{叶酸（Folate）——最重要的孕前/孕期微量营养素：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{推荐摄入量：}备孕妇女应从计划怀孕前3个月开始每日补充\keyword{叶酸400 μg DFE/d}（膳食叶酸当量），或含等量叶酸的复合维生素补充剂，并持续至整个孕期。
        \item \textbf{预防神经管缺陷（Neural Tube Defects, NTDs）：}叶酸缺乏是胎儿神经管未能正常闭合（如脊柱裂、无脑儿）的确定病因，充足叶酸补充可使NTDs发生率降低70\%。孕后3\~{}8周是神经管闭合关键期（此时许多妇女尚不知已怀孕），故必须从孕前开始补充。
        \item \textbf{膳食来源：}深绿色叶菜、肝脏、豆类、强化面粉。
    \end{itemize}
    \item \textbf{铁（Iron）：}
    \begin{itemize}[leftmargin=*]
        \item RNI：\keyword{孕中期25 mg/d，孕晚期29 mg/d}（较非孕期增加约10\~{}12 mg/d）。
        \item 孕期对铁的需求大幅增加——用于母体红细胞含量增加、胎儿和胎盘需要、产时失血储备。
        \item \textbf{生理性贫血的判断标准（WHO）：}孕期Hb < 110 g/L（非孕女性 < 120 g/L）。
    \end{itemize}
    \item \textbf{碘（Iodine）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{RNI：230 μg/d}（较非孕增加约110 μg/d）。
        \item \textbf{严重缺乏可致克汀病（先天性碘缺乏综合征、矮小、智力严重障碍）：}因胎儿甲状腺激素依赖母体碘供给。
    \end{itemize}
    \item \textbf{钙（Calcium）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{RNI：800 mg/d}（孕期钙吸收率显著提高以补偿钙需求）。
        \item 充足摄入可降低妊娠期高血压疾病（妊高征/子痫前期）的发病风险。
    \end{itemize}
    \item \textbf{维生素D：}RNI 10 μg/d（400 IU/d）。缺乏导致新生儿低钙血症和佝偻病风险增加。
\end{enumerate}

\begin{exambox}
\textbf{考点提示——孕期碳水化合物最低量（130 g/d）：}为预防酮体对胎儿中枢神经系统的毒性，孕妇每日碳水化合物摄入量不得低于130 g。在严重早孕呕吐无法进食时，应静脉补充葡萄糖以确保此最低量。
\end{exambox}

\subsection{孕期膳食指南（2022版）——六条核心推荐}

\begin{keybox}
\textbf{《中国孕期妇女膳食指南（2022）》六条核心推荐：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{孕前将体重调整至适宜范围：}使BMI保持在18.5\~{}23.9 kg/m$^{2}$的正常范围内再怀孕。
    \item \textbf{补充叶酸（400 μg DFE/d），常吃含铁丰富的食物，选用碘盐：}从备孕前3个月开始，每日补充叶酸；每周摄入1\~{}2次动物血或肝脏；使用加碘食盐。
    \item \textbf{孕吐严重者，可少量多餐，保证摄入至少130 g/d的碳水化合物：}选择含水分少的谷类制品，避免油炸和油腻食物。
    \item \textbf{孕中晚期适量增加奶、鱼、禽、蛋、瘦肉的摄入：}满足蛋白质+15 g/d（孕中期）和+30 g/d（孕晚期）的增量需求。孕中期每日增加200 g奶及50 g鱼/禽/蛋/瘦肉；孕晚期每日增加200 g奶及125 g鱼/禽/蛋/瘦肉。
    \item \textbf{适量身体活动，维持孕期适宜体重：}每周测量体重。无医学禁忌者每日进行不少于30分钟的中等强度身体活动，如散步、孕妇体操等。
    \item \textbf{禁烟酒，愉快孕育新生命：}孕妇应禁烟酒，避免被动吸烟和不良情绪。
\end{enumerate}
\end{keybox}

% ----- 第三节 乳母营养 -----
\section{乳母营养}

\subsection{泌乳量与母乳分期}

\begin{keybox}
\textbf{泌乳量：}前6个月平均泌乳量约\keyword{750 ml/d}。泌乳量随婴儿生长逐渐增加：1个月约650 ml/d，3个月约750\~{}1000 ml/d，此后基本稳定在750\~{}800 ml/d。

\textbf{不同阶段母乳的成分变化：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{初乳（Colostrum，产后$\sim$7天）：}脂肪和乳糖含量少但低聚糖高；蛋白质高，多为乳清蛋白；\keyword{免疫球蛋白和细胞因子丰富（SIgA、IL）}；维生素A、锌、铜含量高。
    \item \textbf{过渡乳（Transitional Milk，7$\sim$15天）：}蛋白质总量逐渐减少，脂类和乳糖含量逐渐增高。
    \item \textbf{成熟乳（Mature Milk，15天$\sim$）：}蛋白质含量相对低，乳糖和脂类含量较高。前乳（喂养开始部分）较稀约1\%脂肪、富含蛋白质和乳糖；后乳（喂养末尾部分）脂肪含量可达4\%\~{}5\%，为婴儿提供主要能量。
\end{enumerate}

\textbf{乳汁生成方式：}①直接进入乳汁——钠、钾、磷、镁、氯、大多水溶性维生素和水、血浆；②在乳腺内合成且受激素调控——乳糖由葡萄糖合成（受孕酮、催乳素调控）、乳脂在乳汁内形成膜包围的脂肪小球；③免疫物质——巨噬细胞分泌溶菌酶和乳铁蛋白，淋巴细胞产生IgA和干扰素。
\end{keybox}

\subsection{哺乳对母婴双方的益处}

\begin{keybox}
\textbf{母乳喂养对母体的益处：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{促进子宫复原：}吸吮刺激催产素（Oxytocin）释放，加速产后子宫收缩和恢复，减少产后出血。
    \item \textbf{降低远期疾病风险：}哺乳可降低母体患\keyword{乳腺癌、卵巢癌和2型糖尿病（T2DM）}的风险，哺乳时间越长保护效应越明显。
    \item \textbf{促进能量负平衡：}哺乳每日消耗约\~{}650 kcal能量，有助于产后体重恢复。
    \item \textbf{促进母婴情感联结：}哺乳过程中的肌肤接触可促进母子依恋关系的建立。
    \item \textbf{天然避孕作用（哺乳期闭经法，LAM）：}纯母乳喂养在产后6个月内具有一定的避孕效果（需满足三个条件：月经未恢复、纯母乳喂养、婴儿<6月龄）。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{泌乳过程的神经内分泌调节：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{产奶反射（Milk Production Reflex）：}婴儿吸吮乳头 $\rightarrow$ 刺激下丘脑分泌\keyword{催乳素（Prolactin）} $\rightarrow$ 催乳素与乳腺分泌细胞结合 $\rightarrow$ 促进RNA和DNA合成 $\rightarrow$ 乳腺合成酪蛋白和$\alpha$-乳清蛋白等乳汁成分。
    \item \textbf{下奶反射（Let-down Reflex）：}婴儿吸吮 $\rightarrow$ 下丘脑分泌\keyword{催产素（Oxytocin）} $\rightarrow$ 催产素刺激乳腺肌上皮细胞收缩 $\rightarrow$ 排乳。
\end{enumerate}
\end{keybox}

\subsection{哺乳期膳食指南核心推荐}

\begin{keybox}
\textbf{哺乳期妇女膳食指南核心推荐：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{增加富含优质蛋白质及维生素A的动物性食物和海产品摄入：}每日鱼、禽、蛋、瘦肉总量增至200\~{}250 g；每周摄入1\~{}2次动物肝脏（总量85 g猪肝或40 g鸡肝）。
    \item \textbf{保证充足的能量和液体摄入：}能量在孕前基础上增加400 kcal/d；每日饮水量（含汤水）应达到2100 ml。
    \item \textbf{增加钙摄入，重视哺乳期骨骼健康：}每日饮奶400\~{}500 ml，保证钙摄入800 mg/d；多户外活动，补充维生素D。
    \item \textbf{保持身心愉快，保证充足睡眠：}充足的休息和良好的心理状态是维持泌乳量的必要条件。
    \item \textbf{坚持哺乳，适量身体活动：}有助于产后体重恢复和体型重塑。
    \item \textbf{禁烟酒，避免浓茶和咖啡：}咖啡因可经乳汁分泌，每日不超过1\~{}2杯。
\end{enumerate}
\end{keybox}

% ----- 第四节 婴幼儿营养 -----
\section{婴幼儿营养}

\begin{keybox}
\textbf{婴幼儿营养分段管理：}
\begin{itemize}[leftmargin=*]
    \item \textbf{0\~{}6月龄：}纯母乳喂养（Exclusive Breastfeeding）。如无母乳，应给予婴儿配方食品，不可直接用牛乳替代。
    \item \textbf{7\~{}24月龄：}持续母乳喂养+辅食添加（Complementary Feeding）。
\end{itemize}
\end{keybox}

\subsection{0\~{}6月龄——纯母乳喂养指南}

\begin{keybox}
\textbf{《0\~{}6月龄婴儿母乳喂养指南（2022）》核心推荐：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{尽早开奶，初乳为第一口食物：}出生后1小时内开始母乳喂养，产后早期接触有利于建立喂养关系。初乳中丰富的免疫活性物质可为新生儿提供重要的被动免疫保护。
    \item \textbf{坚持纯母乳喂养至6月龄：}不添加水、其他液体和辅食，仅母乳。母乳能够满足6月龄内婴儿全部液体、能量和营养素的需要。
    \item \textbf{按需哺乳（Responsive Feeding）：}按婴儿饥饿信号（觅食反射、吸吮动作）适时喂养，而非固定时间刻板喂养。每日喂8\~{}12次或以上。
    \item \textbf{生后数日开始补充维生素D 400 IU/d（10 μg/d）：}母乳中维生素D含量极低（$\sim$22 IU/L），必须额外补充，无需补钙。
    \item \textbf{定期监测生长指标：}每月测量体重、身长和头围，使用WHO生长标准曲线评估喂养是否充足。
    \item \textbf{不推荐6月龄前喂牛乳/羊乳：}因铁含量低、蛋白质和矿物质含量过高对婴儿肾脏负担过重，且可导致肠道微量出血。
\end{enumerate}
\end{keybox}

\subsection{母乳的优势}

\begin{enumerate}[leftmargin=*]
    \item \textbf{蛋白质优势：}以\keyword{$\alpha$-乳白蛋白（$\alpha$-Lactalbumin）}为主（占乳清蛋白的41\%），易于消化且过敏性低。酪蛋白与乳清蛋白比例适宜（40:60）。
    \item \textbf{免疫因子：}
    \begin{itemize}[leftmargin=*]
        \item \keyword{乳铁蛋白（Lactoferrin）}：竞争性结合铁，抑制需铁细菌生长。
        \item \keyword{溶菌酶（Lysozyme）}：直接破坏细菌细胞壁。
        \item \keyword{分泌型免疫球蛋白A（sIgA）}：覆盖在婴儿肠黏膜表面，阻断病原体和过敏原的黏附。
    \end{itemize}
    \item \textbf{钙磷比优化：}母乳Ca:P $\approx$ 2:1，利于钙吸收。
    \item \textbf{低聚糖（Oligosaccharides）：}母乳特有的低聚糖可作为益生元，促进双歧杆菌和乳酸杆菌的定植和增殖，构建健康的婴儿肠道微生物群。
    \item \textbf{DHA（二十二碳六烯酸）：}母乳中含有DHA，对婴儿大脑和视觉的发育至关重要。
\end{enumerate}

\subsection{7\~{}24月龄——辅食添加六大准则}

\begin{keybox}
\textbf{《7\~{}24月龄婴幼儿喂养指南（2022）》六大准则：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{继续母乳喂养，满6月龄起添加辅食：}辅食添加从满6月龄（约180天）开始，持续母乳喂养至2岁或以上。7\~{}12月龄母乳仍可提供约1/2的能量和蛋白质。
    \item \textbf{从富含铁的泥糊状食物开始，逐步添加达到食物多样：}第一口辅食首选\keyword{富含铁的泥糊状食物}（强化铁的米粉、动物肝脏泥、瘦肉泥）。6月龄时婴儿体内储存的铁已耗尽——\textbf{7\~{}12月龄99\%的铁必须从辅食中获得}，\textbf{75\%的锌同样来自辅食}。
    \item \textbf{提倡顺应喂养，鼓励但不强迫进食：}父母负责提供食物，婴儿决定吃多少。耐心喂养，不强迫、不哄骗，营造愉快的进餐氛围。每次进餐不超过20分钟。
    \item \textbf{辅食不加调味品，尽量减少糖和盐的摄入：}12月龄前辅食中不添加盐、糖及刺激性调味品——保护肾脏不成熟，培养清淡口味，降低日后高血压和慢性病风险。1岁以后逐渐尝试淡口味家庭膳食。
    \item \textbf{注重饮食卫生和进食安全：}辅食制作过程保持清洁，生熟分开。食物应彻底煮熟，不喂食剩饭菜。进食时应有成人看护，防止噎呛。
    \item \textbf{定期监测体格指标，追求健康生长：}每3个月测量体重、身长和头围。参照WHO生长曲线，只要生长趋势正常就无需过分纠结每餐食量。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{辅食添加的技巧（循序渐进）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{每次一种：}每次只添加一种新食物，观察3\~{}5天以排除过敏。
    \item \textbf{由少到多：}从1勺开始，逐渐增加到一餐。
    \item \textbf{由稀到稠：}从泥糊状→碎末状→小块状→条状。
    \item \textbf{由细到粗。}
\end{itemize}

\textbf{辅食添加常见误区：}
\begin{itemize}[leftmargin=*]
    \item 误区1："婴儿需要喝米汤（粥）就够了"——米汤能量和铁含量极低，无法满足7\~{}12月龄婴儿的营养需求。
    \item 误区2："加辅食后母乳就不重要了"——母乳仍然是重要的营养来源，尤其是优质蛋白质和多种免疫活性物质。
\end{itemize}
\end{tipbox}

% ----- 第五节 学龄前儿童营养 -----
\section{学龄前儿童营养（了解）}

\subsection{生理特点}

\begin{keybox}
\textbf{学龄前儿童（3\~{}6岁）的主要生理特点：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{生长发育速率趋缓：}与婴幼儿期相比，生长速率明显减慢，体重年增长约2 kg，身高年增长约5\~{}7 cm。
    \item \textbf{消化系统功能仍不完善：}咀嚼能力较幼儿提高但仍有限，胃肠道消化酶分泌不足，对粗糙、油腻食物的消化能力较弱。
    \item \textbf{神经系统持续发育：}3岁时脑重约为成人的80\%，6岁时可达成人的90\%。神经髓鞘形成持续进行，精细动作协调能力逐渐增强。
    \item \textbf{免疫功能逐渐成熟：}随年龄增长，自身免疫系统日趋完善，但仍易发生感染性疾病。
    \item \textbf{心理和行为发展迅速：}注意力持续时间短，好奇心强，模仿能力增强，易受环境和同伴影响。此时期是培养良好饮食行为习惯的关键窗口期。
    \item \textbf{常见营养问题：}挑食偏食、零食摄入过多影响正餐、含糖饮料摄入过量、钙和铁摄入不足、超重和肥胖呈上升趋势。
\end{enumerate}
\end{keybox}

\subsection{学龄前儿童膳食指南（2022版）——八大核心推荐+五条补充}

\begin{keybox}
\textbf{一般人群膳食指南八大准则（在此年龄段同样适用）：}
\begin{enumerate}[leftmargin=*]
    \item 食物多样，合理搭配
    \item 吃动平衡，健康体重
    \item 多吃蔬果、奶类、全谷、大豆
    \item 适量吃鱼、禽、蛋、瘦肉
    \item 少盐少油，控糖限酒
    \item 规律进餐，足量饮水
    \item 会烹会选，会看标签
    \item 公筷分餐，杜绝浪费
\end{enumerate}

\vspace{4pt}
\textbf{学龄前儿童膳食五条补充推荐：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{规律就餐，自主进食不挑食，培养良好饮食习惯：}每日安排\keyword{三次正餐+2\~{}3次加餐}。加餐以奶类、水果为主，量不宜多，以免影响正餐。鼓励儿童自己使用筷子、勺子进食。
    \item \textbf{每天饮奶，足量饮水，正确选择零食：}每日饮奶300\~{}400 ml（或相当量奶制品）。除奶以外，每日饮水量600\~{}800 ml，以白开水为主，少量多次。零食应选择新鲜水果、奶制品、坚果等，限制高盐高糖高脂的零食。
    \item \textbf{食物应合理烹调，易于消化，少调料、少油炸：}采用蒸、煮、炖、煨等烹饪方式。食物切成小块或细丝，注意色、香、味搭配以刺激食欲。每人每日食盐<3 g。
    \item \textbf{参与食物选择与制作，增进对食物的认知与喜爱：}鼓励儿童参与择菜、洗菜、摆餐具等力所能及的家务劳动，了解食物来源，培养对食物的兴趣。
    \item \textbf{经常户外活动，保障健康生长：}每日户外活动时间不少于\keyword{2小时}（其中至少60分钟中等及以上强度身体活动）。每日视屏时间不超过1小时。减少久坐行为，保证充足睡眠（3\~{}5岁: 10\~{}13小时/天；6岁: 9\~{}11小时/天）。
\end{enumerate}
\end{keybox}

% ----- 第六节 学龄儿童和青少年营养 -----
\section{学龄儿童和青少年营养}

\subsection{生理特点}

\begin{keybox}
\textbf{学龄儿童（6\~{}12岁）和青少年（12\~{}18岁）的主要生理特点：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{第二生长高峰（青春期，Puberty）：}是除外婴儿期的第二个生长发育飞跃期。青春期前生长缓慢（5\~{}6 cm/年），青春期峰值为8\~{}12 cm/年。女孩青春期通常始于10\~{}12岁（乳房发育为起始标志），男孩始于12\~{}14岁（睾丸增大为起始标志）。
    \item \textbf{身体构成显著变化：}青春期内男性肌肉含量大幅增加（睾酮的蛋白同化作用），女性体脂占比高于男性（雌激素作用）。瘦体重（去脂体重）的性别差异在青春期扩大。
    \item \textbf{性成熟与第二性征发育：}女孩——乳房发育→阴毛出现→月经初潮（平均12\~{}13岁）；男孩——睾丸增大→阴茎增长→阴毛出现→首次遗精（平均14\~{}15岁）。
    \item \textbf{骨量快速增长——峰值骨量积累关键期：}青春期是获得峰值骨量（Peak Bone Mass）的最关键阶段，约45\%的成人骨量在青春期积累。充足的钙摄入和体力活动是最大化峰值骨量的核心因素。
    \item \textbf{认知和心理社会发育：}抽象思维能力增强，独立意识增加，同伴影响力显著上升。此时期易出现饮食行为偏离（节食减肥、不吃早餐、在外就餐增多）。
\end{enumerate}
\end{keybox}

\subsection{营养需要}

\begin{keybox}
\textbf{学龄儿童和青少年关键营养素需求特点：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{能量：}青春期能量需求显著增加。11\~{}13岁男2050 kcal/d、女1800 kcal/d；14\~{}17岁男2500 kcal/d、女2000 kcal/d。个体差异大，受身体活动水平影响显著。
    \item \textbf{蛋白质：}青春期蛋白质RNI为55\~{}75 g/d（男>女），约占能量的12\%\~{}14\%。蛋白质供给应确保优质蛋白质（动物性食物+大豆）占1/2以上。\keyword{蛋白质长期摄入不足可致青春期生长迟滞。}
    \item \textbf{钙：}青春期钙RNI为1000\~{}1200 mg/d（峰值骨量积累关键窗口期）。奶及奶制品是最佳钙来源。\keyword{青少年钙摄入不足将无法达到遗传决定的峰值骨量，大幅增加老年期骨质疏松风险。}
    \item \textbf{铁：}青春期铁需求量大幅增加——男孩来自肌肉和血容量增加，女孩则需要弥补月经铁的损失。11\~{}13岁男15 mg/d、女18 mg/d；14\~{}17岁男16 mg/d、女18 mg/d。\keyword{青春期女性是缺铁性贫血高发人群。}
    \item \textbf{锌：}RNI 9\~{}11.5 mg/d。锌缺乏可导致青春期生长迟缓和性发育延迟。
    \item \textbf{碘：}RNI 110\~{}120 μg/d。碘缺乏可导致甲状腺肿和认知功能下降。
    \item \textbf{维生素D：}RNI 10 μg/d（400 IU/d），对于骨骼钙化至关重要。
\end{enumerate}
\end{keybox}

\subsection{主要营养问题与膳食建议}

\begin{enumerate}[leftmargin=*]
    \item \textbf{营养不良和微量营养素缺乏：}
    \begin{itemize}[leftmargin=*]
        \item 铁缺乏/缺铁性贫血（青春期女性最突出）
        \item 钙摄入不足（饮奶量不足，含糖饮料替代奶类）
        \item 锌缺乏可影响青春期发育和免疫功能
    \end{itemize}
    \item \textbf{超重和肥胖：}含糖饮料摄入增加、屏幕时间延长、身体活动不足、不吃早餐/在外就餐频率增高。
    \item \textbf{饮食行为问题：}不吃早餐、偏食挑食、频繁在外就餐、盲目节食减肥（少女多见，可致月经失调和低骨量）。
\end{enumerate}

\textbf{膳食建议：}
\begin{itemize}[leftmargin=*]
    \item 保证充足的钙（每日奶300\~{}500 ml）和铁（红肉、动物血、动物肝脏）摄入。
    \item 三餐规律，尤其是早餐——提供全天能量的25\%\~{}30\%。
    \item 限制含糖饮料和零食，鼓励白开水为主要饮品。
    \item 每日户外活动时间不少于1小时，减少视屏时间<2小时/日。
    \item 女孩警惕盲目节食减肥的危害——可致营养不良性闭经和不可逆的骨量丢失。
\end{itemize}

% ----- 第七节 老年人营养 -----
\section{老年人营养}

\subsection{老年人的生理变化与衰老机制}

\begin{keybox}
\textbf{衰老的自由基学说（Free Radical Theory of Aging）：}
\begin{itemize}[leftmargin=*]
    \item 1956年由Harman提出，是目前比较公认的衰老学说之一。
    \item 自由基攻击细胞膜脂类中的不饱和脂肪酸 $\rightarrow$ 细胞间信息传导受损 $\rightarrow$ 进而破坏细胞内的蛋白质、脂类及核酸。
    \item \keyword{有氧呼吸导致氧损伤的累积是引起机体衰老死亡的主要原因。}
    \item 人体内存在的抗氧化防御系统：SOD（超氧化物歧化酶）、GPx（谷胱甘肽过氧化物酶）、金属硫蛋白等。膳食中摄入的维生素E、维生素C、$\beta$-胡萝卜素等也具有抗氧化作用。
    \item \textbf{核心矛盾：}维持生命 $\rightarrow$ 摄取食物获得营养 $\rightarrow$ 产生自由基 $\rightarrow$ 可以修复但损害累积 $\rightarrow$ 重要器官老化或突变。
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{衰老的相关生理改变（不可逆性进程）：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{体成分变化：}
    \begin{itemize}[leftmargin=*]
        \item 皮肤弹性下降，身高每10年下降约1 cm。
        \item \textbf{体内水分和瘦组织减少，体脂含量增加}（尤其向心性脂肪分布）。
        \item \textbf{肌肉衰减综合征（\keyword{少肌症/Sarcopenia}）：}50岁后肌肉量以每年1\%\~{}2\%的速度下降，60岁以上患病率约5\%\~{}13\%（65岁以上可达15\%\~{}50\%）。表现为骨骼肌质量、力量和功能的进行性丧失。后果：跌倒、骨折、失能、生活质量下降和死亡率增加。
    \end{itemize}
    \item \textbf{器官变化：}
    \begin{itemize}[leftmargin=*]
        \item 脑神经元数量减少10\%\~{}30\%，认知功能可下降（但并非必然发展为痴呆）。
        \item 心肌发生褐色萎缩，血管弹性减退，心输出量减少。
        \item 肾脏功能退化（肾小球滤过率及肾小管重吸收能力降低）。
    \end{itemize}
    \item \textbf{代谢变化：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{基础代谢率（BMR）下降：}约每10年下降2\%，导致能量需求减少。
        \item \textbf{分解代谢>合成代谢：}常出现负氮平衡——骨胶原丢失、肌肉量减少。
    \end{itemize}
    \item \textbf{感觉功能减退：}味觉（味蕾数量减少70\%）和嗅觉敏感度下降，可导致食欲降低和膳食选择偏向高盐高糖食物。
    \item \textbf{消化系统功能减弱：}胃酸分泌减少（萎缩性胃炎高发→影响维生素B$_{12}$和钙的吸收），肠蠕动减慢（便秘），吞咽功能下降。
\end{enumerate}
\end{keybox}

\subsection{老年人的营养需要}

\begin{keybox}
\textbf{老年人关键营养素推荐摄入量：}

\begin{center}
\begin{tabular}{lcc}
\hline
\textbf{营养素} & \textbf{50\~{}64岁} & \textbf{65岁以上} \\
\hline
能量（男/女，kcal/d）
  & 1950 / 1600
  & 1900 / 1550 \\
蛋白质（男/女，g/d）
  & 65 / 55
  & \textbf{72 / 62} \\
脂肪（\%能量）
  & 20\%\~{}30\%
  & 20\%\~{}30\% \\
碳水化合物（\%能量）
  & 50\%\~{}65\%
  & 50\%\~{}65\% \\
钙（mg/d）
  & 800
  & 800 \\
\hline
\end{tabular}
\end{center}
\end{keybox}

\textbf{重要说明：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{蛋白质需要量不减反增：}老年人蛋白质RNI为\keyword{1.0\~{}1.5 g/(kg$\cdot$d)}，高于普通成人的0.8 g/(kg$\cdot$d)。65岁以上男性72 g/d、女性62 g/d——均显著高于50岁组的65 g/d和55 g/d。原因：分解代谢亢进和合成抵抗（\keyword{Anabolic Resistance}）——衰老肌肉对较低剂量氨基酸/蛋白质的合成代谢反应下降，需要更多蛋白质刺激同等幅度的肌蛋白合成。
    \item \textbf{能量需求降低：}随年龄增长BMR下降和身体活动减少。
    \item \textbf{脂肪：}供能比建议为20\%\~{}30\%，脂肪酸组成应保持SFA:MUFA:PUFA = 0.8\~{}1:1:0.6\~{}0.8。
    \item \textbf{碳水化合物：}供能比50\%\~{}65\%，强调选择低血糖生成指数（\keyword{低GI}）的食物如全谷物、杂豆、薯类等。
    \item \textbf{钙：}800 mg/d——因钙吸收率随年龄下降（维生素D不足和肠道钙吸收障碍），预防骨质疏松。
    \item \textbf{维生素D：}65岁以上RNI为15 μg/d（600 IU/d），高于一般成人的10 μg/d。因皮肤合成能力下降和日照减少。
    \item \textbf{维生素B$_{12}$：}因萎缩性胃炎高发致胃酸和内因子分泌减少，B$_{12}$吸收障碍风险增加，必要时需强化或补充。
    \item \textbf{水：}老年人渴觉敏感性下降，易发生隐性脱水。在无禁忌情况下每日饮水量建议不少于1500 ml。
\end{enumerate}

\subsection{老年人膳食指南（2022版）——八大核心推荐+四条补充}

\begin{keybox}
\textbf{一般人群膳食指南八大准则（在此年龄段同样适用）：}
\begin{enumerate}[leftmargin=*]
    \item 食物多样，合理搭配
    \item 吃动平衡，健康体重
    \item 多吃蔬果、奶类、全谷、大豆
    \item 适量吃鱼、禽、蛋、瘦肉
    \item 少盐少油，控糖限酒
    \item 规律进餐，足量饮水
    \item 会烹会选，会看标签
    \item 公筷分餐，杜绝浪费
\end{enumerate}

\vspace{4pt}
\textbf{老年人四条补充推荐：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{食物多样，制作细软，少量多餐，预防营养缺乏：}
    \begin{itemize}[leftmargin=*]
        \item 选择柔软、细碎的食物和蒸煮炖等烹饪方法，以适应口腔和消化能力减弱。
        \item \keyword{每日三餐+2\~{}3次间餐}（上午加餐、下午加餐、睡前加餐），以维持血糖平稳并保证总摄入量充足。
        \item 日常膳食摄入不足或体重过低者，可在医生或营养师指导下使用营养素补充剂或全营养配方食品。
    \end{itemize}
    \item \textbf{主动足量饮水，积极户外活动：}
    \begin{itemize}[leftmargin=*]
        \item 每日饮水量至少1500 ml，少量多次，以白开水或淡茶水为主。
        \item \keyword{每日户外活动1\~{}2次，每日行走$\geq$6000步。}避免久坐，每小时起身活动。
        \item 选择适合自身状况的运动：散步、太极拳、健身操等。理想运动心率 $\approx$ 170 - 年龄。
    \end{itemize}
    \item \textbf{延缓肌肉衰减，维持适宜体重：}
    \begin{itemize}[leftmargin=*]
        \item 保证充足的蛋白质摄入（1.0\~{}1.5 g/(kg$\cdot$d)），每餐均匀分配蛋白质摄入量。
        \item 结合抗阻运动（如举轻哑铃、弹力带训练）可最大程度对抗少肌症进展。
        \item 老年人BMI应不低于20 kg/m$^{2}$，不宜过度追求"瘦"。
    \end{itemize}
    \item \textbf{鼓励陪伴进餐，保持良好食欲：}
    \begin{itemize}[leftmargin=*]
        \item \keyword{鼓励共同进餐（社交性进餐）}——与家人或朋友一起进餐有利于改善食欲和进食质量，预防孤独性营养不良。
        \item 营造愉快的进餐氛围，注意食物的色、香、味搭配。
        \item 关注老年人的口腔健康、咀嚼和吞咽能力，必要时调整食物质地。
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{成功衰老的概念}

\begin{defbox}
\textbf{成功衰老（Successful Aging）：}指在老年期尽可能延长健康寿命，维持高水平的生理和认知功能，仅于生命末期极短时间段出现功能下降和失能，实现"活得健康、走得从容"的老龄化目标。这与单纯追求寿命延长完全不同，后者可能伴随着长期的功能不全和生活质量下降。

\textbf{成功衰老的三大要素（Rowe \& Kahn模型）：}(1) 避免疾病和疾病相关失能；(2) 维持高水平的认知和身体功能；(3) 积极投入生活（社交参与和生产性活动）。
\end{defbox}

\section{运动员及特殊环境人群营养（了解）}

\subsection{运动员的营养特点}

\begin{itemize}[leftmargin=*]
    \item 能量需求因运动强度而高度可变（中等强度运动每日约+500\~{}1500 kcal）。
    \item 碳水化合物对运动表现至关重要——赛前3\~{}4天进行"糖原负荷法"（碳水化合物供能比$\geq 70\%$）可最大化糖原储存。
    \item 蛋白质摄入1.2\~{}2.0 g/(kg$\cdot$d)（耐力运动员偏低、力量运动员偏高）。
    \item 补液重要性——运动中每15\~{}20分钟饮水150\~{}300 ml。
    \item 铁缺乏在运动员（尤其是女性耐力运动员）中较常见。
\end{itemize}

\subsection{高温环境}

\begin{itemize}[leftmargin=*]
    \item 能量需求增加，水和电解质损失显著（出汗可流失3\~{}4 L/h）。
    \item 排汗失钠增加——补液应含电解质（0.5\~{}0.7 g/L钠）。
    \item 钾的需求增加，因汗中含钾。
    \item 注意补充水溶性维生素。
\end{itemize}

\subsection{低温环境}

\begin{itemize}[leftmargin=*]
    \item 能量需求显著增加（体热损失加速，基础代谢率上调）。
    \item 脂肪供能比例可升高——因脂肪的高能量密度和皮下脂肪的保温作用。
\end{itemize}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item 见本章各概念定义框。
    \item 核心：早期营养环境通过发育程序化（表观遗传机制）影响成年慢性疾病风险。指导意义：孕前和孕期营养干预是预防成人慢性病的根本策略，具有极高效费比。
    \item 见本章概念定义框。
    \item 孕早期E+0/P+0；孕中期E+250/P+15；孕晚期E+400/P+30。
    \item 叶酸缺乏致神经管缺陷（NTDs），孕后3\~{}8周是神经管闭合关键期（此时许多妇女尚不知已怀孕），故需孕前3个月开始补充。RNI为400 μg DFE/d。
    \item 低体重<18.5：11\~{}16kg；正常18.5\~{}23.9：8\~{}14 kg；超重24\~{}27.9：7\~{}11kg；肥胖$\geq$28：5\~{}9 kg。
    \item 防止酮体对胎儿中枢神经系统的毒性。严重早孕反应不能进食时需静脉补糖。
    \item 初乳：低脂肪/乳糖、高乳清蛋白/免疫球蛋白；过渡乳：成分过渡期；成熟乳：营养成分稳定，前乳以蛋白质和乳糖为主，后乳以高脂肪提供能量。
    \item (1) 促进子宫复原；(2) 降低乳腺癌/卵巢癌/T2DM风险；(3) 哺乳消耗能量，加速产后体重恢复；(4) 促进母婴情感联结；(5) 哺乳期闭经法（LAM）的天然避孕作用（满足三条件时）。
    \item 见本章定义框。
    \item (1) 继续母乳喂养，满6月龄起添加辅食；(2) 从富含铁的泥糊状食物开始，逐步达到食物多样；(3) 提倡顺应喂养，鼓励但不强迫；(4) 辅食不加调味品，尽量减少糖和盐；(5) 注重饮食卫生和进食安全；(6) 定期监测体格指标，追求健康生长。
    \item 六大准则见上题；(2) 添加技巧：每次一种新食物→观察3\~{}5天；由少到多；由稀到稠；由细到粗。首选强化铁米粉、肝泥、肉泥等富含铁的泥糊状食物。
    \item 保护肾脏不成熟、培养清淡口味（低盐饮食降低日后高血压和慢性病风险）。
    \item 乳铁蛋白：竞争结合铁、抑制需铁菌繁殖；溶菌酶：直接溶解细菌细胞壁；sIgA：覆盖肠黏膜表面，阻断病原体/过敏原粘附侵入。
    \item 生理特点：生长趋缓、消化功能不完善、神经系统持续发育、心理行为发展迅速。五条补充推荐：(1)规律就餐+自主进食；(2)每日饮奶300\~{}400ml+足量饮水+正确选零食；(3)合理烹调少调料；(4)参与食物选择制作；(5)每日户外活动$\geq$2h。
    \item 钙（1000\~{}1200 mg/d，峰值骨量关键期）、铁（女孩月经失铁致IDA高发）、能量（青春期需求显著增加）、蛋白质（55\~{}75 g/d，优质蛋白质占1/2以上）、锌（缺乏致生长迟缓和性发育延迟）。
    \item 见本章概念定义框。
    \item 能量降低原因：BMR下降（每10年\~{}2\%）、体力活动减少、瘦组织减少。蛋白质需增加原因：合成抵抗（Anabolic Resistance），老年人蛋白质合成对摄入蛋白质的敏感性下降，需要更高摄入量来刺激蛋白质合成、减缓肌肉丢失。
    \item 四大补充推荐：(1) 食物多样，制作细软，少量多餐，预防营养缺乏；(2) 主动足量饮水，积极户外活动（$\geq$6000步/日）；(3) 延缓肌肉衰减，维持适宜体重（蛋白质1.0\~{}1.5 g/(kg$\cdot$d)+抗阻运动）；(4) 鼓励陪伴进餐，保持良好食欲。
    \item 答题思路：(1) 生命早期1000天——DOHaD：孕期270d+0-2岁730d为机遇窗口，早期营养不良经表观遗传导致远期代谢综合征高风险；(2) 成年期：膳食行为和生活方式继续强化或修正早期程序化效应； (3) 老年期：少肌症与合成抵抗——蛋白质需要量不减反增（1.0-1.5 g/(kg$\cdot$d)），能量需求下降但蛋白质需求上升形成"老年人的营养悖论"，需配合运动干预以实现成功衰老。三者贯穿营养生命周期理念——营养影响不是点状而是连续的，早期干预效费比最高。
\end{enumerate}
