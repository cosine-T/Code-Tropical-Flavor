% ----- 第一节 DRIs（膳食营养素参考摄入量） -----
\section{DRIs（膳食营养素参考摄入量）}

\begin{defbox}
\textbf{膳食营养素参考摄入量（Dietary Reference Intakes, DRIs）：}为保证人体合理摄入营养素，避免缺乏和过量，以每日平均膳食营养素摄入量表示的一组参考值。DRIs是在RDA基础上发展起来的膳食营养素参考值体系。
\end{defbox}

\subsection{2013版DRIs指标体系（掌握\textsuperscript{*}）}

中国营养学会2013年发布的DRIs指标体系共包含7项指标，构成了完整的膳食营养素参考摄入量体系。

\begin{keybox}
\textbf{1. 平均需要量（Estimated Average Requirement, EAR）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{EAR}是某一特定性别、年龄及生理状况群体中个体对某营养素需要量的平均值。
    \item 根据EAR制定的推荐摄入量可满足50\%个体的需要，但不能满足另外50\%个体的需要。
    \item EAR是制定RNI的基础。
\end{itemize}

\textbf{2. 推荐摄入量（Recommended Nutrient Intake, RNI）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{RNI}可满足特定群体中97\%～98\%的个体需要量。
    \item 关系：\imp{RNI = EAR + 2SD}（SD为标准差）。若缺乏SD数据，则取EAR的变异系数10\%，即 \imp{RNI = EAR$\times$1.2}。
    \item RNI是健康个体日常营养素摄入量的目标值。
    \item 长期达到RNI水平，可满足机体对该营养素的需要，维持组织中有适当的储备。
\end{itemize}

\textbf{3. 适宜摄入量（Adequate Intake, AI）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{AI}在个体需要量研究资料不足、无法计算EAR时使用。
    \item 通过观察或实验获得的健康人群某种营养素的摄入量。
    \item AI可能高于RNI，其准确性不如RNI。
\end{itemize}

\textbf{4. 可耐受最高摄入量（Tolerable Upper Intake Level, UL）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{UL}是平均每日可以摄入营养素的最高限量。
    \item 对一般人群中几乎所有个体都不至于引起健康损害。
    \item 当摄入量超过UL时，引起不良作用的危险性随之增大。
    \item UL不是一个建议的摄入水平，而是安全上限。
\end{itemize}

\textbf{5. 宏量营养素可接受范围（Acceptable Macronutrient Distribution Range, AMDR）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{AMDR}指脂肪、蛋白质和碳水化合物理想的摄入量范围，以占总能量的百分比表示。
    \item 三大宏量营养素AMDR：蛋白质10\%～15\%，脂肪20\%～30\%，碳水化合物50\%～65\%。
\end{itemize}

\textbf{6. 预防非传染病慢性病的建议摄入量（Proposed Intake for Preventing Non-communicable Chronic Diseases, PI-NCD）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{PI-NCD}是以非传染性慢性病（NCD）一级预防为目标的必需营养素的每日摄入量。
    \item 2013版新增指标，体现了DRIs从预防缺乏病到预防慢性病的扩展。
\end{itemize}

\textbf{7. 特定建议值（Specific Proposed Level, SPL）：}
\begin{itemize}[leftmargin=*]
    \item \keyword{SPL}专用于营养素以外的其他食物成分（植物化学物等非营养素生物活性成分）。
    \item 如番茄红素、大豆异黄酮、植物甾醇等的建议摄入量。
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{DRIs指标框架的核心逻辑：}
\begin{center}
EAR $\rightarrow$ RNI（由EAR推导，满足绝大多数个体）\\
AI（EAR无法计算时的替代）\\
UL（安全上限，不能超过）\\
AMDR、PI-NCD、SPL（2013版新增，扩展应用维度）
\end{center}
\end{tipbox}

\begin{exambox}
\textbf{常见考法：}EAR与RNI的关系（EAR$\times$1.2=RNI）；RNI能满足多少百分比人群需要（97\%～98\%）；AMDR的三大宏量营养素比例；PI-NCD与SPL的区别（前者针对营养素、后者针对非营养素生物活性成分）。
\end{exambox}

\section{膳食模式与膳食指南}

\subsection{膳食模式的概念与分类（掌握）}

\begin{defbox}
\textbf{膳食模式（Dietary Pattern）：}指人们长期形成的膳食结构特征，包括食物种类、数量及其在膳食中所占的比例。膳食模式不仅反映个体或群体的饮食习惯，也与健康和疾病的发生密切相关。
\end{defbox}

\begin{keybox}
\textbf{世界三大膳食模式：}

\textbf{1. 西方膳食模式（Western Diet Pattern）：}
\begin{itemize}[leftmargin=*]
    \item 特点：\imp{高能量、高脂肪、高蛋白质}，动物性食物为主，精制谷物多，蔬菜水果少。
    \item 代表性地区：欧美发达国家。
    \item 健康风险：与肥胖、心血管疾病、糖尿病、某些癌症的高发有关。
    \item 优点：蛋白质和钙摄入充足；缺点：膳食纤维不足，饱和脂肪和添加糖过高。
\end{itemize}

\textbf{2. 东方膳食模式（Eastern Diet Pattern）：}
\begin{itemize}[leftmargin=*]
    \item 特点：\imp{以植物性食物为主}，谷物消费量大，动物性食物较少。
    \item 代表性地区：中国、日本等亚洲国家。
    \item 优点：膳食纤维丰富，脂肪供能比低；缺点：优质蛋白质和钙易不足，易出现营养缺乏病。
\end{itemize}

\textbf{3. 地中海膳食模式（Mediterranean Diet Pattern）：}
\begin{itemize}[leftmargin=*]
    \item 特点：\imp{大量蔬菜水果、橄榄油、鱼类、适量葡萄酒}。
    \item 代表性地区：希腊、意大利南部等环地中海国家。
    \item 优点：富含单不饱和脂肪酸（橄榄油）、$\omega$-3脂肪酸（鱼类）、多种抗氧化物质。
    \item 健康证据：多项研究证实降低心血管疾病、某些癌症和总死亡率风险。
    \item UNESCO于2010年将地中海饮食列为人类非物质文化遗产。
\end{itemize}
\end{keybox}

\subsection{《中国居民膳食指南》（2022版）核心原则（掌握）}

注：膳食指南每5年修订一次。2022版已更新为八条准则（原2016版为六条）。

\begin{keybox}
\textbf{《中国居民膳食指南》（2022版）八大准则：}

对于2岁以上所有健康人群：
\begin{enumerate}[leftmargin=*]
    \item \textbf{食物多样，合理搭配}
    \item \textbf{吃动平衡，健康体重}
    \item \textbf{多吃蔬果、奶类、全谷、大豆}
    \item \textbf{适量吃鱼、禽、蛋、瘦肉}
    \item \textbf{少盐少油，控糖限酒}
    \item \textbf{规律进餐，足量饮水}
    \item \textbf{会烹会选，会看标签}
    \item \textbf{公筷分餐，杜绝浪费}
\end{enumerate}
\end{keybox}

\subsection{素食模式与膳食结构补充}

\begin{keybox}
\textbf{素食模式（Vegetarian Pattern）：}

素食主义（Vegetarianism）是指不食用肉、家禽、鱼及其制品，食用或不食用奶制品和蛋类的生活习惯。根据膳食组成不同可分为：
\begin{itemize}[leftmargin=*]
    \item 纯素（Vegan）：不食用任何动物性食物
    \item 蛋奶素（Lacto-ovo Vegetarian）：食用奶类和蛋类
    \item 鱼素（Pescatarian）：食用鱼类但不食用其他肉类
\end{itemize}

素食模式含有更多的膳食纤维、镁、叶酸、维生素C、维生素E、n-6多不饱和脂肪酸、植物化学物和较低的胆固醇及饱和脂肪酸。
\end{keybox}

\begin{keybox}
\textbf{中国居民膳食结构现状：}

我国膳食结构呈现\keyword{并存和偏重}的特点：
\begin{enumerate}[leftmargin=*]
    \item 少部分地区仍保留了东方膳食结构（营养缺乏型）
    \item 大中城市等地区已转变为西方膳食结构（营养过剩型）
    \item 其他地区逐渐向西方膳食结构方向转变
\end{enumerate}
\end{keybox}

\subsection{原2016版六大核心推荐（参考）：}

\begin{keybox}
\textbf{《中国居民膳食指南》（2016版）六大核心推荐：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{食物多样，谷类为主：}
    \begin{itemize}[leftmargin=*]
        \item 每天摄入12种以上食物，每周25种以上。
        \item 每天摄入谷薯类食物250～400g，其中全谷物和杂豆50～150g，薯类50～100g。
    \end{itemize}

    \item \textbf{吃动平衡，健康体重：}
    \begin{itemize}[leftmargin=*]
        \item 各年龄段人群都应天天运动，保持健康体重。
        \item 主动身体活动最好每天6000步，每周至少进行5天中等强度身体活动，累计150分钟以上。
    \end{itemize}

    \item \textbf{多吃蔬果、奶类、大豆：}
    \begin{itemize}[leftmargin=*]
        \item 蔬菜：餐餐有蔬菜，每天摄入300～500g，深色蔬菜应占1/2。
        \item 水果：天天吃水果，每天摄入200～350g新鲜水果，果汁不能代替鲜果。
        \item 奶类：每天摄入相当于液态奶300g的奶制品。
        \item 大豆及坚果：经常吃豆制品，适量吃坚果。
    \end{itemize}

    \item \textbf{适量吃鱼、禽、蛋、瘦肉：}
    \begin{itemize}[leftmargin=*]
        \item 优先选择鱼和禽，吃鸡蛋不弃蛋黄，少吃肥肉、烟熏和腌制肉制品。
        \item 动物性食物摄入适量，不过量。
    \end{itemize}

    \item \textbf{少盐少油，控糖限酒：}
    \begin{itemize}[leftmargin=*]
        \item 成人每天食盐不超过6g（2016版）/ 5g（2022版更新），烹调油25～30g。
        \item 每天摄入添加糖不超过50g，最好控制在25g以下。
        \item 成人如饮酒，男性酒精量不超过25g/d，女性不超过15g/d。
    \end{itemize}

    \item \textbf{杜绝浪费，兴新食尚：}
    \begin{itemize}[leftmargin=*]
        \item 珍惜食物，按需备餐，提倡分餐制。
        \item 选择新鲜卫生的食物和适宜的烹调方式。
    \end{itemize}
\end{enumerate}
\end{keybox}

\section{营养调查与评价（掌握）}

\subsection{营养调查的目的与内容}

\begin{defbox}
\textbf{营养调查（Nutrition Survey）：}运用科学手段，在了解社会人群膳食摄入和营养水平的基础上，全面了解某一人群的营养状况的调查研究。
\end{defbox}

\begin{keybox}
\textbf{营养调查的目的：}
\begin{enumerate}[leftmargin=*]
    \item 了解不同地区、不同人群的膳食结构和营养状况。
    \item 发现营养不平衡人群（营养缺乏或营养过剩），分析原因。
    \item 评价营养干预措施的效果。
    \item 为制定营养政策和推荐食物生产计划提供科学依据。
\end{enumerate}

\textbf{营养调查的四项内容：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{膳食调查}：了解调查对象的食物和营养素摄入情况。
    \item \textbf{人体测量}：了解体格发育和营养状况。
    \item \textbf{临床检查}：检查营养缺乏病的体征和症状。
    \item \textbf{实验室检测}：测定血液、尿液中营养素及其代谢产物的含量，了解体内营养素水平。
\end{enumerate}
\end{keybox}

\subsection{膳食调查方法（掌握）}

\begin{keybox}
\textbf{常用膳食调查方法：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{24小时膳食回顾法（24-Hour Dietary Recall）：}
    \begin{itemize}[leftmargin=*]
        \item 调查对象回忆并描述过去24小时内摄入的所有食物和饮料。
        \item 优点：简便、耗时短、不改变饮食习惯。
        \item 缺点：依赖记忆，单日代表性不足，需要多日调查。
    \end{itemize}

    \item \textbf{食物频率问卷法（Food Frequency Questionnaire, FFQ）：}
    \begin{itemize}[leftmargin=*]
        \item 通过食物清单调查过去一段时间（通常一年）内各类食物的食用频率。
        \item 优点：可反映长期膳食习惯，适用于慢性病流行病学研究。
        \item 缺点：定量不够精确，依赖认知和记忆。
    \end{itemize}

    \item \textbf{称重法（Weighing Method）：}
    \begin{itemize}[leftmargin=*]
        \item 对调查期间食用的所有食物进行称重，计算摄入量。
        \item 优点：最精确，被视为膳食调查的"金标准"。
        \item 缺点：费时费力，可能影响调查对象的饮食习惯。
    \end{itemize}

    \item \textbf{记账法（Accounting Method）：}
    \begin{itemize}[leftmargin=*]
        \item 通过记录调查期间食物采购和消耗的账目，计算人均食物摄入量。
        \item 优点：适用于集体膳食单位（食堂、学校、部队），简便经济。
        \item 缺点：无法获得个体摄入情况。
    \end{itemize}

    \item \textbf{化学分析法（Chemical Analysis）：}
    \begin{itemize}[leftmargin=*]
        \item 收集调查对象实际摄入食物的平行样品，实验室分析营养素含量。
        \item 优点：结果最准确。
        \item 缺点：成本高，操作复杂，仅用于科研。
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{人体测量与BMI（掌握）}

\begin{keybox}
\textbf{人体测量常用指标：}
\begin{itemize}[leftmargin=*]
    \item 身高（Height）、体重（Weight）
    \item 围度：腰围（Waist Circumference）、臀围（Hip Circumference）
    \item 皮褶厚度（Skinfold Thickness）：反映皮下脂肪储备
    \item 上臂肌围：反映骨骼肌储备
\end{itemize}

\textbf{体重指数（Body Mass Index, BMI）：}

\imp{BMI = 体重(kg) / 身高$^2$(m$^2$)}

\textbf{中国成人BMI评价标准（掌握）：}
\begin{center}
\begin{tabular}{@{}ll@{}}
\toprule
\textbf{BMI范围（kg/m$^2$）} & \textbf{评价} \\
\midrule
< 18.5 & 消瘦（体重过低） \\
18.5 ～ 23.9 & 正常范围 \\
24.0 ～ 27.9 & 超重 \\
$\geq$ 28.0 & 肥胖 \\
\bottomrule
\end{tabular}
\end{center}

\begin{tipbox}
\textbf{腰围辅助判定标准：}男性腰围 $\geq$ 90cm（原85cm），女性 $\geq$ 85cm（原80cm）为中心性肥胖（腹型肥胖），即使BMI正常也提示代谢风险增高。
\end{tipbox}
\end{keybox}

% ----- 第四节 公共营养改善 -----
\section{公共营养改善（熟悉）}

\subsection{主要改善措施}

\begin{itemize}[leftmargin=*]
    \item \textbf{食物强化（Food Fortification）：}将某种微量营养素人为添加到特定食物中，以提高其营养价值。代表：\imp{碘盐}（加碘食盐防治碘缺乏病）、\imp{强化面粉}（铁强化面粉防治缺铁性贫血）、维生素A强化植物油。
    \item \textbf{营养教育（Nutrition Education）：}通过信息传播和行为干预，帮助个体和群体掌握食物与营养知识，形成健康的饮食习惯。
    \item \textbf{营养干预（Nutrition Intervention）：}针对特定营养不良问题，采取有计划的改善行动。如学校营养午餐计划、贫困地区儿童营养改善项目。
    \item \textbf{营养立法与政策：}制定和实施食物和营养相关的法律法规和政策，如《国民营养计划》。
\end{itemize}

\subsection{国民营养计划（2017--2030）}

\begin{defbox}
\textbf{国民营养计划（2017--2030年）：}国务院办公厅印发，有步骤地提高国民营养健康水平。设定具体指标目标，覆盖全人群、全生命周期。
\end{defbox}

\textbf{主要目标指标（2020年/2030年）：}
\begin{itemize}[leftmargin=*]
    \item 5岁以下儿童贫血率：<12\% / <10\%
    \item 5岁以下儿童生长迟缓率：<7\% / <5\%
    \item 0～6个月婴儿纯母乳喂养率：>50\% / >60\%
    \item 人均每日食盐摄入量：较2015年降低10\% / 降低20\%
\end{itemize}

\subsection{营养监测与恩格尔系数}

\begin{defbox}
\textbf{营养监测（Nutrition Surveillance）：}长期、连续地收集、分析、解释和传播与人群营养有关信息，用于改善人群营养状况的公共卫生措施。
\end{defbox}

\begin{keybox}
\textbf{恩格尔系数（Engel Coefficient）：}
\begin{itemize}[leftmargin=*]
    \item 公式：恩格尔系数 = 食品支出总额 / 家庭或个人消费支出总额 $\times$ 100\%。
    \item 评价标准：>59\% 贫困，50\%～59\% 温饱，40\%～50\% 小康，30\%～40\% 富裕，<30\% 最富裕。
    \item 恩格尔系数是反映一个国家或地区居民生活水平的重要指标。
\end{itemize}
\end{keybox}

% ----- 第五节 膳食调查评价标准 -----
\section{膳食调查结果评价标准}

\begin{keybox}
\textbf{能量及营养素摄入量评价标准：}
\begin{itemize}[leftmargin=*]
    \item \textbf{供给充足：}实际摄入量 $>$ 90\% RNI（或AI）
    \item \textbf{供给不足：}实际摄入量 $<$ 80\% RNI（或AI），长期供给不足可导致营养不良
    \item \textbf{供给严重缺乏：}实际摄入量 $<$ 60\% RNI（或AI），长期供给缺乏可造成严重健康损害
\end{itemize}

\textbf{三大宏量营养素供能比评价：}
\begin{itemize}[leftmargin=*]
    \item 蛋白质供能比 = 蛋白质摄入量(g) $\times$ 4 / 能量摄入量(kcal) $\times$ 100（参考范围：10\%$\sim$15\%）
    \item 脂肪供能比 = 脂肪摄入量(g) $\times$ 9 / 能量摄入量(kcal) $\times$ 100（参考范围：20\%$\sim$30\%）
    \item 碳水化合物供能比 = 碳水化合物摄入量(g) $\times$ 4 / 能量摄入量(kcal) $\times$ 100（参考范围：50\%$\sim$65\%）
\end{itemize}

\textbf{三餐能量分配：}适宜早餐:中餐:晚餐 = 3:4:3（或3:4:3）。
\end{keybox}

% ----- 第六节 食品营养强化 -----
\section{食品营养强化}

\begin{defbox}
\textbf{食品营养强化（Food Fortification）：}根据营养需要向食品中添加一种或多种营养素、或者某些天然食品，以提高食品营养价值的过程。所添加的物质称为\keyword{食品强化剂}，指为增强营养成分而加入食品中的天然的或者人工合成的属于天然营养素范围的食品添加剂。
\end{defbox}

\begin{keybox}
\textbf{食品营养强化的意义：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{弥补天然食物的营养缺陷：}如向谷类食品中添加赖氨酸。
    \item \textbf{补充加工贮运过程中损失的营养素：}如向精白米面中添加B族维生素。
    \item \textbf{满足特定人群的营养需要：}如配方奶粉、要素膳等。
    \item \textbf{预防营养不良：}如食盐加碘预防碘缺乏病。
    \item \textbf{简化膳食处理，方便摄入：}如婴儿配方食品。
\end{enumerate}
\end{keybox}

% ----- 第七节 食品营养标签 -----
\section{食品营养标签（掌握）}

\begin{defbox}
\textbf{食品营养标签：}向消费者提供食品营养信息和特性的说明，包括营养成分表、营养声称和营养成分功能声称三部分。
\end{defbox}

\subsection{营养成分表}

\textbf{主要内容：}
\begin{itemize}[leftmargin=*]
    \item 强制标示：能量、蛋白质、脂肪、碳水化合物、钠（1+4核心营养素）。
    \item 反式脂肪酸：当配料中使用氢化油脂时必须标示。
    \item 标示单位：每100g、每100mL或每份。
    \item \keyword{营养素参考值（Nutrient Reference Value, NRV）}：用于比较不同食品中营养素含量的参考值，以NRV\%表示。NRV\% = 食品中营养素含量 / NRV $\times$ 100\%。
\end{itemize}

\begin{exambox}
\textbf{常见考点：}NRV是营养标签中用于标注每份食物提供该营养素占每日推荐量百分比的标准参考值，并非个体精确需要量。NRV常用于帮助消费者比较不同食品的营养价值。
\end{exambox}

\subsection{营养声称与功能声称}

\begin{itemize}[leftmargin=*]
    \item \textbf{营养声称（Nutrition Claim）：}描述食物中能量和营养素含量水平的声称，如"高钙"、"低脂"、"无糖"、"富含膳食纤维"。
    \item \textbf{营养成分功能声称（Nutrient Function Claim）：}描述营养素在人体正常生长发育和生理功能方面作用的声称，如"钙有助于骨骼和牙齿的发育"。
\end{itemize}

\subsection{功能食品与保健食品}

\begin{defbox}
\textbf{保健食品（Health Food/Functional Food）：}声称具有特定保健功能或以补充维生素、矿物质为目的的食品。适用于特定人群，具有调节机体功能，不以治疗疾病为目的，对人体不产生任何急性、亚急性或慢性危害。
\end{defbox}

\begin{keybox}
\textbf{保健食品的识别特征：}
\begin{itemize}[leftmargin=*]
    \item \textbf{蓝帽子标志：}经国家市场监督管理总局批准，标注"国食健字"批准文号。
    \item 保健食品不能替代正常膳食，也不能声称治疗疾病。
    \item 与药品的本质区别：药品用于治疗、诊断和预防疾病；保健食品用于调节机体功能。
\end{itemize}
\end{keybox}

% ----- 第六节 食谱编制 -----
\section{食谱编制（了解）}

\subsection{食谱编制的基本原则}

\begin{enumerate}[leftmargin=*]
    \item \textbf{满足营养素需要：}参考DRIs，确保能量和各类营养素达到目标摄入量。
    \item \textbf{食物多样、合理搭配：}谷类为主，荤素搭配，粗细搭配，色彩搭配。
    \item \textbf{符合饮食习惯：}考虑就餐者的口味偏好、宗教信仰、经济条件。
    \item \textbf{经济实惠：}根据当地食物供应和市场价格，选择适当的食物。
    \item \textbf{合理烹调：}减少烹调过程中的营养素损失，注意色香味形。
\end{enumerate}

\subsection{食谱编制的基本步骤}

\begin{enumerate}[leftmargin=*]
    \item 确定目标人群的营养素需要量（参照DRIs）。
    \item 确定主食、副食的数量和种类（按膳食宝塔推荐分配食物）。
    \item 计算食谱中各食物的营养素含量，核对是否满足DRIs。
    \item 调整食谱，使营养素含量与推荐量基本一致。
    \item 编制一日三餐食谱，合理分配餐次比例（早30\%，午40\%，晚30\%）。
\end{enumerate}

\end{enumerate}
