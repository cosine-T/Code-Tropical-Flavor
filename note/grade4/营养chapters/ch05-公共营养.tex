\section{公共营养概述}

\begin{defbox}
\textbf{合理膳食（平衡膳食）：}指提供给机体种类齐全、数量充足、比例合适的能量和各种营养素，并与机体的需要保持平衡，进而达到合理营养、促进健康、预防疾病的膳食。

\textbf{合理膳食要求：}提供种类齐全/数量充足/比例合适的营养素；保证食物安全；科学的烹调加工；合理的进餐制度和良好的饮食习惯；遵循《中国居民膳食指南》。

\textbf{营养不良（Malnutrition）：}由于一种或一种以上营养素的缺乏或过剩所造成的机体健康异常或疾病状态。包括\imp{营养缺乏（Nutrition Deficiency）}和\imp{营养过剩（Nutrition Excess）}。

\textbf{公共营养工作内容：}营养标准制定(DRIs)；居民膳食指南制订；基层营养工作人员培训与指导；营养调查与评价；营养监测；营养教育及营养干预；食物营养规划与营养改善；社区营养评估与指导；饮食行为研究；食物与营养政策法规。
\end{defbox}

\section{膳食营养素参考摄入量（DRIs）（难点*）}

\begin{keybox}
\textbf{DRIs定义：}一组每日平均膳食营养素摄入量的参考值，用于评价膳食营养素供给量能否满足人体需要及是否存在过量摄入风险。\imp{每4$\sim$5年修订一次}。

\textbf{DRIs 四大基础核心指标：}

\textbf{1. 平均需要量（Estimated Average Requirement, EAR）：}满足群体中\imp{50\%}个体需要量的摄入水平。是制订\imp{RNI的基础}。

\textbf{2. 推荐摄入量（Recommended Nutrient Intake, RNI）：}满足群体中\imp{97\%$\sim$98\%}个体需要量的摄入水平。长期摄入RNI水平可维持组织中有适当营养素储备和机体健康。若群体需要量呈正态分布：\imp{RNI = EAR + 2SD}；若变异系数为10\%：\imp{RNI = 1.2 × EAR}。

\textbf{3. 适宜摄入量（Adequate Intake, AI）：}当某营养素个体需要量资料不足、无法计算EAR时，通过观察或实验获得的健康人群某种营养素摄入量。是营养素的一个安全摄入水平。

\textbf{4. 可耐受最高摄入量（Tolerable Upper Intake Level, UL）：}平均每日摄入营养素的最高限量。摄入量达到UL对几乎所有个体均不致危害健康。\imp{有些营养素无足够资料制定UL，但并不意味着过多摄入不存在潜在危害。}

\textbf{DRIs 新增慢性病预防相关指标：}
\begin{itemize}[leftmargin=*]
    \item \imp{AMDR（Acceptable Macronutrient Distribution Ranges）}：宏量营养素可接受范围——CHO/脂肪/蛋白质理想摄入量范围，下限防缺乏，上限降低慢性病风险。以占能量摄入量\%(E\%)表示
    \item \imp{PI-NCD（Proposed Intakes for Preventing NCD）}：预防非传染性慢性病建议摄入量——以NCD一级预防为目标。某些PI可能高于RNI/AI（如VC/钾），另一些可能低于AI（如钠）
    \item \imp{SPL（Specific Proposed Levels）}：特定建议量——以降低成人膳食相关NCD风险为目标的其他膳食成分（主要为植物化学物）每日摄入量
\end{itemize}

\textbf{能量需要量（Estimated Energy Requirement, EER）：}群体的能量推荐量直接等同于该群体的能量EAR，而不是EAR加2倍标准差。EER的制定需考虑年龄/性别/体重/身高/体力活动。
\end{keybox}

\section{膳食结构与膳食指南}

\begin{keybox}
\textbf{膳食结构（Dietary Structure）：}膳食中各类食物种类、数量及其在膳食中所占的比例。

\textbf{三种膳食结构类型：}
\begin{enumerate}[leftmargin=*]
    \item \imp{动物性食物为主（西方模式）}：多数欧美发达国家。\textbf{三高一低}——高能量/高脂肪/高蛋白/低纤维→肥胖/心脑血管疾病/代谢性疾病/肿瘤（结直肠癌）
    \item \imp{植物性食物为主（温饱模式）}：亚洲/非洲部分国家。\textbf{二低一高}——低蛋白质/低脂肪/高植物性食物→感染性疾病风险增加/营养缺乏症
    \item \imp{动植物食物平衡}：日本为代表。动植物消费均衡/水产品食量较大/三大宏量营养素供能比合理
\end{enumerate}

\textbf{中国居民膳食指南2022（针对2岁以上所有健康人群）八准则：}
\begin{enumerate}[leftmargin=*]
    \item 食物多样，合理搭配
    \item 吃动平衡，健康体重
    \item 多吃蔬果、奶类、全谷、大豆
    \item 适量吃鱼、禽、蛋、瘦肉
    \item 少盐少油，控糖限酒
    \item 规律进餐，足量饮水
    \item 会烹会选，会看标签
    \item 公筷分餐，杜绝浪费
\end{enumerate}
\end{keybox}

\section{营养调查与评价}

\begin{keybox}
\textbf{营养调查（Nutrition Survey）：}运用各种手段准确地了解人群或特定个体各种营养指标水平，以判断其营养和健康状况。

\textbf{膳食调查常用方法：}

\textbf{1. 24小时膳食回顾法（24-hour history recalls）：}最常采用的个人食物摄入量资料方法。一般选用3天连续调查（2个工作日+1个周末）。\imp{优点：}时间短/食物能量化/不改变饮食习惯/应答率高。\imp{缺点：}食物份额难准确评估/对幼儿和80岁以上老人可能不适用。

\textbf{2. 食物频率法（Food Frequency Questionnaires, FFQ）：}估计被调查者在规定时间内摄入某些食物的次数或种类。可测量个体"经常摄入量"，在营养与慢性病关系研究中应用广泛。分定性FFQ/定量FFQ/半定量FFQ。\imp{优点：}得到通常膳食摄入量/费用少/应答率高/适用疾病与膳食关系研究。\imp{缺点：}回忆不精确/食物份额估计不准。

\textbf{3. 称重法（Weighed Food Records）：}运用称量工具对一日三餐每餐各种食物量进行称重。调查时间一般3$\sim$7天。\imp{优点：}比其他方法准确，可调查每人每餐膳食变动。\imp{缺点：}需要较大人力物力/要求应答者有一定文化水平/不适合大规模调查。

\textbf{4. 记账法：}记录一定时期内某一饮食单位的食物消耗总量和进餐人数，计算每人每日营养素平均摄入量。可调查较长时期（一个月或更长）。\imp{优点：}账目准确时结果较准确/可调查较长时期。\imp{缺点：}不能分析个体膳食摄入状况。

\textbf{5. 化学分析法：}采集被调查者一日三餐中所有食物，通过实验室化学分析方法测定其营养素含量。\imp{优点：}最精确可靠。\imp{缺点：}操作复杂/费用高/工作量大，仅适用于较小规模的调查或特殊研究目的。

\textbf{人体测量常用指标：}身高/体重/上臂围/腰围/皮褶厚度。可穿戴设备监测身体活动。
\end{keybox}

\section{营养改善与食品强化}

\begin{defbox}
\textbf{营养改善（Nutrition Improvements）：}采用膳食营养干预措施提高营养不良人群营养水平，促使最终恢复营养健康状况的活动。

\textbf{常用方法：}营养教育与咨询；营养配餐与食谱编制；食品营养标签；食品营养强化；新食品原料/新资源食品开发。

\textbf{食品强化（Food Fortification）：}根据营养需要向食品中添加一种或多种营养素或某些天然食品，以提高食品营养价值的过程。\textbf{意义：}弥补天然食物营养缺陷（赖氨酸→谷类）；补充加工贮运中损失营养素（B族维生素→精白米面）；满足特定人群营养需要（配方奶粉/要素膳）；预防营养不良（食盐加碘）；简化膳食处理方便摄入（婴儿配方食品）。
\end{defbox}

\subsection*{参考答案要点}
\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item 见正文。\textbf{EAR}：满足50\%个体需要，制定RNI基础。\textbf{RNI}：满足97-98\%个体需要(EAR+2SD或1.2×EAR)。\textbf{AI}：无法计算EAR时替代RNI。\textbf{UL}：最高限量。\textbf{AMDR}：宏量营养素可接受范围(下限防缺乏/上限降低慢病)。\textbf{PI-NCD}：预防慢病建议摄入量。\textbf{SPL}：其他膳食成分特定建议量。
    \item 见正文关键词框。RNI=EAR+2SD(正态分布时)，AI替代RNI(资料不足时)，UL为安全上限。
    \item 西方(三高一低→肥胖/心脑血管/肿瘤)、温饱(二低一高→营养缺乏/感染)、平衡(日本为代表/动植物均衡/水产品多)。
    \item 八准则见正文。
    \item 24h回顾：时间短/应答高但食物份额难评估。FFQ：分定性/定量/半定量，费用少/适用慢性病研究但回忆不精确。称重法：最准确但费人力物力。记账法：可调查长时期但不能分析个体。化学分析法：最精确可靠但操作复杂/费用高/仅适用小规模。
\end{enumerate}
