\section{膳食营养与慢性病}

% ----- 第一节 超重与肥胖 -----
\subsection{超重与肥胖（掌握）}

\begin{keybox}
\textbf{超重与肥胖的公共卫生意义：}
\begin{itemize}[leftmargin=*]
    \item 超重与肥胖是\imp{多种慢性病的独立危险因素}，包括2型糖尿病、心血管疾病、高血压、脑卒中、某些癌症（如结直肠癌、乳腺癌）。
    \item 中国成人超重率约34.3\%，肥胖率约16.4\%（2020年数据），已成为重要的公共卫生问题。
    \item 肥胖的本质是\imp{能量摄入长期大于能量消耗}导致的体内脂肪过量积累。
\end{itemize}
\end{keybox}

\subsubsection{超重与肥胖的膳食营养防治策略}

\begin{keybox}
\textbf{饮食防治核心策略：}

\textbf{1. 控制总能量摄入：}
\begin{itemize}[leftmargin=*]
    \item 在原有能量摄入基础上，\imp{每天减少500～1000kcal能量摄入}，造成适度能量缺口。
    \item 每月减重1～2kg为宜，不超过4kg。
    \item 每日能量摄入不宜低于1000～1200kcal（女性）/ 1200～1600kcal（男性），保证基本营养需求。
\end{itemize}

\textbf{2. 调整宏量营养素供能比：}
\begin{itemize}[leftmargin=*]
    \item 蛋白质：占总能量\imp{20\%～25\%}，适当提高以保证瘦体重。
    \item 脂肪：占总能量\imp{20\%～30\%}，限制饱和脂肪酸和反式脂肪酸。
    \item 碳水化合物：占总能量\imp{45\%～60\%}，优先选择低GI食物和全谷物。
\end{itemize}

\textbf{3. 增加膳食纤维：}
\begin{itemize}[leftmargin=*]
    \item 每日膳食纤维摄入量\imp{25～30g}。
    \item 富含蔬菜、水果、全谷物和豆类。
    \item 膳食纤维可增加饱腹感，延缓胃排空，减少能量摄入。
\end{itemize}

\textbf{4. 限制添加糖和饱和脂肪：}
\begin{itemize}[leftmargin=*]
    \item 添加糖不超过总能量10\%，最好<5\%。
    \item 限制含糖饮料、甜点、油炸食品。
    \item 饱和脂肪酸不超过总能量10\%。
\end{itemize}

\textbf{5. 体力活动配合：}
\begin{itemize}[leftmargin=*]
    \item 有氧运动与抗阻运动相结合：每周至少150分钟中等强度有氧运动 + 每周2～3次抗阻训练。
    \item 运动不仅消耗能量，还能改善体成分（增加瘦体重，减少体脂）。
    \item 配合行为矫正（自我监测体重、记录饮食日记、规律进餐）。
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{减重目标设定：}初始减重目标为减少原体重的5\%～10\%。即使未达到"理想体重"，减轻5\%体重已可显著改善血糖、血脂和血压等代谢指标。
\end{tipbox}

% ----- 第二节 心血管疾病 -----
\subsection{心血管疾病的营养防治（熟悉）}

\begin{defbox}
\textbf{心血管疾病（Cardiovascular Disease, CVD）：}包括冠心病、脑卒中、高血压、外周血管疾病等。不合理膳食是CVD最重要的可改变危险因素之一。
\end{defbox}

\subsubsection{膳食营养预防原则}

\begin{keybox}
\textbf{心血管疾病的营养防治原则：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{控制总能量，维持理想体重：}将BMI维持在18.5～23.9。超重和肥胖是CVD的独立危险因素。
    \item \textbf{限制饱和脂肪酸和反式脂肪酸：}饱和脂肪酸<总能量7\%～10\%，反式脂肪酸摄入量越少越好。减少动物脂肪、黄油、糕点、油炸食品。
    \item \textbf{增加不饱和脂肪酸：}多不饱和脂肪酸（PUFA）占总能量6\%～10\%。单不饱和脂肪酸（MUFA）有益。鱼类（富含EPA/DHA）每周至少2次。
    \item \textbf{限制胆固醇摄入：}膳食胆固醇\imp{<300mg/日}。减少动物内脏、脑、蛋黄等高胆固醇食物。
    \item \textbf{控制钠摄入：}\imp{每日食盐<5g（约2000mg钠）}。减少加工食品、咸菜、调味品。
    \item \textbf{增加钾摄入：}多食蔬菜、水果、豆类和全谷物。钾有助于降低血压。
    \item \textbf{增加膳食纤维：}每天25～30g，可降低血清胆固醇。
    \item \textbf{限制饮酒：}男性<25g/d酒精，女性<15g/d。
\end{enumerate}
\end{keybox}

\subsubsection{DASH饮食}

\begin{defbox}
\textbf{DASH饮食（Dietary Approaches to Stop Hypertension）：}一种为防治高血压设计的膳食模式。强调摄入充足的蔬菜、水果、低脂奶制品、全谷物、鱼、禽肉和坚果，同时限制钠盐、红肉、甜食和含糖饮料的摄入。
\end{defbox}

\begin{exambox}
\textbf{DASH饮食特点总结：}高钾、高钙、高镁、高纤维、高蛋白，低饱和脂肪、低总脂肪、低胆固醇、低钠。临床试验证实可降低收缩压8～14mmHg。
\end{exambox}

% ----- 第三节 糖尿病 -----
\subsection{糖尿病的营养防治（熟悉）}

\begin{keybox}
\textbf{糖尿病（Diabetes Mellitus）医学营养治疗的总原则：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{控制总能量：}以达到或维持理想体重为目标。根据BMI和活动水平确定个体化能量摄入。
    \item \textbf{合理分配宏量营养素：}
    \begin{itemize}[leftmargin=*]
        \item 碳水化合物：\imp{占总能量50\%～60\%}。优先选择低血糖生成指数（GI）食物（全谷物、豆类等）。严格限制单糖和双糖。
        \item 蛋白质：\imp{占总能量15\%～20\%}。优质蛋白占1/3以上。有糖尿病肾病者需控制蛋白质摄入量。
        \item 脂肪：\imp{占总能量20\%～30\%}。饱和脂肪酸<7\%总能量，限制胆固醇<300mg/d。
    \end{itemize}
    \item \textbf{膳食纤维：}\imp{每日25～30g}，可溶性纤维有助于降低餐后血糖。
    \item \textbf{规律进餐：}定时定量，少食多餐，避免血糖大幅波动。三餐能量分配：早1/5、中2/5、晚2/5，或早中晚各1/3。
    \item \textbf{配合运动治疗：}有氧运动与阻力运动结合，运动前后注意血糖监测。
    \item \textbf{综合管理：}营养治疗须与运动、药物治疗和血糖监测有机结合。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{血糖生成指数（Glycemic Index, GI）：}反映食物摄入后升高血糖的速度和能力。低GI食物（$\leq$55）：全谷物、豆类、牛奶；中等GI（56～69）：全麦面包、糙米；高GI（$\geq$70）：白面包、白米饭、含糖饮料。
\end{tipbox}

% ----- 第四节 癌症 -----
\subsection{癌症的营养防治（了解）}

\subsubsection{世界癌症研究基金会（WCRF）推荐}

\begin{defbox}
\textbf{世界癌症研究基金会（WCRF）}定期发布基于证据的癌症预防建议，从膳食、营养和身体活动角度提出一级预防策略。
\end{defbox}

\textbf{WCRF癌症预防核心建议：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{保持健康体重：}将体重控制在正常BMI范围内，避免成年期体重增长。
    \item \textbf{积极运动：}每周至少150分钟中等强度或75分钟高强度身体活动。
    \item \textbf{摄入丰富的全谷物、蔬菜、水果和豆类：}膳食纤维降低结直肠癌风险。
    \item \textbf{限制"快餐"和其他高脂、高淀粉或高糖的加工食品：}控制能量密度。
    \item \textbf{限制红肉和加工肉类：}红肉每周不超过350～500g，尽量少食加工肉类。加工肉类被IARC列为Ⅰ类致癌物（结直肠癌），红肉被列为IIA类。
    \item \textbf{限制含糖饮料：}多喝白水或不加糖的饮料。
    \item \textbf{限制饮酒：}酒精是多种癌症的确切危险因素（口腔癌、咽喉癌、食管癌、肝癌、结直肠癌、乳腺癌）。
    \item \textbf{不依赖膳食补充剂预防癌症：}满足营养需要应通过膳食，而非补充剂。
    \item \textbf{母乳喂养：}有益于母亲和婴儿，降低母亲乳腺癌风险。
\end{enumerate}

\begin{tipbox}
\textbf{WCRF"第三版专家报告"（2018）核心信息：}在所有人群和国家中推广将癌症预防纳入整体非传染性慢性病预防框架中，因为癌症与肥胖、心血管疾病和糖尿病共享共同的膳食和生活方式危险因素。
\end{tipbox}

% ----- 第五节 痛风 -----
\subsection{痛风的营养防治（了解）}

\begin{defbox}
\textbf{痛风（Gout）：}因嘌呤代谢异常，血尿酸水平升高，尿酸盐结晶沉积于关节和软组织导致的炎症性疾病。高尿酸血症是痛风最重要的生化基础。
\end{defbox}

\textbf{痛风膳食预防原则：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{限制高嘌呤食物：}严格限制动物内脏（肝脏、肾脏）、沙丁鱼、贝类、浓肉汤等高嘌呤食物。痛风急性发作期嘌呤<150mg/d。
    \item \textbf{保持足量饮水：}每日饮水量\imp{>2000mL}，促进尿酸排泄。避免含糖饮料和果汁（果糖促进尿酸生成）。
    \item \textbf{限制酒精摄入：}酒精抑制尿酸排泄并促进生成，啤酒对痛风患者的危害尤为突出。
    \item \textbf{体重管理：}肥胖是痛风的独立危险因素，减重可降低血尿酸水平。
    \item \textbf{合理选择蛋白质来源：}以低脂奶制品、蛋类等低嘌呤蛋白为主。
    \item \textbf{多食蔬菜水果：}富含维生素C的蔬果有助于降低尿酸，但避免花椰菜、菠菜等高嘌呤蔬菜（实际上植物嘌呤对血尿酸影响不及动物嘌呤）。
\end{enumerate}

\section{临床营养}

% ----- 第六节 临床营养概述 -----
\subsection{临床营养概述}

\begin{defbox}
\textbf{临床营养（Clinical Nutrition）：}以患者个体为中心，通过评定其营养状态，对能量和营养素缺乏或过量以及疾病造成的代谢紊乱与功能性变化进行\imp{预防、诊断和管理}的综合性临床学科。

\textbf{核心内容：}
\begin{itemize}[leftmargin=*]
    \item 营养筛查（Nutrition Screening）——快速发现营养风险
    \item 营养评定（Nutrition Assessment）——全面评价营养状况
    \item 营养支持（Nutrition Support）——肠内营养（EN）和肠外营养（PN）
    \item 饮食治疗（Diet Therapy）——治疗膳食与特殊医学用途配方食品（FSMP）
\end{itemize}
\end{defbox}

% ----- 第七节 营养支持小组（NST）-----
\subsection{营养支持小组（NST）}

\begin{defbox}
\textbf{营养支持小组（Nutrition Support Team, NST）：}由医师、临床营养师、药师和护士等多学科专业人员组成的团队，负责对住院患者进行营养筛查、评定，制定和实施个体化营养支持方案，并进行监测和调整。
\end{defbox}

\begin{keybox}
\textbf{NST的人员组成与职责：}
\begin{itemize}[leftmargin=*]
    \item \textbf{医师（Physician）：}担任组长，负责整体决策、置管操作（如中心静脉置管），处理并发症。
    \item \textbf{临床营养师（Clinical Dietitian）：}核心成员，负责营养评定、计算营养素需要量、设计营养支持方案、监测营养效果。
    \item \textbf{药师（Pharmacist）：}负责PN液的配伍和稳定性、药物-营养素相互作用评估。
    \item \textbf{护士（Nurse）：}负责营养支持管路护理、输注操作规范执行、患者教育。
\end{itemize}

\textbf{NST的主要任务：}
\begin{enumerate}[leftmargin=*]
    \item 规范全院营养支持流程和治疗方案
    \item 进行营养筛查、评定和营养支持适应证判断
    \item 制定个体化EN和PN处方
    \item 监测营养支持过程，预防和处理并发症
    \item 开展临床营养继续教育和研究
    \item 进行成本效益分析，合理使用营养支持资源
\end{enumerate}
\end{keybox}

% ----- 第八节 营养筛查与评定 -----
\subsection{营养筛查与评定（熟悉）}

\subsubsection{营养筛查}

\begin{defbox}
\textbf{营养筛查（Nutrition Screening）：}在短时间内用简单的方法发现存在营养风险或营养不良的个体，以便及时进行全面的营养评定和干预。常在\imp{入院24小时内}完成。
\end{defbox}

\begin{keybox}
\textbf{常用营养筛查工具：}

\textbf{1. NRS-2002（Nutrition Risk Screening 2002）：}
\begin{itemize}[leftmargin=*]
    \item ESPEN推荐，适用于\imp{住院成人患者}。
    \item 由三部分组成：
    \begin{enumerate}
        \item \textbf{营养状况评分（0～3分）：}体重减少量（近1～3月>5\%为1分，>10\%为2分，>15\%为3分）、BMI（<18.5为3分，但有腹水等无法称体重者不以此判分）、近1周进食量减少（1分：减少25\%～50\%，2分：减少50\%～75\%，3分：减少>75\%）。
        \item \textbf{疾病严重程度评分（0～3分）：}反映应激代谢程度。慢性病（如肝硬化、COPD）计1分；大手术、脑卒中计2分；头部损伤、骨髓移植、APACHE>10的重症监护患者计3分。
        \item \textbf{年龄评分：}年龄$\geq$70岁加1分。
    \end{enumerate}
    \item \imp{总分$\geq$3分，判定为存在营养风险}，需制定营养支持计划。
\end{itemize}

\textbf{2. SGA（Subjective Global Assessment，主观整体评价）：}
\begin{itemize}[leftmargin=*]
    \item 基于病史（体重变化、膳食摄入变化、胃肠道症状持续>2周、功能状态改变）和体格检查（皮下脂肪丢失、肌肉消耗、踝部/骶部水肿、腹水）。
    \item 将患者分为：\imp{A级（营养良好）、B级（轻～中度营养不良）、C级（重度营养不良）}。
    \item 简单、无创、经济，适用于临床快速评价，有较好的可重复性。
    \item 缺点：偏主观，不能很好区分轻中度与重度营养不良。
\end{itemize}

\textbf{3. MNA（Mini Nutritional Assessment，微型营养评价）：}
\begin{itemize}[leftmargin=*]
    \item 专为\imp{老年人（$\geq$65岁）}设计。
    \item 包含18个项目：人体测量（BMI、臂围、小腿围、近3月体重减少）、综合评价（独立生活/用药/压疮等6项）、膳食问卷（餐次/食物摄入/液体摄入/自主进食等6项）、主观评价（自我健康/营养评价2项）。
    \item 评分标准：\imp{$\geq$24分营养良好，17～23.5分存在营养不良风险，<17分营养不良}。
    \item MNA-SF（Short Form，简版）：仅6项，用于初筛。
\end{itemize}

\textbf{4. MUST（Malnutrition Universal Screening Tool，营养不良通用筛查工具）：}
\begin{itemize}[leftmargin=*]
    \item 英国肠外肠内营养学会（BAPEN）推荐。
    \item 基于三项指标：BMI、近3～6月非计划性体重减少百分比、急性疾病对进食影响。
    \item 适用于\imp{社区和住院各类成年患者}的快速筛查。
\end{itemize}
\end{keybox}

\subsubsection{营养评定}

\begin{defbox}
\textbf{营养评定（Nutrition Assessment）：}由临床营养师或医师对营养筛查发现有营养风险的患者，进行全面的\imp{营养状况综合评价}，包括膳食调查、人体测量、生化检查、临床检查和综合评定，为制定个体化营养支持方案提供依据。
\end{defbox}

\begin{keybox}
\textbf{营养评定的主要内容（ABCDE法）：}

\textbf{A——Anthropometry（人体测量）：}
\begin{itemize}[leftmargin=*]
    \item 身高、体重、BMI（体重kg/身高m$^2$），正常范围18.5～23.9
    \item 体重变化率：近6个月非计划减重>10\%提示严重营养不良
    \item 臂围（MAC）、三头肌皮褶厚度（TSF，反映体脂储备）、上臂肌围（MAMC，反映骨骼肌蛋白储备）
    \item 小腿围、握力（反映肌肉功能）
\end{itemize}

\textbf{B——Biochemistry（生化检测/实验室检查）：}
\begin{itemize}[leftmargin=*]
    \item \imp{内脏蛋白：}白蛋白（Alb，半衰期18～20d，反映慢性营养状态）、前白蛋白（PA，半衰期2～3d，反映近期营养状态）、转铁蛋白（TFN）、视黄醇结合蛋白（RBP）
    \item 免疫功能：总淋巴细胞计数（TLC）、迟发性皮肤超敏反应
    \item 氮平衡（Nitrogen Balance）：氮平衡 = 摄入氮 - 排出氮（24h尿总氮 + 3g）。正氮平衡表示合成>分解，负氮平衡表示分解>合成
    \item 电解质、微量元素、维生素水平
\end{itemize}

\textbf{C——Clinical Examination（临床检查）：}
\begin{itemize}[leftmargin=*]
    \item 营养缺乏体征（毛发脱落、皮肤干燥、口角炎、舌炎、牙龈出血等）
    \item 肌肉和皮下脂肪消耗程度
    \item 水肿/腹水（低蛋白血症体征）
    \item 伤口愈合情况、活动能力
\end{itemize}

\textbf{D——Dietary Assessment（膳食调查）：}
\begin{itemize}[leftmargin=*]
    \item 24小时膳食回顾法
    \item 食物频率法（FFQ）
    \item 称重法
    \item 记账法
\end{itemize}

\textbf{E——Energy and Environment（能量消耗与环境因素）：}
\begin{itemize}[leftmargin=*]
    \item 基础能量消耗（BEE）测定或公式估算（Harris-Benedict公式）
    \item 疾病应激系数（轻度应激1.1～1.2，中度1.2～1.4，重度1.4～1.8）
    \item 活动系数
    \item 社会心理因素、经济状况、进食环境
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{营养筛查 vs 营养评定：}筛查是"发现需要帮助的人"（快速、简单，入院24h内完成），评定是"为需要帮助的人制定个体化方案"（全面、深入）。筛查发现风险后必须进行评定，评定结果指导营养支持方案制定。
\end{tipbox}

% ----- 第九节 营养治疗五步模式 -----
\subsection{营养治疗的五步模式（营养干预阶梯）}

\begin{defbox}
\textbf{营养治疗（Nutrition Therapy）：}根据患者营养状况和疾病特点，通过饮食调整、口服营养补充、肠内营养或肠外营养等途径提供合理营养素，以达到治疗或辅助治疗疾病目的的临床干预手段。
\end{defbox}

\begin{keybox}
\textbf{临床营养干预阶梯（五步治疗模式）：}

根据患者进食和消化吸收功能的递减，\imp{由简到繁}逐步升级营养支持方式：
\begin{enumerate}[leftmargin=*]
    \item \textbf{第一步——饮食营养治疗（Dietary Counseling / Therapeutic Diet）：}患者可正常经口进食时，通过调整膳食结构、改变食物性状和营养素含量进行治疗。包括医院常规膳食和治疗膳食。\imp{这是最符合生理的治疗方式。}
    \item \textbf{第二步——饮食 + 口服营养补充（Oral Nutritional Supplement, ONS）：}当经口进食不能满足营养需要时，在正常饮食基础上补充特殊医学用途配方食品（FSMP）。适用于进食不足（满足需要量的50\%～75\%）的患者。
    \item \textbf{第三步——全肠内营养（Total Enteral Nutrition, TEN）：}当患者无法经口进食或只能进食少量流质时，完全通过管饲（鼻胃管、鼻肠管或造口）供给全部营养素。前提：\imp{胃肠道有功能。}
    \item \textbf{第四步——肠内营养 + 肠外营养（EN + PN / Partial PN）：}当EN不能提供足够营养（如消化吸收功能障碍、EN不耐受）时，联合使用肠内和肠外两种途径。EN提供部分营养以维持肠道功能，PN补充不足部分。
    \item \textbf{第五步——全肠外营养（Total Parenteral Nutrition, TPN）：}当患者完全无法进食且胃肠道完全无功能时，全部营养素由中心静脉途径供给。
\end{enumerate}

\textbf{核心原则：}\keyword{只要胃肠道有功能，就应优先使用肠内营养（If the gut works, use it!）}

\textbf{临床决策要点：}
\begin{itemize}[leftmargin=*]
    \item 每一步向下递进时需评估：①经口/经肠摄入能否满足>60\%目标需要量；②胃肠道功能是否可用；③预期持续时间（<4周或>4周）。
    \item 能EN则不用PN，能用外周不用中心，能部分EN+部分PN就不用全PN。
\end{itemize}
\end{keybox}

\subsection{医院膳食（熟悉）}

\subsubsection{一、基本膳食（Routine Diets）}

\textbf{医院常规膳食（四大类）：}

\subsubsection{二、治疗膳食（Therapeutic Diets）}

\begin{defbox}
\textbf{治疗膳食：}根据患者疾病特点和代谢状况，在基本膳食基础上调整能量、宏量营养素、膳食纤维、矿物质或食物质地，以达到辅助治疗或诊断目的的膳食。
\end{defbox}

\begin{keybox}
\textbf{常用治疗膳食分类与要点：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{高能量膳食（High-Energy Diet）：}
    \begin{itemize}
        \item 适用：消耗性疾病（结核、甲亢、肿瘤）、烧伤、创伤、营养不良恢复期
        \item 原则：在基本膳食基础上增加能量，BEE×活动系数×应激系数，通常>2000～2500kcal/d
        \item 方法：增加餐次（加餐）、增加能量密度（油脂、糖）、配合ONS
    \end{itemize}

    \item \textbf{低能量膳食（Low-Energy Diet / Calorie-Restricted Diet）：}
    \begin{itemize}
        \item 适用：超重/肥胖需减重者、糖尿病肥胖者
        \item 原则：在原有能量摄入基础上减少500～1000kcal/d，但不得低于1000～1200kcal/d
        \item 方法：限制脂肪和糖、增加蔬菜等低能量密度食物、保证蛋白质摄入
    \end{itemize}

    \item \textbf{高蛋白膳食（High-Protein Diet）：}
    \begin{itemize}
        \item 适用：营养不良、烧伤、创伤、大手术前后、肿瘤恶病质、肝硬化（无肝性脑病）
        \item 原则：蛋白质>1.2g/(kg$\cdot$d)，优质蛋白占1/2以上。能量也需相应提高（否则蛋白被氧化供能，起不到氮储存作用）
        \item 方法：增加肉类、鱼、蛋、奶、豆制品
    \end{itemize}

    \item \textbf{低蛋白膳食（Low-Protein Diet）：}
    \begin{itemize}
        \item 适用：急性肾炎、慢性肾衰竭（透析前）、肝性脑病
        \item 原则：蛋白质<0.6g/(kg$\cdot$d)（肾衰竭时根据GFR调整），或肝性脑病时限制至0.5～0.6g/(kg$\cdot$d)。优先选用高生物价蛋白（动物蛋白、大豆蛋白）
        \item 注意：必须保证充足能量（以CHO和脂肪供能），否则内源性蛋白分解加重
    \end{itemize}

    \item \textbf{高纤维膳食（High-Fiber Diet）：}
    \begin{itemize}
        \item 适用：便秘、憩室病、糖尿病、高脂血症、肥胖
        \item 原则：膳食纤维>25～30g/d，可溶+不可溶结合
        \item 方法：全谷物、豆类、蔬菜、水果、燕麦、魔芋等
        \item 注意：大量纤维可影响矿物质（Ca、Fe、Zn）吸收，需增加饮水
    \end{itemize}

    \item \textbf{少渣膳食（Low-Residue Diet）：}
    \begin{itemize}
        \item 适用：消化道手术前后、消化道出血恢复期、结肠镜检查前、腹泻
        \item 原则：限制膳食纤维<10g/d，避免粗粮、坚果、生蔬菜。食物精细切碎煮烂
        \item 亦称低纤维膳食，但"少渣"更强调减少肠道内容物和粪便量
    \end{itemize}

    \item \textbf{限钠膳食（Sodium-Restricted Diet）：}
    \begin{itemize}
        \item 适用：高血压、心力衰竭、肾病水肿、肝硬化腹水、使用糖皮质激素者
        \item 分度：低盐膳食（<2000mg钠/d，约食盐<5g/d）、无盐膳食（<1000mg钠/d，烹饪不用盐）、低钠膳食（<500mg钠/d，限制所有含钠食物）
        \item 方法：限食盐、酱油、味精、腌制食品、加工食品
    \end{itemize}

    \item \textbf{忌碘膳食（Iodine-Restricted Diet）：}
    \begin{itemize}
        \item 适用：甲状腺癌术后、$^{131}$I治疗前准备（需严格忌碘2～4周）
        \item 禁用：加碘盐、海产品（海带、紫菜、海鱼、贝类等）、含碘药物
        \item 可用：无碘盐、淡水鱼虾、禽畜肉、蛋、奶、蔬果
    \end{itemize}

    \item \textbf{低嘌呤膳食（Low-Purine Diet）：}
    \begin{itemize}
        \item 适用：痛风、高尿酸血症、尿酸性肾病
        \item 急性发作期：嘌呤<150mg/d，缓解期<300～600mg/d
        \item 禁用：动物内脏、沙丁鱼、浓肉汤、火锅汤底（极高嘌呤>150mg/100g）
        \item 可用：奶类、蛋类（几乎不含嘌呤）、蔬菜（除花椰菜、菠菜、蘑菇外）、精制谷物
    \end{itemize}

    \item \textbf{MCT膳食（Medium-Chain Triglyceride Diet）：}
    \begin{itemize}
        \item 适用：脂肪消化吸收障碍（乳糜胸、乳糜腹、淋巴管扩张症）、胰腺功能不全、短肠综合征
        \item 原理：MCT（碳链6～12）无需胰脂酶和胆汁酸盐参与即可经门静脉直接吸收，不经淋巴系统
        \item 方法：以MCT油替代部分或全部长链脂肪（LCT），但MCT不含必需脂肪酸（亚油酸、$\alpha$-亚麻酸），长期使用需补充EFA
    \end{itemize}
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{治疗膳食与基本膳食的关系：}治疗膳食是在基本膳食（普食/软食/半流质/流质）基础上对特定成分进行调整。例如：糖尿病膳食 = 普通饭基础上控制总能量和GI；低盐普食 = 普通饭基础上限制钠盐。
\end{tipbox}

\subsubsection{三、试验膳食（Test Diets）}

\begin{keybox}
\textbf{常用试验膳食：}
\begin{itemize}[leftmargin=*]
    \item \textbf{隐血试验膳食：}检查消化道出血前3天，禁食肉类、动物血、绿色蔬菜，食用白色食物（米饭、白面包、牛奶）。以避免假阳性。
    \item \textbf{胆囊造影试验膳食：}检查前禁食高脂餐，造影后进食油炸鸡蛋等高脂餐刺激胆囊收缩排空，观察胆囊浓缩和排空功能。
    \item \textbf{钙磷代谢试验膳食：}用于甲状旁腺功能诊断，定量控制钙、磷摄入。
    \item \textbf{干膳食：}用于尿浓缩功能检查（Addis计数），试验期1天，全天限制饮水，食用含水少的固体食物。
\end{itemize}
\end{keybox}

% ----- 第十一节 肠内营养（EN）-----
\subsection{肠内营养（EN）（熟悉）}

\begin{defbox}
\textbf{肠内营养（Enteral Nutrition, EN）：}通过胃肠道（口服或管饲）提供营养素，满足机体代谢需要的营养支持方式。包括口服营养补充（ONS）和管饲营养（Tube Feeding）。
\end{defbox}

\subsubsection{EN的适应证与禁忌证}

\begin{keybox}
\textbf{肠内营养的适应证：}
\begin{itemize}[leftmargin=*]
    \item 不能经口进食者（昏迷、吞咽困难、口腔/食管术后、脑血管意外）
    \item 经口进食不足者（严重创伤、烧伤、肿瘤恶病质、神经性厌食）
    \item 胃肠道功能存在但口服不能满足需要者（短肠综合征适应期、炎性肠病、胰腺炎恢复期）
\end{itemize}

\textbf{肠内营养的禁忌证：}
\begin{itemize}[leftmargin=*]
    \item 完全性肠梗阻（绝对禁忌）
    \item 严重胃肠道出血
    \item 严重腹胀/腹泻/顽固性呕吐
    \item 弥漫性腹膜炎
    \item 消化道瘘无法建立有效的输注通道
    \item 血流动力学不稳定（休克、严重低灌注）
\end{itemize}
\end{keybox}

\subsubsection{EN的途径}

\begin{keybox}
\textbf{肠内营养途径选择：}

\textbf{短期（<4周）：}
\begin{itemize}[leftmargin=*]
    \item \imp{鼻胃管（Nasogastric Tube, NGT）：}最常用。经鼻→食管→胃。适用于胃排空功能正常者。优点：操作简单、符合生理（胃的储存和消化功能）。缺点：易误吸（胃潴留或意识障碍者）。
    \item \imp{鼻肠管（Nasojejunal Tube, NJT / Nasoduodenal Tube, NDT）：}经鼻→胃→十二指肠或空肠。适用于胃排空障碍、胃潴留、高误吸风险患者。需在内镜或X线引导下置管。
\end{itemize}

\textbf{长期（>4周）：}
\begin{itemize}[leftmargin=*]
    \item \imp{经皮内镜下胃造口（Percutaneous Endoscopic Gastrostomy, PEG）：}经内镜引导经腹壁穿刺置管至胃。适用于长期EN且胃功能正常者（如神经源性吞咽困难、晚期食管癌）。
    \item \imp{经皮内镜下空肠造口（Percutaneous Endoscopic Jejunostomy, PEJ）：}经腹壁置管至空肠。适用于胃切除术后、胃排空严重障碍且需长期EN者。
    \item 手术胃造口/空肠造口：开腹手术时直接置管。
\end{itemize}

\textbf{途径选择原则：}胃功能正常→胃内喂养（NGT/PEG）；胃排空障碍→幽门后喂养（NJT/PEJ）；短期→鼻饲管（<4周）；长期→造口（>4周）。
\end{keybox}

\subsubsection{EN的输注方式}

\begin{keybox}
\textbf{肠内营养输注方式：}

\textbf{1. 间歇重力滴注（Intermittent Gravity Drip）：}
\begin{itemize}[leftmargin=*]
    \item 每次输注200～400mL，每次持续30～60分钟，每日4～6次
    \item 模拟正常进餐模式，较符合生理
    \item 操作简便，无需输液泵
    \item 缺点：易发生腹胀、腹泻、胃潴留
\end{itemize}

\textbf{2. 持续输注（Continuous Infusion）：}
\begin{itemize}[leftmargin=*]
    \item 使用\imp{营养输注泵}以恒定速率持续16～24小时输注
    \item 适用于空肠喂养、危重症患者、EN不耐受者
    \item 优点：减少腹胀、腹泻和误吸风险，营养素吸收更充分
    \item 缺点：需输液泵设备
\end{itemize}

\textbf{3. 推注法（Bolus Feeding）：}
\begin{itemize}[leftmargin=*]
    \item 用注射器在5～10分钟内将200～400mL营养液推入胃管内
    \item 仅适用于胃内喂养，且患者无胃潴留和误吸风险
    \item 操作简便但胃肠不良反应发生率最高，已较少使用
\end{itemize}

\textbf{输注注意事项：}
\begin{itemize}[leftmargin=*]
    \item 开始输注时需\imp{循序渐进}：先用低浓度（稀释）、小容量（20～30mL/h），逐步增加浓度和容量
    \item \imp{床头抬高30°～45°}，减少误吸风险
    \item 每4小时监测胃残余量（GRV），>200mL（或>500mL）提示胃潴留，需暂停或减慢输注
    \item 营养液温度适宜（接近体温37℃左右）
\end{itemize}
\end{keybox}

\subsubsection{EN的优点}

\begin{exambox}
\textbf{肠内营养的优点（常考）：}
\begin{enumerate}[leftmargin=*]
    \item \imp{符合生理途径：}维持胃肠道结构和功能的完整性，刺激消化液（胃酸、胆汁、胰液）和消化道激素（胃泌素、胆囊收缩素、促胰液素）分泌。
    \item \imp{保护肠屏障功能：}维持肠黏膜细胞结构和紧密连接完整性，防止肠源性细菌和毒素移位（Bacterial Translocation），减少肠源性感染和多器官功能衰竭风险。
    \item \imp{改善门静脉循环：}维持肝脏功能和营养代谢。
    \item \imp{经济、安全、操作简便：}并发症较PN少，费用约为PN的1/5～1/10。
    \item \imp{利于血糖控制：}EN的碳水化合物吸收经门静脉→肝脏首过代谢，较PN静脉输注葡萄糖更符合生理。
\end{enumerate}

\textbf{EN的"金句"：}\keyword{有肠道功能就用肠道！（If the gut works, use it!）}这是临床营养支持的首要原则。
\end{exambox}

% ----- 第十二节 肠外营养（PN）-----
\subsection{肠外营养（PN）（熟悉）}

\begin{defbox}
\textbf{肠外营养（Parenteral Nutrition, PN）：}通过静脉途径提供机体所需的全部或部分营养素（包括氨基酸、葡萄糖、脂肪乳、维生素、矿物质和微量元素），用于无法或不宜经胃肠道摄入营养的患者。
\end{defbox}

\subsubsection{PN的途径与分类}

\begin{keybox}
\textbf{肠外营养的途径选择：}

\textbf{1. 外周静脉营养（Peripheral Parenteral Nutrition, PPN）：}
\begin{itemize}[leftmargin=*]
    \item 经外周浅静脉（前臂、手背静脉）输注
    \item 渗透压限制：\imp{<900mOsm/L}（以减少静脉炎风险）
    \item 适用：短期（\imp{<2周}）、部分营养支持、EN补充
    \item 优点：操作简单、并发症少（无需中心静脉置管）
    \item 缺点：不能提供高浓度营养液（受渗透压和容量限制），难以满足完全营养需求
\end{itemize}

\textbf{2. 中心静脉营养（Central Parenteral Nutrition, CPN / TPN）：}
\begin{itemize}[leftmargin=*]
    \item 经中心静脉置管输注，常用途径：
    \begin{itemize}
        \item \imp{PICC（经外周中心静脉置管）：}经贵要静脉或肘正中静脉置管至$\sim$上腔静脉下1/3处，目前最常用。优点：操作相对安全（无气胸风险）、留置时间长
        \item 颈内静脉置管、锁骨下静脉置管、股静脉置管
    \end{itemize}
    \item 渗透压可达1800～2000mOsm/L，可使用高浓度营养液
    \item 适用：\imp{长期（>2周）}、完全营养支持（TPN）
\end{itemize}

\textbf{PN的临床分类：}
\begin{itemize}[leftmargin=*]
    \item \imp{完全肠外营养（Total Parenteral Nutrition, TPN）：}全部营养素由静脉提供，亦称"全合一"（All-in-One）营养。
    \item \imp{补充性肠外营养（Supplemental Parenteral Nutrition, SPN）：}EN不能满足需要时，PN辅助补充不足部分。
\end{itemize}
\end{keybox}

\subsubsection{PN的输注形式}

\begin{keybox}
\textbf{肠外营养制剂的输注形式：}

\textbf{1. 多瓶输注（Multiple Bottle System）：}
\begin{itemize}[leftmargin=*]
    \item 分别输注氨基酸、葡萄糖、脂肪乳等各组分
    \item 操作繁琐，各成分先后输注导致利用不充分
    \item 已逐渐被淘汰
\end{itemize}

\textbf{2. "全合一"输注（All-in-One / AIO）：}
\begin{itemize}[leftmargin=*]
    \item 将所有PN组分（氨基酸、葡萄糖、脂肪乳、电解质、维生素、微量元素）在\imp{严格无菌条件下}混合于一个3L袋中输注
    \item 常用配置方式：
    \begin{itemize}
        \item \imp{工业化三腔袋（Three-Chamber Bag）：}市售成品，氨基酸、葡萄糖、脂肪乳分隔保存，使用时挤破间隔即可混合。方便、安全、无菌保障好
        \item 医院药房配制（Pharmacy-Compounded）：在GPP（良好配制规范）条件下由药剂师个体化配制
    \end{itemize}
    \item \imp{优点：}营养素同时输入，利用效率最高；一次输注，减少操作和污染风险；渗透压降低（脂肪乳稀释），对外周静脉刺激性小
    \item \imp{注意事项：}混合后必须24小时内输完；某些药物不可直接加入3L袋（稳定性问题）
\end{itemize}

\textbf{3. 隔舱输注（Compartmentalized Infusion）：}
\begin{itemize}[leftmargin=*]
    \item 使用双腔或三腔输液器，在进入血管前才混合各组分
    \item 适用于组分间存在稳定性问题的配方
\end{itemize}
\end{keybox}

\subsubsection{PN的适应证与并发症}

\begin{keybox}
\textbf{肠外营养的适应证：}
\begin{itemize}[leftmargin=*]
    \item 消化道无功能或功能丧失：短肠综合征（小肠广泛切除后）、严重放射性肠炎、肠瘘（无法绕过瘘口的远端EN）
    \item EN禁忌或不耐受，不能满足>60\%目标需要量
    \item 高分解代谢状态：大面积烧伤、严重创伤、多器官功能衰竭、大手术后
    \item 胃肠道需要完全休息时：重症急性胰腺炎早期、肠梗阻未解除前、肠道术后过渡期
\end{itemize}

\textbf{肠外营养的常见并发症：}

\textbf{1. 机械性并发症（与置管相关）：}
\begin{itemize}[leftmargin=*]
    \item 气胸、血胸、动脉/神经损伤（锁骨下/颈内静脉穿刺时）
    \item 空气栓塞（导管开放于大气压）
    \item 导管相关感染（Catheter-Related Bloodstream Infection, CRBSI）——最常见、最严重的置管并发症
    \item 导管血栓形成（静脉血栓栓塞、导管堵塞）
\end{itemize}

\textbf{2. 代谢性并发症：}
\begin{itemize}[leftmargin=*]
    \item \imp{高血糖（Hyperglycemia）：}最常见代谢并发症。PN液含高浓度葡萄糖，加之应激状态下胰岛素抵抗，需监测血糖并可能需加用胰岛素
    \item 低血糖（Hypoglycemia）：PN突然中止或胰岛素过量时发生
    \item 高三酰甘油血症：脂肪乳输注过快或不耐受
    \item 电解质紊乱：低钾、低磷、低镁（尤其在合成代谢期大量细胞内转移时）
    \item 酸碱平衡紊乱
\end{itemize}

\textbf{3. 肝胆并发症：}
\begin{itemize}[leftmargin=*]
    \item \imp{胆汁淤积/肝功能损害（PN-Associated Liver Disease, PNALD）：}长期TPN（>2～4周）最主要并发症。表现为ALT、AST、ALP、GGT、胆红素升高
    \item 脂肪肝（过度供能/高GI葡萄糖刺激胰岛素→促进脂肪合成）
    \item 胆石症（胆汁淤积+胆囊排空减少）
\end{itemize}

\textbf{4. 肠屏障功能损害：}
\begin{itemize}[leftmargin=*]
    \item 长期PN缺乏肠内营养对肠黏膜的腔内刺激→肠黏膜萎缩、绒毛高度下降、通透性增加
    \item 菌群移位（Bacterial Translocation）风险增加→肠源性感染和MODS风险
\end{itemize}

\textbf{5. 再喂养综合征（Refeeding Syndrome, RFS）：}
\begin{itemize}[leftmargin=*]
    \item \imp{定义：}长期饥饿或严重营养不良患者快速再喂养（PN或EN均可）后，由于胰岛素大量释放、细胞大量摄取磷/钾/镁，导致严重低磷血症、低钾血症、低镁血症和水钠潴留的代谢紊乱综合征。
    \item \imp{核心机制：}饥饿状态→细胞外磷/钾/镁→再喂养→胰岛素↑↑ + 合成代谢↑→磷/钾/镁大量转入细胞内 + 体液潴留→电解质严重缺乏
    \item \imp{高危人群：}NRS-2002$\geq$5分、长期禁食>7～10天、严重体重减少>10\%～15\%，慢性酒精中毒
    \item \imp{预防措施：}开始营养支持前检测并纠正电解质（尤其血磷<0.5mmol/L时先纠正）；营养支持从低能量（10～15kcal/(kg$\cdot$d)）开始，缓慢递增；补充维生素B$_1$（硫胺素）；密切监测电解质3～5天
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{EN vs PN的选择原则：}
\begin{center}
\keyword{首选EN（肠道有功能时）$\rightarrow$ EN不足时联合PN $\rightarrow$ EN禁忌时单独PN}
\end{center}
肠屏障功能的维护是优先选择EN的核心理由——长期PN使肠道失去腔内营养刺激，导致黏膜萎缩、通透性增加、菌群移位。能部分EN就尽可能保留部分EN（滋养性喂养，Trophic Feeding），即使仅提供10～20mL/h的EN也可维持肠屏障功能。
\end{tipbox}

% ----- 第十三节 特殊医学用途配方食品（FSMP）-----
\subsection{特殊医学用途配方食品（FSMP）（了解）}

\begin{defbox}
\textbf{特殊医学用途配方食品（Food for Special Medical Purposes, FSMP）：}为了满足进食受限、消化吸收障碍、代谢紊乱或特定疾病状态人群对营养素或膳食的特殊需要，专门加工配制的配方食品。须在医生或临床营养师指导下使用。
\end{defbox}

\subsubsection{FSMP的分类}

\begin{keybox}
\textbf{FSMP三大类：}

\textbf{1. 全营养配方食品（Nutritionally Complete Formula）：}
\begin{itemize}[leftmargin=*]
    \item 可作为\imp{单一营养来源}，满足目标人群全部营养需要。
    \item 含有人体所需的所有必需营养素（蛋白质、脂肪、碳水化合物、维生素、矿物质），配比合理。
    \item 适用于能正常消化吸收各类营养素但进食量不足者。
    \item 举例：标准型整蛋白配方（如安素、能全素）。
\end{itemize}

\textbf{2. 特定全营养配方食品（Condition-Specific Complete Formula）：}
\begin{itemize}[leftmargin=*]
    \item 可作为单一营养来源，满足目标人群在\imp{特定疾病或医学状态下}的营养需要。
    \item 在标准配方基础上根据疾病代谢特点调整：糖尿病专用（低GI碳水+高纤维）、肾病专用（低蛋白+低磷+低钾+高必需氨基酸）、肝病专用（高BCAA低AAA）、肿瘤专用（高能量+高蛋白+免疫营养素如$\omega$-3脂肪酸、精氨酸）、呼吸系统疾病专用（高脂肪低碳水，减少CO$_2$产生）等。
\end{itemize}

\textbf{3. 非全营养配方食品（Nutritionally Incomplete Formula）：}
\begin{itemize}[leftmargin=*]
    \item 只能满足\imp{部分营养需要}，不能作为单一营养来源，必须与其他食品配合使用。
    \item 包括：
    \begin{itemize}
        \item 蛋白质（氨基酸）组件——用于高蛋白需求者
        \item 脂肪组件——如MCT组件（用于脂肪吸收障碍）
        \item 碳水化合物组件——如麦芽糊精组件（用于能量补充）
        \item 维生素/矿物质组件
        \item 电解质组件
        \item 膳食纤维组件
    \end{itemize}
\end{itemize}
\end{keybox}

\subsubsection{FSMP与保健食品/药品的区别}

\begin{keybox}
\textbf{FSMP、保健食品与药品的核心区别：}
\begin{center}
\begin{tabular}{@{}p{2.5cm}p{3.5cm}p{3.5cm}p{3.5cm}@{}}
\toprule
\textbf{项目} & \textbf{FSMP} & \textbf{保健食品} & \textbf{药品} \\
\midrule
\textbf{目标人群} & 进食受限、消化吸收障碍、代谢紊乱或特定疾病状态人群 & \imp{普通人群}，调节特定机体功能 & 已确诊的疾病患者 \\
\hline
\textbf{作用} & 提供营养支持 & 调节机体功能（\imp{不以治疗疾病为目的}） & 治疗、预防、诊断疾病 \\
\hline
\textbf{使用方式} & \imp{须在医生或临床营养师指导下}使用 & 可自行选用 & 须在医师指导下使用 \\
\hline
\textbf{注册标志} & \imp{"国食注字TY"}（TY+年份+序号） & \imp{"蓝帽子"标志}（国食健字） & "国药准字" \\
\hline
\textbf{销售渠道} & 医疗机构、药店 & 各类零售渠道 & 医疗机构、药店（处方药/非处方药） \\
\hline
\textbf{法律依据} & 《特殊医学用途配方食品注册管理办法》 & 《保健食品注册与备案管理办法》 & 《药品注册管理办法》 \\
\bottomrule
\end{tabular}
\end{center}
\end{keybox}

\begin{tipbox}
\textbf{FSMP小结：}FSMP不是药品、不是保健食品，是介于普通食品与药品之间的"特殊营养食品"。其注册标准高于普通食品，需进行产品配方设计科学性、安全性、营养充足性和临床效果验证。FSMP产品须标注"请在医生或临床营养师指导下使用"。
\end{tipbox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=5pt]
    \item \textbf{临床营养：}以患者为中心，对能量和营养素缺乏或过量及疾病造成的代谢变化进行预防、诊断和管理。其余名词解释见本章各节定义框。

    \item 控制总能量（每天减少500～1000kcal），调整宏量营养素供能比（蛋白质20\%～25\%，脂肪20\%～30\%，碳水45\%～60\%），增加膳食纤维（25～30g/d），限制添加糖和饱和脂肪，配合有氧+抗阻运动。

    \item 控制能量维持理想体重，限制SFA（<7\%～10\%能量）和反式脂肪，限制胆固醇<300mg/d，控制钠<5g盐/d，增加钾摄入，增加膳食纤维25～30g/d，限制饮酒，多食鱼类（EPA/DHA）。

    \item 控制总能量达标体重，碳水50\%～60\%（优先低GI），蛋白质15\%～20\%（优质蛋白>1/3），脂肪20\%～30\%（SFA<7\%），膳食纤维25～30g/d，规律进餐少量多餐，配合运动和药物治疗。

    \item 五步：①饮食营养治疗（能正常进食时调整膳食）；②饮食+ONS（进食不足时口服补充FSMP）；③全EN（不能进食但肠道有功能）；④EN+PN（EN不能满足需要）；⑤全PN（肠道完全无功能）。递进原则：只要肠道有功能就优先用EN。

    \item 普食（消化功能正常，2000～2500kcal/d）、软饭（轻度消化障碍，1800～2200kcal/d，细软易消化）、半流质（发热/术后/咀嚼困难，1500～1800kcal/d，半流体状5～6餐）、流质（高热/术后过渡期，800～1200kcal/d，全流体状，营养不足不可长期使用<2～3天）。

    \item 高能量（消耗性疾病）、低能量（减重）、高蛋白（烧伤/创伤，>1.2g/kg$\cdot$d）、低蛋白（肾衰竭<0.6g/kg$\cdot$d）、高纤维（便秘/糖尿病，>25～30g/d）、少渣（消化道手术前后<10g/d）、限钠（高血压/心力衰竭/水肿）、忌碘（$^{131}$I治疗前）、低嘌呤（痛风急性期<150mg/d）、MCT（脂肪吸收障碍，不经淋巴系统吸收）。详见正文。

    \item 途径：短期<4周（鼻胃管、鼻肠管），长期>4周（PEG、PEJ）。输注方式：间歇重力滴注、持续输注（输液泵）、推注法。优点：符合生理、保护肠屏障、经济安全、促进消化液和激素分泌。

    \item 适应证：不能经口进食、经口不足但肠道功能存在。禁忌证：完全肠梗阻（绝对）、严重胃肠道出血、弥漫性腹膜炎、血流动力学不稳定。

    \item 途径：外周静脉（<900mOsm/L，<2周）、中心静脉/PICC（可高渗，>2周）。输注形式：多瓶输注（已少用）、全合一（AIO，三腔袋/药房配制）。并发症：①机械性（气胸、CRBSI、血栓）；②代谢性（高血糖最常见、电解质紊乱）；③肝胆（胆汁淤积/PNALD——长期TPN最主要并发症）；④肠屏障损害；⑤再喂养综合征（低磷/低钾/低镁+水钠潴留）。

    \item 首选EN（肠道有功能时就用肠道）→ EN不足时联合PN → EN禁忌时单独PN。理由：EN保护肠屏障功能防止菌群移位，符合生理，更经济安全。即使仅少量EN（滋养性喂养）也可维持肠黏膜完整性。

    \item ABCDE法：A——人体测量（BMI/体重变化/皮褶厚度/臂围/握力）；B——生化（内脏蛋白——Alb/PA/TFN/RBP，氮平衡，电解质/微量元素）；C——临床检查（营养缺乏体征/水肿/肌肉消耗）；D——膳食调查（24h回顾/FFQ/称重法/记账法）；E——能量消耗与环境（BEE/应激系数/活动系数/社会心理）。

    \item NST组成：医师（组长/置管/并发症处理）、临床营养师（营养评定/方案设计/监测）、药师（PN配伍/药物-营养素相互作用）、护士（管路护理/输注操作/患者教育）。任务：规范流程、筛查评定、制定方案、监测并发症、教育培训、成本效益分析。

    \item 分类：全营养配方（单一来源满足全部需要）、特定全营养配方（特定疾病专用如糖尿病/肾病/肿瘤/肝病）、非全营养配方（组件如蛋白/脂肪/MCT/维生素组件）。区别于保健食品（普通人群调功能，蓝帽子）和药品（治疗疾病，国药准字）。FSMP须医生指导下使用，标注"国食注字TY"。
