\section{食品污染概述}

\begin{defbox}
\textbf{食品污染（Food Contamination）：}食物中外来生物性、化学性及物理性有害物质，对人体健康可能产生危害，或影响其食用及商品价值，这一过程称为食品污染。
\end{defbox}

\begin{keybox}
\textbf{食品污染的分类（按污染来源三分类*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{生物性污染（Biological Contamination）：}微生物污染（细菌、霉菌、病毒）、寄生虫及虫卵污染、昆虫污染。是最常见、最重要的食品污染！
    \item \textbf{化学性污染（Chemical Contamination）：}农药残留、有害金属（汞、镉、铅、砷）、$N$-亚硝基化合物、多环芳烃（PAH）、杂环胺、二噁英、食品容器/包装材料迁移物、滥用食品添加剂。
    \item \textbf{物理性污染（Physical Contamination）：}放射性核素污染、异物污染（金属碎片、玻璃、石子等）。
\end{enumerate}
\end{keybox}

\textbf{食品危害的四大来源：}
\begin{enumerate}[leftmargin=*]
    \item 食品本身天然含有或自身产生：如天然有毒动植物（河豚、毒蕈）、储藏中产生的有害物
    \item 加工/储藏过程中形成：如高温烹调产生杂环胺、丙烯酰胺、$N$-亚硝基化合物
    \item 外界污染引入：如环境污染、农药残留、有害金属、微生物污染
    \item 故意滥用添加剂或掺假：如非法添加非食用物质、滥用食品添加剂
\end{enumerate}

\begin{tipbox}
\textbf{食品安全危害的优先控制顺序（WHO建议）：}微生物污染 $>$ 天然毒素 $>$ 化学性污染 $>$ 食品添加剂。这与公众认知恰好相反——公众往往过分担忧食品添加剂，而忽视微生物污染这一最主要的风险来源。
\end{tipbox}

\section{微生物污染及其预防}

\subsection{微生物的分类（按致病能力）}

\begin{enumerate}[leftmargin=*]
    \item \textbf{致病性微生物（Pathogenic）：}直接引起人类疾病，如沙门菌、志贺菌、金黄色葡萄球菌、肉毒梭菌、单增李斯特菌、副溶血性弧菌。致病性微生物是食品安全的首要威胁！
    \item \textbf{条件致病性微生物（Conditional Pathogenic）：}在特定条件下（如免疫力低下、菌群失调、大量摄入）才致病，如大肠杆菌（部分血清型）、变形杆菌。
    \item \textbf{非致病性微生物（Non-pathogenic）：}通常不致病，但可能引起食品腐败变质。
\end{enumerate}

\subsection{菌落总数（Aerobic Plate Count, APC）}

\begin{keybox}
\textbf{菌落总数*：}在规定培养条件下（需氧、36$\pm$1$^\circ$C、48$\pm$2h），每克/每毫升/每平方厘米检样中形成的细菌菌落总数（CFU/g, CFU/mL, CFU/cm$^2$）。

\textbf{食品卫生学意义*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{反映食品的清洁状态：}菌落总数越高，表明食品受微生物污染程度越严重，加工过程的卫生状况越差。
    \item \textbf{反映食品腐败变质的程度：}菌落总数越高，食品腐败变质的可能性越大。
    \item \textbf{预测食品的保质期（货架期）：}根据菌落总数的生长规律，估算食品在特定条件下的可储存时间。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{注意：}菌落总数低不等于完全无致病菌！因为致病菌可能在低菌落总数条件下存在（如少量沙门菌即可致病）；菌落总数高也不一定代表有致病菌。因此菌落总数是卫生质量的指示指标，而非安全性的直接指标。菌落总数必须与致病菌检测结合使用，才能较全面地评价食品卫生质量。
\end{tipbox}

\subsection{大肠菌群（Coliform Group）}

\begin{keybox}
\textbf{大肠菌群*：}在一定培养条件下（36$\pm$1$^\circ$C、24$\sim$48h），能发酵乳糖、产酸产气的需氧和兼性厌氧、革兰阴性、无芽孢杆菌。

\textbf{主要成员：}埃希菌属（Escherichia）、柠檬酸杆菌属（Citrobacter）、肠杆菌属（Enterobacter）、克雷伯菌属（Klebsiella）。

\textbf{食品卫生学意义}\difficulty：
\begin{enumerate}[leftmargin=*]
    \item \textbf{典型大肠杆菌（粪大肠菌群，44.5$^\circ$C仍能生长）检出：}表明食品受到近期粪便污染！因为该菌在体外存活时间短。
    \item \textbf{非典型大肠杆菌检出：}表明食品受到远期（陈旧）粪便污染。因为非粪便来源的肠杆菌在体外可长期存活。
    \item \textbf{作为肠道致病菌的指示菌：}大肠菌群的存在提示可能有沙门菌、志贺菌等肠道致病菌的污染。因为大肠菌群与肠道致病菌来源相同（粪便），且在外界存活时间与肠道致病菌基本一致或稍长。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{大肠菌群计数方法：}
\begin{itemize}[leftmargin=*]
    \item 大肠菌群含量较低时，采用\textbf{MPN法（Most Probable Number，最可能数法）}，结果为MPN/g或MPN/mL。
    \item 大肠菌群含量较高时，采用\textbf{CFU法（平板计数法）}。
    \item GB 4789.3 规定了大肠菌群的检验方法，为强制性食品安全国家标准。
\end{itemize}
\end{tipbox}

\subsection{微生物限量采样方案（ICMSF推荐）}

\textbf{二级采样方案（Two-class Sampling Plan）：}设定$n$（样品数）、$c$（允许超过$m$的最大样品数）、$m$（微生物限量，合格水平）。结果只有"合格/不合格"。适用于致病菌等危害严重的微生物。

\textbf{三级采样方案（Three-class Sampling Plan）：}设定$n$（样品数）、$c$（允许超过$m$的最大样品数）、$m$（可接受限量）、$M$（最高安全限量）。结果分为"满意/可接受/不合格"三级。$m$与$M$之间为"可接受但需关注"区域。

\begin{exambox}
\textbf{采样方案关键参数：}$n$（采样数量）、$c$（允许超过$m$值的最大样品数）、$m$（可接受水平的限量值）、$M$（最高安全限量值，仅三级采样方案有）。
\end{exambox}

\subsection{肠球菌（Enterococci）}

\begin{defbox}
\textbf{肠球菌（粪链球菌，Streptococcus faecalis/Enterococci）：}革兰阳性球菌，主要存在于人和温血动物肠道中。

\textbf{食品卫生学意义：}
\begin{enumerate}[leftmargin=*]
    \item 可作为\textbf{低温食品}（特别是冷冻食品）的粪便污染指示菌。
    \item 肠球菌对外界环境的抵抗力比大肠杆菌和沙门菌更强——在冷冻、高盐条件下可长期存活。
    \item 肠球菌检出 $\neq$ 近期粪便污染（因其存活时间长），需结合大肠杆菌检测结果综合判断。
\end{enumerate}
\end{defbox}

\begin{keybox}
\textbf{细菌菌相（Bacterial Flora）及食品卫生学意义：}

\textbf{概念：}共存于食品中的细菌种类及其相对数量的构成。相对数量较大的细菌称为\keyword{优势菌种（属、株）}。

\textbf{食品卫生学意义：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{影响食品腐败变质的特征：}不同优势菌种产生的腐败产物和感官变化各不相同。
    \item \textbf{影响食品腐败变质的速度和程度：}优势菌种的生长速率和分解能力直接决定腐败进程。
\end{enumerate}
\end{keybox}

\section{霉菌及其毒素对食品的污染}

\subsection{霉菌与霉菌毒素基本概念}

\begin{defbox}
\textbf{霉菌（Mold）：}凡是生长在营养基质上形成绒毛状、蛛网状或絮状菌丝体的真菌（Fungi），统称为霉菌。不包括大型子实体真菌（如蘑菇）。

\textbf{霉菌毒素（Mycotoxin）：}霉菌在其所污染的食品中产生的有毒次级代谢产物。目前已发现400余种霉菌毒素。
\end{defbox}

\begin{keybox}
\textbf{霉菌产毒特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{只限于少数的产毒霉菌：}自然界霉菌种类繁多，但只有少数菌种/菌株能产生毒素。
    \item \textbf{产毒能力可以发生改变：}一株产毒菌株经过传代培养后，产毒能力可减弱或增强，甚至完全丧失产毒能力。
    \item \textbf{产毒没有严格的专一性：}一种霉菌可产生多种不同的毒素（如黄曲霉可产生B1、B2、G1、G2等多种AF）；同一种毒素也可能由不同的霉菌产生。
    \item \textbf{产毒需要一定条件：}产毒菌株只在一定条件下才能产生毒素。
\end{enumerate}
\end{keybox}

\subsection{霉菌产毒条件 — 水分活性（Aw）}

\begin{keybox}
\textbf{水分活性（Water Activity, Aw）*：}相同温度下，食品中水分的蒸汽压（$P$）与纯水蒸汽压（$P_0$）之比，即 $\text{Aw} = P/P_0$。纯水的 Aw = 1.00。

\textbf{各种微生物生长的最低Aw要求：}
\begin{itemize}[leftmargin=*]
    \item Aw 0.98–0.99：大多数微生物都能生长
    \item Aw 0.80–0.85：在1–2周内霉菌等引起腐败变质
    \item Aw 0.70：能较长期抑制微生物生长
    \item Aw 0.65：极少数微生物可生长（某些耐干霉菌和耐高渗酵母）
    \item 大多数霉菌：Aw $\geq$ 0.80可生长（黄曲霉最低 Aw $\approx$ 0.78）
\end{itemize}
\end{keybox}

\textbf{霉菌产毒的主要条件：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{水分活性（Aw）：}大多数霉菌需要 Aw $\geq$ 0.80，适宜相对湿度 80\%–90\%。
    \item \textbf{温度：}最适生长温度 20–28$^\circ$C（一般霉菌）；产毒温度常略低于生长最适温度。
    \item \textbf{营养：}主要以糖类为碳源，少量氮源和矿物质即可满足。
    \item \textbf{氧气：}大多数为专性需氧菌，氧气充足时毒素产量更高。
\end{enumerate}

\subsection{黄曲霉毒素（Aflatoxin, AF）— 最重要的食品污染物之一}

\begin{keybox}
\textbf{黄曲霉毒素（Aflatoxin, AF）* —— 已知最强的天然致癌物！}
\begin{itemize}[leftmargin=*]
    \item \textbf{来源：}黄曲霉（Aspergillus flavus）和寄生曲霉（A.\ parasiticus）产生的次级代谢产物。
    \item \textbf{化学结构：}二呋喃环 + 香豆素（氧杂萘邻酮），基本结构为二呋喃氧杂萘邻酮。
    \item \textbf{主要类型：}B1、B2、G1、G2（紫外线下分别发蓝色和绿色荧光），以及M1、M2（动物体内代谢产物，主要存在于乳及乳制品中）。
    \item \textbf{B1毒性最强：}致癌性排序为 B1 $>$ G1 $>$ B2 $>$ G2。
\end{itemize}
\end{keybox}

\subsubsection{黄曲霉毒素的理化性质}

\begin{enumerate}[leftmargin=*]
    \item \textbf{耐热性强：}一般烹调温度（100–120$^\circ$C）几乎不被破坏，需 268–269$^\circ$C 才完全分解。
    \item \textbf{脂溶性：}难溶于水（溶解度仅 10–20 mg/L），易溶于油脂和多种有机溶剂（氯仿、甲醇等）。
    \item \textbf{在中性或弱酸性溶液中较稳定：}在强碱性条件下（pH 9–10），内酯环被打开，可被破坏。此原理被用于碱炼去毒！
    \item \textbf{紫外线敏感：}在紫外线下产生荧光（B族发蓝紫色荧光，G族发黄绿色荧光），可用于检测。
\end{enumerate}

\subsubsection{产毒条件与易污染食品}

\begin{keybox}
\textbf{黄曲霉产毒条件*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{最适产毒温度：}25–33$^\circ$C（相对湿度 80\%–90\%）
    \item \textbf{最适水分活性（Aw）：}0.93–0.98
    \item \textbf{最适基质：}花生、玉米（产毒量最高），其次为大米、小麦、豆类、棉籽等。
\end{itemize}

\textbf{易污染食品（危险性排序）：}
\begin{enumerate}[leftmargin=*]
    \item 花生及花生制品（最危险！）
    \item 玉米及玉米制品
    \item 棉籽油（粗制棉籽油中含量极高）
    \item 大米、小麦、大麦等谷物
    \item 豆类（花生粕、豆粕等饲料）
    \item 干果、坚果（如开心果、杏仁）
    \item 乳及乳制品（含AF M1）
\end{enumerate}

\textbf{地域特征：}高温高湿地区（热带、亚热带）的食品黄曲霉毒素污染风险最高。我国南方（华南、西南）属于高危地区。
\end{keybox}

\subsubsection{黄曲霉毒素的毒性}

\begin{keybox}
\textbf{黄曲霉毒素的毒性表现（三方面毒性*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{急性毒性：}
    \begin{itemize}[leftmargin=*]
        \item 主要靶器官：\textbf{肝脏}——引起肝细胞坏死、胆管增生、肝出血。
        \item AFB1经口LD$_{50}$：鸭雏 0.24–0.36 mg/kg（最敏感物种之一！），大鼠 5.5–17.9 mg/kg。
        \item 临床症状：发热、呕吐、食欲缺乏、黄疸，严重者出现腹水、下肢水肿、肝大，甚至死亡。
    \end{itemize}
    \item \textbf{慢性毒性：}
    \begin{itemize}[leftmargin=*]
        \item 肝脏慢性损伤：肝实质细胞变性、坏死，纤维组织增生，形成再生结节。
        \item 生长发育迟缓：影响蛋白质合成和营养利用。
        \item 免疫功能下降：抑制细胞免疫和体液免疫。
    \end{itemize}
    \item \textbf{致癌性（最强天然致癌物！）：}
    \begin{itemize}[leftmargin=*]
        \item 诱癌强度是二甲基亚硝胺的\textbf{75倍}！
        \item 可诱发多种实验动物（大鼠、小鼠、鸭、鱼、猴等）的多器官癌症，无动物种属对AF致癌完全抵抗。
        \item 灵长类动物亦可诱癌——猴经AFB1处理可发生肝癌。
        \item \textbf{与人类肝癌密切相关：}流行病学证据表明，膳食AF暴露量与原发性肝癌发病率呈正相关。\textbf{尤为重要的是AF与HBV（乙肝病毒）的协同致癌作用！}HBV感染者暴露于AF时，肝癌风险急剧增高。
        \item IARC分类：AFB1为\textbf{Group 1（确认人类致癌物）}。
    \end{itemize}
\end{enumerate}
\end{keybox}

\begin{exambox}
\textbf{为什么黄曲霉毒素是公认的强致癌物？}
\begin{enumerate}[leftmargin=*]
    \item 致癌强度极高（二甲基亚硝胺的75倍）
    \item 致癌谱广（多物种、多器官）
    \item 灵长类动物可诱癌（与人种最接近的动物）
    \item 与人类肝癌流行病学相关性强
    \item 与HBV有协同致癌效应
\end{enumerate}
\end{exambox}

\begin{keybox}
\textbf{黄曲霉毒素的体内代谢过程*：}

AFB1进入体内主要在\keyword{肝脏}进行代谢，在肝细胞微粒体混合功能氧化酶系（CYP450）的催化下，发生羟化、脱甲基和环氧化反应：

\begin{enumerate}[leftmargin=*]
    \item \textbf{AFM1：}AFB1在肝微粒体酶催化下的\keyword{羟化产物}，最初在牛乳、羊乳中发现。奶牛摄入AFB1污染饲料后，乳汁中排出AFM1。
    \item \textbf{AFQ1：}AFB1的另一种羟化产物，AFB1 $\rightarrow$ AFQ1可能是\keyword{解毒过程}。
    \item \textbf{AFH1：}AFQ1的还原产物，黄曲霉毒醇 $\rightarrow$ AFH1可能是\keyword{另一种解毒途径}。
    \item \textbf{AFB1-8,9-环氧化物：}由CYP450催化的环氧化反应生成，是AFB1的\keyword{终致癌物}，可与DNA结合形成AFB1-N$^7$-鸟嘌呤加合物，导致DNA损伤和突变。
\end{enumerate}

AF有很强的急性毒性，也有明显的慢性毒性与致癌性。AF对肝脏有特殊亲和性（嗜肝毒），具有较强的肝脏毒性并有致癌作用。
\end{keybox}

\subsubsection{摄入途径}

\begin{enumerate}[leftmargin=*]
    \item \textbf{直接摄入：}食用被AF B1污染的食品（花生、玉米、棉籽油、谷物）。
    \item \textbf{间接摄入（通过食物链）：}动物摄入AF B1污染饲料后，体内代谢产生AF M1，分泌到乳汁中。人饮用含AF M1的牛乳/乳制品。AF M1的毒性约为B1的十分之一，但仍归为Group 2B。
\end{enumerate}

\subsubsection{黄曲霉毒素的预防措施}

\begin{keybox}
\textbf{黄曲霉毒素的预防（三个环节*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{防霉（最关键、最根本的措施！）：}
    \begin{itemize}[leftmargin=*]
        \item 控制粮食水分含量至安全水分以下（谷类 $\leq$ 13\%–14\%，花生 $\leq$ 8\%–9\%）
        \item 低温储藏（$\leq$ 10$^\circ$C可有效抑制霉菌生长）
        \item 降低氧气浓度（充$N_2$或$CO_2$气调储藏）
        \item 化学防霉剂（如丙酸、丙酸盐）
    \end{itemize}
    \item \textbf{去毒（对于已污染的食品）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{物理法：}挑选霉粒（人工/光电色选）、碾轧加工（碾去含毒量最高的种皮和胚）、吸附法（活性炭、白陶土吸附植物油中AF）、紫外线照射。
        \item \textbf{化学法：}碱炼法——利用AF在强碱条件下内酯环开环的原理，在植物油精炼中加入NaOH去除AF。氨熏蒸法也可用于饲料去毒。
    \end{itemize}
    \item \textbf{执行食品中AF限量标准：}
    \begin{itemize}[leftmargin=*]
        \item GB 2761-2017《食品安全国家标准 食品中真菌毒素限量》
        \item 玉米、花生及其制品：AFB1 $\leq$ 20 $\mu$g/kg
        \item 大米、其他植物油：AFB1 $\leq$ 10 $\mu$g/kg
        \item 婴幼儿配方食品：AFB1 $\leq$ 0.5 $\mu$g/kg（不得检出，最严格！）
        \item 乳及乳制品：AFM1 $\leq$ 0.5 $\mu$g/kg
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{其他重要霉菌毒素（熟悉）}

\begin{enumerate}[leftmargin=*]
    \item \textbf{赭曲霉毒素（Ochratoxin A, OTA）：}
    \begin{itemize}[leftmargin=*]
        \item 主要由赭曲霉和纯绿青霉产生
        \item 主要污染谷物（小麦、大麦、玉米）及咖啡豆
        \item 主要靶器官：肾脏（致畸、致突变、致癌）——引起巴尔干肾病
        \item IARC Group 2B
    \end{itemize}
    \item \textbf{单端孢霉烯族化合物（Trichothecenes）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{T-2毒素：}可引起ATA（Alimentary Toxic Aleukia，食物中毒性白细胞缺乏症），表现为白细胞减少、出血、坏死。
        \item \textbf{DON（脱氧雪腐镰刀菌烯醇，Deoxynivalenol）：}又称呕吐毒素（Vomitoxin），主要污染小麦、玉米等谷物。急性中毒症状：恶心、呕吐、腹泻。
    \end{itemize}
    \item \textbf{玉米赤霉烯酮（Zearalenone, ZEN）：}
    \begin{itemize}[leftmargin=*]
        \item 主要由禾谷镰刀菌产生，污染玉米、小麦
        \item 具有\textbf{雌激素样活性}——引起猪等动物的雌激素过多综合征（外阴红肿、假发情、不孕）
    \end{itemize}
    \item \textbf{伏马菌素（Fumonisins）：}
    \begin{itemize}[leftmargin=*]
        \item 由串珠镰刀菌产生，主要污染玉米
        \item 鞘脂类合成抑制剂；与人类食管癌高发区相关
        \item IARC Group 2B
    \end{itemize}
    \item \textbf{展青霉素（Patulin）：}
    \begin{itemize}[leftmargin=*]
        \item 主要由扩展青霉产生
        \item 主要污染水果及其制品（苹果汁、苹果酱最突出）
        \item 具有神经毒性、致突变性和免疫抑制性
    \end{itemize}
\end{enumerate}

\begin{keybox}
\textbf{主要产毒青霉及其毒素（补充）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{岛青霉（Penicillium islandicum）：}产生\keyword{岛青霉素}（肝毒素）、\keyword{黄天精}（Luteoskyrin，肝毒素）和\keyword{环氯素}（Cyclochlorotine），主要污染大米，引起"黄变米"中毒——肝脏损害。
    \item \textbf{橘青霉（Penicillium citrinum）：}产生\keyword{桔青霉素}（Citrinin），主要靶器官为肾脏，引起肾小管上皮变性。
    \item \textbf{扩展青霉（Penicillium expansum）：}产生展青霉素，污染水果。
    \item \textbf{皱褶青霉（Penicillium rugulosum）：}产生皱褶青霉素。
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{霉菌菌相（Mold Flora）及食品卫生学意义：}

\textbf{概念：}食品中污染的真菌种类及其相对数量的构成，可从真菌污染度和真菌菌相构成两个方面评定。

\textbf{菌相判级：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{田野霉占优势}（如气连孢霉、芽枝霉、头孢霉等）：表示粮食新鲜，是田间自然带菌的正常菌相。
    \item \textbf{曲霉和青霉检出：}不表明粮食已经霉变，但提示储藏条件可能不良。
    \item \textbf{毛霉、根霉、木霉检出：}说明粮食已开始霉变——这些是储藏后期腐败菌。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{霉菌毒素中毒的共同特点（掌握）*：}
\begin{enumerate}[leftmargin=*]
    \item 中毒的发生主要通过\textbf{被霉菌毒素污染的食品}引起。
    \item 主要损害实质器官（\textbf{肝、肾}最常受累）。
    \item 一般烹调加热（100–120$^\circ$C）\textbf{不能}将霉菌毒素完全破坏去除。
    \item \textbf{没有传染性和免疫性：}霉菌毒素中毒是化学性中毒，不存在抗体和免疫保护，再次接触仍可中毒。
    \item 具有\textbf{季节性和地区性}特点，与产毒霉菌的生长条件有关。
\end{enumerate}
\label{mold_poisoning}
\end{keybox}

\section{食品腐败变质}

\subsection{概念与原因}

\begin{defbox}
\textbf{食品腐败变质（Food Spoilage）：}在微生物为主的各种因素作用下，食品中组成成分被分解、破坏，使其感官性状发生变化、食用价值降低或丧失的一切变化。
\end{defbox}

\begin{keybox}
\textbf{食品腐败变质的主要原因*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{微生物的作用（最主要原因！）：}细菌（最常见腐败菌）、酵母菌、霉菌。
    \begin{itemize}[leftmargin=*]
        \item 机制：微生物分泌胞外酶 $\rightarrow$ 将食品中大分子物质分解为小分子 $\rightarrow$ 吸收进入细胞 $\rightarrow$ 胞内酶代谢 $\rightarrow$ 产生异味物质和有害产物。
    \end{itemize}
    \item \textbf{食品本身的特性：}营养成分（蛋白质、脂肪、碳水化合物含量）、pH值、水分活性（Aw）、渗透压。
    \item \textbf{环境因素：}温度、湿度、氧气、光照。
\end{enumerate}
\end{keybox}

\subsection{食品腐败变质的鉴定指标}

\begin{keybox}
\textbf{食品腐败变质的鉴定指标（四类*）：}
\end{keybox}

\subsubsection{感官指标}
通过嗅觉、视觉、触觉等判断食品的颜色、气味、味道、组织状态的变化。感官鉴定是消费者判断食品质量最直接的方法，也是最敏感的鉴定方法。

\subsubsection{化学指标}

\begin{keybox}
\textbf{1. 挥发性盐基总氮（Total Volatile Basic Nitrogen, TVBN)*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{定义：}食品水浸液在弱碱性条件下，与水蒸气一起蒸馏出来的总氮量。
    \item \textbf{适用对象：}高蛋白食品（肉类、鱼类）。
    \item \textbf{卫生学意义：}反映蛋白质因细菌或酶的作用分解产生的氨和胺类物质的量，是判断高蛋白食品鲜度的常用指标。
    \item 国家标准限值（GB 2707等）：鲜（冻）畜肉 TVBN $\leq$ 15 mg/100g；海水鱼 $\leq$ 30 mg/100g。
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{2. K值（K Value）* —— 判断鱼类鲜度的指标：}

\[
K(\%) = \frac{\text{HxR} + \text{Hx}}{\text{ADP} + \text{AMP} + \text{IMP} + \text{HxR} + \text{Hx}} \times 100\%
\]

\begin{itemize}[leftmargin=*]
    \item ATP（腺苷三磷酸）$\rightarrow$ ADP $\rightarrow$ AMP $\rightarrow$ IMP（肌苷酸，鲜味）$\rightarrow$ HxR（次黄嘌呤核苷/肌苷）$\rightarrow$ Hx（次黄嘌呤）
    \item \textbf{判级标准：}$K < 20\%$ 新鲜（可生食）；$K = 20\%\sim40\%$ 次新鲜（需充分加热）；$K > 40\%$ 初期腐败，不可食用；$K > 60\%$ 明显腐败。
    \item K值反映的是ATP分解产物中次黄嘌呤核苷和次黄嘌呤所占比例，真正的鲜度越差、K值越高。
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{K值与TVBN的区别：}K值适用于鱼类等水产品，反映ATP早期分解程度，比TVBN更灵敏地判断早期鲜度下降；TVBN适用于一般高蛋白食品（特别是畜肉），反映蛋白质分解产生胺类物质的量。
\end{tipbox}

\subsubsection{物理指标}
比重、折光率、黏度、浸出物量等。如牛乳的酸度升高，肉浸出液的黏度改变。

\subsubsection{微生物指标}
细菌总数（菌落总数）、大肠菌群、致病菌检测。是判断食品卫生质量的重要辅助手段。

\subsection{各类营养素的腐败产物}

\begin{enumerate}[leftmargin=*]
    \item \textbf{蛋白质腐败：}
    \begin{itemize}[leftmargin=*]
        \item 途径：蛋白质 $\rightarrow$ 多肽 $\rightarrow$ 氨基酸 $\rightarrow$ 脱羧 $\rightarrow$ 胺类 + CO$_2$
        \item 特征产物：甲胺、腐胺（putrescine）、尸胺（cadaverine）、组胺（histamine）、色胺（tryptamine）、酪胺、吲哚、硫化氢、硫醇。
        \item 感官表现：恶臭（鱼腥味、腐败味）、变色、发黏。
    \end{itemize}
    \item \textbf{脂肪酸败（酸败）：}
    \begin{itemize}[leftmargin=*]
        \item 途径：中性脂肪分解为甘油和游离脂肪酸 $\rightarrow$ 脂肪酸进一步氧化分解。
        \item 特征：产生"哈喇味"（rancid odor）；过氧化值（POV）升高是脂肪酸败的最早期指标！
        \item 感官表现：颜色变黄（褐色）、产生"油耗味"。
    \end{itemize}
    \item \textbf{碳水化合物分解（酸败/发酵）：}
    \begin{itemize}[leftmargin=*]
        \item 途径：糖类 $\rightarrow$ 有机酸 + 醇类 $\rightarrow$ 醛、酮、CO$_2$。
        \item 特征产物：乳酸、醋酸、乙醇、丁酸等。
        \item 感官表现：酸味、产气、变黏。
    \end{itemize}
\end{enumerate}

\subsection{腐败变质食品的处理原则}

\begin{keybox}
\textbf{腐败变质食品的处理原则（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{严重腐败变质：}销毁或改作其他工业用途（如饲料、肥料），严禁作为食品销售。
    \item \textbf{轻度腐败变质：}经过适当的加工处理（如高温灭菌、去除变质部分），将变质的主要指标降至安全限量以下，可以限期食用。
    \item \textbf{限期食用：}对即将变质但尚未发生明显感官异常的食品，应在规定期限内尽快食用完毕。
    \item \textbf{局部变质：}挑选去除变质部分，利用其他完好部位（如切除蔬菜腐烂部分、剔除霉变粮粒）。
\end{enumerate}
\end{keybox}

\subsection{食品保藏方法}
\section{防止腐败变质措施与食品保藏}

\subsection{低温保藏}

\begin{keybox}
\textbf{低温保藏原理：}低温可抑制微生物的生长繁殖和酶的活性，降低食品中化学反应速度。

\textbf{低温保藏分类：}
\begin{itemize}[leftmargin=*]
    \item \textbf{冷藏（Refrigeration）：}0–10$^\circ$C，短期保存
    \item \textbf{冷冻（Freezing）：} $\leq$ $-$18$^\circ$C，长期保存
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{"急冻缓化"原则*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{急冻：}快速冻结，30 min内通过最大冰晶生成带（$-1\sim-5^\circ$C），使食品中心温度迅速降至 $-20^\circ$C。优点：形成的冰晶体积小、均匀分布在细胞内和细胞间，对细胞结构破坏小，解冻后汁液流失少。
    \item \textbf{缓化：}缓慢解冻，在 0–10$^\circ$C 下缓慢融化。优点：融化水分有足够时间被细胞重新吸收，减少汁液流失，保持食品风味和营养。
\end{enumerate}
\end{keybox}

\begin{defbox}
\textbf{TTT原则（Time-Temperature-Tolerance）：}冷冻食品的品温（T）、储藏时间（T）对品质的容许限度（Tolerance）三者之间的关系。冷冻食品的品质随冻藏温度的升高和时间的延长而逐渐下降。遵循TTT原则可预测冷冻食品在特定条件下的保质期。
\end{defbox}

\subsection{高温杀菌}

\begin{keybox}
\textbf{D值（Decimal Reduction Time）*：}在特定温度条件下，杀死90\%（即减少一个对数数量级）的某种微生物所需的时间（min）。D值越小，微生物的热耐受性越弱。

举例：
\begin{itemize}[leftmargin=*]
    \item 金黄色葡萄球菌 D$_{63}$ = 7 min（63$^\circ$C条件下需7 min杀死90\%）
    \item 肉毒梭菌芽孢 D$_{121}$ = 0.1–0.2 min（121$^\circ$C条件下需0.1–0.2 min杀死90\%）
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{Z值（Thermal Resistance Constant）：}使某种微生物的D值降低90\%（即减少一个对数数量级）所需升高的温度（$^\circ$C）。Z值反映微生物对温度变化的敏感性——Z值越小，微生物受温度变化影响越大。

\textbf{F值（Sterilization Value）：}在特定温度（通常指121.1$^\circ$C）和特定Z值（通常Z=10$^\circ$C）条件下，杀死一定数量微生物所需的时间（min）。实际应用中通常要求12D的杀菌强度——即减少12个对数数量级（使芽胞存活概率降至$10^{-12}$），以保证罐头食品的商业无菌。
\begin{itemize}[leftmargin=*]
    \item $F_0$值：指Z=10$^\circ$C、温度为121.1$^\circ$C时的杀菌时间（min），为罐头工业的标准杀菌参数。
\end{itemize}
\end{keybox}

\textbf{常用高温杀菌方法：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{巴氏消毒法（Pasteurization）：}
    \begin{itemize}[leftmargin=*]
        \item 目的：杀死所有致病菌，延长保质期
        \item LTLT（低温长时间）：62.8$^\circ$C、30 min（传统法）
        \item HTST（高温短时间）：71.7$^\circ$C、15 s（目前常用）
        \item 应用：牛乳、啤酒、果汁等
    \end{itemize}
    \item \textbf{超高温瞬时灭菌（UHT）：}
    \begin{itemize}[leftmargin=*]
        \item 135–150$^\circ$C、2 s
        \item 达到商业无菌（Commercial Sterility）——并非绝对无菌，而是杀灭所有在正常储存条件下可生长繁殖的微生物。
        \item 应用：UHT牛乳（常温奶）、豆奶等
    \end{itemize}
    \item \textbf{高温灭菌：}
    \begin{itemize}[leftmargin=*]
        \item 110–121$^\circ$C、20 min（罐头食品常用），可杀灭繁殖型和芽胞型细菌
        \item 蒸汽加压灭菌锅（绝对压力约0.2 MPa）
    \end{itemize}
    \item \textbf{微波杀菌（Microwave Sterilization）：}
    \begin{itemize}[leftmargin=*]
        \item 原理：利用微波的热效应和非热效应杀灭微生物。
        \item 常用频率：915 MHz（穿透厚度大，适用于含水量高、体积大的食品）和2450 MHz（适用于含水量低的食品）。
        \item 特点：快速、节能、对食品品质影响小，能保留更多活性物质和营养成分。
    \end{itemize}
\end{enumerate}

\textbf{按杀菌压力分类：}
\begin{itemize}[leftmargin=*]
    \item \textbf{常压杀菌：}加热温度 $\leq$ 100$^\circ$C，杀灭所有致病菌和繁殖型微生物。常用于液态食物消毒。采用巴氏杀菌法的食品有牛乳、啤酒、醋、葡萄酒等。
    \item \textbf{加压杀菌：}100～121$^\circ$C（绝对压力约0.2 MPa），常用于肉类制品、罐头食品的杀菌，可杀灭繁殖型和芽胞型细菌。
\end{itemize}

\subsection{辐照保藏}

\begin{itemize}[leftmargin=*]
    \item \textbf{辐照源：}$^{60}$Co（钴-60）、$^{137}$Cs（铯-137）产生的$\gamma$射线，或电子加速器产生的电子束。
    \item \textbf{剂量分级：}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{辐照防腐（Radurization）：}低剂量（1–5 kGy）：保鲜（抑制发芽、延迟成熟、杀虫）
        \item \textbf{辐照消毒（Radicidation）：}中剂量（5–10 kGy）：杀灭致病菌（沙门菌等）、寄生虫
        \item \textbf{辐照灭菌（Radappertization）：}高剂量（10–50 kGy）：商业无菌
    \end{enumerate}
    \item \textbf{辐照食品的安全性：}WHO/FAO/IAEA联合专家委员会结论——在适当的辐照剂量下，辐照食品是安全的，不会产生放射性。
    \item 我国已颁布GB 14891系列辐照食品卫生标准。
\end{itemize}

\subsection{其他保藏方法}

\begin{enumerate}[leftmargin=*]
    \item \textbf{化学保藏：}防腐剂（苯甲酸、山梨酸）、抗氧化剂（BHA、BHT、TBHQ）、酸度调节剂。
    \item \textbf{盐渍/糖渍：}利用高渗透压抑制微生物生长。食盐浓度 $\geq$ 10\% 可抑制多数细菌繁殖；糖渍食品糖含量须达60\%～65\%。
    \item \textbf{干制/脱水（Drying/Dehydration）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{机制：}将食品水分降至15\%以下或Aw值在0.00～0.60之间，抑制腐败微生物生长，使食品在常温下可长期保藏。
        \item \textbf{常用方法：}日晒、阴干、喷雾干燥、减压蒸发、冷冻干燥。
        \item \textbf{食品褐变（Browning）问题：}
        \begin{enumerate}[leftmargin=*]
            \item \textbf{酶促褐变（Enzymatic Browning）：}酚酶催化酚类物质形成醌及其聚合物的结果。如切开的苹果、土豆暴露于空气中变褐。
            \item \textbf{非酶褐变/美拉德反应（Maillard Reaction）：}由蛋白质、氨基酸的氨基与糖及脂肪氧化的醛、酮等羰基发生的羰氨反应，使食物产生红棕色和香气。Aw=0.6时最适于褐变；SO$_2$可与羰基结合而阻止褐变。
        \end{enumerate}
        \item \textbf{影响因素：}加热与给氧促进褐变。
    \end{itemize}
    \item \textbf{酸渍/发酵：}利用产酸菌产生乳酸等有机酸，降低pH至4.5以下抑制致病菌。
    \item \textbf{烟熏：}除脱水作用外，烟熏成分（酚类、醛类）具抑菌和抗氧化作用。
    \item \textbf{气调保藏（MAP）：}调节包装内的气体比例（降低O$_2$、增加CO$_2$、充N$_2$），抑制需氧菌和霉菌生长。
\end{enumerate}

\section{农药和兽药残留}

\subsection{农药残留基本概念}

\begin{keybox}
\textbf{农药残留（Pesticide Residue）*：}农药使用后残存于食品、农产品、环境及饲料中的农药原体、有毒代谢产物、降解产物和杂质的总称。

\textbf{最大残留限量（Maximum Residue Limits, MRLs）*：}在生产或保护商品过程中，按照良好的农业生产规范（GAP），直接或间接使用农药后，在食品和饲料中可合法允许的农药残留的最高浓度（mg/kg）。

\textbf{每日允许摄入量（Acceptable Daily Intake, ADI）*：}人类终生每日摄入某物质，而不产生可检测到的健康危害的剂量（mg/kg bw）。
\end{keybox}

\subsection{农药污染途径}

\begin{keybox}
\textbf{农药污染食品的主要途径（四途径*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{直接污染（施药）：}对农作物直接喷洒农药——\textbf{最主要的污染途径！}
    \item \textbf{农作物从污染环境中吸收：}土壤中残留农药、灌溉水中农药被作物根系吸收。
    \item \textbf{食物链和生物富集作用：}饲料 $\rightarrow$ 畜禽体内 $\rightarrow$ 乳、蛋、肉；水体农药 $\rightarrow$ 藻类 $\rightarrow$ 鱼虾 $\rightarrow$ 人体。
    \item \textbf{储运过程中的污染：}贮藏熏蒸杀虫剂污染；运输工具未经彻底清洗而交叉污染。
\end{enumerate}
\end{keybox}

\subsection{主要农药类型及毒性}

\begin{enumerate}[leftmargin=*]
    \item \textbf{有机磷农药（Organophosphates）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：不可逆地抑制乙酰胆碱酯酶（AChE），导致乙酰胆碱在突触积累 $\rightarrow$ 持续兴奋 $\rightarrow$ 神经功能紊乱。
        \item 代表品种：对硫磷（1605）、敌敌畏（DDVP）、乐果（dimethoate）、马拉硫磷（malathion）。
        \item 特点：化学性质不稳定（尤其对光和热），残留期相对较短；急性毒性高，慢性毒性相对低。但某些品种如乐果具潜在致突变性。
    \end{itemize}
    \item \textbf{氨基甲酸酯类农药（Carbamates）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：\textbf{可逆地}抑制胆碱酯酶（与有机磷不同——氨基甲酸酯的酶抑制是可逆的！）。
        \item 代表品种：西维因（carbaryl）、速灭威（MTMC）、涕灭威（aldicarb）。
        \item 特点：杀虫作用迅速，对人畜毒性较低。但在酸性条件下与亚硝酸盐反应可生成$N$-亚硝基化合物（潜在致癌物！）。
    \end{itemize}
    \item \textbf{拟除虫菊酯类农药（Pyrethroids）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：干扰神经细胞膜钠离子通道，影响神经动作电位。
        \item 代表品种：氯氰菊酯（cypermethrin）、溴氰菊酯（deltamethrin）、氰戊菊酯（fenvalerate）。
        \item 特点：高效、低残留、对哺乳动物毒性低。但害虫易产生抗药性，导致用药量不断增大。
    \end{itemize}
    \item \textbf{有机氯农药（Organochlorines，淘汰类）：}
    \begin{itemize}[leftmargin=*]
        \item 代表品种：六六六（BHC/666）、滴滴涕（DDT）。
        \item 特点：\textbf{化学性质极其稳定}——DDT在土壤中消失95\%需要3–30年！脂溶性强，通过食物链积累和浓缩。可通过母乳排出（母乳中DDT含量明显高于牛乳）。
        \item 我国已于1983年停止生产、1984年停止使用有机氯农药。
    \end{itemize}
\end{enumerate}

\subsection{农药残留的控制措施}

\begin{keybox}
\textbf{控制农药残留的措施*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{加强农药管理：}实行农药登记制度和生产许可制度，从源头控制农药质量。
    \item \textbf{安全合理使用农药：}严格遵守农药安全使用准则，特别注意\textbf{安全间隔期}（最后一次施药至收获的天数），确保收获时残留量降至MRL以下。
    \item \textbf{制定和执行食品中农药残留限量标准：}我国GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》规定了564种农药的10092项MRLs，是世界上涵盖农药品种最多的标准之一。
    \item \textbf{研制和推广高效低毒低残留新品种：}推广生物农药、植物源农药。
    \item \textbf{食品安全法规定：}剧毒、高毒农药不得用于蔬菜、水果、茶叶和中草药材。
\end{enumerate}
\end{keybox}

\subsection{兽药残留（熟悉）}

\begin{defbox}
\textbf{兽药残留（Veterinary Drug Residues）：}动物产品的任何可食部分所含兽药原形化合物和/或其代谢产物，以及与兽药有关的杂质的残留。
\end{defbox}

\textbf{兽药残留来源：}
\begin{enumerate}[leftmargin=*]
    \item 动物疾病治疗用药
    \item 饲料添加剂（预防用药、促生长剂）
    \item 环境污染（工业排放 $\rightarrow$ 饲料作物）
\end{enumerate}

\textbf{主要问题：}
\begin{enumerate}[leftmargin=*]
    \item 滥用抗生素（导致耐药菌产生和兽药残留）
    \item 使用违禁/淘汰药物（如氯霉素、硝基呋喃类）
    \item 非法使用饲料添加剂（如\textbf{盐酸克伦特罗/瘦肉精 clenbuterol}——\(\beta\)受体激动剂，促进瘦肉生长）
    \item 不遵守休药期规定，甚至在屠宰前仍用药
\end{enumerate}

\begin{keybox}
\textbf{常见兽药残留的毒性分类：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{急性毒性：}红霉素等大环内酯类可引起急性肝损伤；瘦肉精可引起人的心跳加快、心律失常、肌肉震颤、代谢紊乱。
    \item \textbf{慢性毒性和"三致"作用：}
    \begin{itemize}[leftmargin=*]
        \item 雌激素类可干扰人体内源性激素的正常代谢与功能；
        \item 磺胺类可破坏人体造血机能，引起肾损害；
        \item 氯霉素可引起再生障碍性贫血；
        \item 四环素类可与钙结合，抑制骨和牙的发育；
        \item 庆大霉素和卡那霉素等氨基糖苷类可损害前庭和耳蜗神经，导致眩晕和听力减退；
        \item 雌激素类、硝基呋喃类、砷制剂等有致癌作用。
    \end{itemize}
    \item \textbf{过敏反应：}青霉素类、四环素类、氨基糖苷类、磺胺类和呋喃类等抗菌药物可引起过敏反应。
    \item \textbf{激素样作用：}甲睾酮、丙酸睾酮、苯丙酸诺龙、雌二醇等性激素可产生一系列激素样作用。
    \item \textbf{产生耐药菌株和破坏肠道菌群平衡：}长期低剂量使用抗菌药物可诱导细菌耐药性，并通过食物链传播耐药基因；同时破坏人体肠道正常菌群的平衡。
\end{enumerate}
\end{keybox}

\section{有害金属污染}

\subsection{汞（Mercury, Hg）}

\begin{keybox}
\textbf{汞的污染来源：}
\begin{itemize}[leftmargin=*]
    \item 工业"三废"排放（汞矿开采、氯碱工业、电子工业）
    \item 含汞农药的使用（历史上曾用有机汞作杀菌剂）
    \item 自然来源（火山喷发等）
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{汞的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{甲基汞（Methylmercury）毒性远大于无机汞：}在水体中由微生物将无机汞甲基化形成甲基汞，通过食物链逐级富集（藻类 $\rightarrow$ 浮游动物 $\rightarrow$ 小鱼 $\rightarrow$ 大鱼），在鱼体中以甲基汞形式高度富集。
    \item \textbf{鱼贝类是最重要的甲基汞污染食品！}大鱼（金枪鱼、鲨鱼、剑鱼等）体内甲基汞浓度可比水体高数万至数十万倍。
    \item \textbf{脂溶性：}甲基汞为脂溶性，极易通过生物膜。胃肠道吸收率 $>$ 90\%。
    \item \textbf{强巯基亲和力：}甲基汞与蛋白质中—SH基团结合，抑制多种含—SH的酶。
    \item \textbf{可透过血脑屏障和胎盘屏障：}引起中枢神经系统损害（最典型表现为视野向心性缩小、感觉异常、共济失调、听力障碍）和胎儿先天性水俣病。
    \item \textbf{主要损害靶器官：}大脑和神经系统。
    \item \textbf{历史事件：}日本水俣病（Minamata Disease，1956年）——甲基汞中毒的典型公害病。
\end{enumerate}
\end{keybox}

\subsection{镉（Cadmium, Cd）}

\begin{keybox}
\textbf{镉的污染来源：}
\begin{itemize}[leftmargin=*]
    \item 工业含镉废水、废渣排放 $\rightarrow$ 污染灌溉水体和农田土壤
    \item 水稻对土壤中镉有高度富集能力 $\rightarrow$ "\textbf{镉大米}"
    \item 含镉肥料（磷肥含镉）、含镉电池的不当处置
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{镉的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{生物半衰期极长：}约\textbf{15–30年}！镉一旦进入人体，极难排出。
    \item \textbf{主要蓄积器官：}肾脏（占全身总镉量的1/3）和肝脏。镉在体内与金属硫蛋白（Metallothionein, MT）结合，以Cd-MT复合物形式储存。
    \item \textbf{慢性毒性：}
    \begin{itemize}[leftmargin=*]
        \item 主要靶器官为\textbf{肾脏}——损害肾近曲小管 $\rightarrow$ 低分子量蛋白尿（肾小管性蛋白尿）$\rightarrow$ 高钙尿症 $\rightarrow$ 骨软化和骨质疏松。
        \item 日本\textbf{痛痛病（Itai-itai Disease）}——镉慢性中毒的惨痛公害病。表现：全身骨痛、骨骼变形、多发性骨折等。
    \end{itemize}
    \item \textbf{预防：}袁隆平团队已开发低镉吸收水稻品种，为解决"镉大米"问题提供技术路径。
    \item IARC分类：镉及镉化合物为\textbf{Group 1（确认人类致癌物）}。
\end{enumerate}
\end{keybox}

\subsection{铅（Lead, Pb）}

\begin{keybox}
\textbf{铅的污染来源：}
\begin{itemize}[leftmargin=*]
    \item 历史上含铅汽油燃烧（四乙基铅）——大气铅污染最重要的来源（中国2000年禁用）
    \item 工业"三废"排放（蓄电池、冶炼、油漆行业）
    \item 食品加工设备/容器/管道迁移（如含铅焊锡的罐头、陶瓷釉中铅溶出）
    \item 传统松花蛋制作中使用氧化铅（已禁用）
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{铅的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{典型的慢性蓄积性毒物：}生物半衰期约14年（骨骼中）。主要蓄积在骨骼（90\%以上），其次是肝、肾。
    \item \textbf{最主要危害——神经发育毒性：}胎儿和婴幼儿/儿童对铅的神经毒性特别敏感！\textbf{血铅水平每升高100 $\mu$g/L，儿童IQ平均下降3分以上。}铅可影响突触形成、神经递质释放和髓鞘形成。
    \item 对造血系统的影响：抑制血红素合成酶（\(\delta\)-氨基-\(\gamma\)-酮戊酸脱水酶、铁络合酶），引起贫血。
    \item 对肾脏的损害：慢性铅肾病（间质性肾炎）。
    \item \textbf{2010年JECFA撤销了铅的PTWI（暂定每周耐受摄入量）：}因为现有的剂量-效应分析表明，没有任何铅摄入水平可以被认为是"安全"的，尤其是对婴幼儿神经发育的影响。
    \item \textbf{IARC分类：}无机铅化合物为\textbf{Group 2A（很可能对人类致癌）}——2004年。
\end{enumerate}
\end{keybox}

\subsection{有害金属污染的预防措施}

\begin{keybox}
\textbf{有害金属污染的预防原则*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{消除污染源——根本措施！}加强工业"三废"治理、禁止使用含铅汽油、更换老旧铅水管。
    \item \textbf{严格执行GB 2762《食品安全国家标准 食品中污染物限量》。}
    \item \textbf{妥善保管有毒金属化合物：}防止误食或食品加工过程中的交叉污染。
    \item \textbf{对已污染食品进行科学处理：}可采用剔除、稀释等方法降低危害。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{金属间拮抗作用：}
\begin{itemize}[leftmargin=*]
    \item 铁（Fe）可拮抗铅（Pb）的吸收和毒性
    \item 锌（Zn）可拮抗镉（Cd）的毒性
    \item 硒（Se）可拮抗汞（Hg）、铅（Pb）、镉（Cd）等多种有害金属的毒性
    \item 保证膳食中必需微量元素的充足摄入，是拮抗有害金属的重要营养策略
\end{itemize}
\end{tipbox}

%  第八节 N-亚硝基化合物污染
% =====================================================================
\section{$N$-亚硝基化合物污染}

\subsection{$N$-亚硝基化合物的分类}

\begin{keybox}
\textbf{$N$-亚硝基化合物分类：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{$N$-亚硝胺（$N$-Nitrosamines）：}
    \begin{itemize}[leftmargin=*]
        \item 化学性质稳定，不易水解，在中性和碱性环境中较稳定。
        \item 需要在体内经代谢活化后才具有致癌性（间接致癌物）。
    \end{itemize}
    \item \textbf{$N$-亚硝酰胺（$N$-Nitrosamides）：}
    \begin{itemize}[leftmargin=*]
        \item 化学性质不稳定，见光、受热易分解。
        \item 为直接致癌物和直接致突变物（不需体内代谢活化）。
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{前体物与合成条件}

\begin{keybox}
\textbf{$N$-亚硝基化合物的前体物*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{硝酸盐（NO$_3^-$）和亚硝酸盐（NO$_2^-$）：}广泛存在于自然环境（土壤、水体）和食品中。蔬菜是饮食中硝酸盐的最主要来源（约占70\%–80\%）。
    \item \textbf{胺类物质：}广泛存在于环境和食品中（蛋白质分解产物）。鱼、肉、药物（某些）中含量较高。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{$N$-亚硝基化合物的体内合成条件*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{pH $<$ 3的酸性环境}是该反应的最适条件。
    \item \textbf{胃是体内合成$N$-亚硝基化合物的最主要场所！}胃液pH约1–2，且硝酸盐、亚硝酸盐和胺类可随食物同时进入胃内。
    \item 口腔和膀胱（有感染时）也可发生亚硝化反应。
\end{itemize}
\end{keybox}

\subsection{致癌作用}

\begin{keybox}
\textbf{$N$-亚硝基化合物的致癌作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{多动物种属诱癌：}对多种实验动物（大鼠、小鼠、豚鼠、兔、狗、猪、猴、鱼、鸟等）均有致癌性，\textbf{至今未发现任何动物种属对$N$-亚硝基化合物的致癌作用有抵抗力！}
    \item \textbf{多器官/组织靶向性：}可诱发多种器官肿瘤，主要靶器官为\textbf{肝脏、食管、胃}，也可引起肾、膀胱、肺、脑、周围神经、皮肤等部位肿瘤。
    \item \textbf{多途径均诱癌：}经口、吸入、皮下注射、皮肤涂敷等多种途径均可诱癌。
    \item \textbf{单次大剂量或长期小剂量均可致癌：}具有明显的剂量-效应关系；且各剂量组合有相加作用。
    \item \textbf{可以通过胎盘使子代致癌（经胎盘致癌作用）：}怀孕动物摄入后，可通过胎盘影响胎儿，出生后发生肿瘤。
\end{enumerate}
\end{keybox}

\subsection{主要污染食品}

\begin{enumerate}[leftmargin=*]
    \item 腌制、烤制、油炸、烟熏加工的肉/鱼类制品（咸鱼、腊肉、火腿、香肠等）
    \item 啤酒（麦芽干燥过程可形成NDMA——$N$-亚硝基二甲胺）
    \item 干酪
    \item 腌渍蔬菜（咸菜中亚硝酸盐含量在腌制过程中有"亚硝峰"现象）
\end{enumerate}

\subsection{IARC致癌性分级}

\begin{itemize}[leftmargin=*]
    \item NDMA（$N$-亚硝基二甲胺）：Group 2A（很可能对人类致癌）
    \item NDEA（$N$-亚硝基二乙胺）：Group 2A
    \item NMOR、NMEA、NPYR、NPIP、NDPA等：Group 2B（可能对人类致癌）
\end{itemize}

\subsection{预防措施}

\begin{keybox}
\textbf{$N$-亚硝基化合物危害的预防*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{防止食品霉变：}霉菌可促进亚硝胺的生成，并可将硝酸盐还原为亚硝酸盐。
    \item \textbf{控制肉制品加工中硝酸盐和亚硝酸盐的使用量：}严格执行GB 2760规定的使用范围和最大使用量。
    \item \textbf{施用钼肥（Mo肥料）：}钼是硝酸还原酶的组分，施钼可降低蔬菜中硝酸盐的积累。
    \item \textbf{多食新鲜蔬菜和水果：}\textbf{维生素C、维生素E、多酚等可阻断体内$N$-亚硝基化合物的合成！}（VC将NO$_2^-$还原为NO，从而阻止亚硝化反应）。
    \item \textbf{制定和执行食品中$N$-亚硝基化合物的限量标准。}
    \item \textbf{暴晒污染食品：}利用紫外线破坏$N$-亚硝基化合物。
\end{enumerate}
\end{keybox}

\section{多环芳烃（PAH）污染}

\begin{defbox}
\textbf{多环芳烃（Polycyclic Aromatic Hydrocarbons, PAH）：}由两个或两个以上苯环融合而成的化合物。\textbf{苯并(a)芘（Benzo(a)pyrene, B(a)P）}是最重要、最具有代表性的PAH。
\end{defbox}

\begin{keybox}
\textbf{苯并(a)芘 B(a)P 的特性：}
\begin{itemize}[leftmargin=*]
    \item 由5个苯环组成
    \item 水溶性极低，脂溶性高（极易蓄积于脂肪组织）
    \item 化学性质稳定
    \item 明确动物致癌物（可诱发多种动物多种器官癌症），流行病学证据支持与人类胃癌的关联
    \item IARC Group 1（确认人类致癌物）
\end{itemize}
\end{keybox}

\subsection{污染来源}

\begin{keybox}
\textbf{B(a)P污染食品的主要途径：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{烘烤、烟熏过程中直接污染——最主要的来源！}
    \begin{itemize}[leftmargin=*]
        \item 熏制食品：熏烟中含有大量PAH，烟熏时间越长、温度越高，B(a)P含量越高。
        \item 炭火烤肉/鱼：油脂滴落在炭火上 $\rightarrow$ 热解聚合生成PAH $\rightarrow$ 随烟雾附在食品表面。
    \end{itemize}
    \item \textbf{食品成分在高温下的热解/热聚合：}脂肪在 $>$ 400$^\circ$C 可生成PAH。
    \item \textbf{农作物从环境中吸收：}空气沉降的PAH被作物叶片和果实表面吸附。
    \item \textbf{食品加工过程中接触污染：}如用沥青铺路晒粮（严重违规！）。
\end{enumerate}
\end{keybox}

\subsection{防控措施}

\begin{enumerate}[leftmargin=*]
    \item 治理环境PAH污染（减少工业排放和汽车尾气）
    \item 改进烟熏工艺：避免直接接触炭火，采用间接烟熏
    \item 食用油加工中添加活性炭吸附脱除PAH
    \item 日光/紫外线照射可降低食品表面B(a)P含量
    \item 不吃烧焦的食物
\end{enumerate}

\section{杂环胺（Heterocyclic Amines, HCA）}

\begin{defbox}
\textbf{杂环胺（Heterocyclic Amines）：}在高温烹调条件下，由食品中的蛋白质、氨基酸、肌酸和糖类反应生成的一类具有致突变性和致癌性的杂环芳香族化合物。

\textbf{主要类型：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{氨基咪唑氮杂芳烃类（IQ型，Aminocarboline Type）：}如IQ（2-氨基-3-甲基咪唑并[4,5-f]喹啉）、MeIQ、PhIP。
    \item \textbf{氨基咔啉类（Aminocarboline Type）：}如Trp-P-1、Glu-P-1等（氨基酸热解产物）。
\end{enumerate}
\end{defbox}

\begin{keybox}
\textbf{杂环胺生成的影响因素* ——生成量与以下因素密切相关：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{加热温度（最关键因素！）：}温度越高，生成量越多。从200$^\circ$C升至300$^\circ$C时，杂环胺生成量可增加\textbf{约5倍}！
    \item \textbf{加热时间：}时间越长，生成量越多。
    \item \textbf{水分含量：}水分可抑制杂环胺的生成。含水量越低，生成量越多。
    \item \textbf{烹调方式的影响（总结规律）：}
    \begin{itemize}[leftmargin=*]
        \item 烤、煎、炸、烧烤 $\gg$ 炖、焖、煨、煮
        \item 总体规律：\textbf{温度越高 $+$ 时间越长 $+$ 含水量越少 = 杂环胺生成量越多！}
    \end{itemize}
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{哪些食品杂环胺含量高？}鱼和肉类（高蛋白食品）在高温烹制时杂环胺生成量最大。油炸/烤制的鱼、牛排、炸鸡中杂环胺含量较高。
\end{tipbox}

\subsection{致癌性}

\begin{enumerate}[leftmargin=*]
    \item 可诱发大小鼠肝、肠道、乳腺等多种器官肿瘤，主要靶器官：肝脏。
    \item 在极低剂量下即可与DNA形成加合物（DNA-adduct），可能不存在无作用阈值。
    \item PhIP：IARC Group 2B；IQ：IARC Group 2A。
\end{enumerate}

\section{丙烯酰胺、氯丙醇}

\subsection{丙烯酰胺（Acrylamide）}

\begin{itemize}[leftmargin=*]
    \item \textbf{生成条件：}富含淀粉的食品在 $>$ 120$^\circ$C 高温加工（油炸、烘烤）过程中，由天冬酰胺（asparagine）和还原糖（葡萄糖、果糖）通过Maillard反应生成。
    \item \textbf{高含量食品：}薯条（French fries）、薯片（potato chips）、方便面、油条、速溶咖啡。土豆制品的丙烯酰胺含量约为谷物制品的\textbf{4倍}。
    \item \textbf{毒性和致癌性：}神经毒性（职业暴露），啮齿动物多器官致癌。IARC Group 2A（很可能对人类致癌）。
    \item \textbf{预防：}改进加工工艺（降低油炸温度和时间、避免过度金黄焦脆），原料选用低还原糖的马铃薯品种。
\end{itemize}

\subsection{氯丙醇（Chloropropanols）}

\begin{itemize}[leftmargin=*]
    \item \textbf{首次发现：}在酸水解植物蛋白液（HVP）中发现，用于酱油等调味品中。
    \item \textbf{代表性物质：}3-氯-1,2-丙二醇（3-MCPD）含量最高、最常见。
    \item \textbf{毒性：}3-MCPD具肾毒性和雄性生殖毒性。
    \item \textbf{存在形式：}游离态3-MCPD（酸水解HVP）以及脂肪酸酯形式（即3-MCPD酯，广泛存在于精炼油脂中）。
\end{itemize}

\section{食品容器、包装材料的卫生问题}

\subsection{常见包装材料}

\begin{enumerate}[leftmargin=*]
    \item \textbf{塑料：}PET（聚对苯二甲酸乙二醇酯）、PC（聚碳酸酯）、PE（聚乙烯）、PP（聚丙烯）、PS（聚苯乙烯）、三聚氰胺-甲醛树脂（密胺）、脲醛树脂。
    \item \textbf{橡胶：}天然橡胶、合成橡胶（奶嘴、密封圈）。
    \item \textbf{纸、竹、木：}传统材料，卫生问题较少但需注意。
    \item \textbf{金属、搪瓷、陶瓷、玻璃：}传统材料，但需关注金属离子迁移。
\end{enumerate}

\subsection{主要卫生问题}

\begin{enumerate}[leftmargin=*]
    \item \textbf{有害物质向食品迁移（Migration）——最核心的卫生问题！}
    \begin{itemize}[leftmargin=*]
        \item 塑料中的增塑剂（如邻苯二甲酸酯类，phthalates——具有雌激素样活性，属于内分泌干扰物）
        \item 塑料中的稳定剂、抗氧化剂
        \item 密胺制品（仿瓷餐具）：游离甲醛毒性
        \item 铝制品：盛装酸性或碱性食品可溶解氧化铝膜 $\rightarrow$ 铝溶出（铝摄入过量与阿尔茨海默病的关联虽未最终定论，但已引起广泛关注）
    \end{itemize}
    \item \textbf{包装材料的回收和再生问题：}回收塑料中的不明污染物转移入食品。
    \item \textbf{印刷油墨：}油墨中的有害物质（如苯系物）可能迁移至食品接触面。
    \item \textbf{纳米包装材料：}新型材料的安全性评价体系尚待完善。
\end{enumerate}

\section{放射性污染及物理性污染}

\subsection{食品放射性污染}

\begin{keybox}
\textbf{食品放射性污染的主要核素（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{$^{40}$K（钾-40）：}
    \begin{itemize}[leftmargin=*]
        \item 天然放射性核素，存在于所有动植物体内
        \item 半衰期 $T_{1/2} = 1.28 \times 10^9$ 年
        \item 是食品中天然放射性核素剂量的最主要贡献者
    \end{itemize}
    \item \textbf{$^{131}$I（碘-131）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 8.6$ 天（短半衰期核素）
        \item 危害：主要富集于甲状腺，可诱发甲状腺肿瘤
        \item 可通过母乳传递给婴儿（乳汁中$^{131}$I浓集）
    \end{itemize}
    \item \textbf{$^{90}$Sr（锶-90）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 28.8$ 年（长半衰期核素）
        \item 化学性质与钙类似 $\rightarrow$ 主要沉积于骨骼和牙齿 $\rightarrow$ 对骨髓造血功能产生长期辐照
        \item 在食物链中具重要意义
    \end{itemize}
    \item \textbf{$^{137}$Cs（铯-137）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 30.17$ 年
        \item 化学性质与钾类似 $\rightarrow$ 参与全身代谢、全身均匀分布
        \item 在食物链中具重要意义
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{人为放射性污染的来源}

\begin{enumerate}[leftmargin=*]
    \item \textbf{核爆炸：}核武器试验产生的放射性沉降物（radioactive fallout），污染土壤、水体和农作物。
    \item \textbf{核废料排放：}核电站、核燃料加工企业的放射性废水和废料排放。
    \item \textbf{核事故：}
    \begin{itemize}[leftmargin=*]
        \item 1986年切尔诺贝利核事故——大量$^{131}$I和$^{137}$Cs释放
        \item 2011年福岛第一核电站事故——日本政府2023年决定将处理后核污染水排海（约130万吨，预计排放约30年），引发国际社会和食品安全领域的广泛关注
    \end{itemize}
\end{enumerate}

\subsection{放射性物质向食品的转移途径}

\begin{enumerate}[leftmargin=*]
    \item \textbf{水体 $\rightarrow$ 水生生物 $\rightarrow$ 人体：}
    \begin{itemize}[leftmargin=*]
        \item 水 $\rightarrow$ 水生植物/藻类（浓集倍数可达100–500倍）
        \item 藻类 $\rightarrow$ 鱼贝类（进一步富集）
        \item 鱼贝类 $\rightarrow$ 人体
    \end{itemize}
    \item \textbf{陆地环境 $\rightarrow$ 食物链：}
    \begin{itemize}[leftmargin=*]
        \item 沉降物 $\rightarrow$ 牧草 $\rightarrow$ 牛 $\rightarrow$ 牛乳/牛肉 $\rightarrow$ 人体
        \item 沉降物 $\rightarrow$ 饲料 $\rightarrow$ 鸡 $\rightarrow$ 蛋/禽肉 $\rightarrow$ 人体
    \end{itemize}
    \item \textbf{直接沉降：}放射性沉降物直接附着在蔬菜叶面、水果表面等。
\end{enumerate}

\subsection{放射性污染的生物学效应}

\begin{enumerate}[leftmargin=*]
    \item \textbf{确定性效应（Deterministic Effects）：}效应的严重程度随辐射剂量的增加而增加，存在剂量阈值。如急性放射病、皮肤红斑。
    \item \textbf{随机性效应（Stochastic Effects）：}效应的发生概率与辐射剂量相关，但严重程度与剂量无关，不存在剂量阈值（无阈值假设）。包括\textbf{致癌效应}和\textbf{遗传效应}。
\end{enumerate}

\begin{keybox}
\textbf{电离辐射的照射方式：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{外照射（External Irradiation）：}人体暴露于放射性污染的环境（主要指大气环境），电离辐射（$\gamma$射线、X射线等）直接作用于人体体表。
    \item \textbf{内照射（Internal Irradiation）：}放射性核素进入机体内，作用于人体内部产生生物学效应。以射程短、电离强的$\alpha$、$\beta$射线作用为主。\keyword{内照射常以局部损害为主，呈进行性发展和症状迁延。}
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{食品中天然放射性物质的补充：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{天然辐射源：}大气层外的宇宙射线和地壳中的天然放射性核素。$^3$H（氚）、$^7$Be（铍）、$^{14}$C（碳）和$^{22}$Na（钠）等可通过食物和饮水进入机体。
    \item \textbf{$^{226}$Ra（镭-226）：}可通过饮水和食物进入人体，动物和人体内的$^{226}$Ra主要集中于\keyword{骨组织}中。
    \item \textbf{$^{210}$Po（钋-210）：}自然环境中的$^{210}$Po和$^{210}$Pb处于平衡状态，广泛存在于植物和一些海产品中，是海产品中重要的天然放射性核素。
\end{enumerate}
\end{keybox}

\subsection{物理性污染}

\begin{defbox}
\textbf{物理性污染：}食品中混入非化学性的、非正常来源的异物，如金属碎片、碎玻璃、石块、塑料片、毛发等。
\end{defbox}

\textbf{来源：}
\begin{enumerate}[leftmargin=*]
    \item 田间（石块、泥土、植物碎片）
    \item 加工过程（设备零件脱落、刀具碎片）
    \item 储藏和运输（包装材料碎片）
    \item 人为掺假（故意加入异物以增重）
\end{enumerate}

\textbf{防控措施：}金属探测器、X射线异物检测机、过筛、磁铁分离、严格生产操作规范（GMP）等。GB 7099-2015规定糕点、面包中不得有可见异物。

\subsection*{参考答案要点}

\subsubsection*{名词解释（要点）}

\begin{enumerate}[leftmargin=*, itemsep=4pt]
    \item 菌落总数：在规定培养条件下测得的每单位检样的细菌菌落总数，反映食品清洁状态、腐败程度和货架期。
    \item 大肠菌群：乳糖发酵产酸产气的革兰阴性无芽孢杆菌，作为肠道致病菌的指示菌。典型大肠杆菌提示近期粪便污染。
    \item 水分活性（Aw）：同温度下食品水蒸气分压与纯水蒸汽压之比，反映食品中能被微生物利用的水分比例。
    \item TVBN：弱碱条件下蒸馏出的总氮量，反映蛋白质分解产生的氨和胺类物质。用于高蛋白食品鲜度判断。
    \item K值：ATP分解产物中HxR+Hx占比，$<20\%$为新鲜，$>40\%$为初期腐败。是鱼类鲜度的灵敏指标。
    \item D值：特定温度下杀死90\%某种微生物所需的时间。
    \item MRLs：食品或饲料中法定允许的农药最高浓度。ADI：终生每日摄入某物质而无健康风险的剂量。
    \item 黄曲霉毒素：黄曲霉和寄生曲霉产生的二呋喃氧杂萘邻酮类化合物，已知最强天然致癌物。
\end{enumerate}

\subsubsection*{简答题（要点）}

\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item \textbf{菌落总数意义：}反映清洁状态、腐败程度、预测货架期。\textbf{大肠菌群意义：}典型大肠杆菌=近期粪便污染，非典型大肠杆菌=陈旧性污染，总大肠菌群为肠道致病菌指示菌。
    \item \textbf{AF理化特性：}耐热（268–269$^\circ$C分解）、脂溶性、碱性条件可开环破坏。\textbf{易污染食品：}花生、玉米、棉籽油。\textbf{毒性：}急性肝损伤、慢性肝损害、最强天然致癌物（二甲基亚硝胺的75倍）、与HBV协同致癌。
    \item \textbf{产毒特点：}只少数菌株产毒、产毒能力可变异、无严格专一性、需一定条件。\textbf{中毒特点：}经污染食品引起、损害实质器官、烹饪不破坏、无传染和免疫性、季节性和地区性。
    \item \textbf{腐败原因：}微生物作用（最主要）、食品本身特性、环境因素。\textbf{鉴定指标：}感官、化学（TVBN—高蛋白食品、K值—鱼类）、物理、微生物。\textbf{腐败产物：}蛋白质$\rightarrow$胺类；脂肪$\rightarrow$POV升高、哈喇味；糖类$\rightarrow$有机酸产气。
    \item \textbf{污染途径：}直接施药（最主要）、环境吸收、食物链富集、储运污染。\textbf{控制：}农药管理、安全使用（安全间隔期）、MRL标准（GB 2763-2021）、高效低毒新品种、剧毒农药禁止用于蔬果茶药材。
    \item \textbf{甲基汞：}脂溶性、胃肠道吸收$>90\%$、强—SH亲和力、可过BBB和胎盘、损害脑和神经系统。\textbf{镉：}半衰期15–30年、蓄积肾和肝、肾近曲小管损害$\rightarrow$蛋白尿$\rightarrow$骨软化（痛痛病）。\textbf{铅：}慢性蓄积、半衰期约14年、最主要损害胎儿/婴幼儿神经发育（IQ下降）、2010年撤销PTWI。
    \item \textbf{前体物：}硝酸盐/亚硝酸盐+胺类。\textbf{合成条件：}pH$<$3酸性环境、胃是主要体内合成部位。\textbf{致癌特点：}多物种无抵抗、多器官（肝/食管/胃）、多途径、单次或长期均可、经胎盘致子代肿瘤。\textbf{预防：}防霉、控制硝酸盐/亚硝酸盐用量、施钼肥、多食新鲜蔬果（VC阻断合成）、限量标准。
    \item \textbf{生成影响因素：}温度（最关键！200$\rightarrow$300$^\circ$C可增5倍）、时间、水分含量（含水多则抑制）、烹调方式（烤/煎/炸 $\gg$ 炖/煨/煮）。规律：温度越高+时间越长+水分越少=生成越多。
    \item \textbf{主要核素：}$^{40}$K（天然、$T_{1/2}=1.28\times10^9$yr）、$^{131}$I（甲状腺、$T_{1/2}=8.6$d）、$^{90}$Sr（骨骼、$T_{1/2}=28.8$yr）、$^{137}$Cs（全身、$T_{1/2}=30.17$yr）。\textbf{转移途径：}水$\rightarrow$藻类（100–500倍富集）$\rightarrow$鱼贝类$\rightarrow$人体；牧草$\rightarrow$牛$\rightarrow$乳/肉$\rightarrow$人体。
\end{enumerate}
