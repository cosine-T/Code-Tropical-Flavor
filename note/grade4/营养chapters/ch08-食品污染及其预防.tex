\section{食品污染概述}

\begin{keybox}
\textbf{食品污染（Food Contamination）：}食物中外来生物性、化学性及物理性有害物质，对人体健康可能产生危害，或影响其食用及商品价值，这一过程称为食品污染。

\textbf{食品污染的分类（按污染来源三分类*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{生物性污染（Biological Contamination）：}微生物污染（细菌、霉菌、病毒）、寄生虫及虫卵污染、昆虫污染。是最常见、最重要的食品污染！
    \item \textbf{化学性污染（Chemical Contamination）：}农药残留、有害金属（汞、镉、铅、砷）、$N$-亚硝基化合物、多环芳烃（PAH）、杂环胺、二噁英、食品容器/包装材料迁移物、滥用食品添加剂。
    \item \textbf{物理性污染（Physical Contamination）：}放射性核素污染、异物污染（金属碎片、玻璃、石子等）。
\end{enumerate}
\end{keybox}

\textbf{食品危害的四大来源：}
\begin{enumerate}[leftmargin=*]
    \item 食品本身天然含有或自身产生：如天然有毒动植物（河豚、毒蕈）、储藏中产生的有害物
    \item 加工/储藏过程中形成：如高温烹调产生杂环胺、丙烯酰胺、$N$-亚硝基化合物
    \item 外界污染引入：如环境污染、农药残留、有害金属、微生物污染
    \item 故意滥用添加剂或掺假：如非法添加非食用物质、滥用食品添加剂
\end{enumerate}

\begin{tipbox}
\textbf{食品安全危害的优先控制顺序（WHO建议）：}微生物污染 $>$ 天然毒素 $>$ 化学性污染 $>$ 食品添加剂。这与公众认知恰好相反——公众往往过分担忧食品添加剂，而忽视微生物污染这一最主要的风险来源。
\end{tipbox}

\section{水分活性（Water Activity, Aw）}

\begin{keybox}
\textbf{水分活性（Water Activity, Aw）*：}相同温度下，食品中水分的蒸汽压（$P$）与纯水蒸汽压（$P_0$）之比，即 $\text{Aw} = P/P_0$。纯水的 Aw = 1.00。Aw 反映食品中能被微生物利用的自由水含量。

\textbf{Aw与微生物生长的关系*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{Aw $<$ 0.60：}绝大多数微生物无法生长！食品可在常温下长期保藏，此即干制/脱水保藏的原理。
    \item \textbf{Aw $<$ 0.65：}极少数微生物可生长（某些耐干霉菌和耐高渗酵母）。
    \item \textbf{Aw $<$ 0.70：}能较长期抑制微生物生长。
    \item \textbf{Aw 0.80–0.85：}在1–2周内霉菌等即可引起腐败变质。
    \item \textbf{Aw 0.98–0.99：}大多数微生物都能生长。
\end{itemize}

\textbf{各类微生物生长的最低Aw要求：}
\begin{itemize}[leftmargin=*]
    \item 细菌：一般要求 Aw $>$ 0.9（多数细菌在 Aw $<$ 0.90 时不能生长）
    \item 酵母菌：最低 Aw $\approx$ 0.87
    \item 真菌（霉菌）：最低 Aw $\approx$ 0.80（黄曲霉最低 Aw $\approx$ 0.78）
\end{itemize}
\end{keybox}

\section{微生物污染及其预防}

\subsection{微生物的分类（按致病能力）}

\begin{enumerate}[leftmargin=*]
    \item \textbf{致病性微生物（Pathogenic）：}直接引起人类疾病，如沙门菌、志贺菌、金黄色葡萄球菌、肉毒梭菌、单增李斯特菌、副溶血性弧菌。致病性微生物是食品安全的首要威胁！
    \item \textbf{条件致病性微生物（Conditional Pathogenic）：}在特定条件下（如免疫力低下、菌群失调、大量摄入）才致病，如大肠杆菌（部分血清型）、变形杆菌。
    \item \textbf{非致病性微生物（Non-pathogenic）：}通常不致病，但可能引起食品腐败变质。
\end{enumerate}

\subsection{常见食品细菌}

\begin{keybox}
\textbf{常见食品细菌（掌握常见菌属及其特征）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{假单胞菌属（Pseudomonas）：}革兰阴性需氧杆菌，嗜冷菌，是冷藏食品腐败的优势菌。分解食品中各种成分，是典型的腐败菌。
    \item \textbf{微球菌属（Micrococcus）：}革兰阳性球菌，需氧，对热和干燥具有较强的抵抗力，广泛存在于自然环境。
    \item \textbf{芽胞杆菌属（Bacillus）：}革兰阳性芽胞杆菌，需氧或兼性厌氧，芽胞耐热性强。
    \item \textbf{肠杆菌科（Enterobacteriaceae）：}革兰阴性无芽胞杆菌，兼性厌氧，包括大肠杆菌、沙门菌、志贺菌等。是重要的食品卫生指标菌和致病菌。
    \item \textbf{葡萄球菌属（Staphylococcus）：}革兰阳性球菌，兼性厌氧。金黄色葡萄球菌可产生肠毒素，引起食物中毒。
    \item \textbf{乳酸菌（Lactic Acid Bacteria）：}革兰阳性，包括乳杆菌属、链球菌属等，可发酵糖类产乳酸，常用于食品发酵。
\end{enumerate}
\end{keybox}

\subsection{细菌菌相及优势菌种}

\begin{keybox}
\textbf{细菌菌相（Bacterial Flora）*：}共存于食品中的细菌种类及其相对数量的构成。其中相对数量较大的细菌称为\textbf{优势菌种（属、株）}。

\textbf{食品卫生学意义：}
\begin{enumerate}[leftmargin=*]
    \item 影响食品腐败变质的特征：不同优势菌种产生的腐败产物和感官变化各不相同。
    \item 影响食品腐败变质的速度和程度：优势菌种的生长速率和分解能力直接决定腐败进程。
    \item 通过分析细菌菌相可判断食品的污染来源和储藏条件。
\end{enumerate}
\end{keybox}

\subsection{菌落总数（Aerobic Plate Count, APC）}

\begin{keybox}
\textbf{菌落总数*：}在规定培养条件下（需氧、36$\pm$1$^\circ$C、48$\pm$2h），每克（g）或每毫升（mL）或每平方厘米（cm$^2$）检样中形成的细菌菌落总数。单位：CFU/g、CFU/mL、CFU/cm$^2$。

\textbf{食品卫生学意义*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{反映食品的清洁状态：}菌落总数越高，表明食品受微生物污染程度越严重，加工过程的卫生状况越差。
    \item \textbf{反映食品腐败变质的程度：}菌落总数越高，食品腐败变质的可能性越大。
    \item \textbf{预测食品的保质期（货架期）：}根据菌落总数的生长规律，估算食品在特定条件下的可储存时间。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{注意：}菌落总数低不等于完全无致病菌——因为致病菌可能在低菌落总数条件下存在（如少量沙门菌即可致病）；菌落总数高也不一定代表有致病菌。因此菌落总数是卫生质量的指示指标，而非安全性的直接指标，必须与致病菌检测结合使用。
\end{tipbox}

\subsection{大肠菌群（Coliform Group）与MPN法}

\begin{keybox}
\textbf{大肠菌群（Coliform Group）*：}在一定培养条件下（36$\pm$1$^\circ$C、24$\sim$48h），能发酵乳糖、产酸产气的需氧和兼性厌氧、革兰阴性、无芽孢杆菌。

\textbf{主要成员：}埃希菌属（Escherichia）、柠檬酸杆菌属（Citrobacter）、肠杆菌属（Enterobacter）、克雷伯菌属（Klebsiella）。

\textbf{食品卫生学意义*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{粪便污染指示菌：}大肠菌群来源于人和温血动物粪便。典型大肠杆菌（粪大肠菌群，44.5$^\circ$C仍能生长）检出表明食品受到近期粪便污染；非典型大肠杆菌检出表明食品受到远期（陈旧）粪便污染。
    \item \textbf{肠道致病菌指示菌：}大肠菌群的存在提示可能有沙门菌、志贺菌等肠道致病菌的污染。大肠菌群与肠道致病菌来源相同（粪便），且在外界存活时间与肠道致病菌基本一致或稍长。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{MPN法（Most Probable Number，最可能数法）*：}大肠菌群含量较低时采用的计数方法，基于统计学概率论，结果为MPN/g或MPN/mL。含量较高时采用CFU法（平板计数法）。GB 4789.3 规定了大肠菌群的检验方法。
\end{keybox}

\subsection{微生物限量采样方案（ICMSF推荐）}

\begin{defbox}
\textbf{二级采样方案（Two-class Sampling Plan）：}设定$n$（样品数）、$c$（允许超过$m$的最大样品数）、$m$（微生物限量，合格水平）。结果只有"合格/不合格"。适用于致病菌等危害严重的微生物。

\textbf{三级采样方案（Three-class Sampling Plan）：}设定$n$（样品数）、$c$（允许超过$m$的最大样品数）、$m$（可接受限量）、$M$（最高安全限量）。结果分为"满意/可接受/不合格"三级。$m$与$M$之间为"可接受但需关注"区域。
\end{defbox}

\section{霉菌及其毒素对食品的污染}

\subsection{霉菌与霉菌毒素基本概念}

\begin{defbox}
\textbf{霉菌（Mold）：}凡是生长在营养基质上形成绒毛状、蛛网状或絮状菌丝体的真菌（Fungi），统称为霉菌。不包括大型子实体真菌（如蘑菇）。

\textbf{霉菌毒素（Mycotoxin）：}霉菌在其所污染的食品中产生的有毒次级代谢产物。目前已发现400余种霉菌毒素。
\end{defbox}

\subsection{霉菌产毒条件与特点}

\begin{keybox}
\textbf{霉菌产毒的主要条件：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{水分活性（Aw）：}大多数霉菌需要 Aw $\geq$ 0.80，适宜相对湿度 80\%–90\%。
    \item \textbf{温度：}最适生长温度 20–28$^\circ$C（一般霉菌）；产毒温度常略低于生长最适温度。
    \item \textbf{营养：}主要以糖类为碳源，少量氮源和矿物质即可满足。
    \item \textbf{氧气：}大多数为专性需氧菌，氧气充足时毒素产量更高。
\end{enumerate}

\textbf{霉菌产毒特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{只限于少数的产毒霉菌：}自然界霉菌种类繁多，但只有少数菌种/菌株能产生毒素。
    \item \textbf{产毒能力可以发生改变：}一株产毒菌株经过传代培养后，产毒能力可减弱或增强，甚至完全丧失产毒能力。
    \item \textbf{产毒没有严格的专一性：}一种霉菌可产生多种不同的毒素（如黄曲霉可产生B1、B2、G1、G2等多种AF）；同一种毒素也可能由不同的霉菌产生。
    \item \textbf{产毒需要一定条件：}产毒菌株只在一定条件下才能产生毒素。
\end{enumerate}
\end{keybox}

\subsection{黄曲霉毒素（Aflatoxin, AF）}

\begin{keybox}
\textbf{黄曲霉毒素（Aflatoxin, AF）* —— 已知最强的天然致癌物！}
\begin{itemize}[leftmargin=*]
    \item \textbf{来源：}黄曲霉（Aspergillus flavus）和寄生曲霉（A.\ parasiticus）产生的次级代谢产物。
    \item \textbf{化学结构：}二呋喃环 + 香豆素（氧杂萘邻酮），基本结构为二呋喃氧杂萘邻酮。
    \item \textbf{主要类型：}B1、B2、G1、G2（紫外线下分别发蓝色和绿色荧光），以及M1、M2（动物体内代谢产物，主要存在于乳及乳制品中）。
    \item \textbf{毒性排序：}B1 $>$ G1 $>$ B2 $>$ G2（B1毒性最强）。
\end{itemize}
\end{keybox}

\subsubsection{黄曲霉毒素的理化性质}

\begin{keybox}
\textbf{AF理化性质*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{耐热性强：}一般烹调温度（100–120$^\circ$C）几乎不被破坏，需\textbf{268–269$^\circ$C}才完全分解。
    \item \textbf{脂溶性：}难溶于水（溶解度仅10–20 mg/L），易溶于油脂和多种有机溶剂（氯仿、甲醇等）。
    \item \textbf{在中性或弱酸性溶液中较稳定：}在强碱性条件下（pH 9–10），内酯环被打开，可被破坏。此原理被用于碱炼去毒。
    \item \textbf{紫外线敏感：}在紫外线下产生荧光（B族发蓝紫色荧光，G族发黄绿色荧光），可用于检测。
\end{enumerate}
\end{keybox}

\subsubsection{产毒条件与易污染食品}

\begin{keybox}
\textbf{黄曲霉产毒条件*：}
\begin{itemize}[leftmargin=*]
    \item 最适产毒温度：\textbf{25–33$^\circ$C}（相对湿度 80\%–90\%）
    \item 最适水分活性（Aw）：\textbf{0.93–0.98}
    \item 最适基质：花生、玉米（产毒量最高），其次为大米、小麦、豆类、棉籽等。
\end{itemize}

\textbf{易污染食品（危险性排序）：}
\begin{enumerate}[leftmargin=*]
    \item 花生及花生制品（最危险！）
    \item 玉米及玉米制品
    \item 棉籽油（粗制棉籽油中含量极高）
    \item 大米、小麦、大麦等谷物
    \item 豆类及饼粕（花生粕、豆粕等饲料）
    \item 干果、坚果（如开心果、杏仁）
    \item 乳及乳制品（含AF M1）
\end{enumerate}

\textbf{地域特征：}高温高湿地区（热带、亚热带）的食品黄曲霉毒素污染风险最高。我国南方（华南、西南）属于高危地区。
\end{keybox}

\subsubsection{黄曲霉毒素的体内代谢}

\begin{keybox}
\textbf{AFB1的体内代谢过程*：}

AFB1进入体内主要在\keyword{肝脏}进行代谢，在肝细胞微粒体混合功能氧化酶系（CYP450）的催化下，发生羟化、脱甲基和环氧化反应：

\begin{enumerate}[leftmargin=*]
    \item \textbf{AFB1 $\rightarrow$ AFM1（羟化反应）：}AFB1在肝微粒体酶催化下的羟化产物，最初在牛乳、羊乳中发现。奶牛摄入AFB1污染饲料后，乳汁中排出AFM1。AFM1毒性约为B1的十分之一，但仍归为Group 2B。
    \item \textbf{AFB1 $\rightarrow$ AFQ1（羟化反应）：}AFB1的另一种羟化产物，可能是\textbf{解毒过程}。
    \item \textbf{AFB1 $\rightarrow$ AFH1（还原反应）：}AFQ1的还原产物，黄曲霉毒醇 $\rightarrow$ AFH1可能是\textbf{另一种解毒途径}。
    \item \textbf{AFB1 $\rightarrow$ AFB1-8,9-环氧化物（环氧化反应）：}由CYP450催化的环氧化反应生成，是AFB1的\textbf{终致癌物}。可与DNA结合形成AFB1-N$^7$-鸟嘌呤加合物，导致DNA损伤和突变。
\end{enumerate}

AF有很强的急性毒性，也有明显的慢性毒性与致癌性。AF对肝脏有特殊亲和性（嗜肝毒），具有较强的肝脏毒性并有致癌作用。
\end{keybox}

\subsubsection{黄曲霉毒素的毒性}

\begin{keybox}
\textbf{黄曲霉毒素的毒性表现（三方面*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{急性毒性：}
    \begin{itemize}[leftmargin=*]
        \item 主要靶器官：\textbf{肝脏}——引起肝细胞坏死、胆管增生、肝出血（急性中毒性肝炎）。
        \item AFB1经口LD$_{50}$：鸭雏 0.24–0.36 mg/kg（最敏感物种之一），大鼠 5.5–17.9 mg/kg。
        \item 临床症状：发热、呕吐、食欲缺乏、黄疸，严重者出现腹水、下肢水肿、肝大，甚至死亡。
    \end{itemize}
    \item \textbf{慢性毒性：}
    \begin{itemize}[leftmargin=*]
        \item 肝脏慢性损伤：肝实质细胞变性、坏死，纤维组织增生，形成再生结节。
        \item 生长发育迟缓：影响蛋白质合成和营养利用。
        \item 免疫功能下降：抑制细胞免疫和体液免疫。
    \end{itemize}
    \item \textbf{致癌性（最强天然致癌物！）：}
    \begin{itemize}[leftmargin=*]
        \item 诱癌强度是二甲基亚硝胺的\textbf{75倍}！
        \item 可诱发多种实验动物（大鼠、小鼠、鸭、鱼、猴等）的多器官癌症，无动物种属对AF致癌完全抵抗。
        \item 灵长类动物亦可诱癌——猴经AFB1处理可发生肝癌。
        \item \textbf{与人类肝癌密切相关：}膳食AF暴露量与原发性肝癌发病率呈正相关。\textbf{尤为重要的是AF与HBV（乙肝病毒）的协同致癌作用！}HBV感染者暴露于AF时，肝癌风险急剧增高。
        \item IARC分类：AFB1为\textbf{Group 1（确认人类致癌物）}。
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsubsection{黄曲霉毒素的预防措施}

\begin{keybox}
\textbf{黄曲霉毒素的预防（三个环节*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{防霉（最关键、最根本的措施！）：}
    \begin{itemize}[leftmargin=*]
        \item 控制粮食水分含量至安全水分以下（谷类 $\leq$ 13\%–14\%，花生 $\leq$ 8\%–9\%）
        \item 低温储藏（$\leq$ 10$^\circ$C可有效抑制霉菌生长）
        \item 降低氧气浓度（充$N_2$或$CO_2$气调储藏）
        \item 化学防霉剂（如丙酸、丙酸盐）
    \end{itemize}
    \item \textbf{去毒（对于已污染的食品，7种去毒方法*）：}
    \begin{itemize}[leftmargin=*]
        \item ① 挑选霉粒法：人工或光电色选，挑除霉变、破损粒
        \item ② 碾轧加工法：碾去含毒量最高的种皮和胚
        \item ③ 加水搓洗法：反复搓洗去除表面毒素
        \item ④ 植物油加碱（碱炼法）：利用AF在强碱条件下内酯环开环的原理，加NaOH去除植物油中AF
        \item ⑤ 物理吸附法：活性炭、白陶土吸附植物油中AF
        \item ⑥ 紫外光照射法：利用AF对紫外线敏感的性质
        \item ⑦ 氨气处理法：用于饲料去毒
    \end{itemize}
    \item \textbf{执行食品中AF限量标准（GB 2761-2017）：}
    \begin{itemize}[leftmargin=*]
        \item 玉米、花生及其制品：AFB1 $\leq$ 20 $\mu$g/kg
        \item 大米、其他植物油：AFB1 $\leq$ 10 $\mu$g/kg
        \item 婴幼儿配方食品：AFB1 $\leq$ 0.5 $\mu$g/kg（最严格！）
        \item 乳及乳制品：AFM1 $\leq$ 0.5 $\mu$g/kg
    \end{itemize}
\end{enumerate}
\end{keybox}

\begin{exambox}
\textbf{为什么黄曲霉毒素是公认的强致癌物？}
\begin{enumerate}[leftmargin=*]
    \item 致癌强度极高（二甲基亚硝胺的75倍）
    \item 致癌谱广（多物种、多器官）
    \item 灵长类动物可诱癌（与人种最接近的动物）
    \item 与人类肝癌流行病学相关性强
    \item 与HBV有协同致癌效应
\end{enumerate}
\end{exambox}

\subsection{霉菌毒素中毒的共同特点}

\begin{keybox}
\textbf{霉菌毒素中毒的共同特点（掌握）*：}
\begin{enumerate}[leftmargin=*]
    \item 中毒的发生主要通过\textbf{被霉菌毒素污染的食品}引起。
    \item 主要损害实质器官（\textbf{肝、肾}最常受累）。
    \item 一般烹调加热（100–120$^\circ$C）\textbf{不能}将霉菌毒素完全破坏去除。
    \item \textbf{没有传染性和免疫性：}霉菌毒素中毒是化学性中毒，不存在抗体和免疫保护，再次接触仍可中毒。
    \item 具有\textbf{季节性和地区性}特点，与产毒霉菌的生长条件有关。
\end{enumerate}
\label{mold_poisoning}
\end{keybox}

\subsection{其他重要霉菌毒素（熟悉）}

\begin{defbox}
\textbf{1. 赭曲霉毒素（Ochratoxin A, OTA）：}
\begin{itemize}[leftmargin=*]
    \item 主要由赭曲霉和纯绿青霉产生，污染谷物（小麦、大麦、玉米）及咖啡豆
    \item 主要靶器官：肾脏——引起巴尔干肾病。IARC Group 2B。
\end{itemize}

\textbf{2. 单端孢霉烯族化合物（Trichothecenes）：}
\begin{itemize}[leftmargin=*]
    \item T-2毒素：可引起ATA（食物中毒性白细胞缺乏症），白细胞减少、出血、坏死
    \item DON（脱氧雪腐镰刀菌烯醇）：又称呕吐毒素（Vomitoxin），污染小麦、玉米。急性中毒：恶心、呕吐、腹泻。
\end{itemize}

\textbf{3. 玉米赤霉烯酮（Zearalenone, ZEN）：}
\begin{itemize}[leftmargin=*]
    \item 禾谷镰刀菌产生，污染玉米、小麦。具有雌激素样活性——引起猪雌激素过多综合征（外阴红肿、假发情、不孕）。
\end{itemize}

\textbf{4. 伏马菌素（Fumonisins）：}
\begin{itemize}[leftmargin=*]
    \item 串珠镰刀菌产生，主要污染玉米。鞘脂类合成抑制剂。IARC Group 2B。
\end{itemize}

\textbf{5. 展青霉素（Patulin）：}
\begin{itemize}[leftmargin=*]
    \item 扩展青霉产生，污染水果及制品（苹果汁、苹果酱最突出）。具有神经毒性、致突变性和免疫抑制性。
\end{itemize}
\end{defbox}

\subsection{霉菌菌相}

\begin{keybox}
\textbf{霉菌菌相（Mold Flora）及食品卫生学意义：}

食品中污染的真菌种类及其相对数量的构成。可从真菌污染度和真菌菌相构成两个方面评定。

\textbf{菌相判级：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{田野霉占优势}（如气连孢霉、芽枝霉、头孢霉等）：表示粮食新鲜，是田间自然带菌的正常菌相。
    \item \textbf{曲霉和青霉检出：}不表明粮食已经霉变，但提示储藏条件可能不良。
    \item \textbf{毛霉、根霉、木霉检出：}说明粮食已开始霉变——这些是储藏后期腐败菌。
\end{enumerate}
\end{keybox}

\section{食品腐败变质}

\subsection{概念与原因}

\begin{keybox}
\textbf{食品腐败变质（Food Spoilage）*：}在微生物为主的各种因素作用下，食品中组成成分被分解、破坏，使其感官性状发生变化、食用价值降低或丧失的一切变化。

\textbf{食品腐败变质的主要原因*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{微生物的作用（最主要原因！）：}细菌（最常见腐败菌）、酵母菌、霉菌。微生物分泌胞外酶 $\rightarrow$ 将大分子分解为小分子 $\rightarrow$ 吸收 $\rightarrow$ 胞内酶代谢 $\rightarrow$ 产生异味和有害产物。
    \item \textbf{食品本身的特性：}营养成分（蛋白质、脂肪、碳水化合物含量）、pH值、水分活性（Aw）、渗透压。
    \item \textbf{环境因素：}温度、湿度、氧气、光照。
\end{enumerate}
\end{keybox}

\subsection{食品腐败变质的鉴定指标}

\begin{keybox}
\textbf{食品腐败变质的鉴定指标（四类*）：}
\end{keybox}

\subsubsection{感官指标}

通过嗅觉、视觉、触觉等判断食品的颜色、气味、味道、组织状态的变化。感官鉴定是消费者判断食品质量最直接的方法，也是最敏感的鉴定方法。

\subsubsection{化学指标}

\begin{keybox}
\textbf{1. 挥发性盐基总氮（Total Volatile Basic Nitrogen, TVBN）*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{定义：}食品水浸液在弱碱性条件下，与水蒸气一起蒸馏出来的总氮量。反映蛋白质因细菌或酶的作用分解产生的氨和胺类物质的量。
    \item \textbf{适用对象：}高蛋白食品（肉类、鱼类）。
    \item \textbf{卫生学意义：}是判断高蛋白食品鲜度的常用指标。
    \item 国家标准：鲜（冻）畜肉 TVBN $\leq$ 15 mg/100g；海水鱼 $\leq$ 30 mg/100g。
\end{itemize}
\end{keybox}

\begin{keybox}
\textbf{2. 三甲胺（Trimethylamine）：}鱼肉类腐败时，氧化三甲胺被细菌还原为三甲胺，产生鱼腥味。是判断鱼类鲜度的指标之一。

\textbf{3. 组胺（Histamine）：}组氨酸经细菌脱羧产生。组胺含量过高可导致过敏性食物中毒（鲭鱼中毒）。
\end{keybox}

\begin{keybox}
\textbf{4. K值（K Value）* —— 判断鱼类鲜度的核心指标：}

\[
K(\%) = \frac{\text{HxR} + \text{Hx}}{\text{ADP} + \text{AMP} + \text{IMP} + \text{HxR} + \text{Hx}} \times 100\%
\]

ATP分解途径：ATP $\rightarrow$ ADP $\rightarrow$ AMP $\rightarrow$ IMP（肌苷酸，鲜味）$\rightarrow$ HxR（次黄嘌呤核苷/肌苷）$\rightarrow$ Hx（次黄嘌呤）

\textbf{判级标准：}
\begin{itemize}[leftmargin=*]
    \item $K < 20\%$：新鲜（可生食）
    \item $K = 20\%\sim40\%$：次新鲜（需充分加热）
    \item $K > 40\%$：初期腐败，不可食用
    \item $K > 60\%$：明显腐败
\end{itemize}

K值反映ATP分解产物中HxR和Hx所占比例，越不新鲜、K值越高。K值比TVBN更灵敏地判断鱼类早期鲜度下降。
\end{keybox}

\begin{keybox}
\textbf{5. pH值变化：}一般食品pH值的变化可作为判断食品鲜度的参考指标。新鲜肉的pH值约为5.8–6.2，腐败时因蛋白质分解产生胺类物质而pH上升。

\textbf{6. 过氧化值（Peroxide Value, POV）：}反映脂肪酸败的最早期指标。脂肪分解产生游离脂肪酸，进一步氧化生成过氧化物，POV升高表示脂肪已开始酸败。
\end{keybox}

\subsubsection{物理指标}

比重、折光率、黏度、浸出物量等。如牛乳的酸度升高，肉浸出液的黏度改变。

\subsubsection{微生物指标}

细菌总数（菌落总数）、大肠菌群、致病菌检测。是判断食品卫生质量的重要辅助手段。

\subsection{各类营养素的腐败产物}

\begin{keybox}
\textbf{各类营养素的腐败产物特征*：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{蛋白质腐败：}
    \begin{itemize}[leftmargin=*]
        \item 途径：蛋白质 $\rightarrow$ 多肽 $\rightarrow$ 氨基酸 $\rightarrow$ 脱羧 $\rightarrow$ 胺类 + CO$_2$
        \item 特征产物：甲胺、腐胺（putrescine）、尸胺（cadaverine）、组胺（histamine）、色胺（tryptamine）、酪胺、吲哚、硫化氢、硫醇
        \item 感官表现：恶臭（鱼腥味、腐败味）、变色、发黏
    \end{itemize}
    \item \textbf{脂肪酸败（酸败）：}
    \begin{itemize}[leftmargin=*]
        \item 途径：中性脂肪 $\rightarrow$ 甘油 + 游离脂肪酸 $\rightarrow$ 脂肪酸进一步氧化分解
        \item 特征：产生"哈喇味"（rancid odor）；过氧化值（POV）升高是脂肪酸败的最早期指标
        \item 感官表现：颜色变黄（褐色）、产生"油耗味"
    \end{itemize}
    \item \textbf{碳水化合物分解（酸败/发酵）：}
    \begin{itemize}[leftmargin=*]
        \item 途径：糖类 $\rightarrow$ 有机酸 + 醇类 $\rightarrow$ 醛、酮、CO$_2$
        \item 特征产物：乳酸、醋酸、乙醇、丁酸等
        \item 感官表现：酸味、产气、变黏
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{腐败变质食品的处理原则}

\begin{keybox}
\textbf{腐败变质食品的处理原则（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{严重腐败变质：}销毁或改作其他工业用途（如饲料、肥料），严禁作为食品销售。
    \item \textbf{轻度腐败变质：}经过适当的加工处理（如高温灭菌、去除变质部分），将变质的主要指标降至安全限量以下，可以限期食用。
    \item \textbf{限期食用：}对即将变质但尚未发生明显感官异常的食品，应在规定期限内尽快食用完毕。
    \item \textbf{局部变质：}挑选去除变质部分，利用其他完好部位（如切除蔬菜腐烂部分、剔除霉变粮粒）。
\end{enumerate}
\end{keybox}

\section{食品保藏方法}

\subsection{低温保藏}

\begin{keybox}
\textbf{低温保藏原理：}低温可抑制微生物的生长繁殖和酶的活性，降低食品中化学反应速度。

\textbf{低温保藏分类：}
\begin{itemize}[leftmargin=*]
    \item \textbf{冷藏（Refrigeration）：} \textbf{$-1\sim10^\circ$C}，短期保存
    \item \textbf{冷冻（Freezing）：} \textbf{$\leq-18^\circ$C}，长期保存
\end{itemize}

\textbf{"急冻缓化"原则*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{急冻：}快速冻结，30 min内通过最大冰晶生成带（\textbf{$-1\sim-5^\circ$C}），使食品中心温度迅速降至 $-20^\circ$C。优点：冰晶体积小、均匀分布在细胞内和细胞间，对细胞结构破坏小，解冻后汁液流失少。
    \item \textbf{缓化：}缓慢解冻，在 0–10$^\circ$C 下缓慢融化。优点：融化水分有足够时间被细胞重新吸收，减少汁液流失，保持食品风味和营养。
\end{enumerate}
\end{keybox}

\begin{defbox}
\textbf{TTT原则（Time-Temperature-Tolerance）：}冷冻食品的品温（T）、储藏时间（T）对品质的容许限度（Tolerance）三者之间的关系。冷冻食品的品质随冻藏温度的升高和时间的延长而逐渐下降。
\end{defbox}

\subsection{高温杀菌}

\begin{keybox}
\textbf{D值（Decimal Reduction Time）*：}在特定温度条件下，杀死90\%（即减少一个对数数量级）的某种微生物所需的时间（min）。D值越小，微生物的热耐受性越弱。

举例：金黄色葡萄球菌 D$_{63}$ = 7 min；肉毒梭菌芽孢 D$_{121}$ = 0.1–0.2 min。
\end{keybox}

\begin{keybox}
\textbf{Z值（Thermal Resistance Constant）：}使某种微生物的D值降低90\%（即减少一个对数数量级）所需升高的温度（$^\circ$C）。Z值反映微生物对温度变化的敏感性——Z值越小，微生物受温度变化影响越大。

\textbf{F值（Sterilization Value）：}在特定温度（通常121.1$^\circ$C）和特定Z值（通常Z=10$^\circ$C）条件下，杀死一定数量微生物所需的时间（min）。实际应用中通常要求12D的杀菌强度——使芽胞存活概率降至$10^{-12}$，以保证罐头食品的商业无菌。
\begin{itemize}[leftmargin=*]
    \item $F_0$值：Z=10$^\circ$C、温度为121.1$^\circ$C时的杀菌时间（min），为罐头工业的标准杀菌参数。
\end{itemize}
\end{keybox}

\textbf{常用高温杀菌方法*：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{巴氏消毒法（Pasteurization）：}杀死所有致病菌，延长保质期
    \begin{itemize}[leftmargin=*]
        \item LTLT（低温长时间）：\textbf{62.8$^\circ$C、30 min}（传统法）
        \item HTST（高温短时间）：\textbf{71.7$^\circ$C、15 s}（目前常用）
        \item 应用：牛乳、啤酒、果汁等
    \end{itemize}
    \item \textbf{加压杀菌：}\textbf{100$\sim$121$^\circ$C}（绝对压力约0.2 MPa），可杀灭繁殖型和芽胞型细菌。常用于肉类制品、罐头食品。
    \item \textbf{超高温瞬时灭菌（UHT）：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{135–150$^\circ$C、2 s}
        \item 达到商业无菌（Commercial Sterility）——并非绝对无菌，而是杀灭所有在正常储存条件下可生长繁殖的微生物。
        \item 应用：UHT牛乳（常温奶）、豆奶等
    \end{itemize}
    \item \textbf{微波杀菌（Microwave Sterilization）：}
    \begin{itemize}[leftmargin=*]
        \item 利用微波的热效应和非热效应杀灭微生物
        \item 常用频率：915 MHz（穿透厚度大，适用于含水量高、体积大的食品）和2450 MHz（适用于含水量低的食品）
        \item 特点：快速、节能、对食品品质影响小，能保留更多活性物质和营养成分
    \end{itemize}
\end{enumerate}

\subsection{干燥脱水保藏}

\begin{keybox}
\textbf{干燥脱水保藏：}
\begin{itemize}[leftmargin=*]
    \item \textbf{原理：}将食品水分降至15\%以下或Aw值在\textbf{0.00$\sim$0.60}之间，此时绝大多数微生物无法生长，食品在常温下可长期保藏。
    \item \textbf{常用方法：}日晒、阴干、喷雾干燥、减压蒸发、冷冻干燥。
    \item \textbf{食品褐变（Browning）问题：}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{酶促褐变（Enzymatic Browning）：}酚酶催化酚类物质形成醌及其聚合物。如切开的苹果、土豆暴露于空气中变褐。
        \item \textbf{非酶褐变/美拉德反应（Maillard Reaction）：}蛋白质、氨基酸的氨基与糖及脂肪氧化的醛、酮等羰基发生的羰氨反应。\textbf{Aw = 0.6时最适于褐变}；SO$_2$可与羰基结合而阻止褐变。
    \end{enumerate}
    \item 影响因素：加热与给氧促进褐变。
\end{itemize}
\end{keybox}

\subsection{辐照保藏}

\begin{keybox}
\textbf{辐照保藏：}
\begin{itemize}[leftmargin=*]
    \item \textbf{辐照源：}$^{60}$Co（钴-60）、$^{137}$Cs（铯-137）产生的$\gamma$射线，或电子加速器产生的电子束。
    \item \textbf{剂量分级（按国际惯例）*：}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{低剂量（1–5 kGy）：辐照防腐（Radurization）}——保鲜（抑制发芽、延迟成熟、杀虫）
        \item \textbf{中剂量（5–10 kGy）：辐照消毒（Radicidation）}——杀灭致病菌（沙门菌等）、寄生虫
        \item \textbf{高剂量（10–15 kGy）：辐照灭菌（Radappertization）}——商业无菌
    \end{enumerate}
    \item \textbf{辐照食品的安全性：}WHO/FAO/IAEA联合专家委员会结论——在适当的辐照剂量下，辐照食品是安全的，不会产生放射性。
    \item 我国已颁布GB 14891系列辐照食品卫生标准。
\end{itemize}
\end{keybox}

\subsection{化学保藏及其他方法}

\begin{keybox}
\textbf{化学保存方法：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{盐腌（Salt Preservation）：}利用高渗透压抑制微生物生长。食盐浓度\textbf{$\geq$ 10\%}可抑制多数细菌繁殖。
    \item \textbf{糖渍（Sugar Preservation）：}糖含量须达\textbf{60\%–65\%}才能有效抑制微生物。
    \item \textbf{酸渍（Acid Preservation）：}利用产酸菌产生乳酸等有机酸，降低pH至\textbf{4.5以下}抑制致病菌。
    \item \textbf{防腐剂：}苯甲酸、山梨酸及其盐类。
    \item \textbf{抗氧化剂：}BHA（丁基羟基茴香醚）、BHT（二丁基羟基甲苯）、TBHQ（特丁基对苯二酚）。
\end{enumerate}

\textbf{其他保藏方法：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{烟熏：}除脱水作用外，烟熏成分（酚类、醛类）具抑菌和抗氧化作用。
    \item \textbf{气调保藏（MAP）：}调节包装内气体比例（降低O$_2$、增加CO$_2$、充N$_2$），抑制需氧菌和霉菌生长。
\end{enumerate}
\end{keybox}

\section{农药和兽药残留}

\subsection{农药残留基本概念}

\begin{keybox}
\textbf{农药残留（Pesticide Residue）*：}农药使用后残存于食品、农产品、环境及饲料中的农药原体、有毒代谢产物、降解产物和杂质的总称。

\textbf{最大残留限量（Maximum Residue Limits, MRLs）*：}在生产或保护商品过程中，按照良好的农业生产规范（GAP），直接或间接使用农药后，在食品和饲料中可合法允许的农药残留的最高浓度（mg/kg）。

\textbf{再残留限量（Extraneous Maximum Residue Limits, EMRLs）*：}一些持久性农药虽已禁用，但已造成环境污染，从而在食品中再次残留，为控制这类农药残留而对食品制定残留限量。如DDT、六六六的EMRLs。

\textbf{每日允许摄入量（Acceptable Daily Intake, ADI）*：}人类终生每日摄入某物质，而不产生可检测到的健康危害的剂量（mg/kg bw）。
\end{keybox}

\subsection{农药污染食品的主要途径}

\begin{keybox}
\textbf{农药污染食品的主要途径（四途径*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{直接污染（施药）：}对农作物直接喷洒农药——\textbf{最主要的污染途径！}
    \item \textbf{农作物从污染环境中吸收：}土壤中残留农药、灌溉水中农药被作物根系吸收。
    \item \textbf{食物链和生物富集作用：}饲料 $\rightarrow$ 畜禽体内 $\rightarrow$ 乳、蛋、肉；水体农药 $\rightarrow$ 藻类 $\rightarrow$ 鱼虾 $\rightarrow$ 人体。
    \item \textbf{储运过程中的污染：}贮藏熏蒸杀虫剂污染；运输工具未经彻底清洗而交叉污染。
\end{enumerate}
\end{keybox}

\subsection{主要农药类型及毒性}

\begin{keybox}
\textbf{主要农药类型（四类*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{有机磷农药（Organophosphates, OPPs）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：不可逆地抑制乙酰胆碱酯酶（AChE），导致乙酰胆碱在突触积累 $\rightarrow$ 持续兴奋 $\rightarrow$ 神经功能紊乱
        \item 代表品种：对硫磷（1605）、敌敌畏（DDVP）、乐果（dimethoate）、马拉硫磷（malathion）
        \item 特点：化学性质不稳定（尤其对光和热），残留期相对较短；急性毒性高，慢性毒性相对低。但某些品种如乐果具潜在致突变性
    \end{itemize}
    \item \textbf{氨基甲酸酯类农药（Carbamates）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：\textbf{可逆地}抑制胆碱酯酶（与有机磷不同——氨基甲酸酯的酶抑制是可逆的）
        \item 代表品种：西维因（carbaryl）、速灭威（MTMC）、涕灭威（aldicarb）
        \item 特点：杀虫作用迅速，对人畜毒性较低。但在酸性条件下与亚硝酸盐反应可生成$N$-亚硝基化合物（潜在致癌物）
    \end{itemize}
    \item \textbf{拟除虫菊酯类农药（Pyrethroids）：}
    \begin{itemize}[leftmargin=*]
        \item 毒作用机制：干扰神经细胞膜钠离子通道，影响神经动作电位
        \item 代表品种：氯氰菊酯（cypermethrin）、溴氰菊酯（deltamethrin）、氰戊菊酯（fenvalerate）
        \item 特点：高效、低残留、对哺乳动物毒性低。但害虫易产生抗药性
    \end{itemize}
    \item \textbf{有机氯农药（Organochlorines，已淘汰类）：}
    \begin{itemize}[leftmargin=*]
        \item 代表品种：DDT（滴滴涕）、六六六（BHC/666）
        \item 特点：化学性质极其稳定——DDT在土壤中消失95\%需要3–30年。脂溶性强，通过食物链积累和浓缩。可通过母乳排出（母乳中DDT含量明显高于牛乳）
        \item 我国已于1983年停止生产、1984年停止使用有机氯农药
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{农药残留的控制措施}

\begin{keybox}
\textbf{控制农药残留的措施*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{加强农药管理：}实行农药登记制度和生产许可制度。
    \item \textbf{安全合理使用农药：}严格遵守农药安全使用准则，特别注意\textbf{安全间隔期}（最后一次施药至收获的天数）。
    \item \textbf{制定和执行食品中农药残留限量标准：}GB 2763-2021规定了564种农药的10092项MRLs，是世界上涵盖农药品种最多的标准之一。
    \item \textbf{研制和推广高效低毒低残留新品种：}推广生物农药、植物源农药。
    \item \textbf{食品安全法规定：}剧毒、高毒农药不得用于蔬菜、水果、茶叶和中草药材。
\end{enumerate}
\end{keybox}

\subsection{兽药残留（熟悉）}

\begin{defbox}
\textbf{兽药残留（Veterinary Drug Residues）：}动物产品的任何可食部分所含兽药原形化合物和/或其代谢产物，以及与兽药有关的杂质的残留。

\textbf{兽药残留来源：}
\begin{enumerate}[leftmargin=*]
    \item 动物疾病治疗用药
    \item 饲料添加剂（预防用药、促生长剂）
    \item 环境污染（工业排放 $\rightarrow$ 饲料作物）
\end{enumerate}

\textbf{主要问题：}
\begin{enumerate}[leftmargin=*]
    \item 滥用抗生素（导致耐药菌产生和兽药残留）
    \item 使用违禁/淘汰药物（如氯霉素、硝基呋喃类）
    \item 非法使用饲料添加剂（如\textbf{盐酸克伦特罗/瘦肉精 clenbuterol}——$\beta$受体激动剂，促进瘦肉生长）
    \item 不遵守休药期规定
\end{enumerate}

\textbf{常见兽药残留的毒性：}
\begin{enumerate}[leftmargin=*]
    \item 急性毒性：红霉素等大环内酯类可引起急性肝损伤；瘦肉精可引起心跳加快、心律失常、肌肉震颤、代谢紊乱
    \item 慢性毒性和"三致"作用：雌激素类干扰内源性激素；磺胺类破坏造血机能、引起肾损害；氯霉素可引起再生障碍性贫血；四环素类抑制骨和牙的发育；庆大霉素和卡那霉素损害前庭和耳蜗神经；雌激素类、硝基呋喃类、砷制剂等有致癌作用
    \item 过敏反应：青霉素类、四环素类、氨基糖苷类、磺胺类和呋喃类
    \item 激素样作用：甲睾酮、丙酸睾酮、苯丙酸诺龙、雌二醇等性激素
    \item 产生耐药菌株和破坏肠道菌群平衡
\end{enumerate}
\end{defbox}

\section{有害金属污染}

\subsection{汞（Mercury, Hg）}

\begin{keybox}
\textbf{汞的污染来源：}工业"三废"排放（汞矿开采、氯碱工业、电子工业）；含汞农药的历史使用；自然来源（火山喷发等）。

\textbf{汞的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{甲基汞（Methylmercury）毒性远大于无机汞：}水体中微生物将无机汞甲基化 $\rightarrow$ 甲基汞 $\rightarrow$ 食物链逐级富集。鱼贝类是最重要的甲基汞污染食品！大鱼（金枪鱼、鲨鱼、剑鱼等）体内甲基汞浓度可比水体高数万至数十万倍。
    \item \textbf{脂溶性：}胃肠道吸收率 $>$ 90\%，极易通过生物膜。
    \item \textbf{强巯基亲和力：}与蛋白质中—SH基团结合，抑制多种含—SH的酶。
    \item \textbf{可透过血脑屏障和胎盘屏障：}引起中枢神经系统损害（最典型表现：视野向心性缩小、感觉异常、共济失调、听力障碍）和胎儿先天性水俣病。
    \item \textbf{主要靶器官：大脑和神经系统。}
    \item \textbf{历史事件：}日本水俣病（Minamata Disease，1956年）——甲基汞中毒的典型公害病。
\end{enumerate}
\end{keybox}

\subsection{镉（Cadmium, Cd）}

\begin{keybox}
\textbf{镉的污染来源：}工业含镉废水、废渣排放 $\rightarrow$ 污染灌溉水体和农田土壤；水稻对土壤中镉有高度富集能力 $\rightarrow$ "\textbf{镉大米}"；含镉肥料（磷肥含镉）、含镉电池不当处置。

\textbf{镉的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{生物半衰期极长：}约\textbf{15–30年}！镉一旦进入人体，极难排出。
    \item \textbf{主要蓄积器官：}肾脏（占全身总镉量的1/3）和肝脏。镉在体内与金属硫蛋白（Metallothionein, MT）结合，以Cd-MT复合物形式储存。
    \item \textbf{慢性毒性：}主要靶器官为\textbf{肾脏}——损害肾近曲小管 $\rightarrow$ 低分子量蛋白尿（肾小管性蛋白尿）$\rightarrow$ 高钙尿症 $\rightarrow$ 骨软化和骨质疏松。日本\textbf{痛痛病（Itai-itai Disease）}——镉慢性中毒的惨痛公害病。表现：全身骨痛、骨骼变形、多发性骨折等。
    \item IARC分类：镉及镉化合物为\textbf{Group 1（确认人类致癌物）}。
\end{enumerate}
\end{keybox}

\subsection{铅（Lead, Pb）}

\begin{keybox}
\textbf{铅的污染来源：}历史上含铅汽油燃烧（四乙基铅）——大气铅污染最重要来源（中国2000年禁用）；工业"三废"排放（蓄电池、冶炼、油漆行业）；食品加工设备/容器/管道迁移（如含铅焊锡的罐头、陶瓷釉中铅溶出）；传统松花蛋制作中使用氧化铅（已禁用）。

\textbf{铅的毒作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{典型的慢性蓄积性毒物：}生物半衰期约14年（骨骼中）。主要蓄积在骨骼（90\%以上），其次是肝、肾。
    \item \textbf{最主要危害——神经发育毒性：}胎儿和婴幼儿/儿童对铅的神经毒性特别敏感！\textbf{血铅水平每升高100 $\mu$g/L，儿童IQ平均下降3分以上。}铅可影响突触形成、神经递质释放和髓鞘形成。
    \item 对造血系统的影响：抑制血红素合成酶（$\delta$-氨基-$\gamma$-酮戊酸脱水酶、铁络合酶），引起贫血。
    \item 对肾脏的损害：慢性铅肾病（间质性肾炎）。
    \item \textbf{2010年JECFA撤销了铅的PTWI（暂定每周耐受摄入量）：}因为现有分析表明没有任何铅摄入水平可以被认为是"安全"的，尤其是对婴幼儿神经发育的影响。
    \item IARC分类：无机铅化合物为\textbf{Group 2A（很可能对人类致癌）}（2004年）。
\end{enumerate}
\end{keybox}

\subsection{有害金属污染的预防措施}

\begin{keybox}
\textbf{有害金属污染的预防原则*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{消除污染源——根本措施！}加强工业"三废"治理、禁止使用含铅汽油、更换老旧铅水管。
    \item 严格执行GB 2762《食品安全国家标准 食品中污染物限量》。
    \item 妥善保管有毒金属化合物，防止误食或交叉污染。
    \item 对已污染食品进行科学处理：可采用剔除、稀释等方法降低危害。
\end{enumerate}
\end{keybox}

\begin{tipbox}
\textbf{金属间拮抗作用：}
\begin{itemize}[leftmargin=*]
    \item 铁（Fe）可拮抗铅（Pb）的吸收和毒性
    \item 锌（Zn）可拮抗镉（Cd）的毒性
    \item 硒（Se）可拮抗汞（Hg）、铅（Pb）、镉（Cd）等多种有害金属的毒性
    \item 保证膳食中必需微量元素的充足摄入，是拮抗有害金属的重要营养策略
\end{itemize}
\end{tipbox}

% =====================================================================
\section{$N$-亚硝基化合物污染}

\subsection{分类与化学性质}

\begin{keybox}
\textbf{$N$-亚硝基化合物分类*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{$N$-亚硝胺（$N$-Nitrosamines）：}化学性质稳定，不易水解，在中性和碱性环境中较稳定。需在体内经代谢活化后才具有致癌性（间接致癌物）。
    \item \textbf{$N$-亚硝酰胺（$N$-Nitrosamides）：}化学性质不稳定，见光、受热易分解。为直接致癌物和直接致突变物（不需体内代谢活化）。
\end{enumerate}
\end{keybox}

\subsection{前体物与合成条件}

\begin{keybox}
\textbf{$N$-亚硝基化合物的前体物*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{硝酸盐（NO$_3^-$）和亚硝酸盐（NO$_2^-$）：}广泛存在于自然环境（土壤、水体）和食品中。蔬菜是饮食中硝酸盐的最主要来源（约占70\%–80\%）。
    \item \textbf{胺类物质：}广泛存在于环境和食品中（蛋白质分解产物）。鱼、肉中含量较高。
\end{enumerate}

\textbf{$N$-亚硝基化合物的体内合成条件*：}
\begin{itemize}[leftmargin=*]
    \item \textbf{pH $<$ 3的酸性环境}是该反应的最适条件。
    \item \textbf{胃是体内合成$N$-亚硝基化合物的最主要场所！}胃液pH约1–2，且硝酸盐、亚硝酸盐和胺类可随食物同时进入胃内。
    \item 口腔和膀胱（有感染时）也可发生亚硝化反应。
\end{itemize}
\end{keybox}

\subsection{致癌作用}

\begin{keybox}
\textbf{$N$-亚硝基化合物的致癌作用特点*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{多动物种属诱癌：}对多种实验动物均有致癌性，\textbf{至今未发现任何动物种属对$N$-亚硝基化合物的致癌作用有抵抗力！}
    \item \textbf{多器官/组织靶向性：}可诱发多种器官肿瘤，主要靶器官为\textbf{肝脏、食管、胃}，也可引起肾、膀胱、肺、脑、周围神经、皮肤等部位肿瘤。
    \item \textbf{多途径均诱癌：}经口、吸入、皮下注射、皮肤涂敷等多种途径均可诱癌。
    \item \textbf{单次大剂量或长期小剂量均可致癌：}具有明显的剂量-效应关系；且各剂量组合有相加作用。
    \item \textbf{可以通过胎盘使子代致癌（经胎盘致癌作用）：}怀孕动物摄入后，可通过胎盘影响胎儿，出生后发生肿瘤。
\end{enumerate}
\end{keybox}

\subsection{主要污染食品与IARC分级}

\textbf{主要污染食品：}腌制、烤制、油炸、烟熏加工的肉/鱼类制品（咸鱼、腊肉、火腿、香肠等）；啤酒（麦芽干燥过程可形成NDMA）；干酪；腌渍蔬菜（咸菜中亚硝酸盐含量在腌制过程中有"亚硝峰"现象）。

\textbf{IARC致癌性分级：}NDMA（$N$-亚硝基二甲胺）：Group 2A；NDEA（$N$-亚硝基二乙胺）：Group 2A；NMOR、NMEA、NPYR、NPIP、NDPA等：Group 2B。

\subsection{预防措施}

\begin{keybox}
\textbf{$N$-亚硝基化合物危害的预防*：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{防止食品霉变：}霉菌可促进亚硝胺的生成，并可将硝酸盐还原为亚硝酸盐。
    \item \textbf{控制肉制品加工中硝酸盐和亚硝酸盐的使用量：}严格执行GB 2760规定的使用范围和最大使用量。
    \item \textbf{施用钼肥（Mo肥料）：}钼是硝酸还原酶的组分，施钼可降低蔬菜中硝酸盐的积累。
    \item \textbf{多食新鲜蔬菜和水果：}\textbf{维生素C、维生素E、多酚等可阻断体内$N$-亚硝基化合物的合成！}（VC将NO$_2^-$还原为NO，从而阻止亚硝化反应）。
    \item 制定和执行食品中$N$-亚硝基化合物的限量标准。
    \item 暴晒污染食品：利用紫外线破坏$N$-亚硝基化合物。
\end{enumerate}
\end{keybox}

%  第十节 多环芳烃（PAH）污染
% =====================================================================
\section{多环芳烃（PAH）污染}

\begin{keybox}
\textbf{多环芳烃（Polycyclic Aromatic Hydrocarbons, PAH）：}由两个或两个以上苯环融合而成的化合物。\textbf{苯并(a)芘（Benzo(a)pyrene, B(a)P）}是最重要、最具有代表性的PAH。

\textbf{B(a)P的特性：}
\begin{itemize}[leftmargin=*]
    \item 由5个苯环组成；水溶性极低，脂溶性高（极易蓄积于脂肪组织）
    \item 化学性质稳定；明确动物致癌物，流行病学证据支持与人类胃癌的关联
    \item IARC Group 1（确认人类致癌物）
\end{itemize}
\end{keybox}

\subsection{污染来源}

\begin{keybox}
\textbf{B(a)P污染食品的主要途径：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{烘烤、烟熏过程中直接污染——最主要的来源！}
    \begin{itemize}[leftmargin=*]
        \item 熏制食品：熏烟中含有大量PAH，烟熏时间越长、温度越高，B(a)P含量越高。
        \item 炭火烤肉/鱼：油脂滴落在炭火上 $\rightarrow$ 热解聚合生成PAH $\rightarrow$ 随烟雾附在食品表面。
    \end{itemize}
    \item 食品成分在高温下的热解/热聚合：脂肪在 $>$ 400$^\circ$C 可生成PAH。
    \item 农作物从环境中吸收：空气沉降的PAH被作物叶片和果实表面吸附。
    \item 食品加工过程中接触污染：如用沥青铺路晒粮（严重违规）。
\end{enumerate}
\end{keybox}

\subsection{防控措施}

\begin{enumerate}[leftmargin=*]
    \item 治理环境PAH污染（减少工业排放和汽车尾气）
    \item 改进烟熏工艺：避免直接接触炭火，采用间接烟熏
    \item 食用油加工中添加活性炭吸附脱除PAH
    \item 日光/紫外线照射可降低食品表面B(a)P含量
    \item 不吃烧焦的食物
\end{enumerate}

\section{杂环胺（Heterocyclic Amines, HCA）}

\begin{defbox}
\textbf{杂环胺（Heterocyclic Amines）：}在高温烹调条件下，由食品中的蛋白质、氨基酸、肌酸和糖类反应生成的一类具有致突变性和致癌性的杂环芳香族化合物。

\textbf{主要类型：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{氨基咪唑氮杂芳烃类（IQ型）：}如IQ（2-氨基-3-甲基咪唑并[4,5-f]喹啉）、MeIQ、PhIP。
    \item \textbf{氨基咔啉类：}如Trp-P-1、Glu-P-1等（氨基酸热解产物）。
\end{enumerate}
\end{defbox}

\begin{keybox}
\textbf{杂环胺生成的影响因素* —— 生成量与以下因素密切相关：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{加热温度（最关键因素！）：}温度越高，生成量越多。从200$^\circ$C升至300$^\circ$C时，杂环胺生成量可增加\textbf{约5倍}！
    \item \textbf{加热时间：}时间越长，生成量越多。
    \item \textbf{水分含量：}水分可抑制杂环胺的生成。含水量越低，生成量越多。
    \item \textbf{烹调方式的影响（总结规律）：}
    \begin{itemize}[leftmargin=*]
        \item 烤、煎、炸、烧烤 $\gg$ 炖、焖、煨、煮
        \item 总体规律：\textbf{温度越高 $+$ 时间越长 $+$ 含水量越少 = 杂环胺生成量越多！}
    \end{itemize}
\end{enumerate}

\textbf{高含量食品：}鱼和肉类（高蛋白食品）在高温烹制时杂环胺生成量最大。油炸/烤制的鱼、牛排、炸鸡中杂环胺含量较高。

\textbf{致癌性：}可诱发大小鼠肝、肠道、乳腺等多种器官肿瘤，主要靶器官：肝脏。在极低剂量下即可与DNA形成加合物。PhIP：IARC Group 2B；IQ：IARC Group 2A。
\end{keybox}

\section{丙烯酰胺、氯丙醇}

\subsection{丙烯酰胺（Acrylamide）}

\begin{defbox}
\begin{itemize}[leftmargin=*]
    \item \textbf{生成条件：}富含淀粉的食品在 $>$ 120$^\circ$C 高温加工（油炸、烘烤）过程中，由天冬酰胺（asparagine）和还原糖（葡萄糖、果糖）通过Maillard反应生成。
    \item \textbf{高含量食品：}薯条（French fries）、薯片（potato chips）、方便面、油条、速溶咖啡。土豆制品的丙烯酰胺含量约为谷物制品的\textbf{4倍}。
    \item \textbf{毒性和致癌性：}神经毒性（职业暴露），啮齿动物多器官致癌。IARC Group 2A（很可能对人类致癌）。
    \item \textbf{预防：}改进加工工艺（降低油炸温度和时间、避免过度金黄焦脆），原料选用低还原糖的马铃薯品种。
\end{itemize}
\end{defbox}

\subsection{氯丙醇（Chloropropanols）}

\begin{defbox}
\begin{itemize}[leftmargin=*]
    \item \textbf{首次发现：}在酸水解植物蛋白液（HVP）中发现，用于酱油等调味品中。
    \item \textbf{代表性物质：}3-氯-1,2-丙二醇（3-MCPD）含量最高、最常见。
    \item \textbf{毒性：}3-MCPD具肾毒性和雄性生殖毒性。
    \item \textbf{存在形式：}游离态3-MCPD（酸水解HVP）以及脂肪酸酯形式（即3-MCPD酯，广泛存在于精炼油脂中）。
\end{itemize}
\end{defbox}

\section{食品容器、包装材料的卫生问题}

\subsection{常见包装材料}

\begin{enumerate}[leftmargin=*]
    \item \textbf{塑料：}PET（聚对苯二甲酸乙二醇酯）、PC（聚碳酸酯）、PE（聚乙烯）、PP（聚丙烯）、PS（聚苯乙烯）、三聚氰胺-甲醛树脂（密胺）、脲醛树脂。
    \item \textbf{橡胶：}天然橡胶、合成橡胶（奶嘴、密封圈）。
    \item \textbf{纸、竹、木：}传统材料。
    \item \textbf{金属、搪瓷、陶瓷、玻璃：}传统材料，但需关注金属离子迁移。
\end{enumerate}

\subsection{主要卫生问题}

\begin{enumerate}[leftmargin=*]
    \item \textbf{有害物质向食品迁移（Migration）——最核心的卫生问题！}
    \begin{itemize}[leftmargin=*]
        \item 塑料中的增塑剂（如邻苯二甲酸酯类，phthalates——具有雌激素样活性，属于内分泌干扰物）
        \item 塑料中的稳定剂、抗氧化剂
        \item 密胺制品（仿瓷餐具）：游离甲醛毒性
        \item 铝制品：盛装酸性或碱性食品可溶解氧化铝膜 $\rightarrow$ 铝溶出（铝摄入过量与阿尔茨海默病的关联虽未最终定论，但已引起广泛关注）
    \end{itemize}
    \item 包装材料的回收和再生问题：回收塑料中的不明污染物转移入食品。
    \item 印刷油墨：油墨中的有害物质（如苯系物）可能迁移至食品接触面。
    \item 纳米包装材料：新型材料的安全性评价体系尚待完善。
\end{enumerate}

\section{放射性污染及物理性污染}

\subsection{食品放射性污染}

\begin{keybox}
\textbf{食品放射性污染的主要核素（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{$^{40}$K（钾-40）：}
    \begin{itemize}[leftmargin=*]
        \item 天然放射性核素，存在于所有动植物体内
        \item 半衰期 $T_{1/2} = 1.28 \times 10^9$ 年
        \item 是食品中天然放射性核素剂量的最主要贡献者
    \end{itemize}
    \item \textbf{$^{131}$I（碘-131）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 8.6$ 天（短半衰期核素）
        \item 危害：主要富集于甲状腺，可诱发甲状腺肿瘤
        \item 可通过母乳传递给婴儿（乳汁中$^{131}$I浓集）
    \end{itemize}
    \item \textbf{$^{90}$Sr（锶-90）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 28.8$ 年（长半衰期核素）
        \item 化学性质与钙类似 $\rightarrow$ 主要沉积于骨骼和牙齿 $\rightarrow$ 对骨髓造血功能产生长期辐照
        \item 在食物链中具重要意义
    \end{itemize}
    \item \textbf{$^{137}$Cs（铯-137）：}
    \begin{itemize}[leftmargin=*]
        \item 半衰期 $T_{1/2} = 30.17$ 年
        \item 化学性质与钾类似 $\rightarrow$ 参与全身代谢、全身均匀分布
        \item 在食物链中具重要意义
    \end{itemize}
\end{enumerate}
\end{keybox}

\subsection{人为放射性污染的来源}

\begin{enumerate}[leftmargin=*]
    \item \textbf{核爆炸：}核武器试验产生的放射性沉降物（radioactive fallout），污染土壤、水体和农作物。
    \item \textbf{核废料排放：}核电站、核燃料加工企业的放射性废水和废料排放。
    \item \textbf{核事故：}
    \begin{itemize}[leftmargin=*]
        \item 1986年切尔诺贝利核事故——大量$^{131}$I和$^{137}$Cs释放
        \item 2011年福岛第一核电站事故——日本政府2023年决定将处理后核污染水排海（约130万吨，预计排放约30年），引发国际社会和食品安全领域的广泛关注
    \end{itemize}
\end{enumerate}

\subsection{放射性物质向食品的转移途径}

\begin{enumerate}[leftmargin=*]
    \item \textbf{水体 $\rightarrow$ 水生生物 $\rightarrow$ 人体：}水 $\rightarrow$ 水生植物/藻类（浓集倍数可达100–500倍）$\rightarrow$ 鱼贝类（进一步富集）$\rightarrow$ 人体
    \item \textbf{陆地环境 $\rightarrow$ 食物链：}沉降物 $\rightarrow$ 牧草 $\rightarrow$ 牛 $\rightarrow$ 牛乳/牛肉 $\rightarrow$ 人体；沉降物 $\rightarrow$ 饲料 $\rightarrow$ 鸡 $\rightarrow$ 蛋/禽肉 $\rightarrow$ 人体
    \item \textbf{直接沉降：}放射性沉降物直接附着在蔬菜叶面、水果表面等。
\end{enumerate}

\subsection{放射性污染的生物学效应}

\begin{enumerate}[leftmargin=*]
    \item \textbf{确定性效应（Deterministic Effects）：}效应的严重程度随辐射剂量的增加而增加，存在剂量阈值。如急性放射病、皮肤红斑。
    \item \textbf{随机性效应（Stochastic Effects）：}效应的发生概率与辐射剂量相关，但严重程度与剂量无关，不存在剂量阈值（无阈值假设）。包括\textbf{致癌效应}和\textbf{遗传效应}。
\end{enumerate}

\begin{keybox}
\textbf{电离辐射的照射方式：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{外照射（External Irradiation）：}人体暴露于放射性污染的环境（主要指大气环境），电离辐射（$\gamma$射线、X射线等）直接作用于人体体表。
    \item \textbf{内照射（Internal Irradiation）：}放射性核素进入机体内，作用于人体内部产生生物学效应。以射程短、电离强的$\alpha$、$\beta$射线作用为主。内照射常以局部损害为主，呈进行性发展和症状迁延。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{食品中天然放射性物质补充：}
\begin{enumerate}[leftmargin=*]
    \item 天然辐射源：大气层外的宇宙射线和地壳中的天然放射性核素。$^3$H（氚）、$^7$Be（铍）、$^{14}$C（碳）和$^{22}$Na（钠）等可通过食物和饮水进入机体。
    \item $^{226}$Ra（镭-226）：可通过饮水和食物进入人体，动物和人体内的$^{226}$Ra主要集中于骨组织中。
    \item $^{210}$Po（钋-210）：自然环境中的$^{210}$Po和$^{210}$Pb处于平衡状态，广泛存在于植物和一些海产品中，是海产品中重要的天然放射性核素。
\end{enumerate}
\end{keybox}

\subsection{物理性污染}

\begin{defbox}
\textbf{物理性污染：}食品中混入非化学性的、非正常来源的异物，如金属碎片、碎玻璃、石块、塑料片、毛发等。

\textbf{来源：}田间（石块、泥土、植物碎片）；加工过程（设备零件脱落、刀具碎片）；储藏和运输（包装材料碎片）；人为掺假（故意加入异物以增重）。

\textbf{防控措施：}金属探测器、X射线异物检测机、过筛、磁铁分离、严格GMP等。GB 7099-2015规定糕点、面包中不得有可见异物。
\end{defbox}

\subsection*{参考答案要点}

\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item \textbf{食品污染：}食物中外来生物性、化学性及物理性有害物质，对人体健康可能产生危害或影响其食用及商品价值的过程。三大分类：生物性（微生物/寄生虫/昆虫）、化学性（农药/有害金属/$N$-亚硝基化合物/PAH/杂环胺等）、物理性（放射性核素/异物）。\textbf{Aw：}$\text{Aw} = P/P_0$，同温度下食品水蒸气分压与纯水蒸汽压之比，反映食品中能被微生物利用的自由水。\textbf{菌落总数：}36$\pm$1$^\circ$C、48$\pm$2h需氧培养，每g/mL/cm$^2$检样形成的细菌菌落总数（CFU）。\textbf{大肠菌群：}36$\pm$1$^\circ$C、24$\sim$48h，发酵乳糖产酸产气、革兰阴性无芽孢杆菌，作为粪便污染和肠道致病菌指示菌。\textbf{MPN法：}最可能数法，大肠菌群含量较低时的统计学计数方法。\textbf{霉菌毒素：}霉菌在食品中产生的有毒次级代谢产物。\textbf{细菌菌相：}共存于食品中的细菌种类及其相对数量的构成，优势菌种决定腐败特征。

    \item \textbf{食品腐败变质：}在微生物为主的各种因素作用下，食品成分被分解破坏，感官性状变化、食用价值降低或丧失。\textbf{TVBN：}弱碱条件下蒸馏出的总氮量，反映蛋白质分解产生的氨和胺类，高蛋白食品鲜度指标（鲜畜肉$\leq$15mg/100g，海水鱼$\leq$30mg/100g）。\textbf{K值：}ATP分解产物中HxR+Hx占比，$K<20\%$新鲜，$>40\%$初期腐败，鱼类鲜度灵敏指标。\textbf{D值：}特定温度下杀死90\%微生物所需时间(min)。\textbf{TTT原则：}冷冻食品品温(T)、储藏时间(T)对品质容许限度(Tolerance)三者的关系。\textbf{F值：}特定温度(121.1$^\circ$C)和Z值(10$^\circ$C)下杀死一定数量微生物的时间(min)，通常要求12D。

    \item \textbf{农药残留：}农药使用后残存于食品、农产品、环境及饲料中的农药原体、有毒代谢产物、降解产物和杂质的总称。\textbf{MRLs：}按GAP使用农药后在食品和饲料中可合法允许的农药残留最高浓度(mg/kg)。\textbf{EMRLs：}已禁用但因环境污染再次残留的持久性农药的残留限量（如DDT、六六六）。\textbf{ADI：}人类终生每日摄入某物质而不产生可检测到的健康危害的剂量(mg/kg bw)。\textbf{兽药残留：}动物产品可食部分所含兽药原形化合物和/或其代谢产物及杂质的残留。

    \item \textbf{黄曲霉毒素：}黄曲霉和寄生曲霉产生的二呋喃氧杂萘邻酮类次级代谢产物，已知最强天然致癌物（二甲基亚硝胺致癌强度的75倍），IARC Group 1。\textbf{$N$-亚硝基化合物：}由硝酸盐/亚硝酸盐与胺类在pH$<$3酸性条件（胃是主要合成场所）下合成，多物种/多器官/多途径致癌，可经胎盘使子代致癌。\textbf{PAH：}两个以上苯环融合的化合物，B(a)P是最重要代表，IARC Group 1，主要来源为烘烤烟熏过程。\textbf{HCA：}高温烹调下蛋白质、氨基酸、肌酸和糖类反应生成，温度/时间/水分决定生成量。

    \item \textbf{Aw与微生物生长关系：}Aw = P/P0。Aw$<$0.60绝大多数微生物无法生长（干制保藏原理）；Aw$<$0.65极少数微生物可生长（耐干霉菌、耐高渗酵母）；Aw$<$0.70能较长期抑制微生物；Aw 0.80–0.85在1–2周内霉菌引起腐败；Aw 0.98–0.99大多数微生物都能生长。最低Aw：细菌$>$0.9，酵母菌0.87，真菌（霉菌）0.80（黄曲霉$\approx$0.78）。

    \item \textbf{常见食品细菌：}假单胞菌属（G$-$需氧杆菌，嗜冷，冷藏食品腐败优势菌）；微球菌属（G$+$球菌，需氧，耐热耐干燥）；芽胞杆菌属（G$+$芽胞杆菌，需氧/兼性厌氧，芽胞耐热强）；肠杆菌科（G$-$无芽胞杆菌，兼性厌氧，含大肠杆菌、沙门菌、志贺菌等）；葡萄球菌属（G$+$球菌，兼性厌氧，金葡菌产肠毒素）；乳酸菌（G$+$，发酵糖产乳酸）。

    \item \textbf{菌落总数意义：}①反映食品清洁状态；②反映食品腐败变质程度；③预测保质期/货架期。\textbf{大肠菌群意义：}①粪便污染指示菌（典型大肠杆菌44.5$^\circ$C生长=近期污染，非典型=远期污染）；②肠道致病菌指示菌（与肠道致病菌同源，存活时间一致或稍长）。\textbf{MPN法：}大肠菌群含量较低时采用，基于统计学概率论，结果MPN/g或MPN/mL；含量较高时用CFU平板计数法。

    \item \textbf{霉菌产毒条件：}Aw$\geq$0.80、RH 80\%–90\%、最适温度20–28$^\circ$C、糖类为碳源+少量氮源矿物质、需氧。\textbf{产毒特点：}①只少数菌株产毒；②产毒能力可改变（传代后增强/减弱/丧失）；③无严格专一性（一种霉菌可产多种毒素，一种毒素可由多种霉菌产生）；④需一定条件。\textbf{霉菌毒素中毒特点：}①经污染食品引起；②主要损害肝肾等实质器官；③烹调加热不能破坏；④无传染性和免疫性（化学性中毒）；⑤季节性和地区性。

    \item \textbf{AF理化性质：}耐热（268–269$^\circ$C才分解）、脂溶性（水溶解度仅10–20mg/L）、碱性条件(pH9–10)内酯环开环破坏、紫外线产生荧光。\textbf{产毒条件：}最适温度25–33$^\circ$C，最适Aw 0.93–0.98，最适基质花生、玉米。\textbf{代谢：}AFB1在肝脏CYP450催化下：①AFB1$\rightarrow$AFM1(羟化，乳汁中)；②AFB1$\rightarrow$AFQ1(羟化,解毒)；③AFQ1$\rightarrow$AFH1(还原,解毒)；④AFB1$\rightarrow$AFB1-8,9-环氧化物(终致癌物，与DNA形成加合物)。\textbf{毒性：}急性中毒性肝炎（靶器官肝脏）、慢性肝损伤、致癌性（肝癌，与HBV协同）。\textbf{最强天然致癌物理由：}致癌强度高(75倍)、致癌谱广(多物种多器官)、灵长类可诱癌、与人类肝癌流行病学相关性强、与HBV协同致癌。

    \item \textbf{预防三个环节：}①防霉（最根本）：控制水分（谷类$\leq$13–14\%、花生$\leq$8–9\%）、低温储藏（$\leq$10$^\circ$C）、气调储藏、化学防霉剂。②去毒（7种方法）：挑选霉粒法、碾轧加工法、加水搓洗法、植物油加碱法（碱炼）、物理吸附法（活性炭/白陶土）、紫外光照射法、氨气处理法。③执行限量标准：玉米花生$\leq$20$\mu$g/kg、大米植物油$\leq$10$\mu$g/kg、婴幼儿食品$\leq$0.5$\mu$g/kg、乳制品AFM1$\leq$0.5$\mu$g/kg。

    \item \textbf{食品腐败变质概念：}微生物为主的各种因素作用下，食品成分被分解破坏，感官性状变化、食用价值降低或丧失。\textbf{原因：}微生物作用（最主要，分泌胞外酶分解大分子）、食品本身特性（营养成分/pH/Aw/渗透压）、环境因素（温度/湿度/氧气/光照）。\textbf{鉴定指标：}①感官（最敏感、最直接）；②化学：TVBN（高蛋白食品）、三甲胺（鱼类鱼腥味）、组胺（过敏性中毒）、K值（鱼类鲜度，$<20\%$新鲜，$>40\%$初期腐败）、pH（新鲜肉5.8–6.2，腐败时上升）、过氧化值POV（脂肪酸败最早期指标）；③物理（比重/折光率/黏度）；④微生物（菌落总数/大肠菌群/致病菌）。

    \item \textbf{蛋白质腐败：}蛋白质$\rightarrow$多肽$\rightarrow$氨基酸$\rightarrow$脱羧$\rightarrow$胺类(腐胺/尸胺/组胺/色胺/酪胺)+吲哚+硫化氢+硫醇，表现恶臭/变色/发黏。\textbf{脂肪酸败：}中性脂肪$\rightarrow$甘油+游离脂肪酸$\rightarrow$氧化，POV升高（最早期指标），产生哈喇味，颜色变黄。\textbf{碳水化合物发酵：}糖类$\rightarrow$有机酸+醇类$\rightarrow$醛/酮/CO$_2$，产物乳酸/醋酸/乙醇/丁酸，表现酸味/产气/变黏。

    \item \textbf{低温保藏：}冷藏$-1\sim10^\circ$C短期，冷冻$\leq-18^\circ$C长期。急冻缓化：急冻30min内通过冰晶生成带($-1\sim-5^\circ$C)使中心温度$\leq-20^\circ$C（冰晶小、破坏小）；缓化在0–10$^\circ$C缓慢融化（汁液流失少）。\textbf{高温杀菌：}巴氏杀菌LTLT 62.8$^\circ$C/30min、HTST 71.7$^\circ$C/15s；加压杀菌100$\sim$121$^\circ$C；UHT 135–150$^\circ$C/2s；D值=杀死90\%微生物时间，F值=121.1$^\circ$C下杀菌时间(12D)。\textbf{辐照保藏：}低剂量1–5kGy防腐，中剂量5–10kGy消毒，高剂量10–15kGy灭菌。\textbf{干燥脱水：}水分降至15\%以下或Aw 0.00$\sim$0.60。\textbf{化学保存：}盐腌食盐$\geq$10\%，糖渍糖含量60\%–65\%，酸渍pH$<$4.5。

    \item \textbf{污染途径：}①直接施药（最主要）；②作物从污染环境吸收；③食物链和生物富集；④储运污染。\textbf{控制：}农药管理、安全使用（安全间隔期）、MRL标准(GB 2763-2021)、高效低毒新品种、剧毒农药禁用于蔬果茶药材。\textbf{比较：}有机磷：不可逆抑制AChE，急性毒性高，光热不稳定；氨基甲酸酯：可逆抑制AChE，与亚硝酸盐生成$N$-亚硝基化合物；拟除虫菊酯：干扰钠离子通道，高效低残留，抗药性；有机氯：极其稳定（DDT土壤半衰期3–30年），脂溶性强，已禁用。

    \item \textbf{甲基汞：}毒性远大于无机汞，脂溶性，胃肠道吸收$>$90\%，强—SH亲和力，可过血脑屏障和胎盘屏障，靶器官大脑和神经系统，典型公害病——水俣病(1956)。\textbf{镉：}生物半衰期15–30年，蓄积肾(1/3)和肝，靶器官肾脏——损害近曲小管$\rightarrow$蛋白尿$\rightarrow$骨软化（痛痛病），Group 1。\textbf{铅：}慢性蓄积性毒物，半衰期约14年(骨骼)，最主要危害——神经发育毒性（血铅每升高100$\mu$g/L，儿童IQ下降3分以上），影响造血/肾脏，2010年JECFA撤销PTWI，Group 2A。

    \item \textbf{前体物：}硝酸盐/亚硝酸盐+胺类。\textbf{合成条件：}pH$<$3酸性环境（胃是主要体内合成部位，胃液pH约1–2）。\textbf{致癌特点：}①多物种无抵抗；②多器官靶向(肝/食管/胃为主)；③多途径均可诱癌；④单次大剂量或长期小剂量均可；⑤经胎盘致子代肿瘤。\textbf{预防：}①防霉；②控制硝酸盐/亚硝酸盐用量(GB 2760)；③施钼肥降低蔬菜硝酸盐积累；④多食新鲜蔬果(VC/VE/多酚阻断合成——VC将NO$_2^-$还原为NO)；⑤限量标准；⑥暴晒利用紫外线破坏。

    \item \textbf{影响因素：}①加热温度（最关键！200$\rightarrow$300$^\circ$C增约5倍）；②加热时间（越长越多）；③水分含量（含水多则抑制）；④烹调方式：烤/煎/炸/烧烤 $\gg$ 炖/焖/煨/煮。规律：温度越高+时间越长+水分越少 = 生成越多。

    \item \textbf{主要核素：}$^{40}$K（天然，$T_{1/2}=1.28\times10^9$yr，最主要天然核素贡献者）；$^{131}$I（$T_{1/2}=8.6$d，富集于甲状腺，可经母乳传递）；$^{90}$Sr（$T_{1/2}=28.8$yr，沉积骨骼和牙齿，影响骨髓造血）；$^{137}$Cs（$T_{1/2}=30.17$yr，全身均匀分布）。\textbf{转移途径：}水体$\rightarrow$藻类(富集100–500倍)$\rightarrow$鱼贝类$\rightarrow$人体；牧草$\rightarrow$牛$\rightarrow$牛乳/牛肉$\rightarrow$人体；直接沉降于蔬菜叶面/水果表面。\textbf{照射方式：}外照射（$\gamma$/X射线直接作用于体表）；内照射（放射性核素进入体内，$\alpha$/$\beta$射线为主，局部损害，进行性发展和症状迁延）。

    \item \textbf{B(a)P污染途径：}①烘烤烟熏直接污染（最主要，油脂滴落炭火热解聚合）；②高温热解/热聚合（脂肪$>$400$^\circ$C）；③农作物从环境吸收（空气沉降）；④加工接触污染。\textbf{防控：}治理环境PAH、改进烟熏工艺(间接烟熏)、活性炭吸附、日光/紫外线照射、不吃烧焦食物。

    \item \textbf{丙烯酰胺：}富淀粉食品$>$120$^\circ$C高温加工（油炸/烘烤）时，天冬酰胺+还原糖经Maillard反应生成。高含量食品：薯条、薯片、方便面、油条、速溶咖啡（土豆制品含量约为谷物制品4倍）。神经毒性，IARC Group 2A。预防：降低油炸温度和时间、选用低还原糖马铃薯品种。

    \item \textbf{兽药残留来源：}①动物疾病治疗用药；②饲料添加剂（预防用药/促生长剂如瘦肉精）；③环境污染。\textbf{主要毒性：}急性毒性（红霉素肝损伤、瘦肉精心律失常）；慢性毒性（磺胺类破坏造血/肾损害、氯霉素再生障碍性贫血、四环素抑制骨牙发育、庆大霉素损害听神经）；过敏反应（青霉素/四环素/磺胺类）；激素样作用（性激素）；耐药菌株和破坏肠道菌群平衡。

    \item \textbf{综合防控策略：}（要点）三大污染来源：生物性（微生物——强化HACCP/GMP、冷链管理；寄生虫——加强检验检疫）、化学性（农药——登记制度+安全间隔期+MRLs+高效低毒新品种；有害金属——消除工业污染源是根本+GB 2762限量+金属间拮抗营养策略；$N$-亚硝基化合物——控制硝酸盐/亚硝酸盐+施钼肥+多食新鲜蔬果；PAH——改进烟熏工艺；杂环胺——合理烹调降低温度）、物理性（放射性——核事故应急+食品监测；异物——金属探测器/X射线检测+GMP）。综合防控：完善法规标准体系、建立全程可追溯制度、加强风险监测和风险评估、开展食品安全健康教育。

    \item \textbf{黄曲霉毒素污染调查与防控方案：}（要点）①调查：采样检测可疑食品（花生/玉米/谷物/植物油等）中AFB1含量，现场调查储藏条件（温度/湿度/Aw），了解人员中毒情况（肝功能检测/流行病学调查）。②防控：立即封存/销毁超标食品；查找污染源头（田间/储藏/加工环节）；防霉措施（控制水分、低温储藏$\leq$10$^\circ$C、气调储藏）；已污染食品去毒（挑选霉粒/碾轧加工/碱炼/吸附/紫外线/氨处理）；严格执行限量标准（GB 2761-2017）；加强健康教育（HBV疫苗接种+AF暴晒风险告知，因AF与HBV有协同致癌作用）。
\end{enumerate}
