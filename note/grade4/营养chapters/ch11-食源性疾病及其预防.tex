\section{食源性疾病}

\subsection{食源性疾病的定义}

\begin{keybox}
\textbf{食源性疾病（foodborne disease）的定义：}
通过摄入食物进入人体的各种致病因子引起的、通常具有感染或中毒性质的一类疾病，包括食物中毒。
\end{keybox}

食源性疾病包括三个基本要素：
\begin{enumerate}[leftmargin=*]
    \item \textbf{媒介：}食物是携带和传播病原物质的媒介；
    \item \textbf{致病因子：}导致人体罹患疾病的病原物质是食物中所含有的各种致病因子；
    \item \textbf{症状：}临床特征为急性、亚急性中毒或感染。
\end{enumerate}

\subsection{分类}

食源性疾病的分类：
\begin{enumerate}[leftmargin=*]
    \item 食物中毒
    \item 食源性肠道传染病
    \item 食源性寄生虫病
    \item 人畜共患传染病
    \item 食源性化学物质引起的急慢性中毒
    \item 食物过敏（注意与食品不耐受区别）
    \item 食源性放射病
\end{enumerate}

\subsection{致病因子分类（掌握）}

\begin{keybox}
\textbf{致病因子三大类：生物性、化学性、放射性。}

\textbf{（1）生物性因素：}
\begin{itemize}[leftmargin=*]
    \item \textbf{细菌及其毒素：}引起食源性疾病最重要的病原物。
    \begin{itemize}
        \item 主要包括：
        \begin{enumerate}
            \item 引起细菌性食物中毒的病原菌；
            \item 引起人类肠道传染病的病原菌；
            \item 引起人畜共患病的病原菌。
        \end{enumerate}
    \end{itemize}
    \item \textbf{真菌及其毒素：}包括黄曲霉、赭曲霉、镰刀菌、展青霉、杂色曲霉等及其产生的毒素。
    \item \textbf{病毒和立克次体：}可引起腹泻或肠道传染病，如轮状病毒、柯萨奇病毒、诺如病毒、甲肝病毒等。
    \item \textbf{寄生虫和原虫：}囊尾蚴（绦虫）、毛线虫（旋毛虫）、弓形虫、肝吸虫（华支睾吸虫）、肺吸虫以及其他寄生虫。
    \item \textbf{有毒动物及其毒素：}河豚毒素、雪卡毒素、贝类中的石房蛤毒素、组胺。
    \item \textbf{有毒植物及其毒素：}氰苷类；棉酚；四季豆中的皂素；鲜黄花菜中的类秋水仙碱等。
\end{itemize}

\textbf{（2）化学性因素：}
\begin{itemize}[leftmargin=*]
    \item 农药残留；
    \item 兽药残留；
    \item 有毒有害化学物质污染；
    \item 不符合要求的食品生产工具（食品加工生产）；
    \item 食品接触材料以及非法添加物；
    \item 有毒有害化学物质，如镉、铅、砷、偶氮化合物等；
    \item 反复高温加热油脂产生的油脂聚合物；
    \item 烘烤或烟熏产生的多环芳烃类；
    \item 食品腌制产生的亚硝酸盐等。
\end{itemize}

\textbf{（3）物理性因素：}
\begin{itemize}[leftmargin=*]
    \item 主要是放射性物质：放射性物质的开采、冶炼、国防核武器以及放射性核素其废弃物不合理的排放及意外性的泄漏。
\end{itemize}
\end{keybox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{食源性疾病按致病因子分类（补充）：}引起的致病因子包括生物性、化学性和物理性（放射性）因素。其中生物性因素中的致病性微生物可直接对人体致病并造成危害，包括致病性细菌和细菌毒素、人畜共患传染病病原菌和病毒、产毒真菌和真菌毒素。
\end{tipbox}

% =====================================================================
\subsection{人畜共患传染病}
% =====================================================================

\begin{defbox}
\textbf{人畜共患传染病：}炭疽、结核病、口蹄疫、霍乱、疯牛病、布鲁氏菌病的病原、流行病学特点、临床表现、诊断、治疗与预防。

\textbf{1. 炭疽（Anthrax，熟悉）：}
由炭疽杆菌引起的烈性传染病。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}炭疽杆菌在未形成芽胞之前，55$\sim$58$^\circ$C、10$\sim$15分钟即可被杀死。炭疽杆菌的芽胞具有强大的抵抗力，需140$^\circ$C干热3小时或120$^\circ$C高压蒸汽10分钟杀灭。
    \item \textbf{传播途径：}皮肤接触、呼吸道吸入、经口（食用病畜肉）。
    \item \textbf{病畜肉处理：}6小时内立即采取措施，防止芽孢形成。严禁屠宰和销售。
\end{itemize}

\textbf{2. 结核病（Tuberculosis，熟悉）：}
由结核分枝杆菌（Mycobacterium tuberculosis）引起的人畜共患慢性传染病，牛型结核分枝杆菌可通过食物链传播给人。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}结核分枝杆菌为抗酸染色阳性杆菌，对外界抵抗力较强，在干燥痰液中可存活6$\sim$8个月。但对湿热敏感，\keyword{60$^\circ$C加热30分钟}即可杀灭，\keyword{巴氏消毒法（63$^\circ$C 30分钟或72$^\circ$C 15秒）}可有效杀灭乳中的结核杆菌。
    \item \textbf{传播途径：}经口（食用未经巴氏消毒的带菌乳及乳制品、病畜肉）、呼吸道（飞沫传播）。
    \item \textbf{临床表现：}人感染牛型结核分枝杆菌后，可出现肺结核或肺外结核（淋巴结结核、骨结核、肠结核等）。典型症状包括长期低热、盗汗、乏力、消瘦、咳嗽、咯血等。
    \item \textbf{预防：}
    \begin{enumerate}
        \item 对奶牛进行定期结核菌素试验，阳性病牛应淘汰处理。
        \item 牛乳必须经过巴氏消毒后方可食用。
        \item 加强肉品检验，病畜肉尸应进行高温处理或销毁。
    \end{enumerate}
\end{itemize}

\textbf{3. 口蹄疫（Foot-and-Mouth Disease，熟悉）：}
由口蹄疫病毒引起，在猪、牛、羊等偶蹄动物之间传播的急性传染病，是高度接触性人畜共患病。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}口蹄疫病毒属小RNA病毒科，对外界环境抵抗力较强，在冻肉中可长期存活。对热敏感，\keyword{煮沸立即死亡}。
    \item \textbf{传播途径：}消化道、呼吸道、破损皮肤、黏膜。
    \item \textbf{临床表现：}人感染后主要表现为发热、呕吐、口腔黏膜及手掌、足底出现水疱，儿童较成人易感。一般预后良好。
    \item \textbf{预防：}发现病畜立即屠宰销毁，同群牲畜隔离观察；加强进出口检疫；对疫区进行封锁、消毒；对易感动物接种疫苗。
\end{itemize}

\textbf{4. 霍乱（Cholera，熟悉）：}
由霍乱弧菌（Vibrio cholerae）引起的烈性肠道传染病，属于甲类传染病，可通过被污染的水产品和食品传播。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}霍乱弧菌为革兰氏阴性弧菌，有单鞭毛，运动活泼。对酸敏感，\keyword{对热敏感，煮沸立即死亡}。O1群和O139群为主要致病血清群，产生\textbf{霍乱肠毒素（cholera enterotoxin）}，激活腺苷酸环化酶使cAMP升高，导致肠液大量分泌。
    \item \textbf{传播途径：}粪-口途径传播。经水传播是最主要的传播途径；经食物传播以水产品（鱼、虾、蟹、贝类）最为常见；亦可经生活接触和苍蝇传播。
    \item \textbf{流行病学特点：}夏秋季高发，沿海地区发病率较高。病人和带菌者是主要传染源。
    \item \textbf{临床表现：}潜伏期数小时至5天，一般为1$\sim$2天。典型表现为\textbf{剧烈腹泻（米泔水样便）}、呕吐，迅速出现严重脱水、电解质紊乱和代谢性酸中毒，严重者可因循环衰竭死亡。\keyword{米泔水样便是特征性表现！}
    \item \textbf{预防：}
    \begin{enumerate}
        \item 加强水源管理，确保饮用水安全。
        \item 海产品（尤其是贝类）必须彻底煮熟后食用。
        \item 加强食品从业人员健康检查，带菌者不得从事食品行业。
        \item 对疫区实施隔离、消毒，接种霍乱疫苗。
        \item 发现病例后24小时内上报疫情。
    \end{enumerate}
\end{itemize}

\textbf{5. 疯牛病/牛海绵状脑病（BSE，熟悉）：}
由朊病毒（Prion）引起，病理改变是脑海绵状变性，伴严重神经系统症状和体征。可传播性海绵状脑病（TSE）在人类中表现为克-雅病（CJD）。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}朊病毒是一种不含核酸的蛋白质感染因子，\keyword{对理化因素抵抗力极强}，普通煮沸、紫外线、电离辐射均不能将其灭活。需134$^\circ$C高压蒸汽灭菌1小时以上。
    \item \textbf{临床表现：}食用被疯牛病病原污染的牛肉、牛脑髓的人，有可能患CJD，造成致命性神经变性。CJD是疯牛病在人类的表现形式，病人最初表现为冷漠、进行性共济失调、记忆受损、阵发性痉挛，多在1年内死于全身感染。
    \item \textbf{预防：}严格控制被该病污染的动物组织尤其是神经组织进入食物链；防止献血和捐献器官传播；防止医源性感染。
\end{itemize}

\textbf{6. 布鲁氏菌病（Brucellosis，熟悉）：}
由布鲁氏菌引起的慢性接触性传染病，绵羊、山羊、牛、猪易感。
\begin{itemize}[leftmargin=*]
    \item \textbf{病原：}革兰氏阴性的短小杆菌，有荚膜，无芽胞，无鞭毛，为需氧菌。加热60$^\circ$C、10分钟即被杀灭，对一般消毒剂敏感。
    \item \textbf{传播途径：}消化道（饮用未消毒的乳和乳制品）、皮肤、黏膜、呼吸道。
    \item \textbf{临床表现：}人感染布鲁氏菌较家畜严重，病情复杂，表现为乏力、全身软弱、食欲缺乏、失眠、咳嗽，有白色痰，可听到肺部干鸣音，多呈波浪热（特征性），也有稽留热、不规则热或不发热，睾丸肿大。
    \item \textbf{预防：}
    \begin{enumerate}
        \item 严格控制被该病污染的动物组织尤其是神经组织进入食物链。
        \item 防止献血和捐献器官传播。
        \item 防止医源性感染。
    \end{enumerate}
\end{itemize}
\end{defbox}

\subsection{食源性寄生虫病}
% =====================================================================

\begin{keybox}
\textbf{1. 囊虫病（Cysticercosis，掌握）：}
病原体在牛为无钩绦虫，在猪为有钩绦虫。牛、羊、猪是绦虫的中间宿主，其幼虫在猪和牛肌肉组织内形成囊尾蚴，故本病亦称囊尾蚴病。
\begin{itemize}[leftmargin=*]
    \item 人食入未煮熟的含囊尾蚴的猪/牛肉后，囊尾蚴在肠道发育为成虫（绦虫病）。人若误食绦虫卵，可在自身组织内形成囊尾蚴（囊虫病），以脑、眼、皮下组织最常见。
    \item 肉品检验中囊尾蚴的检验部位：猪在咬肌、深腰肌和膈肌；牛在咬肌、舌肌和心肌。
\end{itemize}

\textbf{2. 旋毛虫病（Trichinosis，掌握）：}
病原体为旋毛虫，多寄生于猪、狗、熊、野猪、猫和鼠等体内。主要寄生部位为膈肌、舌肌和心肌，而膈肌最常见。
\begin{itemize}[leftmargin=*]
    \item 人吃了未彻底煮熟煮透、带有旋毛虫的病畜肉后，经约一周左右，幼虫在体内即发育为成虫。侵入肠黏膜并产生新生幼虫，随血循环散布至全身横纹肌。
    \item 临床症状：早期胃肠道症状（恶心、呕吐、腹泻），随后出现发热、肌肉疼痛（最突出症状）、眼睑水肿。
\end{itemize}

\textbf{3. 弓形虫病（Toxoplasmosis，了解）：}
\begin{itemize}[leftmargin=*]
    \item 病原体为刚地弓形虫（Toxoplasma gondii），猫是终宿主。人主要通过食入未煮熟的含弓形虫包囊的肉类或接触猫粪便污染的食物而感染。
    \item 免疫功能正常者多为隐性感染。免疫功能缺陷者（如艾滋病患者）可引起严重甚至致死性弓形虫脑炎。孕期初次感染可导致胎儿先天性弓形虫病（脑积水、视网膜脉络膜炎等）。
\end{itemize}
\end{keybox}

\subsection{食物过敏}
% =====================================================================

\begin{keybox}
\textbf{食物过敏（food allergy）的概念（掌握）：}
食物的超敏反应，是指摄入体内的食物中的某组成成分，作为抗原诱导机体产生免疫应答而发生的一种变态反应性疾病。存在于食品中可以引发人体食品过敏的成分称为食物致敏原（allergen）。
\end{keybox}

\textbf{食物过敏的基本特点：}
\begin{enumerate}[leftmargin=*]
    \item 任何食物均可诱发过敏，但少数食物是主要过敏原
    \item 仅有部分食物成分具有变应原性，特定蛋白质为主要致敏成分
    \item 不同食物间可发生交叉过敏反应
    \item 食物加工可改变致敏性：加热可使部分过敏原变性降低致敏性，但某些热稳定型过敏原不受加热影响
\end{enumerate}

\textbf{八大类主要致敏食物：}
\begin{enumerate}[leftmargin=*]
    \item 牛奶（Milk）
    \item 鸡蛋（Eggs）
    \item 花生（Peanuts）
    \item 大豆（Soy）
    \item 谷物（小麦等，Grains/Wheat）
    \item 鱼类（Fish）
    \item 甲壳类（Crustaceans）
    \item 坚果类（Tree Nuts）
\end{enumerate}

\section{食物中毒}

\subsection{食物中毒的定义}

\begin{keybox}
\textbf{食物中毒（food poisoning）的定义（掌握）：}
指食用了被有毒有害物质污染的食品或者食用了含有毒有害物质的食品后出现的急性、亚急性疾病。
\end{keybox}

% [补充自往届笔记]
食物中毒亦可表述为：摄入含生物性、化学性有毒有害物质的食品或把有毒有害物质当作食品摄入后出现的非传染性急性、亚急性疾病。

\subsection{食物中毒的分类}

按发病原因分为以下五类：
\begin{enumerate}[leftmargin=*]
    \item \textbf{细菌性食物中毒：}发病率最高、中毒人数最多
    \item \textbf{真菌及其毒素食物中毒}
    \item \textbf{有毒动物中毒：}如河豚鱼中毒
    \item \textbf{有毒植物中毒：}如毒蕈中毒
    \item \textbf{化学性食物中毒：}如亚硝酸盐中毒、有机磷农药中毒
\end{enumerate}

\subsection{食物中毒的特点（掌握）}

\begin{keybox}
\textbf{食物中毒的临床发病特点：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{潜伏期短、发病突然：}短时间内或一二天内有很多人发病，以集体暴发较多见。
    \item \textbf{发病与食物有关：}病人有食用同一有毒食物史，流行波及范围与有毒食物供应范围相一致，停止该食物供应后，流行即终止。
    \item \textbf{患者临床症状相同或相似：}大多数食物中毒以急性胃肠炎为主要表现。
    \item \textbf{一般情况下，人与人之间不直接传染：}不会由食物中毒患者直接传染给健康人。发病曲线呈突然上升之后又迅速下降的趋势，无传染病流行时的余波（拖尾现象）。
\end{enumerate}
\end{keybox}

\begin{keybox}
\textbf{食物中毒的流行病学特点：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{发病的季节性明显：}细菌性食物中毒主要发生在6$\sim$10月，化学性食物中毒季节性不明显，全年均可发生。
    \item \textbf{发病的地区性特点：}明显的地区性，与各地的食品品种和饮食习惯有关。
    \item \textbf{食物中毒原因的分布特点：}食物中毒的发生与吃某种食物有关，患者只局限于食用同一种食物的人群中，停止食用该食物后，发病即停。
    \item \textbf{食物中毒病死率特点：}发病率高，病死率低。食物中毒的病死率较低，死亡人数以有毒动植物食物中毒最多，其次为化学性食物中毒，微生物性食物中毒引起的死亡较少。
    \item \textbf{食物中毒发生场所分布特点：}集体暴发常以节假日改善伙食或集餐多见，与原料不新鲜、食品处理保管不当有关。
\end{enumerate}
\end{keybox}

\section{细菌性食物中毒}

\subsection{细菌性食物中毒的定义}

\begin{keybox}
\textbf{细菌性食物中毒（bacterial food poisoning）：}
指因摄入被致病性细菌或其毒素污染的食物而引起的中毒。细菌性食物中毒是最常见的食物中毒。
\end{keybox}

\subsection{细菌性食物中毒的流行病学特点}

\begin{keybox}
\textbf{细菌性食物中毒的流行病学特点（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{发病率及病死率：}发病率高，但病死率低。细菌性食物中毒无论在发病起数，还是发病人数上均居首位。病死率低。
    \item \textbf{季节性：}夏秋季发病率高。绝大多数细菌性食物中毒发生在温暖的5$\sim$10月较多。
    \item \textbf{中毒食品种类：}动物性食品是引起细菌性食物中毒的主要食品，畜肉类及其制品居首位，其次为禽肉、鱼、乳、蛋类。
\end{enumerate}
\end{keybox}

\subsection{发生原因与发病机制（掌握）}\difficulty

\begin{keybox}
\textbf{细菌性食物中毒发生原因：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{致病菌污染：}畜禽宰杀前后污染（生前感染或宰后污染）；食品在运输、储存、销售过程中污染。
    \item \textbf{储存方式不当：}高温、水分多、适宜pH、营养条件使致病菌大量繁殖。
    \item \textbf{烹调方式不当：}食用前未煮熟或者熟食受到生熟交叉感染或食品从业人员中带菌者的污染，以至食用后引起中毒。
\end{enumerate}
\end{keybox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{细菌性食物中毒的发病机制（三种类型，补充）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{感染型：}靠侵袭力附着于肠黏膜或侵入黏膜及黏膜下层，引起肠黏膜充血、白细胞浸润、水肿、渗出等炎性病理变化。除引起腹泻等胃肠道综合征外，病原菌还进入黏膜固有层，被吞噬细胞吞噬或杀灭，菌体裂解，释放内毒素。内毒素可作为致热原，刺激体温调节中枢，引起体温升高和发热。典型病原菌有沙门氏菌和变形杆菌等。
    \item \textbf{毒素型：}肠毒素激活肠壁上皮细胞腺苷酸环化酶或鸟苷酸环化酶，使胞浆内环磷酸腺苷或环磷酸鸟苷浓度升高，通过蛋白质磷酸化过程，进一步激活细胞内相关酶系统，使细胞分泌功能变化。通过抑制肠壁上皮细胞对Na$^+$的吸收，促进Cl$^-$分泌，使Na$^+$、Cl$^-$和水在肠腔潴留致腹泻。典型病原菌有金黄色葡萄球菌等。
    \item \textbf{混合型：}典型病原菌有副溶血性弧菌。
\end{enumerate}
\end{tipbox}

\subsection{细菌性食物中毒的临床表现}

以急性胃肠炎为主，主要表现为恶心、呕吐、腹痛、腹泻等。

\subsection{细菌性食物中毒的防治原则}

\begin{keybox}
\textbf{细菌性食物中毒的防治原则：}

\textbf{（一）预防措施：}防止污染、控制细菌繁殖、杀灭细菌三管齐下。
\begin{enumerate}[leftmargin=*]
    \item \textbf{防止污染：}
    \begin{itemize}
        \item 加强食品卫生质量检查和监督管理，严格遵守牲畜屠宰前、屠宰中和屠宰后的卫生要求，防止污染。
        \item 食品加工、储存和销售过程要严格遵守卫生制度，做好食具、容器和工具的消毒，避免生熟交叉感染。
        \item 食品加工人员、医院、托育机构人员和炊事员应认真执行就业前体检和录用后定期体检制度，应经常接受食品卫生教育，养成良好的个人卫生习惯。
    \end{itemize}
    \item \textbf{控制细菌繁殖或产生毒素：}在低温或通风阴凉处存放食品以控制细菌繁殖和毒素的形成。
    \item \textbf{高温杀灭病原体：}食品食用前充分加热以杀灭病原体和破坏毒素。
    \item \textbf{对有毒的动植物中毒的预防措施：}主要是鉴别有毒品种。
    \item \textbf{加强安全保管，防止误食或误用。}
\end{enumerate}

\textbf{（二）治疗原则：}
\begin{enumerate}[leftmargin=*]
    \item 对症治疗：治疗腹痛、腹泻、电解质紊乱等。
    \item 特殊治疗：合适的抗菌素（葡萄球菌性食物中毒一般不用）；肉毒杆菌性食物中毒早期使用多价抗毒血清。
\end{enumerate}
\end{keybox}

\subsubsection{一、沙门氏菌食物中毒（掌握）}

\begin{keybox}
\textbf{沙门氏菌食物中毒：}

\textbf{（1）病原菌：}沙门氏菌属（Salmonella），革兰阴性杆菌。\keyword{不分解蛋白质、不产生靛基质}（吲哚），因此\textbf{污染食品后无感官性状改变}——这是其最危险的特性。

\textbf{（2）流行病学特点：}
\begin{itemize}[leftmargin=*]
    \item \textbf{宿主：}在人和动物中有广泛的宿主。
    \item \textbf{中毒食品种类：}多由动物性食物引起，特别是畜肉类及其制品，其次为禽肉、蛋类、奶类及其制品。生前感染和宰后污染两方面，生前感染是肉类食品中沙门氏菌的主要来源。
    \item \textbf{禽蛋类污染：}家禽、蛋类及其制品感染或污染沙门氏菌的机会比较多，尤其是鸭、鹅等水禽及其蛋类带菌率一般为\imp{30\%}$\sim$\imp{40\%}。
    \item \textbf{乳类污染：}患沙门氏菌病奶牛的奶可致奶中带菌，即使健康奶牛的奶在挤出后可以受到带菌奶牛粪便或其他污物的污染。
    \item \textbf{熟制品再污染：}烹调后的熟制品如熟肉、卤肉、内脏、煎蛋等可再次受到生熟交叉污染或食品从业人员带菌者的污染。
    \item \textbf{发病季节分布：}多见于夏秋两季。该两季发病起数和发病人数可达全年发病总起数和总人数的\imp{80\%}。
    \item \textbf{发病率：}发病率高，一般为\imp{40\%}$\sim$\imp{60\%}，最高可达\imp{90\%}。
\end{itemize}

\textbf{其影响因素：}
\begin{itemize}[leftmargin=*]
    \item \textbf{活菌数量多少：}\imp{10万}$\sim$\imp{10亿}个沙门菌进入肠道才出现临床症状。
    \item \textbf{菌型致病力强弱：}以猪霍乱沙门菌致病力最强，鼠伤寒沙门氏菌次之。
    \item \textbf{个体易感性高低：}幼儿、体弱老人及其他疾病患者是易感性高的人群。
\end{itemize}

\textbf{（3）发病机制：}\difficulty
\begin{itemize}[leftmargin=*]
    \item 感染型为主。某些沙门氏菌如鼠伤寒沙门氏菌、肠炎沙门氏菌所产生的肠毒素在导致食物中毒发生中起到重要作用。
    \item 侵袭肠黏膜，抑制小肠黏膜细胞对Na$^+$的吸收，促进Cl$^-$的分泌，使Na$^+$、Cl$^-$和水在肠腔潴留而致腹泻。
\end{itemize}

\textbf{（4）临床特点：}\keyword{潜伏期12$\sim$36h}。\textbf{发热}、恶心呕吐、\textbf{腹痛腹泻（水样便或黄绿色稀便）}。

\textbf{（5）预防措施：}抓住三个环节。
\begin{itemize}[leftmargin=*]
    \item 防止食品被沙门氏菌污染。严格控制沙门氏菌的肉类食物，防止其流入市场。
    \item 严格遵循合理屠宰过程的卫生学要求，避免肉尸受到带菌皮毛、粪便污水、容器等污染。
    \item 食品在储藏、运输、加工、烹调或销售各个环节加强卫生管理。防止食品的生熟交叉污染和食品从业人员带菌者对熟食的污染。
    \item 食品在食用前彻底加热以杀灭病原体。
\end{itemize}
\end{keybox}

\subsubsection{二、副溶血性弧菌食物中毒（掌握）}

\begin{keybox}
\textbf{副溶血性弧菌食物中毒：}副溶血性弧菌食物中毒是我国沿海地区最常见的一种食物中毒。

\textbf{（1）病原菌：}副溶血性弧菌（嗜盐菌），为革兰氏阴性杆菌，呈弧状、杆状、丝状等多种形态，无芽胞，主要存在于近岸海水、海底沉积物和鱼、贝类等海产品中。\keyword{嗜盐菌}——最适生长盐浓度\imp{3.5\%} NaCl，淡水环境中迅速死亡。

\textbf{（2）致病力检验：}神奈川（Kanagawa）试验：该菌能使人或家兔的红细胞发生溶血，在血琼脂培养基上出现$\beta$溶血带，称为"神奈川试验"阳性。\imp{90\%}的致病性菌株为神奈川现象阳性。

\textbf{（3）流行病学特点：}
\begin{itemize}[leftmargin=*]
    \item \textbf{地区分布：}我国沿海地区为副溶血性弧菌食物中毒的高发区。
    \item \textbf{季节性及易感性：}\imp{7$\sim$9月}是副溶血性弧菌食物中毒的高发季节。以青壮年为多。
    \item \textbf{中毒食品种类：}主要是海产食品，墨鱼的带菌率达\imp{93\%}；其次为盐渍食品，如咸菜、腌制的畜禽类食品等。
    \item \textbf{食品中副溶血性弧菌的来源：}海水及沉积物中含有副溶血性弧菌，海产品容易受到污染而带菌率高。沿海地区的饮食从业人员、健康人群及渔民带菌者。
\end{itemize}

\textbf{（4）致病机制：}\difficulty
肠黏膜细胞及黏膜下炎症反应等病理病变，并可产生肠毒素及耐热性溶血毒素。大量活菌和耐热型溶血毒素共同作用于肠道，引起急性胃肠道症状。

\textbf{（5）临床特点：}\keyword{潜伏期6$\sim$12h}。\textbf{上腹阵发性绞痛}（最突出的特点！）、\textbf{水样便或洗肉水样便}（血水样便）、里急后重不明显。发热较明显（37.5$\sim$39.5$^\circ$C）。

\textbf{杀菌条件：}\keyword{56$^\circ$C加热5分钟或90$^\circ$C加热1分钟即可杀灭}；\keyword{含1\%食醋处理5分钟即可杀灭}——食用海鲜蘸醋对预防有意义。

\textbf{（6）预防措施：}紧紧抓住防止污染、控制繁殖和杀灭病原体的三个主要环节。其中\textbf{控制繁殖和杀灭病原菌尤为重要}。
\end{keybox}

\begin{exambox}
\textbf{副溶血性弧菌三大特征：}嗜盐性（3.5\% NaCl最适）、神奈川现象（90\%致病株阳性）、血水样便（洗肉水样便）。
\end{exambox}

\subsubsection{三、金黄色葡萄球菌食物中毒（掌握）}

\begin{keybox}
\textbf{金黄色葡萄球菌食物中毒：}

\textbf{（1）病原菌：}金黄色葡萄球菌，产肠毒素的菌株凝固酶试验常呈阳性。

\textbf{（2）流行病学特点：}
\begin{itemize}[leftmargin=*]
    \item 是最常见的化脓性球菌之一。
    \item \textbf{季节性：}全年皆可发生，但多见于夏秋季。
    \item \textbf{中毒食品种类：}主要是营养丰富且含水分较多的食品，如奶、肉、蛋、鱼及其制品，剩饭。
\end{itemize}

\textbf{（3）食品被污染的原因：}
食物中金黄色葡萄球菌的来源广泛：
\begin{itemize}[leftmargin=*]
    \item 人类带菌者对各种食物的污染（\keyword{最重要的污染来源！}人体鼻咽部带菌率20\%$\sim$50\%，皮肤化脓性病灶含大量致病性葡萄球菌）。
    \item 奶牛患化脓性乳腺炎时，其乳汁中可能带有葡萄球菌。
    \item 畜、禽患其他化脓性感染时，感染部位的葡萄球菌对其肉尸的污染。
\end{itemize}

\textbf{（4）影响肠毒素形成的因素：}
\begin{itemize}[leftmargin=*]
    \item 葡萄球菌污染的程度
    \item 食物存放的湿度及环境
    \item 食品的种类及性状
\end{itemize}

\textbf{（5）发病机理：}\difficulty
毒素型食物中毒。呕吐的机理目前未全部阐明，用恒河猴实验，其肠毒素可能以完整的分子吸收如血。

\textbf{（6）中毒机制：}\keyword{肠毒素（毒素型）}。金黄色葡萄球菌在食品中繁殖时产生肠毒素，该肠毒素\textbf{耐热}——\keyword{100$^\circ$C加热2h才被破坏}，普通烹调方法难以彻底破坏。

\textbf{（7）临床表现：}发病急骤，潜伏期短，一般为\imp{2$\sim$4小时}，最短\imp{1小时}。胃肠道症状明显，如恶心、呕吐、中上腹部疼痛、腹泻等，以\textbf{呕吐最为显著}。\keyword{体温一般正常}。

\textbf{（8）预防措施：}
\begin{itemize}[leftmargin=*]
    \item 防止葡萄球菌污染食物
    \item 防止葡萄球菌对奶的污染
    \item \keyword{患局部化脓性感染的畜、禽肉尸应按病变部位除去后，按条件可食肉经高温处理以熟制品出售。}
    \item \keyword{有局部化脓性感染或上呼吸道感染者应暂时调离食品工作岗位！}
\end{itemize}
\end{keybox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{金黄色葡萄球菌肠毒素中毒机制（补充）：}摄入含金黄色葡萄球菌活菌而无肠毒素的食物不会引起食物中毒，摄入达到中毒剂量的肠毒素才会中毒。肠毒素作用于胃肠黏膜，引起充血、水肿、糜烂等炎症变化和水电解质代谢紊乱，出现腹泻，同时刺激迷走神经的内脏分支引起反射性呕吐。
\end{tipbox}

\subsubsection{四、肉毒梭菌食物中毒（掌握）}\difficulty

\begin{keybox}
\textbf{肉毒梭菌食物中毒：}

\textbf{（1）病原菌：}肉毒梭菌G$^+$、厌氧、产芽孢杆菌，产生的肉毒毒素引起中毒。肉毒毒素是一种毒性很强的神经毒素。

\textbf{（2）流行病学特点：}
\begin{itemize}[leftmargin=*]
    \item \textbf{季节性：}一年四季均可发生，主要发生在\imp{4$\sim$5月}。
    \item \textbf{地区分布：}A型主要分布于山区和未开垦的荒地；B型多分布于草原区耕地；E型多存在土壤、湖海淤泥和鱼类肠道中；F型分布于欧、亚、美洲海洋沿岸及鱼体。
    \item \textbf{中毒食品种类：}家庭自制谷类或豆类发酵品为多见，如臭豆腐、豆酱、面酱等，中国以\textbf{植物性食品为主}（占\imp{91.48\%}），新疆地区发病率最高。
    \item \textbf{来源及食物中毒的原因：}食物中的肉毒梭菌主要来源于带菌的土壤、尘埃及粪便，尤其是带菌的土壤，并对各类食品原料造成污染。
\end{itemize}

\textbf{（3）中毒机制：}\difficulty
\keyword{外毒素——肉毒毒素（botulinum toxin）}，是\textbf{已知最剧烈的神经毒素}。毒素经小肠激活后，主要作用于中枢神经系统的脑神经核、神经肌肉的连接部和自主神经末梢，抑制神经末梢乙酰胆碱的释放，导致肌肉麻痹和神经功能障碍。人的致死剂量约10$^{-9}$mg/kg体重，毒性比KCN强10\,000倍。

\textbf{（4）临床特点：}\keyword{潜伏期数小时至数天，一般为12$\sim$48h}。以\textbf{运动神经麻痹的症状为主}，而胃肠道症状少见。临床特征表现为\textbf{对称性脑神经受损的症状}：早期头痛、头晕、乏力、走路不稳，以后逐渐出现\textbf{视力模糊、眼睑下垂、瞳孔散大}等神经麻痹症状。\textbf{病死率极高}。

\textbf{（5）芽胞耐热性：}\keyword{干热180$^\circ$C 5$\sim$15分钟，湿热100$^\circ$C 5小时，高压蒸汽灭菌121$^\circ$C 30分钟。}

\textbf{（6）治疗：}\keyword{尽早使用多价肉毒抗毒素血清}（A、B、E型），同时对症支持治疗。

\textbf{（7）婴儿肉毒中毒：}\keyword{蜂蜜是1岁以下婴儿肉毒中毒的嫌疑食品}，主要为E型。

\textbf{（8）预防：}
\begin{itemize}[leftmargin=*]
    \item 食品加工前应对食品原料进行彻底清洁处理，特别是肉毒中毒好发地区，土壤、粪便该菌带菌率高，要求更应严格。
    \item 罐头食品生产和制品发酵食品时，应彻底杀灭肉毒梭菌芽孢。
    \item 加工后的食品应避免再污染和在较高温度或缺氧条件存放，防止毒素产生。
    \item \keyword{肉毒梭菌毒素不耐热}，对可疑食物进行彻底加热是破坏毒素预防中毒发生的可靠措施。
    \item 避免不洁之物进入口内。
    \item \textbf{消灭疫源地是解决肉毒中毒的根本措施。}
    \item 家庭自制密封发酵食品为高危风险食品；罐头食品鼓盖/漏气绝对不要购买食用。
    \item 加强卫生宣教，建议牧民改变肉类储藏方式或生吃牛肉的饮食习惯。
\end{itemize}
\end{keybox}

\subsection{其它细菌性食物中毒（了解）}

\begin{defbox}
\textbf{其它细菌性食物中毒的特点与预防：}

\textbf{1. 李斯特菌食物中毒：}
\begin{itemize}[leftmargin=*]
    \item \textbf{病原菌：}主要是单核细胞增生李斯特氏菌，本身可致病，可在血液琼脂上产生李斯特氏菌溶血素O的$\beta$-溶血素。\keyword{在5$^\circ$C低温条件下仍能生长}是该菌的特征。
    \item \textbf{食品中李斯特菌的来源：}冰箱中保存时间过长的乳制品和肉制品多见。
    \item \textbf{特有的中毒表现：}侵袭型李斯特菌中毒突出表现有脑膜炎、败血症、流产或死胎等。
    \item \textbf{预防与治疗：}对冰箱冷藏的熟肉制品及直接入口的方便食品、牛乳等，食用前要彻底加热。
\end{itemize}

\textbf{2. 大肠埃希菌食物中毒：}引起食物中毒的致病性大肠埃希菌血清型主要有：\textbf{O157:H7、O111:B4、O55:B5}等。

\textbf{3. 变形杆菌食物中毒：}
\begin{itemize}[leftmargin=*]
    \item \textbf{病原菌：}引起食物中毒的变形杆菌主要是普通变形杆菌、奇异变形杆菌。该菌可以在低温储存的食品中繁殖。对热的抵抗力不强，加热55$^\circ$C持续1小时即可将其杀灭。
    \item \textbf{中毒食品种类：}主要是动物性食品，特别是熟肉及内脏熟制品。
    \item \textbf{中毒机制：}大量活菌侵入肠道引起的感染型食物中毒；摩氏摩根菌等组氨酸脱羧酶活跃，可引起组胺过敏样中毒。
\end{itemize}

\textbf{4. 蜡样芽孢杆菌食物中毒：}
\begin{itemize}[leftmargin=*]
    \item \textbf{病原菌：}蜡样芽胞杆菌，产致病性肠毒素包括腹泻毒素和呕吐毒素。腹泻毒素毒性作用类似大肠埃希氏菌和霍乱弧菌产生的毒素，腹泻毒素不耐热、对胰蛋白酶敏感；呕吐毒素耐热，对胰蛋白酶不敏感。
    \item \textbf{流行病学特点：}季节性明显，以夏、秋季，尤其是6$\sim$10月为多见。引起中毒的食品种类繁多：包括米粉、米饭、乳及乳制品、肉类制品、蔬菜等。食物受蜡样芽胞杆菌污染的机会多，带菌率较高；受该菌污染的食物在通风不良及温度较高的条件下存放时，其芽胞便可发芽并产生毒素，若食用前不加热或加热不彻底，即可引起食物中毒。
    \item \textbf{预防措施：}控制繁殖：奶类、肉类和米饭等食物只能在低温条件下短时间存放；食用前加热：剩饭及其他熟食在食用前必须彻底加热。
\end{itemize}

\textbf{5. 椰毒假单胞菌酵米面亚种食物中毒：}
\begin{itemize}[leftmargin=*]
    \item \textbf{别名：}臭米面食物中毒。椰毒假单胞菌酵米面亚种产外毒素引起。中毒食品种类主要是谷物类发酵食品，为米酵菌酸和毒黄素所致中毒。
    \item \textbf{中毒机理：}米酵菌酸作用于细胞线粒体内膜；毒黄素作用于细胞呼吸链系统。
    \item \textbf{临床症状：}胃肠道症状和神经症候群的出现较早。继消化道症状后，也可能出现肝大、肝功能异常等中毒型肝炎为主的临床表现，重症者出现肝性昏迷，甚至死亡。
\end{itemize}
\end{defbox}

\section{动植物性食物中毒}

\subsection{河豚鱼中毒（掌握）}

\begin{keybox}
\textbf{河豚中毒：}

\textbf{（1）有毒成分来源：}\keyword{河豚毒素（Tetrodotoxin, TTX）}，是一种非蛋白质神经毒素，毒性比氰化钠强。\textbf{对热稳定，煮沸、盐腌、日晒均不易被破坏。}毒素分布：\keyword{河豚毒素含量在卵巢、肝脏和肠中最高}，皮肤中只含少量的河豚毒素。新鲜洗净的肌肉基本无毒。每年\textbf{春季（2$\sim$5月）}为卵巢发育期，毒性最强。

\textbf{（2）中毒机制：}\difficulty
\begin{itemize}[leftmargin=*]
    \item TTX直接作用于胃肠道，引起局部刺激作用。
    \item TTX\textbf{选择性阻断细胞膜对Na$^+$的通透性}，使神经传导阻断，呈麻痹状态。先麻痹神经末梢和感觉神经，后麻痹运动神经和中枢神经系统。严重者脑干麻痹。
    \item 引起外周血管扩张，血压下降，最后出现呼吸中枢和血管运动中枢麻痹，导致急性呼吸衰竭，危及生命。
\end{itemize}

\textbf{（3）临床特点：}\keyword{潜伏期10min$\sim$3h}。发病急而剧烈，按顺序出现：
\begin{enumerate}[leftmargin=*]
    \item \textbf{先感觉神经麻痹：}手指、\textbf{口唇、舌尖发麻}刺痛
    \item \textbf{后运动神经麻痹：}恶心、呕吐、四肢无力、肌肉麻痹、全身瘫痪
    \item \textbf{最后呼吸麻痹死亡：}呼吸衰竭是致死主要原因。通常死于发病后4$\sim$6小时，最快1.5小时。
\end{enumerate}

\textbf{（4）治疗：}无特效解毒药！尽早洗胃+导泻+对症支持治疗（维持呼吸、升压等）。肾上腺皮质激素和莨菪碱类药物可辅助使用。

\textbf{（5）预防：}
\begin{itemize}[leftmargin=*]
    \item \keyword{禁止销售河豚鱼。}严禁餐饮单位经营加工河豚鱼，加强宣传教育。
    \item 加强卫生宣传教育，首先让居民认识到野生河豚有毒，不要食用；其次让居民能识别河豚，以防误食。
    \item 水产品相关部门严格把关，防止野生河豚进入市场或混进其他水产品中。
    \item 采用河豚去毒工艺。
\end{itemize}
\end{keybox}

\subsection{鱼类引起的组胺中毒（掌握）}

\begin{keybox}
\textbf{鱼类引起的组胺中毒：}

\textbf{（1）有毒成分来源：}过敏性中毒。海产鱼类中的\textbf{青皮红肉鱼}（如鲐鱼/鲭鱼、竹夹鱼、金枪鱼、秋刀鱼等）鱼体中含有较多的组氨酸。当鱼体不新鲜或腐败时，发生自溶作用，组氨酸被释放出来。含组胺无色杆菌或摩氏摩根菌（Morganella morganii）产生\textbf{组氨酸脱羧酶}，使组氨酸脱羧基形成大量的\textbf{组胺}。

\textbf{（2）中毒机制（掌握）：}
\begin{itemize}[leftmargin=*]
    \item 组胺使支气管平滑肌强烈收缩，引起支气管痉挛。
    \item 循环系统表现为局部或全身的毛细血管扩张，面部、胸部和全身皮肤潮红，病人出现低血压、心律失常，甚至心脏骤停。
\end{itemize}

\textbf{（3）临床表现：}发病急、症状轻、恢复快。潜伏期一般数分钟至数小时。食用后迅速出现面部、胸部及全身皮肤潮红和热感，全身不适，血压下降、心律失常。一般体温正常，大多在1$\sim$2天内恢复健康。

\textbf{（4）治疗和预防措施：}
\begin{itemize}[leftmargin=*]
    \item \textbf{治疗：}抗组胺药物（如苯海拉明、扑尔敏等），口服盐酸苯海拉明；或静脉注射10\%葡萄糖酸钙+口服维生素C，对症支持治疗。
    \item \textbf{预防：}
    \begin{itemize}
        \item 防止鱼类腐败变质，禁止出售腐败变质的鱼类。
        \item 鱼类食品必须在冷冻条件下储藏和运输，防止组胺产生。
        \item 避免食用不新鲜或腐败变质的鱼类食品。
        \item 对易产生组胺的青皮红肉鱼类，家庭烹调前可采取一些去毒措施。
        \item 制定鱼类食品中组胺最大允许含量标准：高组胺鱼类（青皮红肉海水鱼）组胺限值 $\leq$ \imp{40 mg/100g}。
    \end{itemize}
\end{itemize}
\end{keybox}

\subsection{毒蕈中毒（掌握）}\difficulty

\begin{keybox}
\textbf{毒蕈中毒：}

\textbf{（1）基本概况：}我国已知毒蕈约80余种，含剧毒可致死的不超过10种。\textbf{毒蕈的特点：}毒蕈颜色美丽，长有疣状物，表面粘脆，蕈柄上有蕈环、蕈托；多生长在腐物或粪肥上，多数不生虫子，有腥辣、苦、酸、臭味，碰坏后易变色或流出乳状汁。

\textbf{（2）有毒成分来源：}
\begin{itemize}[leftmargin=*]
    \item 毒肽（Phallotoxins）：为肝毒，毒性强，作用缓慢。
    \item 毒伞肽（Amanitins）：肝肾毒性，作用强。
    \item 毒蝇碱（Muscarine）：作用类似于乙酰胆碱。
    \item 光盖伞素（Psilocybin）：引起幻觉和精神症状。
    \item 鹿花毒素（Gyromitrin）：导致红细胞破坏。
\end{itemize}
总结：神经、精神毒素：毒蝇碱、鹅膏蕈氨酸、光盖伞素、致幻剂。肝肾毒素：毒肽类、毒伞肽类。肝肾损害型中毒危险性大，死亡率高。

\textbf{（3）中毒分型：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{胃肠炎型：}
    \begin{itemize}
        \item 毒素：胃肠毒素
        \item 潜伏期短（10min$\sim$6h），恶心、呕吐、腹痛、腹泻
        \item 对症支持治疗，预后良好
    \end{itemize}
    \item \textbf{神经精神型：}
    \begin{itemize}
        \item 毒素：神经精神毒素（毒蝇碱、裸盖菇素等）
        \item 出汗、流涎、瞳孔缩小、幻视、精神错乱
        \item \keyword{阿托品（Atropine）}拮抗治疗
    \end{itemize}
    \item \textbf{溶血型：}
    \begin{itemize}
        \item 毒素：溶血毒素（鹿花蕈毒素）
        \item 溶血性贫血、黄疸、血红蛋白尿
        \item \keyword{肾上腺皮质激素}治疗
    \end{itemize}
    \item \textbf{肝肾损害型（最严重！）：}
    \begin{itemize}
        \item 毒素：肝肾毒素（毒肽Phallotoxins和毒伞肽Amanitins）
        \item \textbf{病死率最高。}潜伏期长（10$\sim$24h），病情发展可分为6期：
        \begin{enumerate}
            \item 潜伏期（10$\sim$24h）
            \item 胃肠炎期
            \item \textbf{假愈期}（胃肠炎症状缓解但肝脏损害已开始——最易被忽视！）
            \item 内脏损害期（肝、肾、脑、心损害）
            \item 精神症状期（肝性昏迷、中毒性脑病）
            \item 恢复期
        \end{enumerate}
        \item 抢救：\keyword{巯基解毒剂（二巯基丙磺酸钠、二巯基丁二酸钠等）是抢救关键！}
    \end{itemize}
    \item \textbf{类光过敏型：}
    \begin{itemize}
        \item 毒素：类光过敏毒素
        \item 类似日光性皮炎，身体暴露部位明显肿胀、疼痛，嘴唇肿胀外翻
    \end{itemize}
\end{enumerate}

\textbf{（3）治疗：}
\begin{itemize}[leftmargin=*]
    \item 及时催吐、洗胃、导泻、灌肠，迅速排出毒物。\textbf{鹅膏菌中毒：食用后10小时以内彻底洗胃是关键！}
    \item 根据不同毒素和症状采取不同治疗方案：
    \begin{itemize}
        \item 胃肠型：一般食物中毒处理
        \item 神经精神型：阿托品
        \item 溶血型：肾上腺皮质激素
        \item 肝肾损害型：二巯基丙磺酸钠/二巯基丁二酸钠
    \end{itemize}
\end{itemize}

\textbf{（4）预防：}根本方法——不要采摘自己不认识的蘑菇食用。
\end{keybox}

\begin{exambox}
\textbf{肝肾损害型毒蕈中毒的"假愈期"是重要考点：}胃肠炎症状暂时缓解后病情突然恶化，患者和家属误以为已康复，导致错过抢救时机。巯基解毒剂是关键抢救药物。
\end{exambox}

\subsection{亚硝酸盐食物中毒（掌握）}

\begin{keybox}
\textbf{亚硝酸盐食物中毒：}

\textbf{（1）中毒原因：}
\begin{enumerate}[leftmargin=*]
    \item 误食（误将亚硝酸盐当作食盐使用，最危险！建筑工地常见）
    \item 食品添加剂滥用中毒
    \item 食用含有大量硝酸盐、亚硝酸盐的蔬菜而引起中毒——新鲜腌制的蔬菜（"暴腌菜"），\keyword{腌制第4$\sim$8天亚硝酸盐含量达高峰}
    \item 饮用含亚硝酸盐较多的井水中毒（苦井水）
    \item 肠源性青紫症（肠道功能紊乱时，肠道细菌将硝酸盐还原为亚硝酸盐）
\end{enumerate}

\textbf{（2）中毒机制：}\difficulty
亚硝酸盐摄入过量会使血红蛋白中的Fe$^{2+}$氧化为Fe$^{3+}$，使正常血红蛋白转化为\textbf{高铁血红蛋白（MetHb）}，失去携氧能力导致组织缺氧，出现\textbf{肠源性青紫症（发绀）}。亚硝酸盐还对周围血管有麻痹作用。

\textbf{（3）临床特点：}
\begin{itemize}[leftmargin=*]
    \item \keyword{潜伏期10min$\sim$3h}。
    \item \textbf{肠源性青紫病：}\textbf{口唇、指甲及全身皮肤出现青紫}等组织缺氧表现。
    \item 自觉症状：头晕、头痛、乏力、胸闷、心率快、嗜睡或烦躁不安、呼吸急促，并有恶心、呕吐、腹痛、腹泻，严重者昏迷、惊厥、大小便失禁，可因呼吸衰竭导致死亡。
\end{itemize}

\textbf{（4）特效解毒剂：}\keyword{美蓝（亚甲蓝，Methylene Blue）} + \textbf{维生素C}。小剂量美蓝（1$\sim$2 mg/kg）将MetHb还原为Hb；维生素C作为辅助还原剂。

\textbf{（5）预防：}
\begin{itemize}[leftmargin=*]
    \item 加强对集体食堂尤其是学校食堂、工地食堂的管理，禁止餐饮服务单位采购、储存、使用亚硝酸盐，避免误食。
    \item 肉类食品企业要严格按国家标准规定添加硝酸盐和亚硝酸盐。
    \item 保持蔬菜新鲜，勿食存放过久或变质的蔬菜；剩余熟蔬菜不可在高温下存放过久。
    \item 尽量不用苦井水煮饭，不得不用时应避免长时间保温后的水又用来煮饭菜。
    \item \keyword{安全食用腌菜：腌制20天以后亚硝酸盐基本消失}，方可安全食用。
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{暴腌菜风险：}腌制第4$\sim$8天亚硝酸盐含量达峰值，此时食用中毒风险最大！腌制20天以上才安全。误将亚硝酸盐当食盐是化学性食物中毒的最常见原因。
\end{tipbox}

\subsection{有机磷农药中毒（掌握）}

\begin{keybox}
\textbf{有机磷农药中毒：}

\textbf{（1）中毒原因：}误食农药拌过的种子或误把有机磷农药当作酱油或食用油而食用；喷洒农药不久的瓜果、蔬菜，未经安全间隔期即采摘食用；误食被农药毒杀的家禽家畜。

\textbf{（2）中毒机制：}\difficulty
\keyword{抑制胆碱酯酶（ChE）活性}，使其失去催化水解乙酰胆碱（ACh）的能力 $\to$ 大量ACh在体内蓄积 $\to$ 胆碱能神经过度兴奋 $\to$ 出现毒蕈碱样症状、烟碱样症状和中枢神经系统症状。

\textbf{（3）临床特点：}\keyword{潜伏期30min$\sim$3h}。
\begin{enumerate}[leftmargin=*]
    \item \textbf{毒蕈碱样症状（M样症状）：}\keyword{瞳孔缩小}、\keyword{流涎}、\keyword{大汗}、恶心呕吐、腹痛腹泻、支气管痉挛、呼吸困难。
    \item \textbf{烟碱样症状（N样症状）：}\keyword{肌束震颤}（从眼睑、面部小肌群开始，逐渐发展到全身）、肌肉无力甚至瘫痪。
    \item \textbf{中枢神经系统症状：}头晕、头痛、烦躁不安、抽搐、昏迷。严重者因呼吸中枢抑制和呼吸肌麻痹导致呼吸衰竭死亡。
\end{enumerate}

\textbf{（4）全血胆碱酯酶活性分级：}
\begin{itemize}[leftmargin=*]
    \item 急性轻度中毒：全血胆碱酯酶活性降至正常值的\imp{50\%}$\sim$\imp{70\%}
    \item 急性中度中毒：全血胆碱酯酶活性降至正常值的\imp{30\%}$\sim$\imp{50\%}
    \item 急性重度中毒：肺水肿或脑水肿或昏迷或呼吸麻痹，全血胆碱酯酶活性降至正常值的\imp{30\%以下}
\end{itemize}
根据中毒症状的轻重可将急性中毒分为三度。中毒的潜伏期一般在2小时以内，在短期内引起以全血胆碱酯酶活性下降，出现毒蕈碱、烟碱样和中枢神经系统症状为主的全身症状。

\textbf{（5）特效解毒剂：}
\begin{itemize}[leftmargin=*]
    \item 轻度中毒：\keyword{阿托品（Atropine）}
    \item 中/重度中毒：\keyword{阿托品 + 胆碱酯酶复活剂（解磷定Pralidoxime、氯磷定）}
    \item 阿托品拮抗毒蕈碱样症状（对抗ACh蓄积），解磷定使被抑制的胆碱酯酶复活。
\end{itemize}

\textbf{（6）预防：}
\begin{itemize}[leftmargin=*]
    \item 有机磷农药须由专人保管、有固定专用储存场所，其周围不得存放食品。
    \item 喷药容器应专用，配药操作地点应远离畜圈、饮水源和瓜菜地，以防污染。
    \item 喷洒农药必须穿工作服，戴手套、口罩，并在上风向喷洒，喷药后须用肥皂洗净手、脸，方可吸烟、饮水和进食。
    \item 喷洒农药及收获瓜、果、蔬菜，必须遵守安全间隔期。
    \item 严格执行农药安全使用规定；严禁食用被农药毒死的动物。
\end{itemize}
\end{keybox}

\begin{tipbox}
\textbf{有机磷中毒症状速记：}M样 = 毒蕈碱样 —— 流涎、大汗、瞳孔缩小（"水"的症状）；N样 = 烟碱样 —— 肌束震颤（肌肉症状）。特效解毒剂：阿托品（拮抗M样症状）+ 解磷定（复活ChE）。
\end{tipbox}

\subsection{毒鼠强中毒（掌握）}

\begin{keybox}
\textbf{毒鼠强中毒：}

\textbf{（1）病因：}误食毒鼠强拌过的毒饵（误食）；食物在运输、储存过程中被毒鼠强污染（食物被污染）；食用被毒鼠强毒死的禽畜肉（二次中毒）。

\textbf{（2）中毒机制：}\difficulty
毒鼠强（Tetramine，四亚甲基二砜四胺）是\textbf{GABA（$\gamma$-氨基丁酸）受体拮抗剂}，阻断GABA与其受体的结合，使中枢神经系统失去抑制性调控，导致神经极度兴奋。

\textbf{（3）临床表现：}潜伏期短（数分钟至1小时）。以\textbf{反复发作性、强直性、对称性抽搐}为特征性表现。意识丧失、牙关紧闭、口吐白沫、两眼上翻。严重者因呼吸肌痉挛导致呼吸衰竭死亡。

\textbf{（4）治疗与预防：}无特效解毒药！以清除毒物（催吐、洗胃、活性炭吸附）、镇静止痉（苯巴比妥钠、地西泮）、对症支持治疗为主。预防：严禁生产和使用毒鼠强；加强灭鼠药管理。
\end{keybox}

\subsection{瘦肉精中毒（掌握）}

\begin{keybox}
\textbf{瘦肉精中毒（盐酸克伦特罗中毒）：}

\textbf{（1）病因：}\keyword{瘦肉精（Clenbuterol）}即盐酸克伦特罗，属于$\beta$-肾上腺素受体激动剂（$\beta$-agonist），曾被非法用作动物促生长剂，提高瘦肉率。人食用含克伦特罗残留的动物内脏（尤其是猪肝、猪肺）或肉制品后可致中毒。

\textbf{（2）中毒机制：}\difficulty
克伦特罗选择性激动$\beta_2$-肾上腺素能受体，激活腺苷酸环化酶，使cAMP升高，产生拟交感神经兴奋作用。骨骼肌快收缩纤维中的$\beta_2$受体被激动后，肌肉蛋白合成增加、脂肪分解加速，使瘦肉比例增加。

\textbf{（3）临床特点：}\keyword{潜伏期10min$\sim$6h}。主要表现：
\begin{itemize}[leftmargin=*]
    \item \textbf{心血管系统：}\keyword{心悸、心动过速（心率可达120$\sim$150次/分）}、心律失常、血压升高，严重者可出现心室颤动；
    \item \textbf{骨骼肌系统：}\keyword{肌肉震颤}（以面部、四肢骨骼肌为主）、肌无力；
    \item \textbf{神经系统：}头晕、头痛、焦虑、失眠；
    \item \textbf{代谢紊乱：}低钾血症、高血糖。
\end{itemize}
原有高血压、心脏病、甲亢的患者对克伦特罗更敏感，中毒症状更严重。

\textbf{（4）治疗与预防：}无特效解毒药。以\textbf{对症支持治疗}为主：$\beta$受体阻断剂（如普萘洛尔）可拮抗心血管症状；补钾纠正低钾血症；镇静、补液等。\textbf{预防：}严禁使用$\beta$-激动剂作为饲料添加剂；加强畜禽产品（特别是内脏）的药物残留监测；消费者应选择正规渠道购买肉类产品。
\end{keybox}

\begin{exambox}
\textbf{瘦肉精中毒核心特征速记：}$\beta_2$受体激动剂 $\to$ cAMP升高 $\to$ 交感兴奋症状（心悸、心动过速+肌肉震颤）。禁用$\beta$-激动剂类兽药！猪肝、猪肺等内脏残留风险最高。
\end{exambox}

\subsection{砷中毒（掌握）}

\begin{keybox}
\textbf{砷中毒（Arsenic Poisoning）：}

\textbf{（1）病因：}
\begin{enumerate}[leftmargin=*]
    \item 误食（误将含砷农药或灭鼠药当作食盐、面粉使用，最危险！）
    \item 食品加工过程中使用含砷物质（如滥用含砷食品添加剂、使用含砷容器储存酸性食品）
    \item 食用被含砷工业废水、废气污染的农作物和水产品（砷可经食物链在鱼贝类体内富集）
    \item 食用经含砷防腐剂处理的木材熏制或存放的食品
\end{enumerate}

\textbf{（2）中毒机制：}\difficulty
\keyword{三价砷（As$^{3+}$）与体内含巯基（-SH）的酶结合}，形成稳定的砷-巯基复合物，使酶失去活性。\textbf{丙酮酸氧化酶系统}是砷最敏感的酶系统之一，被抑制后丙酮酸不能进一步氧化，导致细胞呼吸障碍。砷还能损害毛细血管内皮细胞，引起\keyword{毛细血管扩张、通透性增加}，导致出血和休克。砷也是一种确认的人类致癌物（皮肤癌、肺癌、膀胱癌等）。

\textbf{（3）临床特点：}\keyword{潜伏期数分钟至数小时}。
\begin{itemize}[leftmargin=*]
    \item \textbf{急性中毒：}
    \begin{enumerate}
        \item \textbf{胃肠型（最常见）：}口服后迅速出现口中有金属味、咽喉烧灼感，随后剧烈恶心、呕吐、腹痛、腹泻（米泔水样便或血水样便），严重者可因脱水和循环衰竭死亡。
        \item \textbf{神经型：}头晕、头痛、抽搐、昏迷，可因呼吸中枢麻痹死亡。
    \end{enumerate}
    \item \textbf{特征性表现：}\keyword{口中有大蒜样气味（砷化氢的气味）}；指甲出现\textbf{Mees线}（白色横纹）。
    \item \textbf{慢性中毒：}长期摄入低剂量砷可导致皮肤色素沉着、掌跖角化、周围神经炎、贫血，以及皮肤癌、肺癌等恶性肿瘤。
\end{itemize}

\textbf{（4）特效解毒剂：}\keyword{巯基解毒剂}——二巯基丙磺酸钠（DMPS）、\keyword{二巯基丁二酸钠（DMSA）}、二巯基丙醇（BAL）。这些药物含有两个巯基，可与砷结合形成稳定无毒络合物从尿中排出。

\textbf{（5）预防：}
\begin{itemize}[leftmargin=*]
    \item 严格管理含砷农药和灭鼠药，不得与食品混放，使用后必须彻底洗手。
    \item 控制工业含砷"三废"排放，防止污染水源和土壤。
    \item 不使用含砷包装材料或容器接触食品。
    \item 加强海产品（贝类、藻类）砷含量监测。
\end{itemize}
\end{keybox}

\subsection{甲醇中毒（掌握）}

\begin{keybox}
\textbf{甲醇中毒（Methanol Poisoning）：}

\textbf{（1）病因：}
\begin{enumerate}[leftmargin=*]
    \item 饮用含甲醇超标的劣质酒或假酒（最常见的原因），不法商贩用工业酒精勾兑白酒。
    \item 食用含甲醇的工业酒精或消毒酒精。
    \item 大量食用含果胶较高的水果发酵酒或蒸馏酒（如薯干酒、柿子酒），果胶在发酵过程中被果胶酯酶分解产生甲醇。
\end{enumerate}

\textbf{（2）中毒机制：}\difficulty
甲醇本身毒性较低，但其代谢产物具有极高毒性。甲醇在体内经\textbf{醇脱氢酶（ADH）}氧化为\textbf{甲醛}，再经\textbf{醛脱氢酶（ALDH）}氧化为\textbf{甲酸}。\keyword{甲酸是甲醇中毒的主要毒性物质}，可抑制细胞色素c氧化酶，引起\textbf{组织缺氧和代谢性酸中毒}。甲酸和甲醛对视网膜细胞有\keyword{高度选择性毒性}，导致视神经萎缩和永久性视力损害。

\textbf{（3）临床特点：}\keyword{潜伏期8$\sim$36小时}（较乙醇中毒长，因甲醇代谢缓慢）。
\begin{itemize}[leftmargin=*]
    \item \textbf{早期：}类似乙醇中毒症状——头痛、头晕、乏力、恶心、呕吐、腹痛。
    \item \textbf{特征性症状——\keyword{眼部损害}（最典型）：}\keyword{视力模糊、眼前飘雪感、畏光、瞳孔散大、视野缩小}，严重者\keyword{双目失明}。眼底检查可见视盘充血、水肿、视网膜水肿，后期出现视神经萎缩。
    \item \textbf{严重中毒：}代谢性酸中毒（呼吸深快）、昏迷、抽搐、休克，可因呼吸中枢麻痹和循环衰竭而死亡。
    \item \textbf{慢性中毒：}长期少量摄入甲醇可出现视野缩小、不可校正的视力减退、视神经萎缩。
\end{itemize}

\textbf{（4）治疗：}
\begin{itemize}[leftmargin=*]
    \item \textbf{清除毒物：}催吐、洗胃（2\%碳酸氢钠溶液），导泻。
    \item \textbf{特效解毒剂：}\keyword{乙醇（ethanol）}——竞争性抑制醇脱氢酶，阻止甲醇转化为甲醛和甲酸，使甲醇以原形从肺和肾排出。也可使用\keyword{甲吡唑（fomepizole，4-MP）}，为ADH抑制剂，疗效更优且副作用较少。
    \item \textbf{纠正酸中毒：}静脉滴注碳酸氢钠。
    \item \textbf{血液透析：}严重中毒者（血甲醇浓度$>$50 mg/dL或有视力损害证据）应及时进行血液透析，可快速清除甲醇和甲酸。
    \item \textbf{对症支持：}维护呼吸、循环功能，保护视神经（维生素B族等）。
\end{itemize}

\textbf{（5）预防：}
\begin{itemize}[leftmargin=*]
    \item \keyword{严禁用工业酒精勾兑食用酒！}
    \item 加强酒类生产监督管理，严格执行甲醇限量标准（以谷类为原料的蒸馏酒甲醇$\leq$0.6 g/L，以薯干为原料的蒸馏酒甲醇$\leq$2.0 g/L）。
    \item 改进酿酒工艺，控制发酵条件，减少果胶分解产生甲醇。
    \item 加强对散装白酒、配制酒的抽检力度。
    \item 消费者应通过正规渠道购买酒类产品，不饮用来路不明的散装酒。
\end{itemize}
\end{keybox}

\begin{exambox}
\textbf{甲醇中毒核心特征速记：}假酒 $\to$ 甲醇 $\to$ 甲酸（ADH/ALDH代谢）$\to$ 代谢性酸中毒 + \textbf{视神经损害（视力模糊$\to$失明）}。特效解毒剂：\textbf{乙醇}（竞争ADH）或甲吡唑。禁用工业酒精勾兑！
\end{exambox}

\section{食物中毒的调查处理}

\subsection{食物中毒调查的目的（掌握）}

\begin{keybox}
\textbf{食物中毒调查的目的：}
\begin{enumerate}[leftmargin=*]
    \item 查明食物中毒暴发事件发病原因，确定是否为食物中毒及中毒性质；确定食物中毒病例；查明中毒食品；确定食物中毒致病因子；查明致病因子的致病途径。
    \item 查清食物中毒发生的原因和条件，并采取相应的控制措施防止蔓延。
    \item 为病人的急救治疗提供依据，并对已采取的急救措施给予补充或纠正。
    \item 积累食物中毒资料，分析中毒发生的特点、规律，制订有效措施以减少和控制类似食物中毒发生。
    \item 收集对违法者实施处罚的证据。
\end{enumerate}
\end{keybox}

\subsection{现场卫生学和流行病学调查}

\begin{keybox}
\textbf{现场调查内容（掌握*）：}

\textbf{1. 调查病人和进食者，了解发病情况。}

\textbf{2. 调查可疑中毒食物及其加工过程。}

\textbf{3. 调查食品从业人员健康状况。}
\end{keybox}

\subsection{食物中毒事件的控制处理}

\begin{keybox}
\textbf{食物中毒事件的控制处理（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{现场处理：}立即停止食用可疑中毒食品；封存可能导致食物中毒的食品及原料、工具、设备和现场；禁止继续销售和食用；追回已售出的中毒食品或可疑中毒食品；对中毒场所、设备、工具进行彻底清洗消毒。
    \item \textbf{对救治方案进行必要的纠正和补充：}尽快排除毒物（催吐、洗胃、导泻）；使用特效解毒剂（如已确定）；对症支持治疗（补充液体、维持电解质平衡、保护脏器功能）。
    \item \textbf{处罚：}对违反食品安全法律法规的责任单位或个人依法进行处罚。
    \item \textbf{信息发布：}按规定及时发布食物中毒信息。
    \item \textbf{撰写调查报告：}分析中毒原因，总结经验教训，完善食品安全管理制度，防止类似事件再次发生。
\end{enumerate}
\end{keybox}

\section{食物过敏的卫生假说}

\begin{tipbox}
\textbf{卫生假说（Hygiene Hypothesis）：}免疫系统在进化过程中为应对肠道寄生虫而设计，现代社会中缺乏肠道寄生虫感染，导致免疫系统过度活跃，对无害食物抗原产生异常免疫应答。这解释了工业化国家过敏性疾病高发的原因。
\end{tipbox}

\subsection*{四、参考答案}

\subsubsection*{一、名词解释参考答案}
\begin{enumerate}[leftmargin=*, itemsep=4pt]
    \item \textbf{食源性疾病（foodborne disease）：}通过摄入食物进入人体的各种致病因子引起的、通常具有感染或中毒性质的一类疾病，包括食物中毒。
    \item \textbf{食物过敏（food allergy）：}摄入体内的食物中的某组成成分，作为抗原诱导机体产生免疫应答而发生的一种变态反应性疾病。存在于食品中可以引发人体食品过敏的成分称为食物致敏原（allergen）。
    \item \textbf{食物中毒（food poisoning）：}指食用了被有毒有害物质污染的食品或者食用了含有毒有害物质的食品后出现的急性、亚急性疾病。
    \item \textbf{细菌性食物中毒：}指因摄入被致病性细菌或其毒素污染的食物而引起的中毒，是最常见的食物中毒。
    \item \textbf{肠源性青紫症：}亚硝酸盐将血红蛋白中的Fe$^{2+}$氧化为Fe$^{3+}$形成高铁血红蛋白，失去携氧能力，口唇、指尖出现发绀，因与肠道细菌将硝酸盐还原为亚硝酸盐有关，故称肠源性青紫症。
    \item \textbf{高铁血红蛋白血症（Methemoglobinemia）：}血红蛋白中的Fe$^{2+}$被氧化为Fe$^{3+}$形成高铁血红蛋白（MetHb），失去携氧能力导致的病理状态。
    \item \textbf{毒蕈中毒假愈期：}肝肾损害型毒蕈中毒病程中的特殊阶段，胃肠炎症状暂时缓解或消失，但肝脏损害已开始进行性发展，最容易被忽视而导致病情恶化。
\end{enumerate}

\subsubsection*{二、简答题参考答案}
\begin{enumerate}[leftmargin=*, itemsep=4pt]
    \item \textbf{食源性疾病和食物中毒的定义：}
    \begin{itemize}[leftmargin=*]
        \item 食源性疾病：通过摄入食物进入人体的各种致病因子引起的、通常具有感染或中毒性质的一类疾病，包括食物中毒。
        \item 食物中毒：食用了被有毒有害物质污染的食品或含有毒有害物质的食品后出现的急性、亚急性疾病。
    \end{itemize}

    \item \textbf{食物中毒的四大临床发病特点和五大流行病学特点：}

    四大临床发病特点：
    \begin{enumerate}[leftmargin=*]
        \item 潜伏期短、发病突然，短时间内或一二天内有很多人发病，以集体暴发较多见
        \item 发病与食物有关，病人有食用同一有毒食物史，流行波及范围与有毒食物供应范围一致，停止该食物供应后，流行即终止
        \item 患者临床症状相同或相似，大多数食物中毒以急性胃肠炎为主要表现
        \item 一般情况下，人与人之间不直接传染，发病曲线呈突然上升后又迅速下降趋势，无传染病流行时的余波
    \end{enumerate}

    五大流行病学特点：
    \begin{enumerate}[leftmargin=*]
        \item 发病的季节性明显：细菌性食物中毒主要发生在6$\sim$10月，化学性食物中毒全年均可发生
        \item 发病的地区性特点：与各地的食品品种和饮食习惯有关
        \item 食物中毒原因的分布特点：患者只局限于食用同一种食物的人群中
        \item 病死率特点：发病率高，病死率低；死亡人数以有毒动植物食物中毒最多，其次为化学性
        \item 发生场所分布特点：集体暴发常以节假日改善伙食或集餐多见
    \end{enumerate}

    \item \textbf{细菌性食物中毒的发病原因和流行病学特点：}

    三大发病原因：致病菌污染（宰杀前后污染及运输储存销售中污染）；储存方式不当（高温、水分多、适宜pH、营养条件）；烹调方式不当（未煮熟或生熟交叉感染或带菌者污染）。

    三大流行病学特点：发病率高、病死率低，发病起数和人数均居首位；夏秋季发病率高（5$\sim$10月）；动物性食品是主要中毒食品，畜肉类及其制品居首位。

    \item \textbf{四种细菌性食物中毒比较：}
    \begin{itemize}[leftmargin=*]
        \item \textbf{沙门氏菌：}来源为动物性食品（畜禽肉、蛋类、乳类）；中毒机制为感染型（活菌+内毒素）；潜伏期12$\sim$36h；临床特点为发热+水样便/黄绿色稀便，污染食品后无感官改变。
        \item \textbf{金黄色葡萄球菌：}来源为带菌者污染（化脓/呼吸道感染）；中毒机制为毒素型（肠毒素，耐热，100$^\circ$C 2h破坏）；潜伏期1$\sim$6h（最短1h）；临床特点为剧烈呕吐最突出+上腹剧痛+水样腹泻，体温一般正常。
        \item \textbf{副溶血性弧菌：}来源为海产品（嗜盐菌）；中毒机制为混合型（活菌+溶血毒素）；潜伏期6$\sim$12h；临床特点为上腹阵发性绞痛+水样便或洗肉水样便，里急后重不明显。
        \item \textbf{肉毒梭菌：}来源为家庭自制发酵食品和罐头食品；中毒机制为外毒素（肉毒毒素，已知最剧烈的神经毒素）；潜伏期12$\sim$48h；临床特点为对称性颅神经损害（视力模糊、复视、眼睑下垂、吞咽困难、呼吸困难），病死率极高，胃肠道症状极少见。
    \end{itemize}

    \item \textbf{金葡菌肠毒素耐热性及带菌者管理：}肠毒素耐热，100$^\circ$C加热2h才被破坏，普通烹调方法难以彻底破坏。带菌者（化脓性皮肤病、上呼吸道感染者）是食品污染的最重要来源，人体鼻咽部带菌率20\%$\sim$50\%。因此有局部化脓性感染或上呼吸道感染者应暂时调离食品工作岗位；患局部化脓性感染的畜、禽肉尸应按病变部位除去后，经高温处理以熟制品出售。

    \item \textbf{肉毒梭菌毒素作用机制及高病死率原因：}肉毒毒素经消化道吸收进入血液后，主要作用于中枢神经系统的脑神经核、神经肌肉连接部和自主神经末梢，抑制神经末梢乙酰胆碱释放，导致肌肉麻痹和神经功能障碍。高病死率原因：(1)肉毒毒素是已知最剧烈的神经毒素，致死剂量极低（约10$^{-9}$mg/kg，比KCN强10\,000倍）；(2)主要致死原因为呼吸肌麻痹导致呼吸衰竭；(3)芽胞耐热性极强（湿热100$^\circ$C需5小时），普通加热无法杀灭。

    \item \textbf{河豚毒素（TTX）的中毒机制和临床发展过程：}中毒机制：TTX选择性阻断细胞膜对Na$^+$的通透性，使神经传导阻断，呈麻痹状态，同时引起外周血管扩张，血压下降。临床发展过程：先感觉神经麻痹（口唇舌尖发麻）$\to$ 后运动神经麻痹（四肢无力、肌肉麻痹、全身瘫痪）$\to$ 最后呼吸中枢和血管运动中枢麻痹导致急性呼吸衰竭死亡。

    \item \textbf{毒蕈中毒的临床分型及假愈期意义：}临床分型：胃肠炎型、神经精神型（阿托品治疗）、溶血型（肾上腺皮质激素）、肝肾损害型（巯基解毒剂如二巯基丙磺酸钠，病死率最高）、类光过敏型。假愈期的意义：此期胃肠炎症状暂时缓解，但肝脏损害已开始进行性发展，最容易被忽视，需继续严密观察和积极治疗，不可因症状缓解而放松警惕。

    \item \textbf{亚硝酸盐食物中毒：}中毒机制：将Hb中的Fe$^{2+}$氧化为Fe$^{3+}$形成MetHb，失去携氧能力，导致组织缺氧。临床特点：潜伏期10min$\sim$3h，口唇、指甲及全身皮肤青紫（肠源性青紫症），头晕、头痛、乏力、胸闷、心率快，严重者昏迷、惊厥、呼吸衰竭死亡。特效解毒剂：美蓝（亚甲蓝）+ 维生素C。

    \item \textbf{有机磷农药中毒机制和临床表现：}中毒机制：抑制胆碱酯酶（ChE）活性，使ACh大量蓄积，胆碱能神经过度兴奋。三类临床表现：毒蕈碱样症状（M样：瞳孔缩小、流涎、大汗）、烟碱样症状（N样：肌束震颤）、中枢神经系统症状（头晕、抽搐、昏迷）。

    \item \textbf{有机磷中毒ChE活性分级及特效解毒剂：}轻度：ChE 50\%$\sim$70\%（阿托品）；中度：ChE 30\%$\sim$50\%（阿托品+胆碱酯酶复活剂）；重度：ChE $<$30\%，伴肺水肿/脑水肿/昏迷/呼吸麻痹（阿托品+胆碱酯酶复活剂）。特效解毒剂：阿托品（拮抗毒蕈碱样症状）+ 解磷定/氯磷定（复活胆碱酯酶）。

    \item \textbf{食物过敏的概念及八大类致敏食物：}概念：摄入体内的食物中的某组成成分作为抗原诱导机体产生免疫应答而发生的一种变态反应性疾病。八大类：牛奶、鸡蛋、花生、大豆、谷物（小麦等）、鱼类、甲壳类、坚果类。

    \item \textbf{六种人畜共患传染病及结核病和霍乱：}
    \begin{itemize}[leftmargin=*]
        \item 六种常见人畜共患传染病：炭疽、结核病、口蹄疫、霍乱、疯牛病（BSE）、布鲁氏菌病。
        \item \textbf{结核病：}病原为结核分枝杆菌。食源性传播途径为食用未经巴氏消毒的带菌乳及乳制品、病畜肉。预防措施：奶牛定期结核菌素试验、牛乳巴氏消毒、病畜肉高温处理或销毁。
        \item \textbf{霍乱：}病原为霍乱弧菌（O1群和O139群），产生霍乱肠毒素。食源性传播途径为食用被污染的水产品（鱼、虾、蟹、贝类），以粪-口途径传播。预防措施：加强水源管理、海产品彻底煮熟、从业人员健康检查、接种霍乱疫苗、24小时内上报疫情。
    \end{itemize}

    \item \textbf{瘦肉精（盐酸克伦特罗）中毒：}
    \begin{itemize}[leftmargin=*]
        \item 中毒机制：克伦特罗为$\beta_2$-肾上腺素受体激动剂，激活腺苷酸环化酶使cAMP升高，产生拟交感神经兴奋作用。
        \item 主要临床表现：潜伏期10min$\sim$6h。心悸、心动过速（120$\sim$150次/分）、心律失常、血压升高；肌肉震颤（面部、四肢为主）；头晕、头痛、焦虑；低钾血症、高血糖。
        \item 治疗：无特效解毒药。$\beta$受体阻断剂（普萘洛尔）拮抗心血管症状，补钾，对症支持治疗。
        \item 预防：严禁$\beta$-激动剂作为饲料添加剂，加强内脏药物残留监测。
    \end{itemize}

    \item \textbf{砷中毒：}
    \begin{itemize}[leftmargin=*]
        \item 中毒机制：三价砷（As$^{3+}$）与体内含巯基（-SH）的酶结合形成稳定复合物，使酶（尤其是丙酮酸氧化酶系统）失活，导致细胞呼吸障碍；损害毛细血管内皮细胞，增加通透性；为人类致癌物。
        \item 临床特点：胃肠型——口中金属味和\keyword{大蒜样气味}，剧烈恶心、呕吐、腹痛、腹泻（米泔水样便或血水样便）；神经型——头晕、抽搐、昏迷。慢性中毒致皮肤色素沉着、掌跖角化、皮肤癌等。
        \item 特效解毒剂：巯基解毒剂——二巯基丙磺酸钠（DMPS）、二巯基丁二酸钠（DMSA）、二巯基丙醇（BAL）。
    \end{itemize}

    \item \textbf{甲醇中毒：}
    \begin{itemize}[leftmargin=*]
        \item 中毒机制：甲醇在体内经醇脱氢酶（ADH）氧化为甲醛，再经醛脱氢酶（ALDH）氧化为\keyword{甲酸}（主要毒性物质），甲酸抑制细胞色素c氧化酶，引起组织缺氧和代谢性酸中毒。甲酸和甲醛对视网膜细胞有高度选择性毒性。
        \item 特征性临床表现：潜伏期8$\sim$36小时。最典型为\keyword{眼部损害}——视力模糊、眼前飘雪感、畏光、瞳孔散大、视野缩小，严重者双目失明。严重中毒出现代谢性酸中毒、昏迷、休克。
        \item 治疗原则：催吐、洗胃（2\%碳酸氢钠溶液）；\keyword{特效解毒剂：乙醇或甲吡唑}（竞争性抑制ADH）；纠正酸中毒（碳酸氢钠）；严重者行血液透析。
        \item 预防：严禁工业酒精勾兑食用酒；执行甲醇限量标准。
    \end{itemize}

    \item \textbf{食物中毒调查的目的：}①查明发病原因，确定是否为食物中毒及中毒性质，确定中毒食品和致病因子及致病途径；②查清发生原因和条件，采取控制措施防止蔓延；③为病人急救治疗提供依据并对已采取措施给予补充或纠正；④积累资料，分析特点和规律，制订有效措施减少和控制类似事件；⑤收集对违法者实施处罚的证据。
\end{enumerate}

\subsubsection*{三、案例分析参考答案}
\begin{enumerate}[leftmargin=*]
    \item \textbf{【案例分析1】}
    \begin{enumerate}[leftmargin=*]
        \item 最可能的病原体：金黄色葡萄球菌（肠毒素）。
        \item 中毒机制：毒素型——金葡菌在食品中预先产生肠毒素，毒素随食物进入体内引起中毒。肠毒素作用于胃肠黏膜引起充血、水肿、糜烂等炎症变化和水电解质代谢紊乱，同时刺激迷走神经内脏分支引起反射性呕吐。
        \item 肠毒素耐热，100$^\circ$C加热2h才被破坏，普通烹调难以彻底破坏。
        \item 最关键预防措施：有局部化脓性感染或上呼吸道感染者应暂时调离食品工作岗位；患化脓性感染的畜、禽肉应按病变部位除去后高温处理。
    \end{enumerate}

    \item \textbf{【案例分析2】}
    \begin{enumerate}[leftmargin=*]
        \item 最可能的诊断：肉毒梭菌毒素食物中毒。
        \item 肉毒毒素（外毒素），是已知最剧烈的神经毒素。毒性比KCN强10\,000倍，人的致死剂量约10$^{-9}$mg/kg。
        \item 尽早使用多价肉毒抗毒素血清（A、B、E型），同时对症支持治疗。
        \item 预防：家庭自制密封发酵食品为高危风险食品；罐头食品鼓盖/漏气绝对不要食用；蜂蜜不宜喂养1岁以下婴儿；食品原料彻底清洁、低温储存；食用前彻底加热。
    \end{enumerate}

    \item \textbf{【案例分析3】}
    \begin{enumerate}[leftmargin=*]
        \item 最可能的诊断：亚硝酸盐食物中毒。
        \item 中毒机制：亚硝酸盐将Hb中的Fe$^{2+}$氧化为Fe$^{3+}$，形成MetHb，失去携氧能力，导致组织缺氧引起肠源性青紫症。
        \item 特效解毒剂：美蓝（亚甲蓝）+ 维生素C。
        \item 腌制20天以后亚硝酸盐基本消失。
    \end{enumerate}
\end{enumerate}
