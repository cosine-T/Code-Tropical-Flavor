\section{食品中危害的来源和分类}

\begin{tipbox}
\textbf{食品中危害的来源：}
\begin{enumerate}[leftmargin=*]
    \item 食品本身含有或自身变化产生
    \item 食品加工、储存过程中自身形成的有害物质
    \item 外界污染造成
    \item 食品加工过程中有意加入的成分（如食品添加剂滥用，非法加入有毒有害的非食用物质）
\end{enumerate}

\textbf{食品中危害的分类：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{生物因素：}微生物、细菌、真菌、寄生虫、昆虫、病毒
    \item \textbf{化学因素：}各种有机化合物、无机化合物、人工合成物
    \item \textbf{物理因素：}金属、毛发、碎屑、小动物尸体、放射性物质
\end{enumerate}
\end{tipbox}

\section{食品安全性毒理学评价}

\subsection{食品安全性毒理学评价的概念与内容}

\begin{keybox}
\textbf{食品安全性评价概念（掌握）：}对食品中任何组分可能引起的危害进行科学测试、得出结论，以确定该组分究竟能否为社会或消费者接受，据此以制订相应的标准，这一过程称为食品的安全性评价。

\textbf{方法与特点：}方法涉及到食品毒理学、流行病学、临床医学、化学（分析化学、有机化学、生物化学）和生物统计等，其中\textbf{食品毒理学和流行病学}是较为重要的部分。

\textbf{1. 毒理学：}是从毒理学角度，研究食品中所含的内源化学物质或可能含有的外源化学物质对食用者的毒性作用机理，检验和评价食品（包括食品添加剂）的安全性或安全范围，从而确保人类健康的学科。

\textbf{毒理学研究相比流行病学的优点：}
\begin{itemize}[leftmargin=*]
    \item 可进行具体实验设计，且所有条件可保持连续性；
    \item 在进行确定物质的暴露分析时，暴露过程和暴露条件（如饮食、气候等）能被仔细监测和控制，并能通过组织病理学和生物化学等方法提供可能的高敏感性的副作用反应研究等。
\end{itemize}

\textbf{毒理学研究的局限性：}
\begin{itemize}[leftmargin=*]
    \item 毒理学研究结果不能直接应用于人，因为用实验动物小鼠的试验结果应用于\imp{60kg}体重的人体是不合理的。
    \item 在大部分的毒理学试验中，实验动物只接受某一种毒性物质同一时间暴露的反应，而人则一般暴露在不同的化学物质中，由于成分的相互作用，混合或合并的不同物质的暴露可能没有预期（和不可能预期）的健康影响。
\end{itemize}

\textbf{2. 流行病学：}是观察学科。
\end{keybox}

\begin{keybox}
\textbf{食品安全性毒理学评价概念（掌握）：}现代食品安全性评价认为除了进行传统的毒理学评价研究外，还需有食品的成分、生产工艺、卫生学、食品质量标准、人体研究、残留量研究、暴露量研究、消费水平（膳食结构）和摄入风险评价等。

\textbf{毒理学评价适用范围：}
\begin{enumerate}[leftmargin=*]
    \item 适用于评价食品生产、加工、保藏、运输和销售过程中所涉及的可能对健康造成危害的化学、生物和物理因素的安全性（\textbf{5个环节}）
    \item 检验对象包括食品及其原料、食品添加剂、新食品原料、辐照食品、食品相关产品（用于食品的包装材料、容器、洗涤剂、消毒剂和用于食品生产经营的工具、设备）以及食品污染物（\textbf{6个检验对象}）
\end{enumerate}

\textbf{评价程序（内容，掌握）：}
\begin{enumerate}[leftmargin=*]
    \item 急性经口毒性试验
    \item 遗传毒性试验（包括10项试验，一般遵循原核细胞与真核细胞、体内试验与体外试验相结合的原则进行组合）
    \item 28天经口毒性试验
    \item 90天经口毒性试验
    \item 致畸试验
    \item 生殖毒性试验
    \item 毒物动力学试验
    \item 慢性毒性试验
    \item 致癌试验
    \item 慢性毒性和致癌合并试验
\end{enumerate}
\end{keybox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{毒理学试验的四个阶段（熟悉）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{第一阶段：}急性毒性试验——测定经口LD50，联合急性毒性试验。
    \item \textbf{第二阶段：}非急性毒性试验，包括遗传毒性、传统致畸、30天喂养试验。
    \item \textbf{第三阶段：}慢性毒性试验，包括90天喂养、生殖发育和代谢试验。
    \item \textbf{第四阶段：}食品安全性毒理学评价试验。
\end{enumerate}
\end{tipbox}

\subsection{对不同受试物选择性试验的原则}

\begin{keybox}
\textbf{对不同受试物选择性试验的原则（掌握）：}

\textbf{第一类——凡属我国首创的物质：}特别是化学结构提示有慢性毒性、遗传毒性或致癌性，或该受试物产量大、使用范围广、人体摄入量大，应进行\textbf{系统的毒性试验}：包括急性经口毒性试验、遗传毒性试验、90天经口毒性试验、致畸试验、生殖发育毒性试验、毒物动力学试验、慢性毒性试验和致癌试验（或慢性毒性和致癌合并试验）。

\textbf{第二类——凡属与已知物质（指经过安全性评价并允许使用者）的化学结构基本相同的衍生物或类似物：}或在部分国家和地区有安全食用历史的物质，则可先进行急性经口毒性试验、遗传毒性试验、90天经口毒性试验和致畸试验，根据试验结果判断是否需进行毒物动力学试验、生殖毒性试验、慢性毒性试验和致癌试验等。

\textbf{第三类——凡属已知的或在多个国家有食用历史的物质：}同时申请单位又有资料证明申报受试物的质量规格与国外产品一致，则可先进行急性经口毒性试验、遗传毒性试验和28天经口毒性试验，根据试验结果判断是否进行进一步的毒性试验。

\textbf{食品添加剂、新食品原料等：}对于食品添加剂、新食品原料、食品相关产品、农药残留及兽药残留的安全性毒理学评价，应根据《食品安全国家标准 食品安全性毒理学评价程序》（GB 15193.1-2014）的要求，选择适宜的试验。
\end{keybox}

\subsection{对受试物的要求与需要考虑的因素}

\begin{defbox}
\textbf{食品安全性毒理学评价时对受试物的要求与需要考虑的因素：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{试验指标的统计学意义、生物学意义和毒理学意义：}综合考虑指标差异有无生物学意义，并进一步判断是否具有毒理学意义。此外，如在受试物组发现某种在对照组没有发生的肿瘤，即使与对照组比较无统计学意义，仍要给予关注。
    \item \textbf{人的推荐（可能）摄入量较大的受试物：}应考虑给予受试物量过大时，可能影响营养素摄入量及其生物利用率，从而导致某些毒理学表现，而非受试物的毒性作用所致。
    \item \textbf{时间-毒性效应关系：}对由受试物引起实验动物的毒性效应进行分析评价时，要考虑在同一剂量水平下毒性效应随时间的变化情况。
    \item \textbf{特殊人群和易感人群：}对孕妇、乳母或儿童食用的食品，应特别注意其胚胎毒性或生殖发育毒性、神经毒性和免疫毒性等。
    \item \textbf{人群资料：}尽可能收集人群接触受试物后的反应资料，如职业性接触和意外事故接触等。
    \item \textbf{不确定系数（安全系数）：}将动物毒性试验结果外推到人时，鉴于动物与人的物种差异和个体之间的生物学差异，不确定系数通常为\imp{100}倍。但可根据受试物的原料来源、理化性质、毒性大小、代谢特点、蓄积性、接触的人群范围、食品中的使用量和人的可能摄入量、使用范围及功能等因素来综合考虑其安全系数的大小。
    \item \textbf{毒物动力学试验的资料：}在毒性试验中，原则上应尽量使用与人具有相同毒物动力学或代谢模式的动物种系来进行试验。
    \item \textbf{综合评价：}全面考虑受试物的理化性质、结构、毒性大小、代谢特点、蓄积性、接触的人群范围、食品中的使用量与使用范围、人的推荐（可能）摄入量等因素。
\end{enumerate}
\end{defbox}

\section{营养毒理学}

\subsection{营养毒理学概念与研究方向}

\begin{defbox}
\textbf{营养毒理学（Nutritional Toxicology，熟悉）：}是营养学和毒理学交叉形成的一门分支学科。主要研究内容包括（\textbf{三大研究方向}）：
\begin{enumerate}[leftmargin=*]
    \item 营养素过量摄入的不良反应及可耐受最高摄入量（UL）的制定。
    \item 营养素对外源化学物代谢和毒性的影响。
    \item 膳食中有毒有害物质对营养素吸收、代谢和功能的影响。
\end{enumerate}

UL（可耐受最高摄入量）是营养毒理学的重要指标。
\end{defbox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{营养毒理学（Nutritional Toxicology，熟悉）：}是营养学和毒理学交叉形成的一门分支学科。研究内容包括：
\begin{enumerate}[leftmargin=*]
    \item 营养素过量摄入的不良反应及其可耐受最高摄入量（UL）的制定；
    \item 营养素对毒物代谢过程和毒性作用的影响；
    \item 膳食来源的有毒有害物质对营养素吸收、代谢和功能的影响。
\end{enumerate}
\end{tipbox}

\section{食品安全风险分析}

\subsection{风险分析框架的四大步骤}

\begin{keybox}
\textbf{食品安全风险分析（风险评估，掌握）：}评估食品风险，建立危害与风险的内在联系。是对有害事件发生的可能性和不确定性进行的评估，由危害识别、危害特征描述、暴露评估以及风险特征描述四个步骤组成的过程。

\textbf{风险评估程序：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{危害识别（Hazard Identification）：}确定人体摄入某种食品中的危害因素与健康不良效应之间是否存在因果关系。信息来源按重要性程度排序为：流行病学资料、动物毒理学试验、体外试验、化学结构-毒性关系资料。

    \item \textbf{危害特征描述（Hazard Characterization）：}对危害因素可能引起的不良健康效应进行定性和/或定量评价。核心任务：建立剂量-反应关系（Dose-Response Relationship），确定NOAEL或BMDL。

    \item \textbf{暴露评估（Exposure Assessment）：}对通过食品或其他途径摄入人体的生物、化学和物理因素的量进行评估。膳食暴露量 = $\sum$(食品中化学物浓度 $\times$ 食品消费量) / 体重。

    \item \textbf{风险特征描述（Risk Characterization）：}在识别、特征描述和暴露评估的基础上，综合分析危害对人群健康产生不良作用风险及其程度，描述和解释风险评估过程中的不确定性。与健康指导值比较：暴露量 $<$ HBGV $\to$ 风险可接受。
\end{enumerate}
\end{keybox}

% [补充自往届笔记]
\begin{tipbox}
\textbf{风险评估的四大步骤（补充说明）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{危害识别（hazard identification）：}确定某种食品中可能产生不良健康影响的生物、化学、物理因素。资料按重要程度顺序排列为：流行病学资料、动物试验、化学结构-活性关系资料、体外毒理学研究。
    \item \textbf{危害特征描述（hazard characterization）：}对食品中生物、化学、物理因素产生的不良健康影响进行定性和定量评价。
    \item \textbf{暴露评估（exposure assessment）：}对经食物摄入时，生物、化学、物理因素和来自其他来源的暴露量进行定量/定性估算。暴露评估方法通常基于测定食品中化学物的含量和/或通过膳食调查获得的摄入量数据进行计算。
    \item \textbf{风险特征描述（risk characterization）：}在危害识别、危害特征描述和暴露评估的基础上，对不良影响的可能性及特定人群中已发生或可能发生的不良影响的严重性进行定量/定性估计（含不确定性）的综合评估。
\end{enumerate}
\end{tipbox}

\subsection{风险管理与风险交流}

\begin{defbox}
\textbf{风险管理（Risk Management，熟悉）：}考虑风险评估结果和其他法律因素，与利益相关方磋商后权衡利弊，选择适当的政策和预防控制措施。包括：风险评价、风险管理选择评估、管理决定的执行三个阶段。

\textbf{风险交流（Risk Communication，熟悉）：}在风险评估人员、风险管理人员和其他利益者之间所进行的有关风险的信息和建议的相互交流过程。\textbf{风险管理是食品安全管理的核心。}

\textbf{需实施安全风险评估的六种情形：}
\begin{enumerate}[leftmargin=*]
    \item 通过食品安全风险监测或者接到举报发现食品、食品添加剂、食品相关产品可能存在安全隐患的
    \item 为制定或者修订食品安全国家标准提供科学依据需要进行风险评估的
    \item 为确定监督管理的重点领域、重点品种需要进行风险评估的
    \item 发现新的可能危害食品安全因素的
    \item 需要判断某一因素是否构成食品安全隐患的
    \item 国务院卫生行政部门认为需要进行风险评估的其他情形
\end{enumerate}
\end{defbox}

\section{食品安全风险监测}

\subsection{风险监测的概念与目的}

\begin{defbox}
\textbf{食品安全风险监测：}是指通过系统和持续地收集食源性疾病、食品污染以及食品中有害因素的监测数据及相关信息，并进行综合分析和及时通报的活动。食品安全风险监测是针对某种食品的食用安全性展开的评价、预警和检测，是对食品安全风险进行评估的基础和前提，也是风险评估阶段的数据来源。

\textbf{风险监测与监督抽检的区别：}风险监测和监督抽检的总体目的都是发现问题，以保护消费者饮食安全，但各自又有具体的目的。
\begin{itemize}[leftmargin=*]
    \item \textbf{风险监测的主要目的：}是收集数据以制订或修订食品安全国家标准（\textbf{发现实际状况}）。
    \item \textbf{监督抽检的主要目的：}是发现不符合现有的食品安全国家标准的产品（\textbf{合法性审核}）。
\end{itemize}
简言之，一个是为了\textbf{制定规则}，一个是为了\textbf{符合规则}，两者的理念不能混淆。
\end{defbox}

\subsection{风险监测的范围与对象}

\begin{defbox}
\textbf{食品安全风险监测的范围：}
\begin{enumerate}[leftmargin=*]
    \item 食品中各类化学污染物的监测
    \item 各类农业投入品的监测
    \item 食品中各类生物污染物的监测
    \item 各类非法添加物的监测
\end{enumerate}

\textbf{食品安全风险监测对象：}
\begin{enumerate}[leftmargin=*]
    \item 食品
    \item 食品添加剂
    \item 食品包装材料
    \item 食源性疾病
\end{enumerate}

\textbf{优先监测的内容：}
\begin{enumerate}[leftmargin=*]
    \item 健康危害较大、风险程度较高以及污染水平呈上升趋势的
    \item 易于对婴幼儿、孕产妇、老年人、病人造成健康影响的
    \item 涉及的食品流通范围广、消费量大的
    \item 以往在国内导致食品安全事故或者受到消费者关注的
    \item 已在国外导致健康危害并有证据表明可能在国内存在的
\end{enumerate}
\end{defbox}

\section{食品安全预警和快速反应系统}

\difficulty

\begin{defbox}
\textbf{食品安全预警和快速反应系统（了解）：}

\textbf{食品安全事故（Accident）：}指食物中毒、食源性疾病、食品污染等源于食品，对人体健康有危害或者可能有危害的事故。

\textbf{风险监测与预警的关系：}食品安全风险监测是对食品安全风险进行评估的基础和前提，也是风险评估阶段的数据来源。通过系统和持续地收集食源性疾病、食品污染以及食品中有害因素的监测数据，进行综合分析和及时通报，实现对食品安全风险的早期预警。

\textbf{快速反应系统：}基于风险监测数据和风险评估结果，对可能发生的食品安全事故进行快速响应和控制，包括信息通报、追溯召回、应急处置等环节。
\end{defbox}

\section{关键毒理学指标与健康指导值}

\subsection{最大无作用剂量}

\begin{keybox}
\textbf{最大无作用剂量（MNL/NOEL/NOAEL）*：}在一定时间内，某种外源化学物按一定方式与机体接触，用现代检测方法和最灵敏的观察指标不能检出任何有害作用的最高剂量。应用动物实验中最敏感的指标和最能反映受试物危害的指标；除观察一般毒性指标外，还应考虑受试物的特殊毒性指标，如致癌、致畸、致突变、迟发性神经毒性等。

\begin{itemize}[leftmargin=*]
    \item \textbf{MNL（Maximum No-effect Level）：}最大无作用剂量。
    \item \textbf{NOEL（No Observed Effect Level）：}未观察到作用水平。
    \item \textbf{NOAEL（No Observed Adverse Effect Level）：}未观察到有害作用水平。
\end{itemize}
\end{keybox}

\subsection{每日允许摄入量与基准剂量}

\begin{keybox}
\textbf{每日允许摄入量（Acceptable Daily Intake, ADI）*：}人类每日摄入某物质直至终生，根据当时已知事实，不会产生可察觉健康危害的量。对于食品中的非致癌物，ADI来源于试验动物NOAEL。单位：mg/(kg bw$\cdot$d)。

\textbf{推导公式：}
\[
\text{ADI} = \frac{\text{NOAEL}}{\text{UFs}}
\]

其中UFs（Uncertainty Factors，不确定系数）常规取\imp{100}倍（种间差异\imp{10} $\times$ 个体差异\imp{10}）。

\textbf{基准剂量可信下限（Benchmark Dose Lower Confidence Limit, BMDL）：}通过剂量-反应曲线获得的，与背景值相比，达到预先确定的有害效应发生率（通常为\imp{1\%--10\%}）所对应的剂量，一般用\imp{95\%}可信限区间的下限值。BMDL比NOAEL更充分地利用剂量-反应数据，结果更稳定。
\end{keybox}

\subsection{健康指导值}

\begin{defbox}
\textbf{健康指导值（Health-based Guidance Values, HBGV）：}指人类在一定时期内（终生或24小时）摄入某种（或某些）物质，而不产生可检测到的对健康产生危害的安全限值，包括每日允许摄入量、耐受摄入量、急性参考剂量等。

\textbf{主要类型：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{每日允许摄入量（ADI）：}人类终生每日摄入正常使用的某化学物质（如食品添加剂），不产生可检测到的对健康产生危害的量。
    \item \textbf{耐受摄入量（TI）：}人类在一段时间内或终生暴露于某化学物质，不产生可检测到的对健康产生危害的量。包括日耐受摄入量（TDI）、暂定每日最大耐受摄入量（PMTDI）、暂定每周耐受摄入量（PTWI）和暂定每月耐受摄入量（PTMI）。对于环境污染物，采用TDI或PTWI。
    \item \textbf{急性参考剂量（ARfD）：}人类在24小时或更短的时间内摄入食品或饮水中某化学物质（如农药），在短时间内（通常指一餐或一天内）被吸收后不致引起目前已知的任何可检测到的对健康产生危害的剂量。
    \item \textbf{对于营养素：}要制定每日推荐摄入量（RNI值）。
\end{enumerate}

\textbf{不同类型物质的健康指导值适用情况：}
\begin{itemize}[leftmargin=*]
    \item 对于食品（食品添加剂等有意添加物），应提供\textbf{每日允许摄入量（ADI）}
    \item 对于食品中的非致癌物，ADI来源于试验动物\textbf{NOAEL}
    \item 对于环境污染物，采用\textbf{TDI}或\textbf{PTWI}
    \item 对于营养素，要制定每日推荐摄入量（\textbf{RNI值}）
\end{itemize}
\end{defbox}

\subsection*{参考答案要点}

\subsubsection*{名词解释（要点）}

\begin{enumerate}[leftmargin=*, itemsep=4pt]
    \item \textbf{食品安全性评价：}对食品中任何组分可能引起的危害进行科学测试、得出结论，以确定该组分究竟能否为社会或消费者接受，据此以制订相应的标准。
    \item \textbf{食品安全性毒理学评价：}除传统毒理学评价研究外，还需有食品的成分、生产工艺、卫生学、食品质量标准、人体研究、残留量研究、暴露量研究、消费水平（膳食结构）和摄入风险评价等。
    \item \textbf{危害识别：}确定危害因素与健康不良效应之间是否存在因果关系。\textbf{危害特征描述：}对不良健康效应进行定性和/或定量评价，建立剂量-反应关系。
    \item \textbf{暴露评估：}对通过食品摄入人体的因素的量进行评估。\textbf{风险特征描述：}综合前三步，评估危害因素对人群健康产生不良效应的风险和严重程度。
    \item \textbf{营养毒理学：}营养学和毒理学交叉形成的一门分支学科，研究营养素过量摄入的毒副作用及营养素与外来化学物的相互作用。UL是其重要指标。
    \item \textbf{MNL/NOEL/NOAEL：}在一定时间内，某种外源化学物按一定方式与机体接触，用现代检测方法和最灵敏的观察指标不能检出任何有害作用的最高剂量。
    \item \textbf{ADI：}人类每日摄入某物质直至终生，根据当时已知事实，不会产生可察觉健康危害的量。ADI = NOAEL / UFs。
    \item \textbf{UFs：}不确定系数，常规取100倍（种间差异10 $\times$ 个体差异10）。
    \item \textbf{BMDL：}通过剂量-反应曲线获得的，达到预先确定的有害效应发生率所对应的剂量，一般用95\%可信限区间的下限值。
    \item \textbf{HBGV：}人类在一定时期内（终生或24小时）摄入某种（或某些）物质，而不产生可检测到的对健康产生危害的安全限值。
    \item \textbf{食品安全风险监测：}通过系统和持续地收集食源性疾病、食品污染以及食品中有害因素的监测数据及相关信息，并进行综合分析和及时通报的活动。
\end{enumerate}

\subsubsection*{简答题（要点）}

\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item \textbf{评价程序：}10项试验——急性经口毒性试验；遗传毒性试验（10项，遵循原核细胞与真核细胞、体内试验与体外试验相结合的原则）；28天经口毒性试验；90天经口毒性试验；致畸试验；生殖毒性试验；毒物动力学试验；慢性毒性试验；致癌试验；慢性毒性和致癌合并试验。
    \item \textbf{三类原则：}①我国首创物质（化学结构提示有慢性毒性/遗传毒性/致癌性，或产量大、使用范围广、摄入量大）——系统毒性试验；②与已知物质结构基本相同的衍生物或类似物，或在部分国家/地区有安全食用历史——先做急性+遗传毒性+90天+致畸，根据结果判断；③已知的或在多个国家有食用历史的物质，有资料证明质量规格与国外一致——先做急性+遗传毒性+28天，根据结果判断。
    \item \textbf{四大步骤：}①危害识别（确定因果关系，信息来源：流行病学、动物试验、体外试验、构效关系）；②危害特征描述（定性和/或定量评价，建立剂量-反应关系）；③暴露评估（评估摄入量）；④风险特征描述（综合评估风险和严重程度，描述和解释不确定性）。
    \item \textbf{MNL/NOEL/NOAEL：}不能检出任何有害作用的最高剂量。\textbf{ADI：}人类每日摄入某物质直至终生不会产生可察觉健康危害的量。\textbf{公式：}ADI = NOAEL / UFs（常规100倍）。
    \item \textbf{营养毒理学：}三大方向：①营养素过量不良反应及UL制定；②营养素对外源化学物代谢和毒性的影响；③膳食有毒有害物质对营养素吸收、代谢和功能的影响。
    \item \textbf{六种情形：}①发现食品/添加剂/相关产品可能存安全隐患；②为制修订食品安全国标提供依据；③为确定监管重点领域/品种；④发现新的可能危害因素；⑤需判断某因素是否构成隐患；⑥国务院卫生行政部门认为需要。
    \item \textbf{区别：}风险监测——收集数据以制订/修订国标（发现实际状况，制定规则）；监督抽检——发现不符合现有国标的产品（合法性审核，符合规则）。两者理念不能混淆。
\end{enumerate}
