\section{食品安全监督管理概述}

\subsection{食品安全监督管理的概念}

\begin{keybox}
\textbf{食品安全监督管理的概念（掌握）：}指政府及其相关部门开展的食品安全监督执法和食品安全管理工作，包括食品生产加工、流通环节、餐饮环节食品安全的日常监管；实施生产许可、强制检验等食品质量安全市场准入制度；查处生产、制造不合格食品及其他违法行为；食品行业和企业的自律及其相关食品安全管理活动等。
\end{keybox}

\subsection{食品安全法律法规体系}

\begin{keybox}
\textbf{食品安全法律法规体系构成（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{食品安全法律：}如《中华人民共和国食品安全法》（2009年颁布，2015年修订，2018年修正，2021年修正）
    \item \textbf{食品安全法规：}如《食品安全法实施条例》
    \item \textbf{食品安全规章：}由国家市场监管总局、国家卫生健康委等部门制定的部门规章
    \item \textbf{食品安全标准：}包括食品安全国家标准、地方标准、企业标准等
    \item \textbf{其他规范性文件}
\end{enumerate}

\textbf{食品安全法调整的法律关系（了解）：}
\begin{itemize}[leftmargin=*]
    \item 食品生产经营者与消费者之间的民事法律关系
    \item 监督管理部门与行政相对人（食品生产经营者）之间的行政法律关系
    \item 涉及食品安全犯罪行为时的刑事法律关系
\end{itemize}
\end{keybox}

\subsection{食品安全监督管理的原则}

\begin{defbox}
\textbf{食品安全监督管理的原则（熟悉）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{预防为主：}在事实判定、证据论证、科学研究等方面尚未确定的情况下，为防止食品安全损害而采取的预防性措施。强调风险的预先识别和控制。
    \item \textbf{风险管理：}考虑风险评估和其他法律因素，与利益相关方磋商后权衡利弊，选择适当的政策和预防控制措施。
    \item \textbf{全程控制（Process Monitoring）：}对食品从源头的生产，到中间经营销售，再到消费者的消费整个过程的控制监管。"从农田到餐桌"全链条管理。
    \item \textbf{社会共治：}明确了社会监督的法律地位，鼓励消费者、行业协会、新闻媒体等多元主体参与食品安全治理。
\end{enumerate}
\end{defbox}

\section{食品安全标准}

\subsection{概念、性质与分类}

\begin{keybox}
\textbf{食品安全标准的概念（掌握）：}对食品中具有与人类健康相关的质量要素和技术要求及其检验方法、评价程序等所作的规定。是\textbf{强制性标准}。

\textbf{食品安全标准的性质（了解）：}
\begin{itemize}[leftmargin=*]
    \item 强制性：食品安全标准是强制执行的标准。除食品安全标准外，不得制定其他食品强制性标准。
    \item 科学性：以食品安全风险评估结果为依据，参照国际标准制定。
    \item 社会公益性：保护消费者健康和生命安全。
\end{itemize}

\textbf{食品安全标准的分类（熟悉）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{食品安全国家标准：}由国务院卫生行政部门会同国务院食品安全监督管理部门制定，是最高级别标准。
    \item \textbf{食品安全地方标准：}对地方特色食品，没有食品安全国家标准的，省级卫生行政部门可以制定地方标准。
    \item \textbf{团体标准：}由学会、协会等社会团体制定。
    \item \textbf{企业标准：}企业生产的食品没有国标或地标的，应当制定企业标准。
\end{enumerate}

\textbf{制定的主要依据（了解）：}以食品安全风险评估结果为依据，参照国际标准和国外先进标准，考虑我国的膳食结构和消费水平。
\end{keybox}

\subsection{内容与主要技术指标}

\begin{keybox}
\textbf{食品安全标准的内容（了解）：}
\begin{enumerate}[leftmargin=*]
    \item 食品、食品添加剂、食品相关产品中的致病性微生物、农药残留、兽药残留、重金属、生物毒素、污染物质以及其他危害人体健康物质的限量规定
    \item 食品添加剂的品种、使用范围、用量
    \item 专供婴幼儿和其他特定人群的主辅食品的营养成分要求
    \item 对与食品安全、营养有关的标签、标识、说明书的要求
    \item 食品生产经营过程的卫生要求
    \item 与食品安全有关的质量要求
    \item 与食品安全有关的食品检验方法与规程
    \item 其他需要制定为食品安全标准的内容
\end{enumerate}

\textbf{主要技术指标（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{严重危害人体健康的指标：}致病性微生物与毒素（沙门氏菌、金黄色葡萄球菌及其产生的毒素、真菌毒素等）；有毒有害化学物质（砷、铅、汞、镉、多环芳烃类化合物等）；放射性污染物。
    \item \textbf{反映食品可能被污染及污染程度的指标：}菌落总数、大肠菌群等。
    \item \textbf{间接反映食品安全质量发生变化的指标：}水分、含氮化合物、挥发性盐基氮等。
    \item \textbf{营养指标：}碳水化合物、脂肪、蛋白质、矿物质、维生素等营养素和能量、膳食纤维等。专供婴幼儿和其他特定人群的主辅食品的营养成分要求尤其重要。
    \item \textbf{商品质量指标：}如感官指标等。
\end{enumerate}
\end{keybox}

\subsection{限量标准制订与国际标准体系}

\begin{keybox}
\textbf{食品中有毒有害物质限量标准的制订步骤与方法（掌握）：}

\textbf{制订步骤：}
\begin{enumerate}[leftmargin=*]
    \item 通过动物毒理学实验确定NOAEL或BMDL
    \item 根据动物实验结果，考虑运用人的安全系数（100--1000倍），确定人的每日允许摄入量（ADI）或每日可耐受摄入量（TDI）
    \item 考虑来源于食物的该物质所占比例，确定每日总膳食中的允许含量
    \item 考虑该物质的食物种类和人的每日摄入量（食物系数），确定该物质在每种食物中的最大允许量
    \item 综合考虑各方面实际情况，制定食品中的有害限量标准
\end{enumerate}

\textbf{一般原则：}
\begin{itemize}[leftmargin=*]
    \item 无需对食品中所有的污染物和毒素设立限量值
    \item 限量值的设立对消费者总暴露量有显著性意义
    \item 限量值对消费者要有充分的保护
\end{itemize}
\end{keybox}

\begin{defbox}
\textbf{国际食品安全标准体系概况（了解）：}
\begin{itemize}[leftmargin=*]
    \item \textbf{国际食品法典委员会（CAC）：}由FAO和WHO共同建立的政府间国际组织，制定国际食品法典标准（Codex Alimentarius）。
    \item 该标准提出并遵循了食品安全管理原则，将消费者食用安全作为建立与实施食品安全管理体系的关注焦点，重点强调对食物链中影响食物安全的危害进行过程、系统化和可追溯性控制，最终产品的检验仅是辅助或验证手段。
    \item 国际食品法典标准是世界贸易组织（WTO）SPS协定的参考标准，是国际食品贸易的技术依据。
\end{itemize}
\end{defbox}

\section{GMP（良好生产规范）}
\section{GMP（良好生产规范）}

\begin{keybox}
\textbf{GMP（Good Manufacturing Practice）：}良好生产规范，是保证食品具有高度安全性的良好生产管理体系。GMP是注重生产过程中产品质量与卫生安全的自主性管理制度。

\textbf{GMP的四大管理要素（4M）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{Man（人员）：}配备合适且能胜任的从业人员，健康检查合格，经过食品安全知识培训。
    \item \textbf{Material（物料）：}选用良好的原料，原料验收标准，供应商管理。
    \item \textbf{Machine（设备）：}采用标准规范的厂房设施和机械设备，厂房布局合理（人流物流分离），设备易于清洗消毒。
    \item \textbf{Method（方法）：}遵照既定的最优方法进行生产，标准操作规程（SOP），工艺参数控制。
\end{enumerate}

\textbf{GMP的基本精神：}
\begin{enumerate}[leftmargin=*]
    \item 降低生产过程中的人为错误。
    \item 防止食品在生产过程中遭到污染和品质劣变。
    \item 建立企业自主性质量保证体系。
\end{enumerate}
\end{keybox}

\section{HACCP（危害分析与关键控制点）}

\subsection{HACCP概念}

\begin{keybox}
\textbf{HACCP（Hazard Analysis and Critical Control Point）：}危害分析与关键控制点。是"从农田到餐桌"全过程的食品安全预防体系。通过对食品生产全过程的危害分析，确定关键控制点并采取控制措施，将危害降低到可接受水平。

\textbf{HACCP建立的前提条件：}HACCP体系必须建立在GMP和SSOP的基础之上。
\end{keybox}

\subsection{HACCP的7个基本原则}

\begin{keybox}
\textbf{HACCP的7个基本原则（掌握*）：}

\begin{enumerate}[leftmargin=*]
    \item \textbf{进行危害分析（Hazard Analysis）：}对食品生产全过程进行系统的危害分析，识别所有潜在的生物性、化学性和物理性危害。对每个危害进行风险评估。

    \item \textbf{确定关键控制点（Critical Control Point, CCP）：}确定能够实施控制的、对防止和消除食品安全危害或将其降低到可接受水平所必需的某一步骤。CCP的三种控制形式：防止危害发生、消除危害、降低到可接受水平。

    \item \textbf{建立关键限值（Critical Limit, CL）：}在CCP上设定的最大值和/或最小值，用于将危害控制在一定范围内。如巴氏消毒最低72$^\circ$C、15秒。

    \item \textbf{建立CCP的监控系统（Monitoring）：}按照计划对CCP进行观察和测量，以判断CCP是否处于控制之中。监控四大要素：监控什么（What）、怎样监控（How）、监控频次（Frequency）、谁监控（Who）。

    \item \textbf{建立纠偏措施（Corrective Action）：}当监控发现CCP偏离关键限值时，立即采取的措施。包括隔离和评估受影响产品、纠正偏离原因、防止再次发生、记录全部纠偏活动。

    \item \textbf{建立验证程序（Verification）：}确认HACCP体系是否有效运行。验证的三个维度：适宜性、一致性、有效性。

    \item \textbf{建立记录保持程序（Record-keeping）：}所有HACCP相关活动必须有完整、准确的记录。文件包括：HACCP计划文本、危害分析表、CCP监控记录、纠偏记录、验证记录。
\end{enumerate}
\end{keybox}

\subsection{HACCP体系的建立}

\begin{keybox}
\textbf{HACCP体系的建立步骤（掌握*）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{组成HACCP小组：}由多学科专业人员组成，涵盖食品生产、质量管理、卫生、微生物学、工程技术等领域。
    \item \textbf{产品描述：}对产品的原料、组成、加工方法、包装、储存条件、保质期、预期用途和消费者群体进行全面描述。
    \item \textbf{收集和掌握制定HACCP计划所需的相关资料：}包括与产品相关的危害信息、法律法规要求、标准等。
    \item \textbf{绘制流程图并验证流程图：}详细绘制从原料接收到成品出厂的完整生产流程图，并在现场验证流程图的准确性。
    \item \textbf{根据HACCP的7个原理建立及编写HACCP计划：}按照7个原理逐项落实，形成完整的书面HACCP计划文件。
\end{enumerate}
\end{keybox}

\subsection{HACCP的意义}

\begin{defbox}
\textbf{HACCP的意义（了解）：}
\begin{itemize}[leftmargin=*]
    \item 将食品安全从"最终产品检验"转向"全过程的预防性控制"，将被动管理变为主动预防。
    \item 提高食品安全保障水平，降低食品安全事故发生概率。
    \item 与国际接轨，有利于食品国际贸易。
    \item 提高企业经济效益（减少产品损失、降低召回风险）。
\end{itemize}
\end{defbox}

\section{食品经营的监督管理}

\begin{defbox}
\textbf{食品经营的监督管理（了解）：}
\begin{itemize}[leftmargin=*]
    \item 对食品生产、流通、餐饮服务等环节实施全面监督管理。
    \item \textbf{食品生产环节：}实施食品生产许可制度，GMP和HACCP体系推行。
    \item \textbf{食品流通环节：}食品经营许可，进货查验记录，索证索票制度，食品储存和运输的卫生要求。
    \item \textbf{餐饮服务环节：}餐饮服务许可，从业人员健康管理，原料采购索证，加工操作卫生规范，餐具消毒。
    \item \textbf{食品召回制度：}发现不符合食品安全标准的食品，生产者应当立即停止生产并召回；经营者应当立即停止经营并通知相关生产者。
\end{itemize}
\end{defbox}

\section{食品安全法}

\begin{defbox}
\textbf{食品安全法（2015年修订）：}确立了以食品安全风险监测和评估为基础的科学管理制度。2015年10月1日修订版正式实施，被称为"史上最严"食品安全法。

\textbf{四大原则：}预防为主、风险管理、全程控制、社会共治。

\textbf{核心制度：}食品安全风险监测制度、食品安全风险评估制度、食品安全标准制度、食品生产经营许可制度、食品召回制度、食品安全信息发布制度。
\end{defbox}
