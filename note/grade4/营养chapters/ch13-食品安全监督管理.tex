\section{食品安全监督管理概述}

\subsection{食品安全监督管理的概念}

\begin{keybox}
\textbf{食品安全监督管理的概念（掌握）：}指政府及其相关部门开展的食品安全监督执法和食品安全管理工作，包括食品生产加工、流通环节、餐饮环节食品安全的日常监管；实施行政许可、强制检验等食品质量安全市场准入制度；查处生产、制造不合格食品及其他违法行为；食品行业和企业的自律及其相关食品安全管理活动等。
\end{keybox}

\subsection{食品安全法律法规体系}

\begin{keybox}
\textbf{食品安全法律法规体系构成（掌握）：}食品安全法律；食品安全法规；食品安全规章；食品安全标准；其他规范性文件。
\end{keybox}

\subsection{食品安全监督管理应遵循的原则和方法}

\begin{defbox}
\textbf{食品安全监督管理的原则和方法（熟悉）：}

\textbf{1. 预防为主：}在事实判定、证据论证、科学研究等方面尚未确定的情况下，为防止食品安全损害而采取的预防性措施。

\textbf{2. 风险管理：}考虑风险评估和其他法律因素，要与利益相关方磋商并权衡利弊，选择适当的政策和预防控制措施。

\textbf{3. 全程控制（Process monitoring）：}对食品从源头的生产，到中间经营销售，再到消费者的消费整个过程的控制监管。

\textbf{4. 社会共治：}法律明确了社会监督的法律地位。
\end{defbox}

\section{食品安全标准}

\subsection{食品安全标准的概念、性质和分类}

\begin{keybox}
\textbf{食品安全标准（Food safety standard）的概念（掌握）：}指对食品中具有与人类健康相关的质量要素和技术要求及其检验方法、评价程序等所作的规定。是\textbf{强制性标准}。
\end{keybox}

\begin{defbox}
\textbf{食品安全标准的分类（熟悉）：}
\begin{itemize}[leftmargin=*]
    \item 国家标准
    \item 行业标准
    \item 地方标准
    \item 团体标准
    \item 企业标准
\end{itemize}
\end{defbox}

\subsection{食品安全标准的内容和主要技术指标}

\begin{keybox}
\textbf{食品安全标准的内容（了解）：}
\begin{enumerate}[leftmargin=*]
    \item 食品、食品添加剂、食品相关产品中的致病性微生物、农药残留、兽药残留、重金属、生物毒素、污染物质以及其他危害人体健康物质的限量规定
    \item 食品添加剂的品种、使用范围、用量
    \item 专供婴幼儿和其他特定人群的主辅食品的营养成分要求
    \item 对与食品安全、营养有关的标签、标识、说明书的要求
    \item 食品生产经营过程的卫生要求
    \item 与食品安全有关的质量要求
    \item 与食品安全有关的食品检验方法与规程
    \item 其他需要制定为食品安全标准的内容
\end{enumerate}

\textbf{主要技术指标（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{严重危害人体健康的指标：}包括致病性微生物与毒素（如沙门氏菌、金黄色葡萄球菌及其产生的肠毒素、真菌毒素、副溶血性弧菌等）；有毒有害化学物质（如砷、铅、汞、镉、多环芳烃类化合物等）；放射性污染物。
    \item \textbf{反映食品可能被污染及污染程度的指标：}包括菌落总数、大肠菌群等。
    \item \textbf{间接反映食品安全质量发生变化的指标：}包括水分、含氮化合物、挥发性盐基氮等。
    \item \textbf{营养指标：}包括碳水化合物、脂肪、蛋白质、矿物质、维生素等营养素和能量、膳食纤维等指标。专供婴幼儿和其他特定人群的主辅食品的营养成分要求尤其重要。
    \item \textbf{商品质量指标。}
\end{enumerate}
\end{keybox}

\subsection{食品中有毒有害物质限量标准制订}

\begin{keybox}
\textbf{食品中有毒有害物质限量指标的一般原则（掌握）：}
\begin{enumerate}[leftmargin=*]
    \item 无需对食品中所有的污染物和毒素设立限量值；
    \item 限量值的设立对消费者总暴露量有显著性意义；
    \item 限量值的设立对消费者要有充分的保护，暴露量极少的食品对污染物限量没有经济学和公共健康意义。
\end{enumerate}

\textbf{食品中有毒有害物质限量标准的制订步骤与方法（掌握*）：}

\textbf{制订步骤：}
\begin{enumerate}[leftmargin=*]
    \item 动物毒性实验——确定NOAEL或BMDL
    \item 根据动物实验结果，考虑运用人的安全系数（100--1000倍），确定人的每日允许摄入量（ADI）或每日可耐受摄入量（TDI）
    \item 考虑来源于食物的该物质所占比例，确定每日总膳食中的允许含量
    \item 考虑该物质的食物种类和人的每日摄入量（食物系数），确定该物质在每种食物中的最大允许量
    \item 综合考虑各方面实际情况，制定食品中的有害限量标准
\end{enumerate}
\end{keybox}

\subsection{食品安全标准体系概况}

\begin{defbox}
\textbf{食品安全标准体系概况（了解）：}
该标准提出并遵循了食品安全管理原则，将消费者食用安全作为建立与实施食品安全管理体系的关注焦点，重点强调对食物链中影响食物安全的危害进行过程、系统化和可追溯性控制，最终产品的检验仅是辅助或验证手段。
\end{defbox}

% [补充自往届笔记] 食品安全标准的定义和分类补充说明
\begin{tipbox}
\textbf{要点提示：}食品安全标准是对食品中具有与人类健康相关的质量要素和技术要求及其检验方法所作的规定。分类：食品安全国家标准、食品安全地方标准、企业标准。
\end{tipbox}

% [补充自往届笔记] 食品安全标准的主要技术指标详细分类
\begin{defbox}
\textbf{食品安全标准的主要技术指标（补充）：}
\begin{enumerate}[leftmargin=*]
    \item 严重危害人体健康的指标：
    \begin{itemize}[leftmargin=*]
        \item 生物性：致病性微生物与毒素（如沙门氏菌、金黄色葡萄球菌及其产生的肠毒素、真菌毒素、副溶血性弧菌等）
        \item 化学性：有毒有害化学物质（如砷、铅、汞、镉、多环芳烃类化合物等）
        \item 物理性：放射性污染物等
    \end{itemize}
    \item 反映食品可能被污染及污染程度的指标：菌落总数、大肠菌群等
    \item 间接反映食品安全质量发生变化的指标：水分、含氮化合物、挥发性盐基氮等
    \item 营养指标：碳水化合物、脂肪、蛋白质、矿物质、维生素、膳食纤维等
    \item 商品质量指标
\end{enumerate}
\end{defbox}

\section{GMP（良好生产规范）}

\subsection{GMP的概念}

\begin{keybox}
\textbf{GMP（Good Manufacturing Practice）的概念（掌握）：}食品良好生产规范。是HACCP实施的前提，是政府强制性的有关食品生产、加工、包装、贮存、运输和销售的卫生要求。

是为保障食品安全和质量而制定的贯穿食品生产全过程的一系列措施、方法和技术要求。它是一种特别注重生产过程中产品质量与卫生安全的自主性管理制度。GMP要求食品生产企业具备良好的生产设备、合理的生产过程、完善的质量管理和检测系统，确保最终产品的安全质量符合有关标准。
\end{keybox}

\subsection{GMP的主要内容（4M管理要素）}

\begin{keybox}
\textbf{GMP的主要内容（4M，熟悉）：}
\begin{enumerate}[leftmargin=*]
    \item \textbf{人员（Man）：}要配备合适且能胜任的从业人员。要求从业人员健康检查合格，经过食品安全知识培训。
    \item \textbf{原料（Material）：}要选用良好的原料来制造。
    \item \textbf{设备（Machine）：}要采用标准规范的厂房和机器设备。厂房布局合理（人流物流分离），设备易于清洗消毒。
    \item \textbf{方法（Method）：}要遵照既定的最佳方法进行制造。包括标准操作规程（SOP），工艺参数控制。
\end{enumerate}
\end{keybox}

\subsection{SSOP（卫生标准操作程序）}

\begin{defbox}
\textbf{SSOP（Sanitation Standard Operation Procedures）的概念（熟悉）：}

SSOP是HACCP实施的前提条件。指在食品生产和加工过程中实施清洗、消毒和卫生保持的作业文件。

是食品加工企业为了保证达到GMP所规定的要求，确保加工过程中消除不良因素，使加工出的食品符合要求而制定的。

\textbf{GMP与SSOP的关系：}
\begin{enumerate}[leftmargin=*]
    \item SSOP是具体形成文件的，GMP没有要求
    \item GMP通常与SSOP的程序和工作指导书有关，GMP为SSOP明确了总的规范和要求
    \item 食品企业必须先遵循GMP的规定，然后建立并有效地实施SSOP
    \item GMP和SSOP是相互依赖的，只强调GMP的卫生控制方面（8个主要卫生条件），如果SSOP的设计不符合GMP的要求，再好的设计标准，也是不合理的
\end{enumerate}

\textbf{GMP、SSOP与HACCP的关系：}
\begin{itemize}[leftmargin=*]
    \item SSOP和GMP是基础和前提条件
    \item SSOP在对HACCP系统的支持性程序中扮演重要角色
    \item SSOP的重点集中在食品和加工有关的危害上
    \item SSOP能控制加工厂环境
\end{itemize}

\textbf{总结：}
GMP是一套规范；SSOP是一套标准操作规程；HACCP是一套过程控制体系。三者互为基础、缺一不可。离开了GMP和SSOP谈HACCP计划，HACCP计划只能是空中楼阁。同理，只有GMP和SSOP控制，也不能保证完全消除食品安全隐患，因为它们只做到了环境控制，不能代替危害分析和关键控制点。
\end{defbox}

\section{HACCP（危害分析与关键控制点）}

\subsection{HACCP的概念}

\begin{keybox}
\textbf{HACCP（Hazard Analysis and Critical Control Point）的概念（掌握*）：}

危害分析与关键控制点。是一个食品安全预防性管理体系。由7个原理组成：危害分析（HA）、确定关键控制点（CCP）、确定关键限值（CL）、监控关键控制点（M）、纠偏措施（CA）、验证（V）、记录保持（R）。

是一种食品安全保证体系，是为了防止食品安全问题的发生，对食品生产加工过程中造成食品污染的各种危害因素进行系统、全面的分析，确定能有效预防、消除和减少危害的加工环节，即"关键控制点"，进而在关键控制点对危害因素进行控制，同时建立有效监控手段，当偏移时予以纠正，并及时对控制方法进行纠正和补充。
\end{keybox}

\subsection{HACCP的7个基本原理}

\begin{keybox}
\textbf{HACCP的7个基本原理（掌握*）：}

\textbf{1. 进行危害分析（HA）：}
收集信息，评估危害和导致其存在的条件的过程，以便确定哪些对食品安全有重要意义，从而应被列入HACCP计划中。危害分析分为三个阶段：危害识别和危害评估。

\textbf{2. 确定关键控制点（CCP）：}
有效控制是指防止危害的发生、消除危害或将危害降低到可接受的水平。

\textbf{3. 建立确定的关键控制点极限值（CL）：}
在CCP上设定的最大值和/或最小值，用于将危害控制在一定范围内。如巴氏消毒最低\imp{72}$^\circ$C、\imp{15秒}。

\textbf{4. 对关键控制点进行监控（M）：}
按照制定的计划进行观察和测量，判断某一CCP是否处于受控之下，并作准确记录，以备未来验证。

有效控制是指防止危害的发生、消除危害或将危害降低到可接受的水平。

\textbf{5. 建立纠偏措施（CA）：}
当监控发现CCP偏离关键限值时，立即采取的措施。包括隔离和评估受影响产品、纠正偏离原因、防止再次发生、记录全部纠偏活动。

\textbf{6. 建立验证程序（V）：}
确认HACCP体系是否有效运行。

\textbf{7. 建立有效记录的档案系统（R）：}
所有HACCP相关活动必须有完整、准确的记录。包括：HACCP计划文本、危害分析表、CCP监控记录、纠偏记录、验证记录。
\end{keybox}

\subsection{HACCP体系的建立}

\begin{keybox}
\textbf{HACCP体系的建立步骤（掌握*）：}
\begin{enumerate}[leftmargin=*]
    \item 组建HACCP小组
    \item 产品描述（预备步骤）
    \item 收集和掌握制定HACCP计划所需的相关资料
    \item 绘制流程图并验证流程图
    \item 根据HACCP的7个原理建立及编写HACCP计划
    \item HACCP计划的验证
\end{enumerate}
\end{keybox}

% [补充自往届笔记] HACCP建立步骤详细描述
\begin{tipbox}
\textbf{要点提示（补充自往届笔记）：}HACCP体系的建立步骤：组建HACCP工作组；描述产品并确定产品预期用途；绘制产品加工流程图并现场确认流程图；危害分析确定关键控制点（CCP）；确定关键限值；建立监控程序；建立纠偏措施；验证审核HACCP计划；建立运行和有效记录档案制度。
\end{tipbox}

\section{食品经营的监督管理}

\begin{defbox}
\textbf{食品经营的监督管理（了解）：}
\begin{enumerate}[leftmargin=*]
    \item 检查经营许可证是否在有效期内。食品经营许可证印制为"许可证"，换证时有效期\imp{5年}。
    \item 检查经营许可证是否按规定年检
    \item 检查是否超范围经营
    \item 检查是否无证经营
\end{enumerate}
\end{defbox}

% [补充自往届笔记] 食品生产经营的监督管理扩展
\begin{tipbox}
\textbf{要点提示（补充自往届笔记）：}对食品生产经营的监督管理，涵盖食品生产、流通、餐饮服务等环节，包括实施行政许可、强制检验等食品质量安全市场准入制度，查处生产制造不合格食品及其他违法行为。
\end{tipbox}

\section{食品安全法与相关制度}

\begin{defbox}
\textbf{食品安全法（2015年修订，了解）：}确立了以食品安全风险监测和评估为基础的科学管理制度。\imp{2015年10月1日}修订版正式实施，被称为"史上最严"食品安全法。

\textbf{四大原则：}预防为主、风险管理、全程控制、社会共治。

\textbf{核心制度：}食品安全风险监测制度、食品安全风险评估制度、食品安全标准制度、食品生产经营许可制度、食品召回制度、食品安全信息发布制度。
\end{defbox}

\subsection{食品安全风险监测}

\begin{defbox}
\textbf{食品安全风险监测（了解）：}
指通过系统和持续地收集食源性疾病、食品污染以及食品中有害因素的监测数据及相关信息，并进行综合分析和及时通报的活动。食品安全风险监测是针对某类食品的食用安全性展开的评价、预警和检测，是对食品安全风险管理的基础和前提，也是风险分析阶段的科学数据来源。

\textbf{风险监测与监督抽检的区别：}
风险监测和监督抽检的目的都是发现问题，以保护消费者食用安全，但两者有具体的目的：
\begin{itemize}[leftmargin=*]
    \item 风险监测的主要目的：为收集数据以制定和修订食品安全国家标准和掌握实际情况
    \item 监督抽检的主要目的：是发现不符合执行的食品安全国家标准的产品（即合格与否评价）
    \item 两者之间：一个是为了制定标准，一个是为了判定符合标准——两者不能混淆
\end{itemize}

\textbf{食品安全风险监测的范围：}
\begin{enumerate}[leftmargin=*]
    \item 食品中各种化学污染物监测
    \item 投入品和农业投入品的监测
    \item 食品中各种生物污染物监测
    \item 违法添加物监测
\end{enumerate}

\textbf{食品安全风险监测的对象：}
\begin{enumerate}[leftmargin=*]
    \item 食品
    \item 食品添加剂
    \item 食品包装材料
    \item 食源性疾病
\end{enumerate}

\textbf{优先监测的内容：}
\begin{enumerate}[leftmargin=*, start=5]
    \item 健康危害较大、风险程度较高以及污染水平呈上升趋势的
    \item 易于对婴幼儿、孕产妇、老年人、病人造成健康影响的
    \item 流通范围广、消费量大的
    \item 以往在国内导致食品安全事故或者受到消费者关注的
    \item \imp{5年}内在国外导致健康危害并有证据表明可能在国内存在的
\end{enumerate}
\end{defbox}

% [补充自往届笔记] 食品安全的监督抽检内容
\begin{tipbox}
\textbf{要点提示（补充自往届笔记）：}食品安全的监督抽检主要内容包括：食品安全风险监测和食品安全风险评估。对食品生产经营的监督管理，涵盖食品生产、流通、餐饮服务等环节，包括实施行政许可、强制检验等食品质量安全市场准入制度，查处生产制造不合格食品及其他违法行为。

食品安全监督管理的原则和方法包括：预防为主（在事实判定、证据论证、科学研究尚未确定的情况下为防损害取的预防措施）、风险管理（考虑风险评估和利弊权衡，与利益相关方磋商选择适当的政策）、全程控制（从源头到消费全过程监管）、社会共治（法律明确社会监督地位）。
\end{tipbox}

% [补充自往届笔记] 食品生产经营的监督管理（完整补充）
\subsection{食品生产经营的监督管理（补充）}

\begin{defbox}
\textbf{食品生产经营的监督管理（补充自往届笔记）：}
对食品生产环节、流通环节、餐饮服务环节的全过程实行监督管理。食品安全监督管理的核心原则：
\begin{enumerate}[leftmargin=*]
    \item \textbf{预防为主：}以预防为主导，强调风险的预先识别和干预，通过风险评估确定优先领域和控制措施
    \item \textbf{风险管理：}食品安全监管应在风险评估基础上，结合经济、文化、技术等因素进行分级管理
    \item \textbf{全程控制：}从农田到餐桌的全过程监控
    \item \textbf{社会共治：}政府主导、企业负责、行业自律、媒体监督、公众参与的多元治理格局
\end{enumerate}
\end{defbox}

\section{食品安全事故与健康指导值}

\subsection{食品安全事故}

\begin{tipbox}
\textbf{食品安全事故概念（了解）：}
\textbf{食品安全事故（Accident）：}指食源性疾病、食物中毒、食品污染等源于食品、对人体健康有危害或者可能有危害的事故。

\textbf{健康指导值（health-based guidance values, HBGV）：}指人类在一定时期内（如\imp{24小时}）摄入某种（或某些）物质，而不产生可检测到的对健康危害的安全限值。包括每日允许摄入量、每日可耐受摄入量、急性参考剂量等。
\end{tipbox}

\subsection{各类健康指导值}

\begin{defbox}
\textbf{健康指导值的分类（了解）：}

\textbf{(1) 每日允许摄入量（acceptable daily intake, ADI）：}指人类终生每日随膳食摄入使用的某种化学物质（如食品添加剂），不产生可检测到的对健康危害的量。

\textbf{(2) 可耐受摄入量（tolerable intake, TI）：}指人类在一段时间内或终生暴露于某种化学物质，不产生可检测到的对健康危害的量。具体包括：
\begin{itemize}[leftmargin=*]
    \item 暂定每日最大可耐受摄入量（provisional maximal tolerable daily intake, PMTDI）
    \item 暂定每周可耐受摄入量（PTWI）
    \item 暂定每月可耐受摄入量（PTMI）
\end{itemize}

\textbf{(3) 急性参考剂量（ARFD）：}指人类在\imp{24小时}或更短时间内摄入食品及饮用水中的某种化学物质（如农药），在短时间内（通常指一餐或一天内）吸收后，不产生目前已知的任何可检测到的对健康危害的量。

\textbf{食品与健康指导值的关系：}
\begin{itemize}[leftmargin=*]
    \item 食品中应用的应提供每日允许摄入量（ADI - acceptable daily intake）
    \item 食品中的致癌物，ADI来源于实验动物NOAEL（no-observed-adverse-effect level）
    \item 对于环境污染物：TDI（tolerable daily intake）/ Provisional tolerable weekly intake（PTWI）
    \item 对于营养素：要制定每日推荐摄入量（RNI值）
\end{itemize}
\end{defbox}

\subsection{基准剂量下限（BMDL）}

\begin{defbox}
\textbf{基准剂量下限（BMDL）概念（了解）：}
通过剂量-反应曲线获得的，与背景值相比，达到预先确定的损害效应概率（通常为\imp{1\%--10\%}）相应反应的剂量。一般取95\%置信区间的可信限下限值。
\end{defbox}

% [补充自往届笔记] NOAEL与BMDL补充
\begin{tipbox}
\textbf{要点提示（补充自往届笔记）：}NOAEL（未观察到有害作用的水平）是通过动物毒性实验确定的最高无有害作用剂量。BMD（基准剂量）是通过对剂量-反应数据进行数学模拟得到的产生特定效应水平（如10\%额外风险）的剂量，一般用95\%可信限下限值BMDL代替NOAEL。
\end{tipbox}

\section{食品安全性风险分析（补充巩固）}

\begin{defbox}
\textbf{风险分析框架（了解）：}

\textbf{风险评估概念：}对各种食品风险，包括危害（风险）的定义和特征描述。对有害事件发生的可能性和不确定性进行评估（危害识别、危害特征描述、暴露评估以及风险特征描述）四个部分构成的整个过程。

\textbf{风险分析构成要素：}
\begin{enumerate}[leftmargin=*]
    \item 危害识别
    \item 危害特征描述
    \item 暴露评估（即膳食暴露评估）
    \item 风险特征描述：在危害识别、危害特征描述和暴露评估的基础上，综合分析危害对人群健康产生不良作用的风险及其程度，同时描述和解释风险评估过程中的不确定性。
\end{enumerate}

\textbf{实施食品安全风险分析的时机/情形：}
\begin{enumerate}[leftmargin=*]
    \item 通过食品安全风险监测或者接到举报发现食品、食品添加剂、食品相关产品可能存在安全隐患的
    \item 为制定或者修订食品安全国家标准提供科学依据需要进行风险评估的
    \item 为确定监督管理的重点领域、重点品种需要进行风险评估的
    \item 发现新的可能危害食品安全因素的
    \item 需要判断某一因素是否构成食品安全隐患的
    \item 国务院卫生行政部门认为需要进行风险评估的其他情形
\end{enumerate}

\textbf{2. 风险管理：}根据风险评估结果，风险管理机构选择适当的政策并执行。

\textbf{3. 风险交流：}在风险评估人员、风险管理人员、消费者和其他有关各方之间进行的有关风险的信息和意见的互动交流过程。
\end{defbox}

\section{食品安全性毒理学评价（跨章节关联）}

\subsection{食品中的危害因素来源和分类}

\begin{defbox}
\textbf{食品中危害因素的来源：}
\begin{enumerate}[leftmargin=*]
    \item 食品本身固有的或发生变化的物质
    \item 食品加工、保藏过程中有意无意形成的有害物质
    \item 环境污染物
    \item 食品加工、保藏中使用的成分、食品添加剂使用，是否含可能有害的非食品用物质
\end{enumerate}

\textbf{食品中危害因素的种类：}
\begin{enumerate}[leftmargin=*]
    \item 生物性因素：微生物、细菌及其毒素、病毒、寄生虫、昆虫、螨虫
    \item 化学性因素：天然有机化合物、无机化合物、人工合成物
    \item 物理性因素：毛发、皮毛、木屑、铁钉、小虫尸体、放射性物质
\end{enumerate}
\end{defbox}

\subsection{食品安全性毒理学评价的概念与内容}

\begin{defbox}
\textbf{食品安全性评价概念（了解）：}
对食品中任何组分可能引起的危害进行科学测试、得出结论，以确定该组分究竟能否为社会和消费者接受，据此制定相应的标准，这一过程称为食品的安全性评价。

\textbf{特点：}
涉及食品毒理学、流行病学、临床医学、化学（分析化学、有机化学、生物化学）和生物统计等，其中食品毒理学和流行病学是较为重要的部分。

\textbf{1. 毒理学：}是从毒理学角度，研究食品中所含的内源化学物质或可能含有的外源化学物质对食用者的毒性作用机理，检验和评价食品（包括食品添加剂）的安全性或安全范围，从而确定安全限量的学科。

\textbf{毒理学研究相较于流行病学的优点：}
\begin{itemize}[leftmargin=*]
    \item 可进行研究方案的设计，条件均一，能够消除混杂因素的干扰
    \item 能容易地确定物质的暴露条件、暴露过程和暴露剂量（包括饮食和饮水）被详细记录和控制，可通过组织病理学、生物化学等方法进行可能的最高剂量和最大效应研究等
\end{itemize}

\textbf{毒理学研究的局限性：}
\begin{itemize}[leftmargin=*]
    \item 毒理学研究结果不能直接应用于人，因为实验动物（小鼠）和\imp{60kg}体重的人是不同的
    \item 大部分的毒理学试验中，实验动物只涉及某一种物质和同一时间暴露的反应，而人一般暴露在不同化学物中，由于成分的相互作用、混合物的不同，物质的暴露可能有预料不到（和不能预料）的结果影响
\end{itemize}

\textbf{2. 流行病学是观察学科。}
\end{defbox}

\subsection{食品安全性毒理学评价程序与适用范围}

\begin{defbox}
\textbf{现代食品安全性评价（了解）：}
除了进行传统的毒理学评价研究外，还包括食品的成分、营养素、吸收代谢、食品添加剂的安全性、食品中风险因素研究、总膳食研究（暴露量研究）、膳食水平（膳食结构）、风险特征描述等。

\textbf{食品安全性评价程序的适用范围：}
\begin{enumerate}[leftmargin=*]
    \item 用于评价食品生产、加工、保藏、运输和销售过程中所涉及的可能对健康造成危害的化学、生物和物理因素的安全性
    \item 评价对象包括食品新资源、食品添加剂、新食品原料、保健食品、食品相关产品（包括食品的包装材料、容器、洗涤消毒剂、用于食品生产经营的工具、设备，以及食品污染物）。特别注意：\imp{5}个环节，\imp{6}个对象
\end{enumerate}
\end{defbox}

\subsection{毒理学评价试验的内容}

\begin{defbox}
\textbf{毒理学评价试验的内容（了解）：}
\begin{enumerate}[leftmargin=*]
    \item 急性经口毒性试验
    \item 遗传毒性试验
    \item \imp{28天}经口毒性试验
    \item \imp{90天}经口毒性试验
    \item 致畸试验
    \item 生殖毒性试验
    \item 毒物动力学试验
    \item 慢性毒性试验
    \item 致癌试验
    \item 慢性毒性和致癌合并试验、致癌合并试验
\end{enumerate}
共\imp{10}项试验，一般遵循循序渐进原则：先做急性，再做遗传，再做亚慢性、慢性等。

\textbf{对不同受试物质选择试验的原则：}
\begin{itemize}[leftmargin=*]
    \item \textbf{我国创制的新物质，特别是化学结构提示有潜在毒性、遗传毒性或致癌性的物质，或使用范围广、量大者，应进行系统的毒性试验，}包括急性经口毒性试验、遗传毒性试验、\imp{90天}经口毒性试验、致畸试验、生殖毒性试验、毒物动力学试验、慢性毒性试验和致癌试验（或慢性毒性和致癌合并试验）
    \item \textbf{对于已知物质（指已有全面评价资料允许使用者），}其化学结构与另一已知毒性的化合物相同，且在部分国家和地区有安全食用历史的物质，可先进行急性经口毒性试验、遗传毒性试验、\imp{90天}经口毒性试验和致畸试验，根据结果判断是否需进行毒物动力学试验、生殖毒性试验、慢性毒性试验和致癌试验等
    \item \textbf{对于已知的基于人群有食用历史的物质，}同时与待评价单位联系和申报资料样品一致，可先进行急性经口毒性试验、遗传毒性试验和\imp{28天}经口毒性试验，根据结果判断是否需进行进一步的毒性试验
    \item 食品添加剂、新食品原料、食品相关产品、农药残留、兽药残留等的安全性毒理学评价，应根据《食品安全国家标准 食品安全性毒理学评价程序》（GB 15193.1-2014）的要求选择适当的试验
\end{itemize}
\end{defbox}

\subsection{食品安全性毒理学评价时需要考虑的重要因素}

\begin{defbox}
\textbf{需综合考虑的因素：}

\textbf{1. 指标的统计学意义、生物学意义和毒理学意义：}综合考虑指标是否有统计学、生物学和毒理学意义，而不是一味判断是否有毒理学意义。此外，如果在试验中发现某种剂量组没有发现异常，但是检出值似乎有统计学意义，也需要引起注意。

\textbf{2. 人的推荐剂量或最大摄入量：}对于最大摄入量较大的受试物，应考虑高剂量对营养素吸收的影响造成表现营养素不平衡，从而影响某些毒理学表现（假阳性的毒性表现）。

\textbf{3. 时间-剂量-效应关系：}在对受试物/实验动物的毒性效应进行分析时，要注意不同剂量水平下毒性效应随时间的变化情况。

\textbf{4. 特殊人群和易感人群：}对妊娠妇女、哺乳母亲和儿童食用的食品，应特别注意其胚胎毒性或生殖发育毒性、神经毒性和免疫毒性等。

\textbf{5. 人群资料：}尽可能收集人群接触受试物后的反应资料，如职业性接触和意外事故接触等。

\textbf{6. 不确定系数（安全系数）：}将动物毒性实验结果外推到人时，鉴于动物和人的种属和个体之间的生物学差异，用不确定系数通常为\imp{100}。可根据受试物来源、毒性大小、代谢特性、接触暴露情况、人群接触范围、食品中使用量及人类可能摄入量、使用范围及可能性等综合确定其安全系数的大小。

\textbf{7. 毒物动力学资料：}在毒性学试验中，原则上应尽量使用与人具有相同毒物动力学代谢模式的动物或品系来进行试验。

\textbf{8. 综合评价：}全面考虑被评价物质的理论性质、结构、毒性大小、代谢特性、接触暴露情况、人群接触范围、食品中的使用量和食用范围、人类的推荐摄入量等，进行综合评价。
\end{defbox}

\end{enumerate}

\subsubsection*{名词解释（要点）}

\begin{enumerate}[leftmargin=*, itemsep=4pt]
    \item \textbf{食品安全监督管理：}政府及其相关部门开展的食品安全监督执法和食品安全管理工作，包括食品生产、加工、流通环节、餐饮环节食品安全的日常监管等。
    \item \textbf{食品安全标准：}对食品中具有与人类健康相关的质量要素和技术要求及其检验方法、评价程序等所作的规定，是强制性标准。
    \item \textbf{GMP：}良好生产规范，是为保障食品安全和质量而制定的贯穿食品生产全过程的一系列措施、方法和技术要求。GMP是HACCP实施的前提。
    \item \textbf{SSOP：}卫生标准操作程序，指在食品生产和加工过程中实施清洗、消毒和卫生保持的作业文件，是HACCP实施的前提条件。
    \item \textbf{HACCP：}危害分析与关键控制点，是"从农田到餐桌"全过程的食品安全预防和控制体系。
    \item \textbf{CCP：}关键控制点，能够实施控制的、对防止和消除食品安全危害或将其降低到可接受水平所必需的某一步骤。
    \item \textbf{CL：}关键限值，在CCP上设定的最大值和/或最小值，用于将危害控制在一定范围内。
    \item \textbf{ADI：}每日允许摄入量，人类终生每日随膳食摄入使用的某种化学物质而不产生可检测到的对健康危害的量。
    \item \textbf{TDI：}每日可耐受摄入量，人类终生每日暴露于某种化学物质不产生可检测到的对健康危害的量。
    \item \textbf{HBGV：}健康指导值，人类在一定时期内摄入某种物质而不产生可检测到的健康危害的安全限值。
    \item \textbf{BMDL：}基准剂量下限，达到预先确定的损害效应概率（1\%--10\%）相应反应的剂量，一般取95\%置信区间的可信限下限值。
    \item \textbf{食品安全事故：}指食源性疾病、食物中毒、食品污染等源于食品、对人体健康有危害或者可能有危害的事故。
\end{enumerate}

\subsubsection*{简答题（要点）}

\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item \textbf{食品安全监督管理：}政府及其相关部门开展的食品安全监督执法和食品安全管理工作，包含食品生产加工、流通环节、餐饮环节的日常监管；实施行政许可、强制检验等市场准入制度；查处不合格食品和违法行为；行业和企业自律管理活动等。
    \item \textbf{法律法规体系构成：}食品安全法律；食品安全法规；食品安全规章；食品安全标准；其他规范性文件。
    \item \textbf{四大原则：}①预防为主；②风险管理；③全程控制；④社会共治。
    \item \textbf{食品安全标准：}是对食品中具有与人类健康相关的质量要素和技术要求及检验方法、评价程序等所作的规定，是强制性标准。分类：国家标准、行业标准、地方标准、团体标准、企业标准。
    \item \textbf{技术指标：}①严重危害人体健康的指标（生物性/化学性/物理性）；②反映污染及污染程度的指标（菌落总数、大肠菌群）；③间接反映安全质量变化的指标（水分、含氮化合物、挥发性盐基氮）；④营养指标；⑤商品质量指标。
    \item \textbf{限量标准制订步骤：}①动物毒性实验确定NOAEL或BMDL；②用安全系数（100--1000）确定ADI或TDI；③确定每日总膳食中的允许含量；④确定每种食物中的最大允许量；⑤制定限量标准。
    \item \textbf{GMP及4M：}良好生产规范，贯穿食品生产全过程的管理体系。四大要素：Man（人员）、Material（原料）、Machine（设备）、Method（方法）。
    \item \textbf{HACCP的7原则：}①危害分析（HA）；②确定关键控制点（CCP）；③建立关键限值（CL）；④监控CCP（M）；⑤建立纠偏措施（CA）；⑥建立验证程序（V）；⑦建立记录保持程序（R）。
    \item \textbf{HACCP建立步骤：}①组建HACCP小组；②产品描述；③收集制定HACCP计划所需资料；④绘制并验证流程图；⑤按7个原理编写HACCP计划；⑥HACCP计划的验证。
    \item \textbf{GMP-SSOP-HACCP关系：}GMP是规范，SSOP是标准操作规程，HACCP是过程控制体系。三者互为基础、缺一不可。SSOP和GMP是HACCP的前提条件。
    \item \textbf{风险监测：}通过系统和持续收集食源性疾病、食品污染及有害因素的监测数据并综合分析和通报。范围：化学污染物、农业投入品、生物污染物、违法添加物。对象：食品、食品添加剂、食品包装材料、食源性疾病。
    \item \textbf{风险监测vs监督抽检：}风险监测——为收集数据以制定和修订标准；监督抽检——发现不符合现行标准的产品。一个为制定标准，一个为判定符合标准，不能混淆。
    \item \textbf{风险分析时机：}①接到举报发现安全隐患；②为制修订标准提供依据；③确定监管重点领域品种；④发现新的危害因素；⑤判断是否构成安全隐患；⑥卫生行政部门认为需要的其他情形。
    \item \textbf{毒理学评价10项试验：}急性经口毒性、遗传毒性、28天经口毒性、90天经口毒性、致畸、生殖毒性、毒物动力学、慢性毒性、致癌、慢性毒性和致癌合并试验。选择原则：新创物质做系统全面试验；已知物质可先做急性+遗传+90天+致畸再判断；有食用历史物质可先做急性+遗传+28天再判断。
    \item \textbf{毒理学评价需考虑因素：}①指标的三重意义（统计/生物/毒理学）；②人的推荐剂量；③时间-剂量-效应关系；④特殊人群和易感人群；⑤人群资料；⑥不确定系数（通常100）；⑦毒物动力学资料；⑧综合评价。
\end{enumerate}

\subsubsection*{论述题（要点）}

\begin{enumerate}[leftmargin=*, itemsep=6pt]
    \item \textbf{HACCP的7个基本原理：}
    ①进行危害分析（HA）——收集信息，评估危害和导致其存在的条件，确定对食品安全有意义的危害，分为危害识别和危害评估两个阶段。
    ②确定关键控制点（CCP）——能够有效控制的点，控制指防止、消除危害或将其降低到可接受水平。
    ③建立关键限值（CL）——在CCP上设定的最大值和/或最小值。
    ④对CCP进行监控（M）——按计划观察和测量，判断CCP是否处于受控之中。
    ⑤建立纠偏措施（CA）——发现偏离CL时立即采取的措施。
    ⑥建立验证程序（V）——确认HACCP体系是否有效运行。
    ⑦建立有效记录的档案系统（R）——所有HACCP活动必须有完整准确的记录。

    \item \textbf{限量标准制订的一般原则和步骤：}
    一般原则：①无需对所有污染物设立限量值；②限量值对消费者总暴露量有显著意义；③限量值对消费者要有充分保护。
    制订步骤：①动物毒性实验确定NOAEL或BMDL；②用安全系数确定ADI或TDI；③确定每日总膳食允许含量；④按食物种类确定每种食物的最大允许量；⑤综合实际制定限量标准。

    \item \textbf{对不同物质选择试验的原则：}
    ①我国创制的新物质（化学结构提示有毒性）——系统的全套试验；
    ②已知物质（有安全食用历史）——先做急性+遗传+90天+致畸，视结果决定是否继续；
    ③已知的有食用历史物质——先做急性+遗传+28天，视结果决定是否继续；
    ④食品添加剂等——按GB 15193.1-2014要求选择适当试验。
\end{enumerate}
