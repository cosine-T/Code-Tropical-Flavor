# Step2: 章节内容核查与修订 Skill

## 概述

在 Step1 生成初版笔记后，逐章对内容进行核查。核验来源包括教学大纲、教师授课 PPT/PDF、往届笔记，确保知识点无遗漏、无冗余、重难点标注准确。**所有修改均需用户确认后再执行。**

---

## 一、工作流程

```
大纲重点 ←→ 当前章节内容 → 发现差异（缺/多/错）
                              ↓
                         用户确认是否修改
                              ↓
                      PPT/PDF 补充核查 → 再次确认
                              ↓
                         执行修改 + 编译验证
```

---

## 二、逐章核查清单

对每一章执行以下四步：

### 步骤 A：大纲重点对照

1. **读取大纲原文**，提取该章的掌握/熟悉/了解内容标记
2. **读取当前 .tex 章节文件**，提取：
   - `\chapterintro{...}` 内的学习目标描述
   - 所有 `\keybox{...}` 中的重点内容
   - 所有 `\keyword{...}` 标记的关键术语
   - 所有 `\imp{...}` 标记的重要知识点
3. **对比差异**，列出：
   - 大纲要求掌握但笔记中**缺失**或**未用 keybox 标注**的内容
   - 大纲要求熟悉但笔记中**过于简略**的内容
   - 笔记中有但大纲**未提及**的内容（可能是 PPT 补充，需标注来源）
   - 大纲标注 `*` 难点但在笔记中**未特别说明**的内容

### 步骤 B：用户确认（大纲部分）

将差异列表呈现给用户，格式如下：

```
### [科目] 第X章 大纲核查结果

**缺失重点（大纲要求但笔记未覆盖）：**
1. xxx — 建议添加 \keybox
2. ...

**标注不足（应升级为 keybox/imp）：**
1. xxx — 当前为普通正文，大纲标注为双下划线
2. ...

**难点未标注：**
1. xxx — 大纲标*，建议在 \chapterintro 和正文中添加"（教学难点*）"

**可能的冗余：**
1. xxx — 大纲未提及，请确认是保留（PPT补充）还是删除

请逐项回复：保留/删除/修改/补充说明
```

### 步骤 C：PPT/PDF 补充核查

1. **提取 PPT 内容**：使用 python-pptx 或 pdfplumber 提取该章对应课件的文本
2. **提取 PDF 内容**：从往届笔记 PDF 中提取对应章节文本
3. **对比当前笔记**，找出：
   - PPT 中有但笔记**遗漏**的知识点细节
   - PPT 中**标红/加粗/特殊强调**但在笔记中未突出显示的内容
   - 往届笔记中的**额外总结/口诀/表格**等有价值的补充
   - 课件中的**图表/流程图**（提示用户是否需要在笔记中补充）
4. **列出发现**，按重要程度排序（核心缺失 > 细节补充 > 美化建议）

### 步骤 D：最终确认与修改

汇总步骤 B 和 C 的发现，生成一份**完整的修改建议单**，包含：
- 每项修改的具体位置（节/段落）
- 修改类型（新增 keybox / 补充正文 / 添加表格 / 调整标注等）
- 修改的草稿文字

用户逐项确认后，使用 Edit 工具执行修改。修改完成后运行 xelatex 验证编译。

## 三、具体核查维度

### 3.1 术语完整性

- 大纲列出的核心概念是否全部以 `\defbox` 形式定义？
- 关键术语是否使用了 `\keyword{}` 标记？
- 英文术语是否标注？

### 3.2 逻辑结构

- 章节内部层次是否清晰：概念 → 分类 → 机制 → 影响因素 → 应用/防控？
- 同级标题（subsection）之间的内容量是否大致均衡？
- 是否有明显的逻辑跳跃或缺失的过渡段落？

### 3.3 表格使用

- 对比性内容（如分类、比较、发展历程）是否使用了 `\begin{table}`？
- 表格是否清晰可读、是否有 caption？
- PPT 中的重要表格是否已纳入笔记？

### 3.4 复习题质量

- 复习题是否覆盖了该章所有掌握内容？
- 题型是否合理（名词解释覆盖术语，简答覆盖重点机制/策略）？
- 参考答案是否准确、完整？

### 3.5 标注准确性

- `\keybox` 是否与大纲双下划线内容严格对应？
- `\imp{}` 使用是否克制（不是所有重点都标，只标最核心的）？
- 章节导览中的掌握/熟悉/了解描述是否与大纲一致？

## 四、核查时的具体操作

### 读取大纲中该章内容

```python
# 从大纲 .doc 或 .txt 中提取特定章节
import re

with open("大纲.txt", "r", encoding="utf-8") as f:
    text = f.read()

# 匹配章节标题及其后续内容（直到下一章或文件结束）
pattern = r"(第[四五六七八九十\d]+章[^\n]*\n)((?:(?!第[四五六七八九十\d]+章).*\n)*)"
chapters = re.findall(pattern, text, re.MULTILINE)

for title, content in chapters:
    print(f"=== {title.strip()} ===")
    # 提取双下划线内容
    double_underline = re.findall(r"双下划线[：:]\s*(.+?)(?=\n|$)", content)
    # 提取单下划线内容
    single_underline = re.findall(r"单下划线[：:]\s*(.+?)(?=\n|$)", content)
    # 提取*难点
    difficulties = [line for line in content.split("\n") if line.rstrip().endswith("*")]
```

### 对比 PPT 内容

```python
from pptx import Presentation
from pptx.util import Inches

prs = Presentation("课件.pptx")
chapter_keywords = []  # 该章关键词列表

for slide in prs.slides:
    for shape in slide.shapes:
        if shape.has_text_frame:
            for para in shape.text_frame.paragraphs:
                text = para.text.strip()
                # 检查是否为红色/加粗文本（教师强调内容）
                for run in para.runs:
                    if run.font.bold or (run.font.color and run.font.color.rgb):
                        chapter_keywords.append(run.text)
```

### 交叉比对逻辑

```
大纲掌握内容 ∩ 笔记 keybox/keyword = 已覆盖 ✓
大纲掌握内容 - 笔记 keybox/keyword = ⚠️ 缺失
PPT标红内容 - 笔记正文 = ⚠️ 遗漏教师强调内容
笔记正文 - (大纲 + PPT) = 需确认来源（往届笔记？自行总结？）
```

## 五、修改操作指南

### 添加缺失的重点内容

```latex
% 在合适的小节中添加
\begin{keybox}
\textbf{XXX概念/机制：}
具体内容描述...
\end{keybox}
```

### 升级现有内容为重点

将普通段落改写为 `\keybox` 包装，或添加 `\keyword{}`、`\imp{}` 标记。

### 补充术语定义

```latex
\begin{defbox}
\textbf{术语名（English）}定义内容...
\end{defbox}
```

### 调整章节导览

修改 `\chapterintro{...}` 中的掌握/熟悉/了解描述，确保与大纲一致。

### 补充/修改复习题

在 `\section{复习题}` 部分添加或修改题目，确保覆盖所有重点内容。

---

## 六、注意事项

1. **绝不自动修改**：所有修改建议必须先呈现给用户，得到明确确认后才能执行
2. **标注修改来源**：如果是根据 PPT 补充的内容，可在注释中标注 `% 来源：授课PPT`
3. **保持风格一致**：新增内容的语言风格、框的使用方式需与现有笔记一致
4. **编译验证**：每次修改后运行 xelatex 验证，确保无编译错误
5. **不要过度标注**：`\imp{}` 和 `\keybox` 适量使用，每页不超过 2-3 个 `\keybox` 为佳
6. **尊重用户判断**：用户是最终决定者，如果用户认为某项不需要修改，尊重其决定
7. **往届笔记仅供参考**：往届笔记可能有错误或过时，以大纲和 PPT 为准
